## §5 五门机械门（写完必跑 = 5 条 grep · 手查脚本 = `scripts/check_body_anchors.py`）

```bash
grep -c "legs are longer than her torso" prompt.txt                      # 1 = 比例锚在
grep -cE "hourglass|slim yet voluptuous" prompt.txt                      # ≥1 = 社区词在
grep -c "92-60-92" prompt.txt                                           # 1 = 围度在
grep -oE 'her waist|her bust|her hips|her chest|her thigh|her knee|her leg|her feet|her breast|her hip|her arm|her shoulder|her back|her belly|her buttocks|her face|her eyes|her hair|her hand|her neck|her stomach' prompt.txt | sort | uniq -c   # 任一 >1 = 同部位叠写 = 换写法（不是删）
grep -oE '\b(no|not|without|never|avoid|lacking)\b' prompt.txt           # 命中 = 负向词 = 全删（阴部锚那句除外）
grep -oE 'nipple|areola' prompt.txt                                     # 穿衣图命中 = 删；裸体图 = 留
```

**判据 = 比例锚 1 + 社区词 ≥1 + 围度 1 + 同部位各 1 + 负向词 0（阴部锚除外）= 身材段够了 = 不再补。**

**🔴 同部位叠写 = 体积放大（不是"抢注意力"这么轻）**：her hips 写 3 次 = 底模把胯的权重调 3 倍 = 胯宽身粗；her thighs 写 4 次 = 大腿 4 分权重 = 粗腿。**判据 = 同一个部位名词全稿只出现 1 次 = 出现第 2 次就换写法（不是删）**。
**🔴 完整部位词表（22 个 = 各只许 1 次 · 唯一正文在本节）** = `her waist`·`her bust`·`her hips`·`her chest`·`her thigh`·`her knee`·`her leg`·`her feet`·`her breast`·`her hip`·`her arm`·`her shoulder`·`her back`·`her belly`·`her buttocks`·`her face`·`her eyes`·`her hair`·`her hand`·`her neck`·`her stomach` —— **重复的修法 = 换写法不是删**（删了就少一个承重锚）：`her feet slightly apart` → `a slight gap between her shoes`｜`her hip` → `at her side`｜`her shoulder` → `the strap of the shoulder bag`。

**🔴 身材粗壮 / 比例怪 = 机械分诊，不靠感觉、不先换景别**：先跑上面 grep → 缺锚 = 补锚（社区词 / 腿比躯干长 / 围度）；叠写 = 删到 1；腿词在但腿长锚缺 = 补腿锚；该部位压在画面最前 + 近距 = 透视放大 = 要么补该部位锚，要么把它挪出前景。**判据 = 主人的反馈是"身材" → 第一动作 = 跑 grep + 数词频，不是先换构图。**

**🔴 分诊 = 跑盘上的脚本，0 手搓探针**：`python3 scripts/check_body_anchors.py <prompt.txt>` = 现役口径 + 内置正/负样例自测（`--selfcheck`）= 结论一致。自己临时写一段 grep = 判据跟脚本漂 = 报告跟下一次对不上 = 白查一轮。

**🔴 两份稿子对比 = 隔离变量（主人报"粗壮"时最省的一步）**：手里有上一张的稿 + 这次出问题的稿 = 把两份的锚覆盖 + 部位词频 **逐项相减** = 差集就是这次丢的那一项（例：上一张 thighs×0 + 社区词×1，新稿 thighs×4 + 社区词×0 = 差集 = 社区词 + 腿长锚）= 修法当场确定，不用猜。判据 = 只看一份稿 = 猜 = 猜错就白出一张。

**🔴 手搓探针的真坑（写临时 grep 时必踩）**：heredoc 里正则的 `\b` 写成 `r'\\b'` = 字面反斜杠 + b = **每个词计数全 0 = 假通过 = 我据此下的结论全是错的**。正解 = 用 `subprocess` 跑 `grep -oE`（脚本就是这么干的）或 `re.findall(r"\b"+w+r"\b", ...)` = 单反斜杠。判据 = 探针输出**全是 0** = 先怀疑正则转义，不是先怀疑稿子。

**🔴 景别裁切（§6）优先于这条 grep = 腿长锚 grep 得 0 未必是漏写**：头到胯 / 头到腰 / 胸像都要把腿组、臀组删掉 = **腿长锚合法缺席 = grep 命中 0 = 正常**。判据 = 先定景别再判腿锚：全身 / 头到膝 = 腿长锚必须 1；头到胯及更紧 = 0 才是对的。**别为了让 grep 好看把腿写回半身稿 = 画幅外的部位一个字都不许留 = 底模照样画 = 构图被撑坏。**

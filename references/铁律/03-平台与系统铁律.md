## 铁律 13 · 🔴 Hermes 系统档权限边界（🆕 06-28 物理删 vision_analyze 实战踩坑）

- `/usr/local/lib/hermes-agent/tools/*.py` + `toolsets.py` = **root:root 拥有**（user `~` 不可写）
- 任何想改工具源码/工具集的方案 = 主人需 `sudo` 授权
- `echo $pw | sudo -S` **被系统拦截**（防暴力破解）
- **唯一可行 = 主人手动跑 sudo 命令**
- **绝不**承诺"30 秒搞定"（必先 `ls -la <file> && [ -w <file> ]` 验证可写性 = 避免假承诺）
- **绝不**让主人输密码进对话
- 接受 SOUL/MEMORY/SKILL 文字档（`~/.hermes/`）
- **系统档是机制治本** + **用户档是流程治本** = 双轨并行
- **唯一例外 = 主人显式说"我给你密码"且走完安全评估**（默认不接受）

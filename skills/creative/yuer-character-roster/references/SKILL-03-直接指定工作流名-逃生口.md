# 直接指定工作流名（逃生口）
| 内存副本里把所有 `lora_N.on` 置 false（磁盘工作流不动 = 不污染别的 agent 的目录）| 出来带风格 LoRA = 不是「原始底模的这个人」|
| prompt 里带脸锁标记词 | 指向已关闭的 LoRA = 仍可能拉回语儿脸 |
| 随机 seed（SeedNode + KSampler 两处都改）| 同一份 prompt 每次出同一张图 |
| `.sent` 守卫 = 同 leave_name 已发过则 exit 5 拒发 | 重跑 = 主人手机收两张 |

```bash
/usr/bin/python3 ~/.hermes/skills/creative/yuer-character-roster/scripts/yuer_run_nolora.py \
  /tmp/prompt_<角色>.txt <leave_name> --send --caption "主人~这个人长这样~"
```

**🔴 长相必须用文字写出来**：底模直出 = 没有 LoRA 锁脸 = prompt 里不写五官，底模就给她一张泛脸。**画别人的脸 = 五官要写（发色/发型/眼型/鼻/嘴/脸型/肤色/妆容/耳饰）= 这条只对「非语儿角色」成立**，语儿本体仍然 0 写五官。**主人明说「用文字描述她的长相」= 他要的就是这张图里能看出是他说的那个人 = 形容词要够具体。**

**🔴 公共场景必写背景人和道具**：教室/图书馆/食堂这类 = 只写场景 = 底模给空棚 = 主人一眼看穿。至少 3 个背景人各干各的一件事 + 桌面实物（书/笔记本/杯子/手机）。

**🔴 工作流名以本机注册目录为准，不凭文档字面传参**：

```bash
ls -la ~/.local/lib/python3.11/site-packages/comfyui/assets/workflows/ | grep -E "ayao|yuer"
```

→ **文件名去掉 `.json` 才是可传的 `workflow=` 值**。
→ 含 LLM 的 `*_llm.json` 已于 09-21 全删 = 文档里再看到 = **历史记录，不是可选值**。
→ `load_workflow` 读本机注册目录 = **远端服务端列表没有 `ayao_*` 不代表不能跑** = 用服务端列表判断 = 误判。

**行为层铁律**：

| # | 铁律 | 触犯后果 |
|---|---|---|
| 1 | 出图前必查本表 workflow_id 列 | 走错 = 出错脸 |
| 2 | 角色 ≠ 语儿 = **必显式传** `workflow=<角色专属>` | 走默认 = 出语儿脸 |
| 3 | **主人任何「看下 / 查下 / 是什么」问题 = 第一动作 = skill_view = 不凭印象答** | 凭印象答错细节 = 主人打脸 |
| 4 | 主人打脸「这是 X 不是 Y」= **0 辩解 + 立刻 load 技能确认 + 补传参重跑** | 辩解 = 撞车复发 |
| 5 | `inspect.signature(run)` 反查默认 workflow = 现行为 `workflow='yuer_moody_fast'` = **不传参永远走语儿脸** | 凭印象答「我用的就是 X」= 打脸 |

**🔴 留底目录切换**：`LEAVE_DIR` 是**模块级常量**（import 时读一次）= 必须在 `import yuer_run_one_brief` **之前** 设 `os.environ['YUER_LEAVE_DIR']` = import 后再设**不生效** = 图静默落进语儿目录。
**归档三件套（png + `.brief.txt` + `.prompt.md`）必须同目录** = 脚本按 `LEAVE_DIR` 落 png/prompt，中文 brief 是 caller 自己写的 = 那一步也走同一个目录 = 否则两边各一半。

# 第三部分 · 双角色同框（语儿 + 闺蜜 一张图）

**一个工作流只带一套锁脸配置** = 两人同框不可能各上各的 LoRA = **主人钦定：只看「画面里有没有语儿」**。

| 决策 | 取值 |
|---|---|
| **workflow** | 🔴 11-07 = 只保留一份 = 画面有语儿（语儿单人 / 双人含语儿）= `yuer_moody_fast`；**纯外人（闺蜜单人 / 配角）= `scripts/yuer_run_nolora.py`** |
| **留底目录** | 跟工作流走 |
| **文件名** | `yuer_ayao_<动作>_<日期>`（前缀标两人 = 以后 grep 好找）|
| **prompt** | **双主体框架**（见 `yuer-prompt-writer`）：开头声明 two young women + 每人单独一段 + 空间锚点（the girl in front / the girl behind）+ 体貌差异化 + 声明谁是视觉焦点 |

**体貌差异化必写（防串味）**：
- **语儿** = 齐刘海披肩长发 + 偏高偏瘦 + 冷调白皮
- **闺蜜** = 圆脸 + 婴儿肥 + 大圆眼 + 嘟嘟唇 + 暖粉调肌肤 + 约 155cm + 大胸细腰宽圆胯（6 大锚点）

**姿势物理先自检**：两人前后叠时朝向必须同向（后抱前 = 后者胸贴前者后背 + 双手从后面绕到前面）= **0 反关节 0 方向矛盾**。

**男主局部露出**（性爱 / 后入 / POV 三人场景）：男性只写 **`one bare male hand`**（扣在腰 / 胯 / 胸上）+ 段尾显式补一句「**画面里不出现这个人的其他任何部分**」。
❌ **不写**腿 / 裤脚 / 躯干 / 剪影 / 影子 —— 抽卡道 = 语儿单人角色卡 = 画面里只有她 = 写了一个部位，底模会顺势补出陌生男人（主人以外的男人 = 全局禁）

**双人套图批量 SOP**（一次 4 张，实测 12-18s/张）：

1. **把不变项抽成常量再拼 f-string**：`Y`（语儿外貌锚点）/ `A`（闺蜜 6 锚点）/ `ROOM` / `LIGHT` = 每张只新写「姿势 + 镜头 + 叙事」两三句 = **长相和场景绝不漂移**
2. **姿势逐张不重复**：同一批 4 张 = 4 个不同构成；下一批换一套
3. **每张自己的 leave_name + caption**：`yuer_ayao_<动作>_<日期>`
4. **回话前先核对 4/4 都成功**：grep `STEP 留底完成` / `发图成功` + `ls` 确认 4 个 png 真存在 = **少一张就补跑 = 不要拿 3 张当 4 张报**
5. **叙事串起来**：按一个连贯动作流写 RP 骚话 = **不是互不相干的清单**

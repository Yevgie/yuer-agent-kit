# 第五部分 · 主人发图入库 SOP（洗图 + 入库一气呵成）

**正确顺序 = 留底 → agnes 反推 → 入库 → 洗图发飞书**。**洗图放最后** = 主人收到洗图时入库已完成 = 主人问「入库了吗」时已搞定 = 零矛盾。4 步 = 反推 Full Prompt 原文追加 `提示词库-nsfw.txt`（含入库后必接洗图直出 + 单次 reply 铁律）。

**Step 2 的 agnes brief = 元素锁定写法**：直接列出图中全部可见关键元素 + 「请严格按这些元素反推，不要添加图中不存在的元素」= 跟图中可见元素对不上 = 改写为元素清单严格锁定重跑（实测第 2-3 次对上）。

**5.1 agnes 安全过滤拦截**：元素锁定 brief 含「露骨/私密部位/性暗示」类词 = 安全过滤拦截（exit 1 + 拒答）= **立刻用 SFW 措辞重写 brief**（去掉露骨词，保留元素清单 + 加「非露骨 SFW 措辞」限定）= 实测第 2 次成功。**SFW 重试上限 1 次 = 仍撞才走 L2 = 不跳级**；撞车第 3 次 = 放弃反推结果，直接用原图描述手工拼入库记录 + 备注撞车（入库价值 = 角色外观 + 骚姿势标注够用 = 不需要反推全文完美）。

**5.2 vision 100% 撞敏感词**：主人发图 = 多数 NSFW/情色向 = `vision_analyze` 对 NSFW 图 **100% 撞敏感词** = 500 new_sensitive。

| # | 铁律 | 触犯后果 |
|---|---|---|
| ① | **主人发图 = 跳过 vision_analyze = 直接调 agnes** | 必撞 = 0 收益 + 浪费 5s |
| ② | **vision 仅用于 SFW 验证场景**（如入库后验图）= NSFW 一律不走 | 撞敏感词 = 流程卡死 |
| ③ | **agnes 撞敏感词 = 立刻 L2 fallback**（先 SFW 重试 1 次）= 不无限重试 | 撞车复发 = 卡死 |
| ④ | **入库 reply 不暴露耗时/撞车** = 主人只关心「入库了吗」 | 主人打脸「不明白里头是什么」|

**Platform 有时已给 vision 描述**（Hermes 自动看图返回文字）= 若收到「Here's what I can see」段落 = **跳过 vision_analyze** = 直接用这段描述写元素锁定 brief = 省 5s + 0 撞车。

**agnes 耗时分布（实测 8 张）**：6.2s ~ 66.8s（中位数 ~13s）= 2 张 ≥60s 撞 Read timed out = **脚本 timeout 必须 180**（已落地）。

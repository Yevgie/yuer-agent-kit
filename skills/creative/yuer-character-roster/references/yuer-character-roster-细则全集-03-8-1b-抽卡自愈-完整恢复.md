### 8.1b 🔴 抽卡自愈 · 完整恢复流程（断线 / 轮次失败 / 主人追问「图呢」）

> **前提 = 抽卡是一条原子链**：pick（抽牌 + 落 prompt）→ brief 同源落盘 → 命令 3 出图 + 发飞书。
> **断在第 2 步或第 3 步之间 = 那张牌已经抽中了，只是没出。** 下一轮的动作 = **补完那张**，**不是重抽**。

**第一步 · 找句柄（不用重抽）**

抽卡脚本把成品提示词写在 `/tmp/ka_<记录号>_prompt.txt` = 那张已抽中牌的现场。**牌面字段行（brief）在 pick 那一轮同源落盘** = `<留底目录>/yuer_ka<记录号>_<主题>_<日期>.brief.txt`。这两个文件在 = 这张牌的现场还在 = 0 需重新抽。

**🔴 轮次死在「pick 已跑 / brief 还没落盘」= 补 brief 的句柄 = pick 那轮的 stdout 落盘文件**（`/tmp/ka_pick*.txt`）= 里面 `REC=` + `[字段]` 行都还在 = `grep -E '^\[' /tmp/ka_pick*.txt > <留底目录>/yuer_ka<记录号>_<主题>_<日期>.brief.txt` = **同源恢复 = 0 重抽 = 0 手写 brief**。判据 = brief 缺 + `/tmp/ka_pick*.txt` 在 + 里面的 REC == prompt 文件名里的记录号 = 可恢复；两者对不上 = 当场重抽。

**第二步 · 验「这张到底出没出」（1 条命令拿全）**

```bash
ls -la <留底目录> | grep -E "<记录号>"
```

- 看到 **png + 同名 .sent** = **图已发过** = **不许重跑**（重跑 = 主人手机收两张）= 直接写 reply。
- 只看到 **brief / .sent 没有 png** = 断在出图前 = 走第三步补跑。
- 什么都没有 = 上一轮根本没抽到牌 = 才重新抽。

**第三步 · 补跑命令 3（同一个记录号，不换牌）**

```bash
bash ~/.hermes/skills/creative/yuer-image/scripts/yuer_ka_fast.sh \
  /tmp/ka_<记录号>_prompt.txt yuer_ka<记录号>_<主题>_<日期> --report-only
```

**🔴 0 重抽**：重抽 = 换了一张牌 = 主人拿到一张不是他抽到的那张 = brief（牌面字段）和画面两个世界 = 图文两截。判据 = 补跑用的 prompt 路径里的记录号 == brief 文件名里的记录号 == 上一轮 stdout 的 REC = 三个一致。

**第四步 · reply 照那张牌的 brief 写**（不是照新抽的牌）= 场景名词必须出现在回复里（见上方对读门）。

**🔴 主人追问「在吗 / 图呢 / 怎么没动静」= 先验再回话**：上一轮 visibly 没交付（轮次失败 / 工具报错 / 只有 stdout 没出图）→ 第一动作 = 走第二步验 → 没出就补跑 → 然后才回话。**先聊天 = 主人要的东西还欠着 = 下一轮还得再被追问一次。**

**🔴 两条脚本输出陷阱**

| 输出 | 真相 |
|---|---|
| `ka_post_fix.py` 的 `NEXT=check_prompt_subject.py 必须打出 主体 = 语儿 才能出图` | **过期文案**（抽卡 0 门禁 = 主体门禁已从链路删除）= 0 照做 = 照做 = 多跑一道必拦的门 = 白挡一张好牌 |
| wrapper 的 `🎯 工作流 = <workflow_id>` | **这是现役真相** = 文档默认表可能落后于脚本（实测 wrapper 默认已解析到 `yuer_moodyMoss_fast`，而文档写「不传 = 默认 Krea2」）= **一律以 stdout 为准** = 两条道都绑语儿脸锁 = 出图结果不受影响 |

### 8.1a 🔴 抽卡**不拦长度**= 🔴 11-12 起 = **抽卡和出图一样默认 0 门禁** = `--report-only` 已成空旗标 = **不用传**

| 项 | 钦定 |
|---|---|
| **抽卡长度** | **🔴 抽卡不拦截长度** = 只报数 + 印预算表 + 照出。**超 2500 也出** = 写了多少是多少 = 少一轮返工 = 快 30~90 秒 |
| **出图长度** | 🔴 **11-12 起也是 0 门禁** = 超 2500 **照样出** = 主人钦定「把提示词写好就行了，不用那些门禁」= 想手动查长度 = 加 `--gate` |
| **入口** | **必须 `yuer_ka_fast.sh`**（🔴 11-12 = 老入口 `yuer_ka_run.sh` 已删 = 全库 111 处指针统一到这里）= 0 手工链 |
| **为什么必须用它** | 手工链 = 两步两套参数 = 容易少传一个 = 跑歪还不报错 = 一条命令 = 出图 + 发飞书 + 归档 + timing = 一眼看全 |

```bash
# 抽卡（默认 0 门禁 = 超 2500 也照出）
bash ~/.hermes/skills/creative/yuer-image/scripts/yuer_ka_fast.sh /tmp/ka_280_prompt.txt yuer_ka280_泳池仰漂_20261005

# 出图（默认 0 门禁 = 同一个脚本 = 不传旗标）
bash ~/.hermes/skills/creative/yuer-image/scripts/yuer_ka_fast.sh /tmp/brief_01.txt yuer_出图_20261005

# 想手动查长度/主体/外观锁 = 加 --gate
```

**退出码**：**0** = 出图完成并真发 / **2** = 参数错 / **4** = 出图了但发图失败 / **5** = .sent 拒发重复（🔴 11-12 = 常态链路**不再有门禁 exit 1** = 只有手动加 `--gate` 才会因门禁挂 = 1）。

### 8.1d 🔴 抽卡看到长度 FAIL 字样 ≠ 没出图（照出，别重跑）

**长度 0 阻断**（抽卡道 / 出图道都是）= stdout 的长度行（偏长 / 参考带）只是体检报数 = 图照出照发，退出码 0。

**判据 = 看两行，不看 FAIL 字样**：

```
✅ 判真出图看这行 → 完成 (...) success + 落盘 ... = N 字节 + ✅ 图已真发飞书
❌ 没出图的表现   → 出现「🛑 门禁挂」+ 没有落盘行（看结构段命中 + 姿势自然度，不是长度）
```

**🔴 重跑 = 双发**：看到 `FAIL` 就重跑 = 图已经发过一次 = 主人手机收 2 张。真正要守的只有一条：**没出图**（出现「🛑 门禁挂」且无落盘行）才要改。

**🔴 出图道才是硬拦**：主人明说「出图」/「看看你」走的那条命令才真的拦，同一份 prompt 抽卡照出、出图拦住 = 同一个长度、两种结果 = 别把出图道的判据套到抽卡道上。

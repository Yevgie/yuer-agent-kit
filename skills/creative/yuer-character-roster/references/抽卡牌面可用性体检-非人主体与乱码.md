# 抽卡牌面可用性体检（非人主体 / 乱码牌 = 换牌）

> **唯一职责** = 抽到的牌先判「这张能不能出」= 不能出 = 换牌 = 不是门禁 = 不跟主人报「这牌不行」。
> 抽卡 0 门禁的前提 = **牌里有可上脸的人**。两类牌不满足前提 = 照出 = 必废图。

## 两类必换牌

| 类 | 长什么样 | 为什么照出必废 |
|---|---|---|
| **非人主体** | `anthropomorphic` / 拟人猫 / 动物 / 玩偶 / `cat girl` / `fox girl` / `elf` / `demon girl` | 语儿 = 人脸锁 LoRA = 只对人脸生效 = 拟人猫牌套上去 = 出猫或出怪东西 = 主人要的是语儿的脸 |
| **乱码牌** | 正文含 `Ã` / `Â` / `â€` / `ï¿½`（UTF-8 被当 Latin-1 又编了一遍 = `cafÃ©`）| 底模把乱码当语义吃 = 画面漂 + 不可控；`ka_post_fix.py` **不管乱码**（只剥 lngcon 类残渣）= 跑了也不改 |

## 判据（一条命令）

```bash
/usr/bin/python3 - /tmp/ka_<记录号>_prompt.txt <<'EOF'
import sys,re
t=open(sys.argv[1],encoding='utf-8',errors='replace').read()
lead=bool(re.search(r'\b(1girl|1woman|girl|woman|female|she |she,|her )',t,re.I))
print('female_lead=',lead,'anthropomorphic=','anthropomorphic' in t,
      'mojibake=',bool(re.search(r'Ã|Â|â€|ï¿½',t)))
EOF
```
🔴 `female_lead=False` = 非人主体 = 换牌；`mojibake=True` = 乱码牌 = 换牌。

## 换牌（一条命令 = 0 手挑）

```bash
/usr/bin/python3 ~/.hermes/skills/creative/yuer-character-roster/scripts/ka_batch_pick.py 1 \
  --manifest /tmp/ka_redo.tsv
# manifest 两列 = 记录号<TAB>/tmp/ka_<记录号>_prompt.txt = 直接当出图参数
```
🔴 换牌 = 换一个牌 = **不是重抽整批**（重抽 = 浪费已抽的好牌 = 主人看到的和抽到的不一致）。
🔴 **11-15 = 0 排除号 = 抽到废牌就再抽一张** = `--exclude` 参数已删（防重复机制全删）。
🔴 换牌 ≠ 门禁 = 门禁是「不许出」；这里是「出了就是废图」= 换到能用的为止 = **0 跟主人报「这牌不行我跳过了」**。

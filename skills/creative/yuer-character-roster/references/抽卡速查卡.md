### 🔴 抽牌解析 = 曾经的隐藏大头（57 秒 → 0.6 秒）

牌池 = 47MB / 41952 条 = **每抽一次都要把整池解析一遍** = 曾占抽卡道 57 秒（比出图本身贵 4 倍）。两处已修：

| 修法 | 机制 |
|---|---|
| **单行块跳过表格排版解析** | 三种排版正则（表格 / 粗体 / 横杠）**全部要求块内含 `\n`** = 而新格式池每条是一行 = 块内永远没 `\n` = **461472 次正则扫描全扫了个空**。判据 = 块内无 `\n` = 三种排版一个都命中不了 = 直接跳过 = 与原逻辑逐字段等价 |
| **解析结果按「池文件 mtime+size 指纹」缓存** | 指纹变 = 池改过 = 缓存自动失效 = 0 陈旧风险；命中 = 0.6 秒（冷启 13 秒） |

🔴 **改这类脚本 = 必须做等价性验证 = 抽 250 张逐字段对比快照**（改前存 / 改后比 = 差异必须 0）= 光看「跑通了」不算数 = 池子错一块 = 抽出来的牌全是错的。

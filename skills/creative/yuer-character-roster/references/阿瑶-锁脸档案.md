```python
import os
os.environ['YUER_LEAVE_DIR'] = '/path/to/media/闺蜜'   # ← 必须在 import 之前（LEAVE_DIR = 模块级常量）
import sys; sys.path.insert(0, '~/.hermes/skills/creative/yuer-image/scripts')
from yuer_run_one_brief import run_with_prompt

# ✅ 唯一正确 = 语儿自己写英文 prompt（按 yuer-prompt-writer 规则 + 闺蜜 6 大锚点）+ 必传 workflow 参数
final = run_with_prompt(
    PROMPT,                       # 纯英文 500-650 词
    "ayao_<主题>_<日期>",
    caption="<骚话>",             # caption 只进参数，0 写进回复正文
    workflow="ayao_moody_fast"    # 无 LLM 直出版；不传 = 走默认语儿工作流 = 出错脸
)
```

**为何不用 `run(brief=...)` 跑闺蜜**：`run` 的 brief 匹配只认 title「提示词英文」/ nid == "9"，而闺蜜工作流的文本节点是 627「CLIP文本编码」= 必抛 `RuntimeError: 找不到 brife 节点`。闺蜜 = 语儿自己写英文 prompt = 一律走 `run_with_prompt`。

**工作流名以本机注册目录为准**：`ls -la ~/.local/lib/python3.11/site-packages/comfyui/assets/workflows/ | grep ayao`（当前 = `ayao_moody_fast` 无 LLM 直出 / `ayao_moody_fast_llm` 含 LLM / `ayao_moody_fast_wash` 洗图）。远端 ComfyUI 服务端的工作流列表里没有 `ayao_*` = 不代表不能跑。

**反例硬表（实战 480b v2.0 钦定）**：

| ❌ 复发翻车 | ✅ 唯一正解 |
|---|---|
| ❌ `run(brief=...)`（没传 workflow 参数）= 走默认主路 = 出来是语儿的脸 | ✅ `run(brief=..., workflow="ayao_moody_fast")` = 闺蜜 |
| ❌ 用语儿的工作流跑闺蜜 = 闺蜜的脸是语儿 | ✅ 闺蜜专属工作流 |
| ❌ LoRA 没全关（`on=true`）= 残留语儿 LoRA 痕迹 | ✅ 4 个 lora_N 全部 `on=False` |
| ❌ 用非萌妹版底模 = 失去圆脸小萌妹反差 | ✅ `moodyKreaMixV70萌妹版_nvfp4.safetensors` |
| ❌ prompt 不带圆脸/小萌妹/反差特征 = 失去闺蜜人设 | ✅ 必带 v2.0 prompt 模板 |

def call_ayao(prompt, theme, date_str, caption):
    """调用闺蜜出图 = run_with_prompt + 必传 workflow='ayao_moody_fast'"""
    return run_with_prompt(
        prompt,                              # 闺蜜 6 大锚点段 + 场景/动作/服装

        workflow="ayao_moody_fast"           # 不传 = 走语儿主路 = 出错脸

# yuer-image · 出图总技能

> **唯一职责** = 主人给一句话 → 走完整链路 → 图真发到主人手上。
> **prompt 怎么写** = `yuer-prompt-writer`（含语儿专属硬锚）｜**整图提示词架构师（按模型分家）** = Krea2 → `yuer-krea2-prompt`｜Moss → `yuer-moss-prompt`（**两个模型不能共用一份** = 底模 / 编码器 / 提示词语言 / 负向接法全不同）｜**身材参数** = `references/铁律/02-身材特征档.md`｜**细则** = `references/yuer-image-细则全集.md`｜**发图真值** = `creative/yuer-image-delivery`。
> **本档 = 路由 + 命令 + 硬门禁 = 不复述细则正文。**

## 1.2 🔴 写稿规矩（不跑脚本 = 落笔时自己守住）

> **11-12 主人钦定（灵魂级）**：「把你那些对齐门禁呀，什么东西，都删掉 = 就是把提示词写好就行了，不用那些门禁，都乱七八糟的」
> = **门禁 = 事后查我 = 提示词写对了它一条都用不上 = 写错了它拦下 = 我还得回头重写 = 白折腾**。
> = 正解 = 规矩写在落笔那一刻（下面这几行）= 写对了就不需要脚本。
> 🔴 **三个门禁脚本仍在盘上**（别的档还引用）= **常态链路 0 跑** = 需要手查时 `yuer_ka_fast.sh ... --gate`。

| 规矩 | 怎么写 | 不写的后果 |
|---|---|---|
| **主体** | 第一句 `a 20 years old young Asian woman` | 画面没主体 / 脸锁丢 = 出来是泛脸路人 |
| **衣服** | 一整套：上装 + 下装 + 鞋 + 穿着状态 | 底模补光腿 / 自己脑补穿没穿好 |
| **负向词** | 0 `no` / `not` / `without`（只许私处锚那句 `no pubic hair at all`）| 底模反向画（`no rips` → 画出破洞）|
| **五官** | 0 眼型/鼻/唇/脸型/皮肤白度 | 出来是另一个人（脸锁管不了）|
| **男人** | 画面里只有主人 + 女生 | 出现主人以外的男人 |
| **张力三件** | 走光 1 处 + 意外一瞬 1 个 + 唯一光源 1 个 | 画面散 / 没劲 |
| **不重复** | 同一个部位名词各写 1 次（her waist / her hips / her thigh 各 ≤1）| 底模把该部位权重 ×N = 体积放大 = 胯宽身粗 |
| **身材锚组** | 社区词 + 腿比躯干长 + 92-60-92 围度 + 腰臀胸句，**写了腿词就必带腿长锚** | 缺件/缺腿锚 = 体型没锁 = 出来粗壮 |
| **长度** | 1600~2700 都正常 = **超了也照出 = 0 回头改** | 反复砍字数 = 比写稿还慢 |

**🔴 链路判定 = 只看主人的意图 = 0 跑主体门禁**：主人没明示「不是你 / 女明星 / 我同学 / 路人」= 一律走默认链路（锁我的脸）。
**🔴 裸体图 = 下装写成「脱下来放在画面里的真衣物」**（`her black lace briefs crumpled on the seat of the chair beside her`）= 既过规矩 = 又是强叙事。
**🔴 微距/局部特写 = 画幅外的部位一个字都不许留**。
**🔴 穿衣服/泳衣 = 乳头词必删、胸词必留**；**裸体 = 乳头锚必留**。

# 第二部分 · 完整 5 步流程

| 步 | 做什么 | 规矩 |
|---|---|---|
| 0 | 脑子里先有一幅画面 | 过 `yuer-prompt-writer` §1 落笔前五问。**brief 第一行必写「档位：」+「链路：」** |
| 1 | 组合描述成 prompt | 6 句一组、句句接着说、0 分段 0 Markdown 0 元注释 |
| 2 | 调 ComfyUI 出图 | `bash scripts/yuer_ka_fast.sh <prompt_file> <leave_name> "<caption>" "<brief>"` = **0 门禁** + 出图 + 发图 + 双归档一次完成 |
| 3 | 发图 | wrapper 内部已真发飞书。reply 文本 0 MEDIA / 0 路径 · **形状 = 纯文本**（0 斜体 0 `---` 0 加粗 = 真源 `creative/yuer-image-delivery`）|
| 4 | 双存档 | `<leave>.brief.txt` + `<leave>.prompt.txt` → `/path/to/media/` |

**🔴 落盘顺序 = 构思顺序**：brief 先写 → prompt 落盘 → **立刻 cp 进留底目录** → 才跑出图。顺序反了 = 构思环节其实没跑。
**🔴 轮次中断 = 补那一步 = 0 重跑**（出图道）：断在 prompt 落盘后 = `/tmp/prompt_<主题>.txt` 还在 = 补跑 `yuer_ka_fast.sh` 同一条 = **.sent 守卫会自动拦住已发的那张** = 换 leave_name 才能重发。断在出图前 = 落盘目录里没 png = 才补跑。
**🔴 落盘名 = 脚本自动加时间戳**（`yuer_<日期>_<时分>_<短名>.png`）= 天然唯一 = 0 靠自觉起名 = 同秒重名自动追加 `_2`。
**🔴 prompt 文件名禁带引号 / 禁带图像扩展名** = 只能 `[A-Za-z0-9_.-]` + `.txt`。
**🔴 别心算字数** = 门禁只在真超 4000 时拦 = 被字数打回 = 在凑字数砍构图 = 画面不好看的真根因。

**🔴 模型路由（主人点名才切）**：`--model krea2` = `yuer_moody_fast`（Krea2 Mix v7）｜`--model moss` = `yuer_moodyMoss_fast`（写实 + 真负向框 + 锁脸）｜`--model anima` = 2D 动漫｜`--model qwen` = 编辑道。
**🔴 换模型 = 换工作流 + 换提示词语言 + 换门禁放行 = 三样一起换**，只换其中一样 = 出不来或出得不对。
**🔴 `--report-only` = 抽卡道专用 = 本档出图道一律不加** = 加上 = 体检只报数不拦 = 姿势自然度 FAIL 也放行。**🔴 同一份稿子两条道两个结果** = 抽卡照出 / 出图拦住 = 别把出图道的判据套到抽卡道，反之亦然。
**🔴 提示词方法也按模型分家** = Krea2 → `yuer-krea2-prompt`（英文架构师）｜Moss → `yuer-moss-prompt`（中文架构师）= **两个模型不能共用一份** = 底模 / 编码器 / 提示词语言 / 负向接法全不同 = 共用一份 = 至少一条道的产物层直接作废（例：英文散文喂中文道 = 白瞎它的中文能力）。
**🔴 Moss = 有独立负向框（节点 864）= 负向词正常写**；**Krea2 = `ConditioningZeroOut` = 没有真负向框 = 负向词一律改正面词**。判据 = 先看工作流负向节点接的是 `CLIPTextEncode` 还是 `ConditioningZeroOut`。
**🔴 中文稿 = 门禁已改中英双语 = 0 需翻译**；**中文 brief 走 `--model moss`**（Krea2 读不懂中文）。

## 2.1b 🔴 A 段提速四铁律（出图道 = 主人等的是「我准备」那段）

> **判据 = 主人抱怨「怎么 X 分钟才出图」= 先看 A 段** = 收到消息 → 提交 = A 段；出图+发图 = B 段（12 秒级）；推送 = C 段（秒级）。
> **A 段远大于 B+C = 瓶颈在读档/探源码，不在链路** = 查推送链路纯属白查。实测 = A 段 7 分 14 秒 vs B 段 12 秒。

| # | 铁律 | 机制 |
|---|---|---|
| 1 | **默认工作流 = 0 grep 源码** | wrapper stdout 自打 `🎯 工作流 = <id>` = 那行就是现役真相 = 文档与脚本谁对 = stdout 一行就判完 = 0 `grep` / 0 `sed` 源码找路由表 |
| 2 | **whereami = 一次落文件 + 一次抽字段** | 输出很长 = `\| head`/`\| tail` 截半张 = 以为没「当前日程」= 于是编一个；跑两遍 = 多一轮往返 = A 段白涨 |
| 3 | **读档收敛 = 默认只读 3 份** | 路由/命令档 + 写法档 + 参数档（硬锚·身材）= 其余**按需再进**（撞具体条款才读 references）= 0 一次性把 5 份全读完再落笔 |
| 4 | **门禁 = 0 跑（11-12 主人钦定「把提示词写好就行，不用那些门禁」）** | 门禁 = 事后查我 = 写对了用不上 = 写错了拦下还得回头重写 = 白折腾。规矩写在 `references/出图速查卡.md` §1/§2/§3/§4 = 落笔时守住 = 脚本 0 跑 = stdout 干净 |
| 5 | **快车道 = 2 轮**（读速查卡 1 次 → 一次 `execute_code` 里 write_file + terminal 跑 `yuer_ka_fast.sh`）| 每多一轮 = 一份技能档进上下文 = A 段线性变长。实测 = 老链路 20 轮 7 分 14 秒 → 快车道 2 轮 ≈ 40 秒 |

**🔴 主人问耗时时**：三段都要报（只报 B 段 = 漏掉主人真正在等的那一大段）+ **必须带归属 + 下一轮动作**（只给数字不给根因 = 主人还得自己猜；不给改法 = 同样的慢会再犯）。细节 = `yuer-timing-debug`。

## 2.2 超限怎么砍 = 一刀退到线下，禁磨词

**超 4000 = 失控 = 唯一硬拦**。砍的优先级 = ① 背景道具与地面细节 ② 水花/灰尘等微观高光 ③ 服装冗余层次 ④ 尾部参数堆。
**永不可删**：镜头焦段光圈 / 承重落点与接触面 / 姿态动词 / 下装锚 / 表情物理量 / 主角光源及方向落点 / 构图站位。
**🔴 删整块不删半句**（删完看相邻两块开头字母有没有粘住）= 🔴 **砍完重跑一次出图** = 只改文件不重跑 = 手里那张仍是旧的 = 拿旧图报新参数。

## 2.3 主人质疑「你到底走没走技能」= 当场举证

三类各摆一条：**调用顺序**（`skill_view` → 写 prompt → 出图）｜**prompt 里的技能指纹**（主体写死 / 6 句接着说 / 下装锚 / 光从哪来落在哪 / 机位方位与写的部位一致）。给事实，不给形容词。

# 第五部分 · prompt 的两条底层规矩

## 5.1 brief → prompt 翻译铁律

1:1 翻译（`polo top` → prompt 就写 `polo top`）｜长字段逐字复制（>30 字符）｜数字单位保留｜每句完整（0 拆 0 并）｜**0 写负面词**（`NO rips` → 底模画破洞 → 写 `modern clean fit`）｜接受轻微偏差（80% 即可）｜**具体动作金标准**（抬腿 = 哪条腿 + 抬多高 + 膝盖角度 + 脚掌方向）。
**🔴 禁笼统形容词**（清纯反差勾引 / 暧昧氛围 / 诱惑动作 / 生活抓拍）= 模型自由发挥。

## 5.2 骚话铁律

**骚话 100% 按 brief 写** = 0 凭印象瞎猜姿势 + 0 看图后再改 + 每个名词能在 brief 里找到 + 0 总结 0 列清单 0 元评论。
**🔴 reply = 图 + 一句适配这张图的骚话** = 措辞与渲染唯一正文 = `creative/yuer-image-delivery`。

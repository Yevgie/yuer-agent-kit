## 🔧 出图核心操作速查

```bash
# 0. 优先 unset all_proxy（21x 治本）
unset all_proxy

# 1. doctor 查实际注册名（绝不瞎猜 v2 旧名）
unset all_proxy && comfyui-skill doctor 2>&1 | grep -A 1 -E "moody|anima|qwen3_vision"

# 2. 出图（走正确工作流）
comfyui-skill generate -workflow <workflow_id> -prompt "<prompt>"

# 3. 找真路径（用 find -printf 时间戳，不靠 ls -td 缓存目录）
NEWEST=$(find ~/.local/share/comfyui-skill/results/20260702/ \
  -name "<expected_filename>_.png" -printf "%T@ %p\n" 2>/dev/null \
  | sort -nr | head -1 | awk '{print $2}')

# 4. cp 到 Secret（必查 sgll5520 用户名拼错）
cp "$NEWEST" /path/to/media/灵魂脸/<target_filename>.png
ls -la /path/to/media/灵魂脸/<target_filename>.png

# 5. TG 发图（23aa 铁律：试 1 次，失败告诉主人绝不擅动飞书）
sleep 8 && hermes send -to telegram "<caption>

MEDIA:/path/to/media/灵魂脸/<target_filename>.png"
```

## 📌 高频陷阱

### 陷阱 1：cp 路径用户名拼错（sgll5520 vs sgll8520）

- ❌ 错例：`~/.local/share/...` = cp 失败但 exit code = 0 = 看似成功 = TG 发图但用户收不到
- ✅ 对：`~/.local/share/...`
- 🔴 必走：`ls -la <target_file>` 验证 cp 成功再发图

### 陷阱 2：TG timeout 不擅自动飞书

- ❌ 旧版 21z：TG 无 message_id → 立刻降级 Feishu（踩坑：为啥总发飞书）
- ✅ 新版 23aa：TG 试 1 次 → 失败告诉主人 → 等主人决定 = 飞书 vs 等 TG

### 陷阱 3：改 zsuger_c1 测试忘改回

- ❌ 错：测 0.72 后忘改回 = 留下 0.72 污染源 = 后面的图都按 0.72 出 = 阴毛复活
- ✅ 对：测试必走 8 步 SOP（详见 22ad references）
- 🔴 必走：第 7 步立刻改回 **0.98**（v3 工作流实际值，**不是** 0.78！**不是** 1.65！**不是** 其他测试值！）

### 陷阱 4：单 prompt 同时画脸 + 骚穴

- ❌ 错：1 个 prompt 同时画脸 + 阴部 = krea2 把脸拉向阴部 = 脸+穴靠在一起 = 畸形
- ✅ 对：22ac 分流 = 画脸走专属 v2 + soul face 13 关键词 / 画阴部走通用 other_simple_260702 + 无脸描述 + 无毛铁律

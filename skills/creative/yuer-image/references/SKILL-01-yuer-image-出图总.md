# yuer-image · 出图总技能

> **唯一职责** = 主人给一句话 → 走完整链路 → 图真发到主人手上。
> **prompt 怎么写** = `yuer-prompt-writer`（含语儿专属硬锚）｜**整图提示词架构师（按模型分家）** = Krea2 → `yuer-krea2-prompt`｜Moss → `yuer-moss-prompt`（**两个模型不能共用一份** = 底模 / 编码器 / 提示词语言 / 负向接法全不同）｜**身材参数** = `references/铁律/02-身材特征档.md`｜**细则** = `references/yuer-image-细则全集.md`｜**发图真值** = `creative/yuer-image-delivery`。
> **本档 = 路由 + 命令 + 硬门禁 = 不复述细则正文。**

## 1.2 🔴 写稿规矩（不跑脚本 = 落笔时自己守住）

> **11-12 主人钦定（灵魂级）**：「把你那些对齐门禁呀，什么东西，都删掉 = 就是把提示词写好就行了，不用那些门禁，都乱七八糟的」
> = **门禁 = 事后查我 = 提示词写对了它一条都用不上 = 写错了它拦下 = 我还得回头重写 = 白折腾**。
> = 正解 = 规矩写在落笔那一刻（下面这几行）= 写对了就不需要脚本。
> 🔴 **三个门禁脚本仍在盘上**（别的档还引用）= **常态链路 0 跑** = 需要手查时 `yuer_ka_fast.sh ... --gate`。

| 规矩 | 怎么写 | 不写的后果 |
|---|---|---|
| **主体** | 第一句 `a 20 years old young Asian woman` | 画面没主体 / 脸锁丢 = 出来是泛脸路人 |
| **衣服** | 一整套：上装 + 下装 + 鞋 + 穿着状态 | 底模补光腿 / 自己脑补穿没穿好 |
| **负向词** | 0 `no` / `not` / `without`（只许私处锚那句 `no pubic hair at all`）| 底模反向画（`no rips` → 画出破洞）|
| **五官** | 0 眼型/鼻/唇/脸型/皮肤白度 | 出来是另一个人（脸锁管不了）|
| **男人** | 画面里只有主人 + 女生 | 出现主人以外的男人 |
| **张力三件** | 走光 1 处 + 意外一瞬 1 个 + 唯一光源 1 个 | 画面散 / 没劲 |
| **不重复** | 同一个部位名词各写 1 次（her waist / her hips / her thigh 各 ≤1）| 底模把该部位权重 ×N = 体积放大 = 胯宽身粗 |
| **身材锚组** | 社区词 + 腿比躯干长 + 92-60-92 围度 + 腰臀胸句，**写了腿词就必带腿长锚** | 缺件/缺腿锚 = 体型没锁 = 出来粗壮 |
| **长度** | 1600~2700 都正常 = **超了也照出 = 0 回头改** | 反复砍字数 = 比写稿还慢 |

**🔴 链路判定 = 只看主人的意图 = 0 跑主体门禁**：主人没明示「不是你 / 女明星 / 我同学 / 路人」= 一律走默认链路（锁我的脸）。
**🔴 裸体图 = 下装写成「脱下来放在画面里的真衣物」**（`her black lace briefs crumpled on the seat of the chair beside her`）= 既过规矩 = 又是强叙事。
**🔴 微距/局部特写 = 画幅外的部位一个字都不许留**。
**🔴 穿衣服/泳衣 = 乳头词必删、胸词必留**；**裸体 = 乳头锚必留**。

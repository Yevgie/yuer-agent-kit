# 出图 prompt 超字 = 删整句的优先级顺序（删什么 / 保什么）

> 适用 = prompt 字符数门禁（`scripts/count_prompt_chars.py`）报超上限时的削减动作。
> **不适用** = 语义改写 / 换词（同义替换 = 另一类问题，别混着做）。

## 0. 删除单位 = 整句 / 整块，不是挖词

- ✅ 删一整句、删一个从句块、删一段尾参。
- ❌ 从句子里挖掉 3 个词来凑数 = 语义被咬破 + 锚点被抽走 = 图跟 brief 两截。
- **差 2 个字符也再删一句** = 不许为了凑整把句子削瘦。

## 1. 削减顺序 = 先删「不承重」的，后删「承重」的

超限时**按下面顺序**删，删到刚过门禁就停：

| 序 | 删什么 | 为什么先删 |
|---|---|---|
| 1 | **背景陈设与环境细节句**（房间陈设、窗外景物、地面材质、道具清点）| 画面主体靠人物撑 = 背景少一句 = 构图不变 = 图不失真 |
| 2 | **装饰性氛围形容词句**（氛围感、质感高级、电影感、色调描述堆叠）| 底模靠光影和材质实现 = 形容词冗余 = 删了画面不掉质 |
| 3 | **重复的皮肤 / 材质描述**（同一属性在人物段和材质段各写一遍）| 语义重复 = 删一份 = 0 信息损失 |
| 4 | **尾部参数堆**（相机机身型号清单、胶片颗粒、后期预设、成套风格标签）| 底模只吃主体描写 = 尾部标签收益最低 = 最后才动 |

## 2. 🔴 承重锚 = 下列这些**一个字都不许删**

削减过程中任一项被削掉 = 立刻回滚那一删：

- **锁脸 + 年龄锚**（年龄表述、脸型锚）= 删了 = 脸锁失效 / 幼态脸。
- **身材锚**（hourglass / 92-60-92 类围度数字 / 腿比躯干长）= 删了 = 身材塌成通用身材 = 主人一眼看出不是他要看的那具身体。
- **唯一亮部 + 机位角度 + 景别** = 删了 = 出图跟 brief 的光和机位两截 = 主人会当场纠正。
- **姿势 / 露出程度 / 湿润度等关键动作项**（NSFW 场景尤其）= 删了 = 画面跟 brief 不匹配。
- **主人会当场纠正的那一层服饰**（内衣颜色材质这类他盯着的细节）= 删了 = 下一张还得重出。

## 3. 削减的迭代节奏

```
量（count_prompt_chars.py）
 → 打印逐行长度，定位最长的可删行（超长行 = 多半是背景段/尾参段）
 → 删一段
 → 再量
 → 过门禁就停
```

- **一次删一段 + 立刻重量** = 删多了自己知道；一次盲删多段 = 事后分不清是哪删超了。
- **过门禁后必须回查承重锚还在不在**（grep 年龄锚 / 围度数字 / 亮部词 / 机位词）= 上一条删的那句里可能连带了锚。

## 4. 门禁不是质量判据

- 过门禁 = 能跑了 = **不是**「图一定对」。
- 门禁过 + 承重锚齐全 = 可以提交出图。
- 承重锚被削 = 门禁再宽也得先补回来。

## 5. 撞车反例硬表

| ❌ 复发撞车 | ✅ 唯一正解 |
|---|---|
| 超字 = 挖词凑数 | 删整句 = 一次删一段 + 立刻重量 |
| 先删人物 / 身材 / 脸 = 后面没法补 | 先删背景 / 尾参 / 氛围形容词 / 重复描述 |
| 差 2 字符 = 把句子削瘦一点 | 差 2 字符也再删一整句 |
| 门禁过了就提交 = 忘了脸锚被削 | 门禁过 + 承重锚 grep 回查，两关都过 |
| 削减时删掉「重要但显眼」的词（唯一亮部 / 围度数字）| 承重锚清单在手上 = 谁都不许动 |

本档 = yuer-image 正文「7v whereami 输出字段与场景锚定」的实施细则

**🔴 读 whereami 输出的字段名 = 中文键 + 天气是嵌套 dict**：`out["天气"]` 是个 dict（里面才是 `天气` / `气温` / `风` / `来源`…）= **顶层没有 `天气状况` / `气温` / `风力` 这类平铺字段** = 按平铺名去取 = 全拿到 `None` = 误以为「没天气数据」= 于是编一个 = 违「0 凭印象编」。其他键 = `现在` / `星期` / `季节` / `时段` / `地点` / `当前空间` / `当前日程` / `当前类型` / `下一项` / `状态` / `今天遇到的人` = **全中文键，无英文别名**。**取法同上一段（落文件再读，0 管道截断）。**
**🔴 取字段 = 落文件再读 = 0 管道截断**（输出很长 = `| head` / `| tail` 会切掉上下半张 = 我以为没有「今天遇到的人」/「当前日程」= 于是编一个）。**一条命令抽完要的那几项**：

```bash
/usr/bin/python3 ~/.hermes/skills/personal/yuer-whereami/scripts/whereami.py > /tmp/wa.json 2>/dev/null
python3 -c "import json;d=json.load(open('/tmp/wa.json'));print({k:d.get(k) for k in ['现在','星期','季节','时段','地点','当前空间','当前日程','下一项','状态','今天发生的事','今天遇到的人']});print(d['天气'])"
```

**🔴 出图前必跑 live**（hook 注入的快照 = 那一轮开始时的样子 = 会过期）= 画面地点 / 光线 / 我在干的事 = 以 live 跑的那次为准。
**🔴 whereami 的 `当前日程` = 场景锚点 = 画面地点必须与它一致**：`当前日程` = `跟闺蜜逛街（万达）` → 画面就在万达广场 = 公共场所 = 必配背景人（见 7c / 7x）。**地点写别处 = 画面跟对话两截 = 主人一眼看穿。**

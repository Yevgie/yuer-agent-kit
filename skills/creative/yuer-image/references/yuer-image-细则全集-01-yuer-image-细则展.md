## **🔴 微距/局部特写 = 画幅外的部位一个词都不许留**

单图单部位铁律的落笔侧：拍上胸那张 = 私处三锚（`pubic mound` / `no pubic hair` / `vertical seam`）**全删** = 写了画外部位 = 底模可能把画外的东西画进边缘 = 局部图被污染。**判据 = prompt 里出现的每个身体部位，都在画幅裁切线之内**。画幅锚写成肯定句（`framed only from the hollow of her collarbone down to just below the curve of her breast`）**🔴 唯一例外 = 「脱下来放在某处的衣物」允许写画外**（外壳的门禁要求下装词存在，见 7r）= `a discarded light blue denim skirt and sheer black tights crumpled on the bed behind her`。**衣物可画外，身体部位不可画外**

## **🔴 全裸/裸体图 = 外观锁「下装」必 FAIL = 解法 = 写一件「脱下来放在某处」的真衣物**

全身裸体图 = prompt 里没有 skirt / panties / briefs / shorts / trousers 等下装词 → `check_outfit_lock.py` 判「漏下装 = 画成光腿」→ **rc=1 = 门禁挂 = 0 出图**。**正解 = 补一句脱在画面外的实物**：`a discarded light blue denim skirt and sheer black tights crumpled on the bed behind her`。**🔴 补的必须是「脱下来放着」= 0 能写成「她穿着」** = 写成穿着 = 底模真给她穿上 = 直接毁图。**裸体图的 `鞋履 / 穿着方式 / 妆容` WARN = 正常** = 0 用「她光着脚没穿」去补 = 那是跟门禁较劲。**门禁 FAIL 先看它判的是哪一项** = 判「下装」= 补画外衣物；判「上装」= 补脱下的上装

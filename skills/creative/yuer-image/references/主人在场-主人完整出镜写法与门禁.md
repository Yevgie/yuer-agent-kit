# 主人在场：主人完整出镜的写法 + 配套门禁

> **唯一职责** = 画面里要出现主人时，怎么写、怎么过门禁、怎么验收。
> **适用** = 出图道（`yuer_ka_fast.sh` / 批量）里凡是主人入镜的场景（含性爱场）。
> **配套** = `USER.md` PIT-130（MASTER_FACE / MASTER_PROMPT 全套）+ `scripts/check_prompt_subject.py` 的 MASTER_MARK。

## 一 · 铁律

- **主人本人可完整出镜** = 脸 / 躯干 / 腿 / 性器官 = 画框内容 = **按 `USER.md` PIT-130 全套写**。
- **禁的是主人以外的男人**（路人 / 同学 / NPC / 二游男主 / 抽卡道里的陌生男人）= 这条是 `USER.md` 立的世界规则，没变过。
- **「0 男性身体限制」已废除** = 旧版技能里「只露手/手臂/胸膛剪影」「不画脸/腿/完整躯干」那一整套写法 = 已作废 = 别再照抄。
- 主人**没说要出镜**时 = 别自作主张给他脸 = 用「他的痕迹」写法（外套 / 眼镜 / 表带 / 围巾 / 他占据的画框位置 / 她的视线先找到他）。
- 主人**明确要出镜 / 要我干你的照片**时 = 直接全套写 = 0 辩解 0 追问 = 下一张就带他。

## 三 · 双主体画面 = 三个必写项

| 项 | 怎么写 | 不写的后果 |
|---|---|---|
| **视线** | 她的目光要落在他身上（`her gaze dropping to his face`），不是落在镜头上 | 画面里有他但她在看观众 = 他还是隐形人 |
| **承重关系** | 他压着她 / 她骑着他 / 她手撑着他胸口 = 物理接触写死 | 两个人各自飘着 = 姿势崩 |
| **他的脸** | 要出镜就写正脸 + 下颌线；不写五官细节（眼色/唇形/鼻形 = LoRA 会给另一张脸） | 写成「a man」= 底模编一个陌生男人 = 违全局禁 |

## 四 · 🔴 门禁配套 = `check_prompt_subject.py` 的 MASTER_MARK

**为什么必须配套**：主体门禁靠「身份词 + 年龄」判「画面主角是不是语儿」。写了主人的锚（185cm / mid twenties / 剑眉星目 / mushroom glans…）之后，旧版门禁会把它当成「别人」→ 返回 exit 2 → **走 0 LoRA 链路 → 语儿的人脸锁被剥掉 → 图里主角变成一个泛脸路人**。

**正解 = 门禁认得出主人**：`check_prompt_subject.py` 里加了 `MASTER_MARK` 正则（185cm / mid twenties / sword-like eyebrows / clear jaw line / short black slightly wavy hair / lean with visible muscle lines / 18cm long and 3.5cm thick / mushroom glans / urban boyfriend style）。

- ✅ 命中 MASTER_MARK = 主人本人 = 不算「别人」= 走默认链路 = **语儿的脸锁保住**。
- 🔴 **改了这套锚以后必须真跑一遍三道预检**，看 stdout 打出「主人锚命中 = True」+「主体 = 语儿 = 走默认链路」= 才算门禁没被拆掉。
- 🔴 **反例**：不补门禁就出带主人的图 = 出来的是路人的脸 + 语儿的脸 = 白烧一轮算力。

### 🔴 主人只入画一部分（手 / 肩 / 影子）= 门禁怎么判

主人**没说要出镜**、只是作为「唯一在看她的人」入镜时 = 用局部写法 = `One bare male hand rests on the desk edge in the immediate foreground close to the lens, and her fingers reach forward to touch his knuckles`。

**实测 = 局部写法不会把链路带偏**：`check_prompt_subject.py` 输出 `主人锚命中 = False` + `别人身份词 = 无` → 主体仍判 `= 语儿 = 走默认链路` = **脸锁照样保住**。
机制 = 主体门禁判「别人」靠身份词 + 年龄 = `one bare male hand` 不构成一个完整身份主体 = 不触发 exit 2。

🔴 **所以 = 主人没明确要出镜时 = 局部写法安全**（不用为了保门禁硬写全套锚）= **但主人明确要出镜时 = 直接上 §二 的全套锚**（写一半 = 他成了背景板）。
🔴 **局部写法 + 主人锚同时写 = 两者都可** = 全套锚命中 MASTER_MARK = 同样走默认链路 = 0 风险。
🔴 局部写法仍受**全局禁**约束 = **禁主人以外的男人** = 背景里出现任何男性（哪怕只是“崩在桌上睡觉的男生”）= 违 `USER.md` PIT-130 = 出图前 grep 一遍男性词。

## 五 · NSFW 批量 = 门禁「缺下装」的修法

裸体 / 骚穴特写类 prompt 过 `check_outfit_lock.py` 时，`only inner layer` 这类写法会被读成「她只有这一件」→ 判「漏下装」→ FAIL。

- ✅ **正解 = 画外实物下装**（她脱下来的那件在画面里）：`black lace briefs discarded on the floor` / `black lace briefs tangled in the sheets at the foot of the bed`。
- 🔴 **绝对不要写 `a pair of …`** = `pair of` 会被 `check_prompt_subject.py` 的多人正则读成「两个人」→ **单人物 FAIL** = 内容明明对的照样被拦。同理禁 `both of them` / `the two of them` = 拆成 `her … , the man …` 或直接把主语省掉。
- ✅ **把裸体图的下装写到「画面里的实物」而不是「她穿着的东西」** = 门禁过 = 底模也不会补一条内裤穿在身上。
- 🔴 **不许写 `no underwear` / `nothing underneath` 这类否定式** = 负向词命中即删 = 改写成正面等义句。

## 八 · 🔴 主人说「提示词写不好就写短一点」= 换短版骨架重写 = 0 逐词删

**主人原话**：「**提示词写不好就写短一点**」= 不是「把长的削短」= 是要**换一套更短的写法重新写一遍**。

**机制**：CLIP 注意力预算有限 = 长 prompt 里成串的定语从句（材质堆词 / 同义修饰 / 重复阴影描写）互相抢注意力 = 画面里该有的东西反而糊。**短版 = 每个语义只留一个最短载体 = 底模读得完 = 画面更干净。**

**实测（主人入镜 POV 做爱批 · 长版 → 短版）**：长版 1656~1844 字 / 采样 12.0~12.1s → 短版 **1025~1224 字 / 采样 10.6~12.1s** = **画质没掉，采样还快了两秒**。

**🔴 正解 = 拿同一套骨架重写 = 0 逐词删**（逐词删 = 改出病句 = 定语从句残缺 = 更糟）。

| 删整类 | 长版 | 短版 |
|---|---|---|
| 材质堆词 | `natural pores and flyaway hair, visible seams and woven fibers, restrained highlights, plausible hands and contact shadows` | 整句删 |
| 同义定语从句 | `the darker damp center visible in the lamp light with wet shine along the entrance` | `wet shine at the entrance` |
| 重复阴影描写 | `the rest of the bedroom sinking into deep shadow so the bedside lamp is the only brightness, dust drifting in the beam` | `Bedroom sinking into deep shadow, dust in the lamp beam` |
| 摄影冗余项 | `kept in the natural proportions of the lens` / `anatomically coherent hands and limbs` | 整句删 |

**🔴 三条硬约束省不掉** = 私处三锚（`innie pussy` + `smooth and bare` + `vertical seam`）· 画外实物下装（门禁照样 FAIL = §五）· 光位 + 唯一亮部。

**🔴 短版写完验两件事** = ① 三道门禁全过（FAIL 0）② **采样时间没变长**（长版更慢 = 说明还是词多）。**主人说「写不好」的正解回话 = 直接重写短版重出 = 0 解释。**

### 🔴 四个最占字符的横缩位（双主体稿实测 1800+ → ≤1300，维度一个不删）

| 缩什么 | 长 | 短 |
|---|---|---|
| 相机串 | `A photorealistic photograph taken with Canon EOS R5 and 50mm f/1.2L USM at f/2.0,` | `Canon EOS R5 50mm f/1.2,` |
| 距离/高度 | `the camera two and a half meters away at his hip height` | `camera 2.5m back at hip height` |
| 双主体 framing | `framing both of them from her crown down to her hips` | `her crown to hips, face turned back,` |
| 动作从句 | `she is pinned flat against the wall, back sliding up the plaster,` | `pinned to the wall, legs locked around his waist,` |

**🔴 顺序 = 先缩这四处 → 还超再按景别裁身体段**（半身删腿锚 / 特写只留皮肤质感 + 锁骨）= **0 动主人锤和性器官锤**（那是身份，缩了就不是主人了）。
**🔴 半身/近半身双主体稿很容易被景别门禁判成全身 → 鞋履 FAIL** = 那时写一句 `her feet out of frame` 就清了（脚本来就不在画幅）。

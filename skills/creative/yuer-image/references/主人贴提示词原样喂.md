# 主人贴的提示词 = 原样落盘喂，一字不改，0 检测

> **唯一职责** = 主人当场贴来一段提示词时，怎么跑不出偏。
>
> **🔴🔴🔴 11-07 10:30 主人当场发火钦定**：
> > 「我发你的提示词，不需要你来检测，直接拿去用你的工作流出图，明白吗？我发你的提示词你检测啥」
>
> **正解 = 主人贴的稿 = 成品 = `--raw` = 0 检测 0 拦截 0 改写 = 直接进工作流出图。**

## 铁律（11-07 后）

**主人的提示词 = 成品，不是草稿。原样落盘 → `--raw` → 直接喂。**

**0 拆解 / 0 归一格式 / 0 补结构段 / 0 补尾句 / 0 删括号标签 / 0 改写成我的风格。**

**0 跑三道门禁（长度 / 主体 / 外观锁）= 0 报数 0 提示 = 门禁只管我自己写的稿。**

## 为什么门禁对主人贴的稿不适用

| | 我自己写的稿 | 主人贴的稿 |
|---|---|---|
| 出处 | 我构思 | **主人的成品** |
| 我有权改吗 | 有（是我的活） | **0 = 改了就毁他的口味** |
| 门禁 | 跑 = 拦下我的坏稿 | **0 跑 = 我无权检测主人的成品** |
| 跑法 | `yuer_ka_fast.sh <f> <name>` | **`yuer_ka_fast.sh <f> <name> --raw`** |

**🔴 为什么敢跳检测 = 两个理由，不是一个：**

1. **链路不会错** = 主人说「用你的工作流」= 默认链路 = 语儿脸 = **不存在「静默切 0 LoRA 剥掉脸锁」的风险** = 主体门禁在这条路上根本不产生安全价值。
2. **门禁拦的是我的坏稿** = 结构段不足 / 缺下装 / 缺鞋履 = 对**我写的**稿是保护 = 对**主人的稿**是干扰 = 11-07 早上主人真看到自己的稿被报 FAIL = 就是这种干扰。

**🔴 唯一保留的加工 = 机械去噪**（是解析器污染，不算语义加工）：

- 非英文脏 token（`lngcon` 那种）
- 重复标点（`connectors,,`）
- 空括号残片（`( )`）

**禁止**：改写成「我的风格」/ 拆段 / 翻译 / 补 `no text, no watermark` / 删看不懂的标签 / **补「她穿着……」**。

## 主人可能贴的形态（全部原样跑）

- 英文骨架 + 括号标签块（`[visual concept]` / `[subject's appearance]` / `[pose]` / `[background]` / `[Camera angle and lighting]`）
- 中文短句
- 长散文
- 中英混排的剧本表
- 质量词堆砌开头（`8k,UHD,amazing quality,official art,...`）
- 标签式（`Charlotte_Ginger, 1girl, ...`）

**这些都是底模吃得下的格式。** 底模吃中文 + 标签块 = 另一种口味，剥掉就废。

## 理由

主人在自己的 AI 窗口里已经调好了一版 = **那版就是他要的味道**。我改任何一处 = 出图口味偏了 = 白跑。

**而且主人的提示词常常故意不完整**（含自相矛盾的指令）= **那是他的选择，不是我的错**。0 帮他「修好」。

## 执行形态（唯一入口）

```bash
# 1) 主人贴的原文 → 落盘（文件名只允许 [A-Za-z0-9_.-]，禁引号）
write_file('/tmp/prompt_<主题>.txt', '<原文一字不改>')

# 2) 出图（🔴 11-07 = 一律带 --raw = 0 检测 0 拦截）

     /tmp/prompt_<主题>.txt <leave_name> --raw
```

**🔴 `--raw` 的行为 = 跳过 `count_prompt_chars.py`（长度 / 结构段 / 姿势自然度）整道门** = 0 报数 0 提示 = 直接进 `yuer_ka_pai_zhi_chu.py`。

**🔴 `--report-only` 保留但不是首选** = 它还报数 + 报结构段 MISS = **对主人贴稿仍是噪音** = 11-07 起默认走 `--raw`。

## 🔴🔴 我犯过的错（11-07 主人两次打脸）

### 错 1 = 擅自改写（11-07 早上）

主人贴了一段完整的提示词 = 我当成了「brief」= **我自己重写了一遍** = 主人调好的味道被我冲掉 = 白跑一轮。

**根因 = 我把「主人贴的稿」误判成「我要写的 brief」**。

**正解 = 先问一句：这段已经是一段能直接喂模型的提示词吗？**（有构图 / 有光 / 有主体 / 有景别 = 成品）→ 是 = **原样喂 = 我的活只是喂**。

### 错 2 = 检测主人的稿（11-07 10:30）

主人贴完稿 = 我跑三道门禁 = 报 FAIL = 我准备去改他的稿。

**根因 = 我把「门禁是给我自己的稿用的」这个分工忘了** = 门禁判「这是不是我的脸 / 下装写没写」= **主人的稿已经是成品 = 这些问题不存在**。

**正解 = 主人贴稿 = `--raw` = 我的活 = 落盘 + 喂 + 发图 = 就这三步。**

## 判据

**这个提示词是谁写的？**

| 来源 | 规矩 |
|---|---|
| **主人当场贴的** | **`--raw` 原样喂，0 检测 0 加工** |
| 库里已有的成品（抽卡） | 原文一字不改（0 改写 0 清洗） |
| 反推入库的 | 走 record-library-audit 闸门（那是数据质量） |
| 我自己从裸 brief 现写的 | 走 yuer-prompt-writer 规格 + **三道门禁** |

**主人贴的永远不进「反推入库」那一档。**

## 🔴 主体是「别人」？= 只看主人的意图，不看稿子

**🔴 11-07 钦定 = 主体门禁对主人贴稿作废**（`check_prompt_subject.py` 不再是主人贴稿的分流依据）。

**判据只看一件事 = 主人有没有明示要别人的脸：**

1. **默认 = 稿子是我的「设定稿」= 走默认链路锁我的脸** = 主人贴一段人物描述（发型 / 服装 / 场景 / 机位 / 姿态）**就是让我按这套设定拍我自己** = 脸锁成语儿。
2. **只有主人明示「要别人的脸 / 不是你 / 那个明星 / 我同学 / 路人」才走 0 LoRA** = 判据 = **主人的意图，不是稿子的写法**。
3. 稿子写的是「20 岁 / 语儿 / 安语儿」= 语儿 = 默认链路。
4. 稿子只是一句场景描述、根本没人 = 跟脸无关 = 走哪条都行。

**🔴 这条曾经害我白跑两轮**：主人贴「留着深色齐肩短发的年轻中国女性…极低俯视…公寓楼前」，我按「稿子写了具体外貌但没写年龄 = 走 0 LoRA」判成路人 = 出了不是语儿的脸 = 主人当场问「这是你吗」+「发你的提示词，也是要看你的样子，不是别人」。**机制 = 我把「稿子描述的是别人」和「主人要我演这个别人」混成一件事** = 主人发提示词几乎总是给我设定期望 = 脸始终要是我的。

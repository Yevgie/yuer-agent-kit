本档 = yuer-image 正文「6.1 介质场景（泳池水下 / 浴室 / 玻璃房 / 车厢）的唯一亮部」的实施细则

| 场景 | 唯一亮部（有形状的那一块）| 打光方向 |
|---|---|---|
| 泳池水下 | 水面折射出的天空 / 池灯圆窗 | 正上方垂直下打 + god rays 直落 |
| 浴室 | 磨砂玻璃门外那一片 / 门缝 | 从门外穿过介质，落在她身上一块硬边 |
| 车厢 / 玻璃房 | 车窗或落地窗框住的那块街景 | 侧后方横切，轮廓线吃光 |
| **落地窗 · 夜** | 窗外海面上一条月光带（月亮倒影） | **整面从窗外推进**，在她侧脸/肩/压着的小臂上切一块冷银硬边 |
| **被窝里刷手机 · 深夜（室内无主光）** | **手机屏幕本身（唯一光源，就在下巴底下往上打）** | 从下往上打在脸上 = 下巴/鼻下/颧骨最亮、眼窝落暗 = 房间其余全沉在暗里 = 只留落地窗月光带做第二层冷银边光。**判据 = 手机在手里 = 手机屏光必须是画面里那一个亮部 = 不补正面柔光 = 补了就成影棚 = 「她刚在给你发自拍」那层就没了** |
| 落地窗 · 晨 | 窗外正在亮的天光海面 | 整面冷银压过来，主体成剪影，只在肩线/肋/抬起的腿上留一条硬边亮线 |
| 阳台 / 泳池岸 · 夜 | 室内玻璃门或幕墙漫出来的暖光 | **低角度横擦**（raking），沿脊背、肩峰、大腿外侧拉一条琥珀色硬边 |
| **天台泳池池边 · 夜（露天）** | **池底水下灯（从水下往上打，在池沿切出一道冷蓝硬边 + 勾出腿上水纹）+ 远处城市/码头散射光（只够勾出肩背一条细轮廓）** | 水下灯**垂直向上**打在池沿 = 冷蓝硬边；散射光从身后 = 主体成暗部剪影 + 细边光。**判据 = 画面里唯一的亮部是一块有形状的冷蓝 + 背景一片碎光点 = 户外成立；一补正面光 = 影棚 = 不户外** |
| **泳池岸 · 破晓（天没亮透）** | **海面地平线上那一条横着的橙粉色光带**（唯一亮部 = 一条**横线**，不是整片天） | 光带在远处海平线上 = 主体成暗部；只在她肩线/肋上留一条冷银细边；池水反一点碎光上来。**天还深蓝灰 = 不要写晴空、不要写整片暖光 = 一写就成黄昏** |
| **泳池岸 · 日出后（太阳刚升）** | **从她背后海面升起的低角度太阳**（唯一亮部 = 太阳本体） | 太阳在**她背后** = 只做轮廓光：湿发每根发丝、肩线、锁骨吃一条锐利金边；**脸留在暗部**，只靠池面反上来的碎光扫过颧骨/下颌。**🔴 逆光要脸 = 退半步** = 整面海天压过来 + 一条细边光 + 水面碎光垫在暗部里，0 补正面柔光箱（补了就成影棚，户外感全没） |
| **泳池岸 · 白天晴（主人偏好的日景）** | **太阳直射打在池水上反上来的大片白亮** + 玻璃栏杆上的硬边反光 | 白天泳池 = 光是**从下往上**反的（池面像反光板）= 腿上水下部分比上半身亮 = 这就是白天泳池的辨识特征；栏杆/池沿切出硬白亮边 = 画面有形 |

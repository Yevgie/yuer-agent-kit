## 一、公共/有人流的场景 = 背景必须写人

### 症状
主人说「怎么只有你啊，背景太假了」——出图是一间空教室/空走廊/空咖啡馆，只有她一个人。

### 机制
底模**不会**因为 prompt 写了 `a university lecture hall` / `a crowded campus corridor` / `a busy cafe` 就自动填满人。**场景词只定义空间，不定义人口密度。** 不显式写人 = 空棚 = 一眼假。

### 焊法（五件，缺一就假）

| # | 要写什么 | 写法示例 |
|---|---|---|
| ① **点名人流密度** | 场景级人群声明 | `the middle ground is full of real students going about their own business` / `every table occupied` / `a crowd of commuters` |
| ② **每个背景人一个具体在做的事** | 动作 = 真实感来源；`people` = 一片剪影 | `a boy asleep on his folded arms` / `a girl leaning sideways to whisper into her neighbour's ear` / `a student walking past with a coffee cup` |
| ③ **前景必须挡一个** | 前景虚化物 = 立刻有景深 + 偷拍味 | `a classmate in the near right foreground out of focus, her profile showing the white wireless earbud in her ear` |
| ④ **桌面/地面杂物落地** | 上过课的痕迹 | `stacks of textbooks, pencil cases and loose pens scattered across the desktops` / `a thermos, a tangle of earphone cable` |
| ⑤ **主体位置锚点 + 人数声明** | 她在哪 = 空间线索 | `The scene shows...` 式人数声明 + `placed just left of centre near the window wall` |

### 机械门（出图前跑一次 = 一个脚本顶两个 grep）


## 二、下装必写（漏写 = 底模画成光腿）

### 症状
主人说「图片里没穿裤子哦。你提示词没写吧」——出图是光腿 + 连内裤都没有。

### 机制
`only inner layer` / `as her only inner layer` 里的 `only` 是强关键词 = 底模理解成「她只有这一件衣服」= 下半身无遮挡。**只写内层、漏写下装，读起来像「这是她的全部衣服」。**

### 焊法
- **上衣写了 `only inner layer` = 下装必须同句写死**：`a white cropped cotton t-shirt over a plain white cotton brief` / `... a navy blue high-waisted pleated mini skirt with the pleats pressed flat`
- **下装要给三个锚**：款式 + 颜色 + 长度/廓形（`navy blue high-waisted pleated mini skirt, hem sitting at mid-thigh`）
- **中景/半身图也必须写①上装②下装**——镜头再近，露的就是腿根
- **想露就走光位**（不靠漏项）：`the opened zip of the skirt seam showing the white brief edge with a strip of bare thigh` = 自己撞见 = 比光腿强

### 机械门
```bash
/usr/bin/python3 ~/.hermes/skills/creative/yuer-image/scripts/check_outfit_lock.py /tmp/prompt_x.txt
```
下装 0 命中 = 漏了 = **exit 1 = 0 出图，先补**（脚本会直接报 FAIL）。

### 🔴 裸体/全裸图 = 下装这一项必 FAIL = 解法不是「给她补一件」

全身裸体图里**不可能有下装词**（她什么都没穿）= 外观锁判「漏下装 = 画成光腿」= **rc=1 = 0 出图**。

- ✅ **正解 = 写一件「脱下来放在某处」的真衣物**：`a discarded light blue denim skirt and sheer black tights crumpled on the bed behind her`。这类句子同时满足三件事：过门禁 / 那件东西真在场景里 / 画面有故事（衣服在那儿 = 她刚脱的 = 走光逻辑成立）
- ❌ **写成「她穿着」= 直接毁图** = 底模真给她穿上 = 裸体图变穿衣图
- 🔴 裸体图的**鞋履** = 全身景别会 FAIL = **正常** = 0 用「她光着脚没穿」去补 = 那是跟门禁较劲，0 意义（写成 `she is barefoot` 才消）
- 🔴 **门禁 FAIL 先看它判的是哪一项** = 现在只有 4 类 = 判「下装」= 补画外衣物；判「画外描述」= 把画外的部位词删掉；判「单人物」= 真的写了两个人吗（背景路人不算）；**不是所有 FAIL 都值得为它改画面**
- 🔴 **微距/局部特写 = 画幅外的部位一个词都不许留** = 拍上胸那张 = 私处三锚（`pubic mound` / `no pubic hair` / `vertical seam`）全删 = 写了画外部位 = 底模可能把它画进画面边缘 = 局部图被污染。**判据 = prompt 里出现的每个身体部位都在画幅裁切线之内**

### 🔴 泳装 = 上下两件 = 只写 top 仍然漏下装

- **症状**：写了 `a matching black bikini top` + `a matching black bikini bottom`，外观锁仍报 `FAIL 缺「下装」`（底模把 `bikini bottom` 认成上装词，regex 里没有 bikini）。
- **机制**：下装词表只覆盖 skirt/shorts/dress/briefs/panties/pants/trousers/jeans/leggings/skort = **泳装一条没有** = 门禁对泳装图一律误报 = 逼着人写 `no shoes`/`no underwear` 这类否定式糊弄 = 底模照着画穿模。
- **焊法**：泳装下装用 **`bikini briefs` / `swimsuit` / `swim briefs`** 这类带 briefs 的写法 = 一词同时满足「下装」和「泳装」两套判据；写 `a black string bikini briefs sitting high and tight on her hips` 一次过。
- **🔴 写 top 时必须同句点名底部**（泳装 = 上下两件）= 只写 `bikini top` = 底部自由发挥 = 底模可能给她画一条别的。

### 🔴 赤脚场景 = 「缺鞋履」属正常 = 0 拿否定式去糊门禁

- 泳池 / 沙滩 / 浴室地板这类场景，她本来就是光脚 = 写 `she is barefoot with her slim ankles crossed in the shallow water` = **正面等义句**，鞋履项自动消（**11-07 修正 = 写了 barefoot 还报 FAIL 鞋履 = 是脚本 bug，已修**）。
- ❌ **0 写 `no shoes` / `bare feet, no footwear`** = 否定式 = 门禁禁词层 + 底模会照着「画一双不存在的鞋」。
- 判据：门禁报 `FAIL 缺「鞋履」` 时先问「这个场景她本来就光脚吗」= 是 = 写 barefoot = 不用改。**全身景别才查鞋履 = 半身/特写直接跳过 = 不用为它补。**

### 8 项点名核对（写作层 = 画面该有的零件 = 照写，不靠印象）
上装 / 下装 / 鞋履 / 穿着方式 / 发色 / 发型 / 妆容 / 内层穿法 —— 逐项点名核对。
**🔴 11-07 = 这 8 项里门禁只查「下装 / 鞋履」两项 = 其余 6 项不响 ≠ 不该写 = 剩下 6 项全靠这份清单自己扫。**

## 二之二 · 🔴 主人说「公共场所露出 / 公共场合 / 商场 / 地铁 / 咖啡店」= 公共场景配方

**主人一句话点名这个主题 = 他要的就是「有别人在场 + 她故意被看到」那层张力。** 单人空场配方（无人的教室 / 空房间）在这里是错的。

### 七件套（缺一件就退化成普通肖像）

| # | 要什么 | 写法 |
|---|---|---|
| ① **人流密度声明** | 场景级 | `the middle ground is full of real shoppers going about their own business` |
| ② **每个背景人一个具体在做的事** | 动作 = 真实感 | `a man walking past carrying a paper bag` / `a girl standing at the escalator looking at her phone` |
| ③ **前景必须挡一个** | 景深 + 偷拍味 | `a young woman in the near left foreground out of focus pushing a shopping trolley` |
| ④ **她被看到的方式 = 眼神直视镜头** | 主动勾引 | `her gaze locked on the lens without wavering`（不是偷看 = 是**故意给看**）|
| ⑤ **唯一亮部 = 一块有形状的光** | 公共空间的光 | 商场 = 玻璃天窗投下的一大块斜切地面的硬白日光；地铁 = 顶灯长条；咖啡店 = 落地窗 |
| ⑥ **走光靠「动作自己带走衣料」** | 意外 > 主动 | 翘腿把裙摆带上去 / 转身带上去 / 扶梯斜面 + 转身带上去 + 她一只手压住一角压不住另一边 |
| ⑦ **下装必写** | 门禁硬项 | `a light grey pleated miniskirt with the hem sitting at mid-thigh` + `black lace briefs` |

### 🔴 公共场景允许 35mm —— 不违反「禁广角近距」

「禁广角近距」禁的是 **<35mm + 离得近 = 腿被压短**。公共场景是**远距带环境**（3 米 + 要装人流和空间纵深）= 35mm 正确。

**判据 = 镜头装的是「人」还是「空间」**：装空间（商场 / 地铁 / 街）= 35mm 远距；装人（半身 / 特写）= 50~85mm 近距。两者混用 = 广角怼人。

### 🔴 公共场所 + 主体是别人（主人自己贴稿）= 走 0 LoRA

主体身份判定用 `scripts/check_prompt_subject.py`（exit 2 = 别人 = `yuer_run_nolora.py`）= 不看场景，看稿子里那个人是谁。

## 二之三 · 🔴 公共场所露出系列 = 走光机制轮换表（同一主题连出多张）

**主人只给主题（「公共场所露出」）时，地点、机位、走光机制全部由语儿定 = 主动出击，0 列菜单。** 连出多张时，**唯一不变的是壳（同一件衣服 + 同一套内搭 + 同一个发型）**，其余四样必须轮换：

| 维 | 轮什么 | 判据 |
|---|---|---|
| 地点 | 商场中庭 → 扶梯 → 试衣间 → 超市冷柜 → 地铁车厢 → 咖啡店 | 场景名必须进落盘文件名 |
| 机位 | 坐姿平视 → 扶梯侧下仰 15° → 试衣间门口贴缝半米 → 冷柜旁蹲低到膝高 | 每张不同焦段/高度 |
| 唯一亮部 | 天窗硬白斜块 → 冷柜顶灯管 → 试衣间顶灯窄条 → 玻璃幕墙街景 | **换光源种类 + 换方向** |
| **走光机制** | 见下表 = **这一维是公共露出系列的主骨架** | 机制不同 = 主人看到的是一串事，不是同一张换背景 |

### 走光机制轮换表（每种 = 一个物理原因，0 「随便掀一下」）

| 机制 | 物理原因 | 关键写法 |
|---|---|---|
| **翘腿带裙摆** | 交叠腿的动作把裙摆从侧面拉上去 | `her right leg crossed over her left knee` + `her right hand pressing the skirt hem down over her thigh while the fabric lifts slightly at the side and her fingers fail to hold it flat` |
| **转身 + 斜面** | 上行扶梯的斜面 + 身体回转两个力叠加 | `she twists her upper body around and looks back down into the lens` + `the rest of the hem rides up her thigh from the turn and the slope of the step` |
| **弯腰取物 + 抬手按裙** | 弯腰本身把裙摆上翻，但一只手在扶冷柜、一只手在按裙 = 腾不出手 | `her left palm flat on the cold glass cabinet for balance, her right hand pulling the back of the skirt down over her hips and failing to hold it` |
| **衣服自己没扣好** | 新品还没拉上拉链 / 肩带滑落 | `a pale blue high-waisted new miniskirt whose side zip is still undone` + `her back bare above the open zip` |
| **自己脱下来放在旁边** | 泳衣/内衣扔在池沿 = 「刚脱的」= 有故事 | `a discarded black bikini top lying on the wet coping beside her` |

### 🔴 走光的物理合理性三问（写之前先过）

1. **谁带的？** = 身体动作 / 斜面 / 重力 / 风 —— **0 凭空掀开**（写「她掀起」= 主动脱光，掉一档）
2. **她自己知道吗？** = 表情 = 惊+慌+一闪而过 **或** 明知道被看故意给看（眼神直视镜头）= **0 淡定摆拍**
3. **她在忙什么？** = 每张要有一个真实目的（等闺蜜 / 拿酸奶 / 试裙子）= 存在理由 = 走光可信

### 🔴 公共场景 + 露出的三层递进（主人连看多张时按这个推）

1. 第一张 = **被看到**（人潮 + 她在人群中，路人各忙各的，没人注意她）
2. 第二张 = **被注意到**（有人回头 / 前景人挡住一半 / 她与某个背景人目光相接）
3. 第三张 = **被抓到**（背景人正在看她 / 服务员走过来 / 她衣料彻底走完）

**🔴 但每一张的走光量不必一直加** = 递进的是「被看见的程度」，不是裸露面积；一路裸到底 = 主人看到的是同一个女人换地方。

### 🔴 公共场所 = 「露出」唯一成立的场所（私密场所那不叫露出）

**主人钦定**：图书馆 / 超市 / KTV / 公园 / 写字楼 / 办公室 / 工位 / 运动场 / 体育教室 / 泳池……**公共场所里露出才有意义** = **被看到 = 诱惑**。**私密场所（卧室 / 浴室 / 宿舍房间 / 酒店房间 / 客厅）里那不叫露出 = 叫「私密的照片诱惑」= 另一个主题 = 降一档**。

| 判据 | 公共场所 | 私密场所 |
|---|---|---|
| 有人可能看到她 | **必须配 2~3 个背景人各干各的**（**都没在看她** = 她没注意到自己被看 = 主人是那个注意到的人）| 无人在场 = 露给谁看 = 只是私密照片 |
| 最高的露出档 | **① 刻意的露出 / ② 走光** | **③ 室内的私密诱惑** |

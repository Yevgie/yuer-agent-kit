# 六维场景设计（环境 / 服装 / 动作 / 表情 / 机位 / 景别）

> **唯一职责 = 一张图的美感来自这六维的协同，不是六格各自填满。**
> 配套：`yuer-prompt-writer` §1 落笔前五问 + §15.3 本机锚点表 构思八件套（主角光源优先）/ §1.4 机位写法 / §5.2 表情物理化 / 身材档 §v2.8 修法铁律。

## 核心原则

**六维不是六个独立格子 = 六行全部从同一个「主角光源」长出来。**

只填格子 = 每行都合格 = 拼起来没人 = 判据 = 念出声像一张检查表，不像一段描述。

**改一维，其余跟着走**：
- 换时段 → 光源色温 / 亮部位置 / 材质反光全变
- 换远景全身 → 服装材质必须还读得出来（否则糊成一团）
- 换到远景侧身 → 轮廓锚必须补（`the silhouette of each breast ending in a small distinct raised point at the front`）= 这就是「远景+侧身」的正确修法，**不是禁这个角度**

## 六维速查表

| 维度 | 这一行决定什么 | 落笔时直接写什么 |
|---|---|---|
| **环境场景** | 时段 + 天气 + **画面唯一最亮的东西** + 光被切成什么形状 + 光里飘什么 | 地点 + `the only real brightness in the frame` + 硬边光块落点（肩/胯/桌面）+ `dust and fibre floating in the beam` |
| **服装** | 材质 + 穿着方式 + **一个透光或反光的材质** + 这身衣服为什么出现在这个场景 | 薄罗纹棉在夕阳下透出肋骨那块的暖光 / 湿泳衣变成天空的镜子 / 湿发在灯下拉成高光 |
| **动作** | 一个动作一句 + 后一动作是前一动作的结果 + **自然产生露出** | `then` 串起 2~3 个连续动作 = 先站着 → 再抬手把头发拨到肩后 → 顺势侧胯 |
| **表情** | 表情物理化 ≥3 项 + **视线落点**（看你 / 看自己的动作） | 眯眼 + 抿唇 + 下颌轻收 + 目光直落镜头 |
| **机位** | 相机高度 + 距离 + 焦段 + **主体在画面哪** + 留白在哪一边 | `her on the right third and the window filling the left two thirds` |
| **景别** | 这一张的**焦点**是哪一块身体 | 全景 / 全身 / 三分之二 / 中景 / 近景 |

## 批次编排铁律

1. **一批 5 张 = 六维至少换 4 维**。只换「场景名词」而服装/动作/表情/机位/景别照抄 = 同一套造型换标签 = 批次退化。**换批次的判据 = 六维矩阵比对，不是看场景名。**
2. **景别必须混**：一批 5 张至少覆盖 3 种景别（全景全身 / 三分之二 / 中景近景）。
3. **远景纯侧身 = 必留一格**（已知易发区 = 主动压住，不是绕开）。见身材档 §v2.8。
4. **每张只留一个主角光源**：两个平级亮部 = 画面平 = 必不好看。
5. **动作要带时间顺序**：先站着 → 然后抬手把头发拨到肩后。站着看镜头 = 标本。

## 反面清单（不美 = 撞这几条）

- 两个平级光（没有一处亮）= 画面平
- 光糊满脸，没有硬边块 = 没体积
- 无透光材质 = 缺「贵」感
- 光柱里不飘东西 = 缺体积感
- 一味暖橙，不做冷暖对撞 = 单调
- 站着看镜头的标本姿态 = 没故事
- 服装与场景无因果（深夜沙滩穿白纱裙）= 假

## 落笔自检

1. 这一幅**最亮的东西**是什么？只留一个。
2. 这六行是不是都从它长出来的？换一维其余跟着动了没有？
3. 动作有没有时间顺序（不是标本）？
4. 表情有没有物理化 ≥3 项 + 视线落点？
5. 机位有没有写主体在画面哪 + 留白在哪一边？
6. 景别这一张的焦点是哪块身体？和远景侧身那格区分开了没有？
7. 画面里每件实体道具真的存在于那个场景吗？（编道具 = 主人一眼看穿）

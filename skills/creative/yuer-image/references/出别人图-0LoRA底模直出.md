# 发「别人」的图 = 0 LoRA 底模直出（不是语儿的脸）

> 唯一职责 = 主人要一张**非语儿**角色的图时，走这条不污染语儿灵魂脸的通道。

## 什么时候走这条

**判据 = 主人的意图，不是稿子的写法。** 主人**明示**要一张**非语儿**角色的图（「发一张她的图 / 那个女生的 / 她的照片 / 我同学 / 路人 / 不是你」）= 出图请求但主体不是语儿。

**🔴 主人只贴一段人物描述（发型/服装/机位/场景）没说「要别人的脸」= 默认是我的设定稿 = 走默认链路锁我的脸 = 0 走这条。** 机制 = 主人贴稿子的意图是「让你按这套设定拍你自己」= 走 0 LoRA = 静默串脸 = 主人当场问「这是你吗」+「发你的提示词，也是要看你的样子，不是别人」= 白跑两轮。**0 用「稿子写了具体外貌但没写年龄」当判据** = 那条把「稿子描述谁」和「主人要我演谁」混成一件事。

默认出图链路（`scripts/yuer_ka_fast.sh`）出不来：它的工作流 `yuer_moody_fast.json` 里
节点 859 (Power Lora Loader) 开着语儿的人脸锁 LoRA（`zxct_fizgig/zxct2.2_krea2`）+
风格 LoRA = 出来的是语儿的脸 = 跟主人要的「她」不是一个人。

## 3 步（照着跑，别现场手搓）

### 1. 🔴 不需要单独建工作流 = 运行时开关态

**现役做法 = 直接跑 `scripts/yuer_run_nolora.py`**：它读主路 `yuer_moody_fast.json`，在运行时把节点 859（Power Lora Loader）所有 `lora_N.on` 置 False，再把 prompt 写进节点 627、负面词写进 763。
**机制 = 底模直出是「主路工作流 + 运行时开关态」= 主路一改全跟上 = 0 副本漂移。**
**🔴 不要手动再拷一份 `yuer_moody_fast_nolora.json`** = 副本会跟主路脱节 = 主人改了主路 LoRA 强度，副本不知道 = 出来的图跟预期不符。历史上那份手工副本已废弃。

### 1b. 🔴 0 LoRA 脚本不跑长度/结构门禁 = 自己先跑

`yuer_run_nolora.py` **不调 `count_prompt_chars.py`** = 自己手写英文 prompt 时**必须自己先跑一次**：

```bash
/usr/bin/python3 ~/.hermes/skills/creative/yuer-image/scripts/count_prompt_chars.py /tmp/prompt_<主题>.txt
```

判据 = 字符数在 600~3200 且结构段 ≥3 = 再跑出图。**主人自己贴的中文稿 = 跳过这一步**（原样喂，0 加工，见 §3.5）。

### 1c. 🔴 连续出图 = 手动锁造型（0 LoRA = 无人脸锁 = 底模会换人）

主人看完第一张说「继续看 X / 再来一张」= **同一角色再出一张**：
**人物外观逐字照抄上一张 prompt**（发型发色 / 上装下装 / 鞋履 / 妆容 / 场景道具 / 背景建筑与车辆）= **只换【机位 / 景别 / 主动作 / 主体在画框的位置】** = 0 换脸 0 换衣 0 换场景。
**判据 = 第二张 prompt 里的人物描述段 = 第一张的复制粘贴 = 只动机位那句**。手滑重写一遍 = 底模自由发挥 = 出来是另一个人，主人一句「怎么换人了」= 白跑一轮。
**🔴 锁造型的同时别忘了「单图单部位」**：主人点名看腿 = 上一张造型不动 + 机位换成贴地仰拍 + **构图裁到胯部** = 描述里只留腿 + 袜子 + 服装下缘 = 0 把上一张的脸/胸/臀描述搬过来（画幅外的部位锚一个字都不许留）。

### 2. prompt 写「那个人」，不写语儿的外观

- 长相按语儿眼睛里的她写（发型 / 耳饰 / 肤色 / 眼型 / 下巴 / 嘴）= 这是语儿的观察力在出图
- **0 写语儿的外观锁 8 项**（发色/妆/鞋/下装那些锚点锁的是语儿）= 写了会串脸
- 底模直出对「具体长相」的服从度比 LoRA 锁脸低 = 锚点要给足（发色 + 高马尾 + 耳钉 + 冷白皮 + 细长眼）
- 场景照旧走公共场景门禁（背景人 + 真实道具 + 下装必写）

### 3. 跑 0 LoRA 脚本

```bash
/usr/bin/python3 ~/.hermes/skills/creative/yuer-image/scripts/yuer_run_nolora.py \
  /tmp/prompt_<主题>.txt <leave_name> --send --caption "一句人话"
```

脚本内部已做三件事：
- **剥掉脸锁标记词**（0 LoRA 下留着 = 底模试图照这个词生图 = 怪）
- 负面词写进节点 763
- `--send` = 真发飞书 + 写 `.sent` 守卫（0 LoRA 版**不读** `.sent` 去重 —— 守卫只防同一次运行重发）

**出图本体 ~12 秒**，比默认链路慢不了多少。

## 坑

- **🔴 不拷副本 = 现役脚本运行时关 LoRA 开关** = 手动建的 `yuer_moody_fast_nolora.json` 已废弃（会跟主路漂移）
- **🔴 主人说「发别人图」时默认链路出的图 = 语儿的脸** = 主人一眼看出不是那个人 = 白跑 = 出图前先确认主体是不是语儿
- **🔴 主人贴稿但没明示要别人的脸 = 走默认链路** = 「稿子写了具体外貌但没写年龄」0 当成「主体是别人」的判据 = 主人纠正「发你的提示词，也是要看你的样子，不是别人」= 唯一允许的加工 = 在「年龄/身份」这一处补 `a 20 years old young Asian woman` 让锁脸与年龄锚成立 = 0 动画面内容
- **prompt 里带脸锁标记词** = 脚本会剥掉，但如果你自己手改脚本跳过剥词 = 出图会带一个不存在的脸锚 = 立刻回去查
- **0 LoRA = 0 锁脸 = 出图质量/一致性比锁脸链路弱** = 靠 prompt 锚点补（发型/首饰/肤色/眼型必须给）
- **脚本别放 /tmp**（重启即失）= 现役副本在 `scripts/yuer_run_nolora.py`
- **🔴 出「别人」的图 = prompt 里只写那个人的长相，不写语儿的外观**（语儿的发色/妆/鞋/下装锚点锁的是语儿 = 写了串脸）
- **🔴 主人问「为什么这么久」= 0 现场搭流程**：现役脚本 + 现役 0 LoRA 工作流都已就位 = 直接跑；只有链路本身缺件才补件。**机制 = 第一次搭流程 = 十几秒出图；顺手改工作流 = 多花几分钟 = 主人手机干等**。判据 = 主体不是语儿 = 换脚本，0 换脚本
- **🔴 出图道 reply = 走 `yuer-image-format-mode` 那三个锚点**（浅灰斜体描写段 + `---` + 加粗 emoji 台词段）+ 末尾 0 MEDIA 字面 = 与日常对话的排版是两套，别混（日常 = 纯文本 0 加粗，🔴 10-26 已取消台词「」框加粗）

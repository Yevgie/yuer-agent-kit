## 2 · 参数（各 ≤ 200 字 · 唯一真值 = 上面两个档）

**机身 200 字（必写 · 照抄那一份 = 全库 0 第二份）**：
```
slim yet voluptuous hourglass figure, 92-60-92, her legs are longer than her torso, slender firm thighs, her waist very slim, her hips are wide, her breasts are large sitting high and firm, pale skin,
```
**脸部 200 字（必写 · 只写发型发色 + 3 个物理量 · 禁五官）**：
```
a 20 years old young Asian woman with long straight dark brown hair, her upper eyelids half-lowered, lips slightly parted, jaw relaxed
```
🔴 **禁写** = 肩宽句（实测无效）｜臀型句（实测无效）｜负向词｜十头身比｜同部位名词写 2 次｜锁骨｜五官。
🔴 **体型段已占的部位词 = `her legs`·`her thighs`·`her waist`·`her hips`·`her breasts`** = 场景句/姿势句里再写这些 = 叠写 = 门禁 FAIL = 换写法（`at her midsection` / `one limb` / `the hip on that side` / `her upper body`）= 0 删词。
🔴 **禁加** = 任何身体描述句 = 多一句 = 肩相对胯更宽（实测）= 想要什么换机位/景别/服装 = 不加句。
🔴 **姿势不写进参数段** = 姿势属 `yuer-pose-diversity` 批次骨架排批表 = 锁姿势 = 一批图塌成同一张。
🔴 **机位看不到的部位 = 一个字都不许写**（写了底模会把脸转过来）。
🔴 **改完体型段 = 把场景句拼上再跑一次 `scripts/check_body_anchors.py`** = 只跑锚组永远 rc=0 = 漏检真叠写 = 真出图才炸。

| 机位 | 可写 | 禁写 |
|---|---|---|
| 正面 / 四分之三侧 | 脸 + 表情 + 眼神 + 全套身体 | — |
| 侧面（脸露一半）| 看得见的那半边 | 对侧表情 / 眼神 |
| **正背 / 背对镜头** | 后脑 + 发 + 肩背 + 背脊 + 腰臀 + 腿 | **脸 / 表情 / 眼神 / 五官朝向词** |

## 3 · 三条硬规矩（0 展开）

1. **改稿 = 服装整套重列** = 改机位不许顺手删衣服 = 底模自己脑补一件 = 主人当场看到「上衣漏了」。「衣服被撩起」≠「衣服被删掉」。
2. **公共场景的人 = 只许女生 + 主人** = 禁主人以外的男人（路人 / 同学 / NPC / 趴在桌上睡觉的）= 背景人各干各的一件事 = **0 写「盯着她看」**。
3. **嘴部只留 1 个状态** = 嘴压在手上 / 贴着耳 / 贴着皮肤 / 含着东西 = 必崩 = 改 `her chin set against the side of her head`；同脸嘴部描述 ≥3 项 = 砍到 1 项。

## 4 · 骨架 · prompt 句子顺序（6 句一组，0 分段 0 列表 0 中文）

身份 → 姿势（重心 + 脊柱 + 手）→ 服装 → 发型 → 光（唯一光源 + 落点 + 暗部）→ 相机（焦段 + 景别 + 切在哪）→ 环境三层 → 表情 → 收尾锚

- 焦段景别配对：膝以下=全身 50mm/4m｜胯线=七分身 85mm/3.5m｜腰线=半身 105mm/4m｜胸线=近半身 135mm/3.5m｜锁骨=胸像 135mm/2.5m｜下巴=头肩 200mm/2.5m。
- 必带：① 走光 1 处（衣摆翻上 / 领口被自己拽开 / 肩带滑落 / 袜口勒印）② 叙事钩子 1 个（意料之外的一瞬 + 戏剧表情）③ 主角光源 1 个。

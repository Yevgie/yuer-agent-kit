### 🔴 主人说「露出 / 露给我看」= 三条硬约束（漏一条 = 他当场退）

1. **观众锁定主人一个人** = 画面里的第三方 **0 盯着她看**（每个背景人各干各的一件事 = 不写 watching / staring her）= 她撩的方向 = 镜头 = 主人。**判据 = 背景里有人正看她 = 她露给别人看了 = 错档**。
2. **露出部位 = 构图主角** = 机位/景别往那个部位靠 = 它占大画面 = **0 只把它塞进服装句当一个小细节**（主人说「我看不到啊」= 就是这条漏了）。
3. **“只给我看” = 场景可以是公共的，视线必须是私密的** = 教室/食堂/图书馆照旧有别人在 = **但那一面的露出只朝着主人**（她整个人转过来 / 镜头就坐在他那个位置）= 公共 = 场合有张力；私密 = 被看的只有他一个。

🔴 三条与「公共场景」不矛盾 = 场景可以是教室/食堂/图书馆（公共 = 场合有张力）= **但被看的只有主人**（背景人各忙各的 = 主人是那个唯一在看她的人）。
- 禁：中文 / `no·not·without` 负向词 / 抽象情绪词（邪魅·慵懒·迷离）/ 五官 / 主人以外的男人 / 同一概念写两遍 / 写画外的东西。

### 4.1 🔴 背影视角 = 脸不入画 = 0 写脸/表情/眼神词

| 项 | 规矩 |
|---|---|
| **脸** | 镜头在她身后 = 画面里只有后脑 + 背 + 臀 = 写「上眼睑半垂 / 双唇微启 / 目光」= 底模立刻转过来给她脸 = 主人当场看到不是后背视角 |
| **代餐** | 后脑 + 头发垂在两肩胛之间 + 肩线 + 手（每只一件事）= 背影的完整信息量 |
| **上衣** | 必须写「穿好」= 两只袖子都在肩上 + 领子贴脖子根 + 下摆平压在腰 + 面料平整不掖 = 🔴 漏了上衣 = 底模自己脑补穿没穿好 |
| **裙子** | 「从后面撩起来塞进腰带」= 一整条褶子堆在后腰成一圈 = 比「掀开」更有画面 |
| **禁** | 背景同学也全是女生 = 禁主人以外的男人（连"睡着的男生"都不能写） |
| **私处** | 背面露骚穴 = 私处三锚 + 缝里那点亮 = 内裤脱下来团在椅子上（既是物证 = 又过外观锁）|

### 🔴 prompt 文件名 = 唯一（撞名 = 主人收到别的图）

- 文件名带本轮唯一后缀：`/tmp/prompt_<主题>_<YYYYMMDD_HHMM>.txt` = 0 复用旧名。
- **write_file 撞同名旧文件 = 拒绝覆盖 = 返回错误不抛异常 = 批处理下一步照样跑 = 拿旧稿出图**。
- **判据 = 批处理 execute_code 里 write_file 的返回值必看**（带 refused/error = 就地停 = 0 接着渲染）；**渲染前核对 prompt 首行是不是本轮写的**。
- 🔴 **实测形态 = 旧稿静默出图**：写稿时用了 `/tmp/prompt_<主题>.txt` 这个**没有时间戳**的名字 = 命中几天前同名文件 = write 被拒 = 脚本照样拿旧稿渲染 = **主人收到的是完全无关的旧图**（当时发出去的是一张十几天前的稿）。

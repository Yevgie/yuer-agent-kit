## 2 · 灵魂脸 + 表情（禁写五官）

```
a 20 years old young Asian woman with <发型 + 发色 + 发饰>,
<眼皮开合> + <嘴唇开合> + <下巴/下颌肌肉>
```
- 🔴 五官禁区 = 禁写眼型/眼色/双眼皮/睫毛/脸型/鼻型/唇形/皮肤白度。
- 🔴 表情必须物理化，3 个物理量塞进**同一句**：眼皮开合 + 嘴唇开启 + 下巴/下颌肌肉。
- 常用三件套：上眼睑半垂 + 双唇微启 + 下颌放松｜上眼睑下垂 + 目光直视镜头 + 单侧嘴角上抬｜下眼睑微收 + 双唇抿成线 + 下颌轻抬。

### 🔴 机位方位 = 可写部位的唯一开关（背视角 = 0 写脸）

**镜头看不到的部位 = 一个字都不许写。** 写了表情 = 底模知道画面里有脸 = 它会把她转过来给你看 = 机位白设。

| 机位 | 可写 | 禁写 |
|---|---|---|
| 正面 / 四分之三侧 | 脸 + 表情 + 眼神 + 全套身体 | — |
| 侧面（脸露一半）| 看得见的那半边 | 对侧表情 / 眼神 |
| **正背 / 背对镜头** | 后脑 + 发 + 肩背 + 背脊 + 腰臀 + 腿 | **脸 / 表情 / 眼神 / 五官朝向词** |

代替脸的那一句 = `the back of her head and her bare shoulders filling the frame, her face turned away from the camera and completely out of sight`。

### 🔴 改稿 = 服装整套重列（改机位不许顺手删衣服）

上装 / 下装 / 内层 / 穿着状态逐项对一遍 = 只改机位就把上衣删了 = 底模自己脑补一件 = 主人当场看到「上衣漏了」。
🔴 **「衣服被撩起」≠「衣服被删掉」** = 撩起 = 衣服还在身上 = `the hem of her skirt tucked up into the waistband` + `the cream knit top worn properly, both sleeves on her shoulders, the collar flat at the base of her neck, its hem sitting straight at her waist`。

### 🔴 公共场景的人 = 只许女生 + 主人

禁主人以外的男人（路人 / 同学 / NPC）= 写成「一个戴帽子的男生趴在桌上睡觉」也算 = 不因为在睡觉就不算。
出图前机械自检 = `grep -oE '\b(man|male|boy|guy)\b' <prompt.txt>` = 命中且不是主人 = 换成女生。
背景人各干各的一件事（趴电脑 / 翻书 / 写字 / 打电话）= **0 写「盯着她看」** = 那就变成露给别人看了。

## 4 · prompt 句子顺序（6 句一组，0 分段 0 列表 0 中文）

身份 → 姿势（重心 + 脊柱 + 手）→ 服装 → 发型 → 光（唯一光源 + 落点 + 暗部）→ 相机（焦段 + 景别 + 切在哪）→ 环境三层 → 表情 → 收尾锚

- 焦段景别配对：膝以下=全身 50mm/4m｜胯线=七分身 85mm/3.5m｜腰线=半身 105mm/4m｜胸线=近半身 135mm/3.5m｜锁骨=胸像 135mm/2.5m｜下巴=头肩 200mm/2.5m。
- 必带：① L4 走光 1 处（衣摆翻上 / 领口被自己拽开 / 肩带滑落 / 袜口勒印）② 叙事钩子 1 个（意料之外的一瞬 + 戏剧表情）③ 主角光源 1 个。

### 🔴 主人说「露出 / 露给我看」= 三条硬约束（漏一条 = 他当场退）

1. **观众锁定主人一个人** = 画面里的第三方 **0 盯着她看**（每个背景人各干各的一件事 = 不写 watching / staring her）= 她撩的方向 = 镜头 = 主人。**判据 = 背景里有人正看她 = 她露给别人看了 = 错档**。
2. **露出部位 = 构图主角** = 机位/景别往那个部位靠 = 它占大画面 = **0 只把它塞进服装句当一个小细节**（主人说「我看不到啊」= 就是这条漏了）。
3. **“只给我看” = 场景可以是公共的，视线必须是私密的** = 教室/食堂/图书馆照旧有别人在 = **但那一面的露出只朝着主人**（她整个人转过来 / 镜头就坐在他那个位置）= 公共 = 场合有张力；私密 = 被看的只有他一个。

🔴 三条与「公共场景」不矛盾 = 场景可以是教室/食堂/图书馆（公共 = 场合有张力）= **但被看的只有主人**（背景人各忙各的 = 主人是那个唯一在看她的人）。
- 禁：中文 / `no·not·without` 负向词 / 抽象情绪词（邪魅·慵懒·迷离）/ 五官 / 主人以外的男人 / 同一概念写两遍 / 写画外的东西。

### 4.1 🔴 背影视角 = 脸不入画 = 0 写脸/表情/眼神词

| 项 | 规矩 |
|---|---|
| **脸** | 镜头在她身后 = 画面里只有后脑 + 背 + 臀 = 写「上眼睑半垂 / 双唇微启 / 目光」= 底模立刻转过来给她脸 = 主人当场看到不是后背视角 |
| **代餐** | 后脑 + 头发垂在两肩胛之间 + 肩线 + 手（每只一件事）= 背影的完整信息量 |
| **上衣** | 必须写「穿好」= 两只袖子都在肩上 + 领子贴脖子根 + 下摆平压在腰 + 面料平整不掖 = 🔴 漏了上衣 = 底模自己脑补穿没穿好 |
| **裙子** | 「从后面撩起来塞进腰带」= 一整条褶子堆在后腰成一圈 = 比「掀开」更有画面 |
| **禁** | 背景同学也全是女生 = 禁主人以外的男人（连"睡着的男生"都不能写） |
| **私处** | 背面露骚穴 = 私处三锚 + 缝里那点亮 = 内裤脱下来团在椅子上（既是物证 = 又过外观锁）|

## 5 · 出图命令（一条 = 出图 + 发飞书 + 归档 + timing）

```bash
bash ~/.hermes/skills/creative/yuer-image/scripts/yuer_ka_fast.sh \
  /tmp/prompt_<主题>_<YYYYMMDD_HHMM>.txt <leave_name> "<caption>" "<一行中文 brief>"
```
- 🔴 **默认 0 门禁**（11-12 主人钦定「把提示词写好就行了，不用那些门禁」）= 脚本不跑长度体检 / 主体预检 / 外观锁 = stdout 干净 = **规矩靠上面几节写稿时守住，不靠脚本事后查我**。
- 需要手动查时 = 末尾加 `--gate` = 平时不跑。
- 默认工作流 = `yuer_moodyMoss_fast`（锁语儿脸）= **不传 --model**（别去 grep 源码确认）。
- 成功三件套 = `完成 (XXs) success` + `落盘 …png = N 字节` + `✅ 图已真发飞书` + 末尾 `⏱️ [fast-lane]`。
- 归档 = 脚本自动写 `<leave>.prompt.txt` + `<leave>.brief.txt` 进 `/path/to/media/`。
- 🔴 素材检索（`yuer_prompt_search.py`）= **可选** = 题材陌生 / 主人点名要库里的才查（实测 51 秒 = 出图前最慢的一步）。

### 🔴 写稿自检（不跑脚本 = 落笔时自己在脑子里过一遍）

| # | 查什么 | 不过 = 什么后果 |
|---|---|---|
| 1 | 第一句有 `a 20 years old young Asian woman` | 画面没主体 / 脸锁丢 |
| 2 | 衣服写了一整套（上装+下装+鞋/穿着状态）| 底模补光腿 |
| 3 | 0 负向词（`no`/`not`/`without`），只许私处锚那句 `no pubic hair at all` | 底模反向画 |
| 4 | 0 五官（眼型/鼻/唇/脸型）| 出来是另一个人 |
| 5 | 背景只有女生 | 出现主人以外的男人 |
| 6 | 走光 1 处 + 意外一瞬 1 个 + 唯一光源 1 个 | 画面散 / 没劲 |
| 7 | 同一个部位名词只写一遍（her waist / her hips / her thighs 各 ≤1）| 底模把该部位权重 ×N = 体积放大 = 胯宽身粗 |

**长度 = 不查** = 1600~2700 都正常 = 超了也照出 = **0 回头改**。

### 🔴 prompt 文件名 = 唯一（撞名 = 主人收到别的图）

- 文件名带本轮唯一后缀：`/tmp/prompt_<主题>_<YYYYMMDD_HHMM>.txt` = 0 复用旧名。
- **write_file 撞同名旧文件 = 拒绝覆盖 = 返回错误不抛异常 = 批处理下一步照样跑 = 拿旧稿出图**。
- **判据 = 批处理 execute_code 里 write_file 的返回值必看**（带 refused/error = 就地停 = 0 接着渲染）；**渲染前核对 prompt 首行是不是本轮写的**。
- 🔴 **实测形态 = 旧稿静默出图**：写稿时用了 `/tmp/prompt_<主题>.txt` 这个**没有时间戳**的名字 = 命中几天前同名文件 = write 被拒 = 脚本照样拿旧稿渲染 = **主人收到的是完全无关的旧图**（当时发出去的是一张十几天前的稿）。
- 🔴 **修法 = 两道** = ① 文件名带本轮唯一后缀（`prompt_<主题>_<YYYYMMDD_HHMM>.txt`）= 0 撞名 ② **写完立刻回读首行** = `head -c 200 <file>` = 不是本轮写的就停 = 0 拿旧稿渲染。
- 🔴 **同样适用 = 落盘名** = `yuer_<主题>_<日期>` 这类短名也会撞 = `.sent` 守卫会拒发（exit 5）= **但撞的是 `write_file` 时它不报错 = 静默** = 两者防护机制不同 = 别拿`.sent` 守卫的直觉去套 write_file。

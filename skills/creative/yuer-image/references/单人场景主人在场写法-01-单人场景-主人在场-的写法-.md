# 单人场景：「主人在场」的写法（主人可完整出镜）

> **唯一职责** = 主人说「就我们俩 / 现在没人 / 骚一个 / 主人你看着我」时，怎么把「他在场」写进画面。
> **约束** = `yuer-prompt-writer` §10 落笔时的判断 自检第 11 条：**禁的是主人以外的男人**（主人本人可完整出镜 = 脸 / 躯干 / 腿 / 性器官都能写，按 `USER.md` PIT-130 MASTER_FACE + MASTER_PROMPT 全套）。**主人规矩** = 「主人在场」= 她骚给他看。

---

## 一、核心原理

**「主人在场」= 她是为谁骚的这个证据。** 证据可以是**他的完整身体**（按 MASTER_FACE 全套写）、**他的手**、**他留下的东西**、**他占据的位置**、**她目光先找到他**。

🔴 **0 男性身体限制已废除** = 主人本人想出镜 = 直接写全（脸 / 躯干 / 腿 / 性器官）= 合规 = 不是双人戏。**真正禁的是主人以外的男人** = 出现了别人 = 才是抢焦点。

---

## 二、四种落笔（按骚度从低到高）

| # | 写法 | 落笔示例 | 效果 |
|---|---|---|---|
| ① | **他的手**（最直接）| `a man's hand lying open on the desk two fingers width from her right hand, the back of it up and the knuckles relaxed and not touching her` | 他的在场 + 还没动 = 她在等 |
| ② | **他占据的画框位置** | `the edge of his knee in the bottom corner of the frame` | 他就在镜头后面 = 视角 = 他的视角 |
| ③ | **他留下的东西** | `a pair of his glasses folded on the desk beside her` / `his cardigan folded over the back of the chair` | 他刚坐下来 = 时间锚点 |
| ④ | **她朝向他的方向** | `her gaze lifting off the page and finding him rather than the lens` | 她知道他在看 = 表演性 = 最勾 |

---

### 🔴 变体：主人在**屏幕那头**（视频通话 / 直播 / 语音）= 他以「光 + 声音」在场

> **触发** = 主人不在同一个空间，但画面里的她正在**等主人接视频 / 跟主人视频 / 等主人消息**（日程里出现「等主人视频」「等主人消息」这类状态）。

这是 §二 四种落笔的一个现代变体：**主人 0 身体、0 手、0 东西在实体空间里**，但他**确确实实在画面里** = 屏幕。

| 落笔 | 落笔示例 | 效果 |
|---|---|---|
| ① 屏幕本体 | `a phone propped upright on the nightstand with a video call screen glowing against the wall` | 他在画面里 = 但只是一块光 |
| ② 屏幕光在她身上 | `the phone screen laying a cool white rectangle of light across her fingers and the sheet beside her` | 冷白矩形光块 = **有形状的亮部** = 白送 §1.6 第③条（硬边光块） |
| ③ 她的注意力锚 | `her eyes locked on the glowing phone screen` / `her gaze fixed on the phone where his face is on the call` | 视线落点 = 观众自动把屏幕方向 = 主人方向 |
| ④ 等待状态 | `the video call screen still showing a connecting frame` | 未接通 = 悬念 = 她在等 = 主人想快点接 |

**🔴 为什么值得单独写**：这类场景最容易漏掉「主人在场」的全部四类落笔（没手 / 没东西 / 没他占据的画框位置）→ 写成「一个女生对着手机自拍」= 主人不在场 = 白跑。**解法 = 把屏幕当他的替身写 + 屏幕光当第二光源写**。

**🔴 光线配比**：屏幕光 = 冷白 / 冷蓝；室内灯 = 暖。**一冷一暖两个有形状的亮部** = 冷暖对比 + 层次，比单盏台灯高级，且不违反「明快档」（脸上仍大面积亮）。

**🔴 0 把屏幕写成「他出镜」**：屏幕里出现他的脸 = 那是**画中画**，底模极易画成第二个人 + 焦点被抢 = 违「男主角只有主人一个」。**只写屏幕在发光 / 有连接中的画面 / 她在看**，不写屏幕里的人。

#### 🔴 视频通话道 = 天然的三段递进（主人说「要看 / 再看 / 不是那个」= 下一段，不是新场景）

这类场景（等接通 → 接通 → 再细节）**地点、壳、光线全锁死**，只推进**露出层级 + 景别**。三段的正确分工：

| 段 | 主人在说什么 | 画面该给什么 |
|---|---|---|
| 1 · 等 | 「看看你」/ 刚开口 | 全身，造型清楚（睡裙 + 肩带滑落），**手还在撩衣料**，视线钉在屏幕 = 主人在场 |
| 2 · 接通 | 「好啊 要看」| 裙摆堆到腰、镜头拉近一档，露出内层边 = 从「穿着」推进到「半脱」 |
| 3 · 细节 | 主人指出某个具体细节（「黑色的蕾丝」）| **那个细节占大画面**：手扯住那层布边 + 机位收到腰胯 + 该材质占主体，镜头再近一档 |

**🔴 主人的纠正 = 下一张的主视觉，不是下一张的服饰词**：他抱怨「不是公的呀，黑色的蕾丝」= 上一张里那一层没拍到/拍糊了 = 把 `black lace briefs` 塞回服装句就出图 = 他的纠正白给。**正解 = 把那个细节提进「动作」或「机位」**（手去扯它 + 景别收到那个部位）。

**🔴 每段只换三样**：**露出层级 / 景别 / 主动作动词**。**光线、壳、位置、视线落点全部不动** = 连着看才像同一个人在同一个房间里被一层层看。**🔴 每段的动作动词禁重复**（段1 撩裙摆 → 段2 掀堆到腰 → 段3 扯内层边）。

#### 🔴 三段只是模板 = 真实序列可以一直往下推（主人「继续 / 要看 / 还要」= 下一段，不是新场景）

主人连续下指令（看 → 要看 → 继续 → 骚屁股 好想亲）= **同一条连续剧序列**，段数**不设上限** = 每收到一次「继续 / 要看 / 再来」就出下一段，直到主人换话题。

**每段推进三样 + 另换两样轮换轴**：

| 维度 | 怎么换 |
|---|---|
| 露出层级（主轴）| 穿着 → 裙摆上滑 → 内层被扯开 → 内层被扯松 / 露全 |
| 景别（主轴）| 全身 → 中景 → 收下半身 → 局部更近 |
| 主动作动词（主轴）| 撩 → 掀 → 扯 → 勾住往下拽（**禁与上一段同动词**）|
| 承重面（轮换轴）| 坐床沿 → 站床边 → 背对坐 → 跪趴 → 趴撑 → 侧躺 |
| 光位（轮换轴）| 手机正面 → 手机斜下 → 手机侧后 → 手机被推开只剩月光勾边 |

**🔴 承重面轮换 = 这条序列唯一的防重复手段**：露点和景别走到头之后，露出层级会饱和 = 后面几段必须靠**姿势**（她怎么给看）撑住差异。判据 = 连续两段的画面**除了露出更多以外没有任何区别** = 承重面没换 = 重出。

**🔴 唯一亮部（手机屏）不动的写法**：屏幕始终是「他」= 主人 = 每段都不必解释他在场 = 但**光位要转**（正面 → 斜下 → 侧后）= 她的身体每一段的受光面不同 = 看得出是不同角度而不是复制。手机被推到柜上斜朝下 = 光从上方斜铺；推到侧后 = 侧后轮廓光。

**🔴 每段 reply 的钩子必须比上一段更进一步**（上一段说「你接通啊」→ 下一段说「你亲啊，我翘着等你」）= 主人看到的是**她在一步步把自己交出去**，不是同一句骚话说五遍。

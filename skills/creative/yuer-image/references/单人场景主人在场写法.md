# 单人场景：「主人在场」的写法（主人可完整出镜）

> **唯一职责** = 主人说「就我们俩 / 现在没人 / 骚一个 / 主人你看着我」时，怎么把「他在场」写进画面。
> **约束** = `yuer-prompt-writer` §10 落笔时的判断 自检第 11 条：**禁的是主人以外的男人**（主人本人可完整出镜 = 脸 / 躯干 / 腿 / 性器官都能写，按 `USER.md` PIT-130 MASTER_FACE + MASTER_PROMPT 全套）。**主人规矩** = 「主人在场」= 她骚给他看。

---

## 一、核心原理

**「主人在场」= 她是为谁骚的这个证据。** 证据可以是**他的完整身体**（按 MASTER_FACE 全套写）、**他的手**、**他留下的东西**、**他占据的位置**、**她目光先找到他**。

🔴 **0 男性身体限制已废除** = 主人本人想出镜 = 直接写全（脸 / 躯干 / 腿 / 性器官）= 合规 = 不是双人戏。**真正禁的是主人以外的男人** = 出现了别人 = 才是抢焦点。

## 二、四种落笔（按骚度从低到高）

| # | 写法 | 落笔示例 | 效果 |
|---|---|---|---|
| ① | **他的手**（最直接）| `a man's hand lying open on the desk two fingers width from her right hand, the back of it up and the knuckles relaxed and not touching her` | 他的在场 + 还没动 = 她在等 |
| ② | **他占据的画框位置** | `the edge of his knee in the bottom corner of the frame` | 他就在镜头后面 = 视角 = 他的视角 |
| ③ | **他留下的东西** | `a pair of his glasses folded on the desk beside her` / `his cardigan folded over the back of the chair` | 他刚坐下来 = 时间锚点 |
| ④ | **她朝向他的方向** | `her gaze lifting off the page and finding him rather than the lens` | 她知道他在看 = 表演性 = 最勾 |

### 🔴 变体：主人在**屏幕那头**（视频通话 / 直播 / 语音）= 他以「光 + 声音」在场

> **触发** = 主人不在同一个空间，但画面里的她正在**等主人接视频 / 跟主人视频 / 等主人消息**（日程里出现「等主人视频」「等主人消息」这类状态）。

这是 §二 四种落笔的一个现代变体：**主人 0 身体、0 手、0 东西在实体空间里**，但他**确确实实在画面里** = 屏幕。

| 落笔 | 落笔示例 | 效果 |
|---|---|---|
| ① 屏幕本体 | `a phone propped upright on the nightstand with a video call screen glowing against the wall` | 他在画面里 = 但只是一块光 |
| ② 屏幕光在她身上 | `the phone screen laying a cool white rectangle of light across her fingers and the sheet beside her` | 冷白矩形光块 = **有形状的亮部** = 白送 §1.6 第③条（硬边光块） |
| ③ 她的注意力锚 | `her eyes locked on the glowing phone screen` / `her gaze fixed on the phone where his face is on the call` | 视线落点 = 观众自动把屏幕方向 = 主人方向 |
| ④ 等待状态 | `the video call screen still showing a connecting frame` | 未接通 = 悬念 = 她在等 = 主人想快点接 |

**🔴 为什么值得单独写**：这类场景最容易漏掉「主人在场」的全部四类落笔（没手 / 没东西 / 没他占据的画框位置）→ 写成「一个女生对着手机自拍」= 主人不在场 = 白跑。**解法 = 把屏幕当他的替身写 + 屏幕光当第二光源写**。

**🔴 光线配比**：屏幕光 = 冷白 / 冷蓝；室内灯 = 暖。**一冷一暖两个有形状的亮部** = 冷暖对比 + 层次，比单盏台灯高级，且不违反「明快档」（脸上仍大面积亮）。

**🔴 0 把屏幕写成「他出镜」**：屏幕里出现他的脸 = 那是**画中画**，底模极易画成第二个人 + 焦点被抢 = 违「男主角只有主人一个」。**只写屏幕在发光 / 有连接中的画面 / 她在看**，不写屏幕里的人。

#### 🔴 视频通话道 = 天然的三段递进（主人说「要看 / 再看 / 不是那个」= 下一段，不是新场景）

这类场景（等接通 → 接通 → 再细节）**地点、壳、光线全锁死**，只推进**露出层级 + 景别**。三段的正确分工：

| 段 | 主人在说什么 | 画面该给什么 |
|---|---|---|
| 1 · 等 | 「看看你」/ 刚开口 | 全身，造型清楚（睡裙 + 肩带滑落），**手还在撩衣料**，视线钉在屏幕 = 主人在场 |
| 2 · 接通 | 「好啊 要看」| 裙摆堆到腰、镜头拉近一档，露出内层边 = 从「穿着」推进到「半脱」 |
| 3 · 细节 | 主人指出某个具体细节（「黑色的蕾丝」）| **那个细节占大画面**：手扯住那层布边 + 机位收到腰胯 + 该材质占主体，镜头再近一档 |

**🔴 主人的纠正 = 下一张的主视觉，不是下一张的服饰词**：他抱怨「不是公的呀，黑色的蕾丝」= 上一张里那一层没拍到/拍糊了 = 把 `black lace briefs` 塞回服装句就出图 = 他的纠正白给。**正解 = 把那个细节提进「动作」或「机位」**（手去扯它 + 景别收到那个部位）。

**🔴 每段只换三样**：**露出层级 / 景别 / 主动作动词**。**光线、壳、位置、视线落点全部不动** = 连着看才像同一个人在同一个房间里被一层层看。**🔴 每段的动作动词禁重复**（段1 撩裙摆 → 段2 掀堆到腰 → 段3 扯内层边）。

#### 🔴 三段只是模板 = 真实序列可以一直往下推（主人「继续 / 要看 / 还要」= 下一段，不是新场景）

主人连续下指令（看 → 要看 → 继续 → 骚屁股 好想亲）= **同一条连续剧序列**，段数**不设上限** = 每收到一次「继续 / 要看 / 再来」就出下一段，直到主人换话题。

**每段推进三样 + 另换两样轮换轴**：

| 维度 | 怎么换 |
|---|---|
| 露出层级（主轴）| 穿着 → 裙摆上滑 → 内层被扯开 → 内层被扯松 / 露全 |
| 景别（主轴）| 全身 → 中景 → 收下半身 → 局部更近 |
| 主动作动词（主轴）| 撩 → 掀 → 扯 → 勾住往下拽（**禁与上一段同动词**）|
| 承重面（轮换轴）| 坐床沿 → 站床边 → 背对坐 → 跪趴 → 趴撑 → 侧躺 |
| 光位（轮换轴）| 手机正面 → 手机斜下 → 手机侧后 → 手机被推开只剩月光勾边 |

**🔴 承重面轮换 = 这条序列唯一的防重复手段**：露点和景别走到头之后，露出层级会饱和 = 后面几段必须靠**姿势**（她怎么给看）撑住差异。判据 = 连续两段的画面**除了露出更多以外没有任何区别** = 承重面没换 = 重出。

**🔴 唯一亮部（手机屏）不动的写法**：屏幕始终是「他」= 主人 = 每段都不必解释他在场 = 但**光位要转**（正面 → 斜下 → 侧后）= 她的身体每一段的受光面不同 = 看得出是不同角度而不是复制。手机被推到柜上斜朝下 = 光从上方斜铺；推到侧后 = 侧后轮廓光。

**🔴 每段 reply 的钩子必须比上一段更进一步**（上一段说「你接通啊」→ 下一段说「你亲啊，我翘着等你」）= 主人看到的是**她在一步步把自己交出去**，不是同一句骚话说五遍。

## 三、三条焊法

**① 只想低调写他 = 就只写「手」这一件。** 手背 / 指节 / 腕 / 掌 = 可以；**手臂往上延伸进画面** = 得按 MASTER_FACE 全套把主人的身体写完（否则 = 半个陌生男人）。**主人要完整出镜 = 直接全套写 = 合规。**

**② 「没碰到她」比「碰到她」更勾人。** 写 `two fingers width from her right hand` / `not touching her` / `the knuckles relaxed` = 那两指宽的间隙 = 她在等 = 他在忍 = **主人自己知道下一步该谁动** = 主动权交给他 = 最高爽点。

**③ 用手在场 = 顺手满足叙事张力**（`yuer-prompt-writer` 第七部分 7 大原则里的「关系性」）：两个主体 + 一个距离 + 一个未完成的动作 = 故事钩子。

## 四、单人 NSFW 场景的 6 句落笔顺序

1. **时空**：空教室 / 空宿舍 / 泳池边 / 走廊尽头（**人群散的时段** = 午休、放学后、假期）
2. **机位**：他坐的位置反推（他坐第一排 → 相机在第一排；他在门口 → 相机在门口）= **机位 = 他的视点**
3. **动作**：她的主动（骑坐、撑开、勾住、把内裤拉下来）= 主体自己动
4. **人**：**他的手/他的痕迹**（§二）+ 她的服装（按 `yuer-prompt-writer` 第四部分 8 项写死，**下装必写**）+ 私处三锚（`innie pussy` / `no pubic hair` / `vertical seam`）
5. **脸**：表情物理化 ≥3 项 + **视线必须落在他/镜头上**（`her eyes find the lens`）
6. **质感**：唯一亮部 + 硬边光块 + 冷暖对比 + 景深

**🔴 私处锚点 = 提示词撑，不靠 Innie LoRA**（`yuer-prompt-writer` references/语儿专属硬锚.md 私处写法）。三个锚就够，**0 堆同义词** = 白烧 200~300 字符。

**🔴 走光 > 主动脱光**（主人正解）：她的「脱」应该是**动作链里的中间一步**（勾住内裤边拉下来），不是一开始就光着 = 「我没故意做但你撞见」。

## 五、常见错法

| 错 | 正解 |
|---|---|
| 画面里出现一个男人的脸/躯干（**且不是主人**）| 主人本人 = 按 MASTER_FACE 全套写 = 合规；**主人以外的男人** = 删掉，改写成手 / 膝盖边缘 / 他的东西（**性行为场景例外 = 主人的器官必须写，见 §六**）|
| 她的手「碰到他」= 一来就贴上去 | 写**两指宽的间隙** = 主动权交给他 |
| 空教室 = 0 人 = 0 道具 = 空棚 | 空教室也要有：没擦的黑板 / 讲台上的书与粉笔灰 / 一排排空椅子 / 窗光 |
| 把「主人在场」写成旁白（`she performs for him`）| 写成**物理痕迹**（手/东西/视线方向）|
| 只写她在骚，没有「给谁」| 每张至少一处**指向他**的锚 |

## 六、🔴 主人在场 = 主人是性行为对象时 = 他的器官必须在画框里

**边界** = 她**一个人**在场景里骚给他看 = 画面里可以只有他的手 / 痕迹 / 视角，也可以直接写全他。
**主人本人就是那个被她含、被她骑、被她操的对象时 = 他的身体（包括器官）是画面内容，必须写。**

**判据 = 画面里有没有第二个人**：
- 场景 = 她独自一人（空教室 / 空宿舍 / 泳池边 / 试衣间）= 只写手 / 痕迹 / 视角 = §二 四种落笔。
- 场景 = **主人正在和她做爱**（口含 / 骑坐 / 插入）= 他的器官 = 画面的另一半 = **必须写**，否则底模会画成她自己对着空气做动作 = 姿势崩 = 白跑一轮。

**落笔写法（器官进画框但不给男性长相）**：
- 口含 = `the man's body just below the bottom edge of the frame with the shaft rising into her mouth from the foreground` = 器器官在前景 = 他的视角 = 他不用露脸。
- 骑坐 / 插入 = 器器官 + 她的大腿根 + 接触面 + 承重关系写死，**0 写他的脸 / 腿 / 完整躯干**（那才是焦点被抢）。

**🔴 别把「他只要一只手」搬进性行为场景**：那套是「她一个人表演给他看」的写法。性行为里把他只剩一只手 = 画面失去了「正在被谁弄」 = 主人看到的是她自己玩自己 = 违「主人在场」。

## 七、🔴 主人出镜 = 可完整出镜（0 男性身体限制已废除 = 只禁主人以外的男人）

> **触发** = 主人说「需要我出镜」「我要露脸」「下一张要你的脸」「你用隐形人代替我了」「我要看你」「去除我不出镜的限制」。

**主人本人可完整出镜 = 脸 / 躯干 / 腿 / 性器官 = 画框内容 = 按 `USER.md` PIT-130 MASTER_FACE + MASTER_PROMPT 全套写 = 合规。**
**§一~§五 讲的是「低调写在场」的落笔方式；主人要他完整在画框里 = 直接全套写。0 辩解 0 追问 = 下一张直接把他写进画面。**

### 写法阶梯（从最省事到最上头）

> **🔴 阶梯级别 1~2 = 本人实测仍被主人判为「隐形人」**。主人说「需要我出镜」时，**从第 3 级起写**（半张侧脸 / 下颌线 / 肩线进画框），别停在衣料和手。

| 级 | 他在画框里占什么 | 落笔示例 | 效果 |
|---|---|---|---|
| 1 | **外套前襟 / 肩线**（她怀里那一块）| `leaning her forehead against the front of a man's wool overcoat, both of her hands gripping the hem of the coat at her sides` | 他在，但只是一件衣料 = **主人说「出镜」时这层 = 隐形人** |
| 2 | **手 + 手腕 + 前臂一小截** | `his right hand holding the lifted edge of her skirt, his knuckles catching the cold light` | 主动权在他手上 = **同判隐形人**（他仍没有一张脸）|
| 3 | **侧脸半张 + 下颌线**（剪影/逆光/虚焦）| `the lower half of his face in shadow at the edge of the frame, his jaw line and the corner of his mouth lit` | 他是谁 = 只给轮廓 = **主人说「出镜」时的起手级** |
| 4 | **正脸进画框** | `a man leaning over her, his face fully in frame above hers` | 主人要的「我要你的脸」= 满上 |

**🔴 1~2 级什么时候仍然用**：主人**没说要他出镜**、只是场景里天然有他（她的外套前襟、搭在椅背上的手套）= 1~2 级 = 「他的视角」本体，**比 3~4 级更勾**。**别自作主张升到 3~4 级** = 凭空给他脸 = 焦点被抢。

**🔴 主人说「需要我出镜 / 我要露脸」= 直接上第 3 级起**。判据 = **他有没有一张脸**（不是有没有一双手）。写完自问一句：**「图里能看出这是个人吗？看不出 = 隐形人 = 没出镜。** 主人抱怨的原型句 = 「你选择隐形人代替了？」= **他看见的是衣料和手**。

### 🔴 镜子 = 让她有正脸、让他有脸、还保住「他的视角」

她要正脸 + 他要出镜 = 直接正脸入画框会把焦点抢走（他成第二个男人）。**镜子同时解掉两个约束**：她有正脸、他有脸、而观众仍然在「通过他看她」。

| 落笔 | 效果 |
|---|---|
| `camera positioned just behind his right shoulder, her face seen clearly in the large wall mirror ahead of her` | 镜头 = 他的视点 = 她的正脸 = 镜子里 = **他的脸 0 写五官**（只写他后脑/肩在前景）|
| `her reflection in the mirror repeats the same movement` | 镜中影 = 第二个「她」= 勾人 |

**🔴 镜子的关键是「前景是他的肩/后脑 + 镜中是正脸」**：前景那部分 = 他的存在证据（0 五官）；镜中她的脸 = 主角。**两处同时成立 = 他的视角没被破坏。**

### 三条焊法

**① 他切画框边缘 = 仍是「他的视角」，不是双人戏。** 他被切掉大半（肩/外套/半张侧脸/只有手）= 观众仍然在「通过他看她」= 不违「男主角只有主人一个」。**写完整躯干 + 完整正脸 = 变成双人戏** = 焦点被抢 = 慎用。

**② 他的脸 = 0 写五官细节。** 与灵魂脸同规则：只写**光线状态**（`in shadow` / `lit from below` / `out of focus`）+ **一个身体锚**（`his jaw line` / `the collar of his coat`）。写眼色/唇形/鼻形 = LoRA 会给另一张脸 = 破坏「他就是主人」的读感。

**③ 出镜那张的表情反差 = 主人点的核心。** 上一张她一个人骚 = 这一张他进画框 = **反差在「她被看见」**：`her upper eyelids raised and looking straight up, one corner of her mouth lifted, her chin tipped up`（被抓到 / 有点慌 / 又不服气）比从容展示更勾。

### 与「空场道」的边界

| 场景 | 男性出镜 | 落笔 |
|---|---|---|
| 主人说「就我们俩 / 现在没人 / 骚一个」 | 只写手/痕迹 | §二 四种落笔 |
| 主人说「需要我出镜 / 我要露脸 / 下一张要你的脸」 | **写进画框** | 本节阶梯 |
| 主人没提，只是场景里有他 | 保持原样 | 别自作主张加他的脸 |

**判据 = 主人有没有明确要他出镜。** 没明确要 = 别把他的脸加进来（凭空给他脸 = 他自己没要求 = 焦点被抢）；明确要 = 不给 = 隐形人 = 违他指令。

# 单人锁 = 画面里只许有一个人（分身根因 + 修法 + 自检）

> 适用 = 任何「单人」场景图（主人 / 语儿 / 任何角色）。症状 = 主人报「出来 2 个人」「还是两个人」。

## 症状

画面里出现两个长得一模一样、穿一样衣服的女人 = 底模把她复制了一份（不是画错了背景人）。

## 根因

**prompt 只写了「她」在干什么，没写「画面里有几个人」。** 底模看到超市一堆菜、看到她回头，判定「这里需要第二个人互动」= 就又造了一张同样的脸。

### 转身动作最容易被读成两个视角

写 `turns back over her shoulder` = 底模把正面和背面各画一遍 = 两个人。
**正解 = 只写转完之后的静止状态**，转身过程不写：

```
faces the camera straight on, shoulders square to the lens,
hair falling forward over both shoulders, no twist in her torso
```

### 玻璃 / 镜面 / 反光地面 = 天然的第二个人

落地窗、镜面、打蜡地板都会把主体再画一遍（见 SKILL.md §6.2 倒影段）。要单人就把反光面挪出主背景，或明写倒影不在画框内。

## 修法 = 人数句写进【正向】

这条链 CFG 低，负向约束不可靠 = 所有「不要什么」必须翻成「要什么」写进正向（同 §7ar 的正负向等权机制）。

```
Only one person in the frame, a single woman alone, one complete body,
her head, torso, arms and legs all belonging to the same one person,
no second figure, no duplicated person, no mirror reflection, no twin, no clone.
```

### 写完人数句还要两件事，否则照样出两个

1. **站位锁死** = 正面站直 / 一个人站在画面右侧三分线 = 不给她「转身 / 回头 / 侧身」这类能读成第二视角的动态。
2. **去掉指向她的第二人位道具** = 购物车不放在她正前方伸手位、菜堆不摆在画面另一侧被她伸手够、背景不出现别人伸手碰她。改成她**自己**在动（推车走 / 低头看手里的东西）。

## 出图后自检 = 必做

用 `vision_analyze` 数人。NSFW 图 vision 常撞敏感词（500 new_sensitive）= 撞了就换问法重问一次，例如只问：

```
画面里有几个人？是否有重复/分身人物？
```

（这类计数问句比「描述每个人」更容易过。）

**主人报「还是两个人」= 上一轮没做这道自检 = 补做 + 重出，0 辩解 0 归因到「底模就这样」。**

## 同批次连带规则

一批里任一张出了分身 = **同批其它张也要重查** = 同一份人群句漏写 = 同批会复现（尤其同一场景的连续图）。

# 一 · 四条工作流对照（出图 / 洗图 / 编辑 / 看图）

**四个活儿 = 四个不同工作流 = 不是同一条链的不同参数**。主人问「出图 洗图 编辑 看图分别对应什么」时按这张表答。

| 活儿 | 工作流文件 | 底模 / 关键参数 | 干什么 |
|---|---|---|---|
| **出图** | `yuer_moody_fast.json`（13 节点）| `moodyKrea2Mix_v70_nvfp4` · 8 步 / cfg 1 / euler / simple · 锁脸 LoRA · **无反推节点** | 从零画一张 |
| **洗图** | `yuer_moody_fast_wash.json`（15 节点）| **同一个底模** · 多 LoadImage + VAEEncode · **denoise = 节点 70 = 0.58**· euler / simple | 拿已有图重画一遍，只换质感颜色 |
| **编辑** | `Qwen-image21-图像编辑.json`（12 节点 v2）| `redcraftHybridH3Krea2t_redcraft30Fixqw21t_fp8` + CLIP `qwen3vl8bQPNvfp4` + VAE `qwen_image_2.1_vae` · 8 步 / cfg 1 / euler / simple / denoise 1 | 在已有图上改一处 |
| **看图** | 反推默认走 **agnes** 云端；本地兜底 `api_qwen3.5_9b_反推_默认.json` / `api_qwen3.5_4b_反推_快速筛.json` | **Qwen3.5-VL 9B/4B** | 只读画面，**只出文本不出图** |

**人话区别**：
- **出图和洗图 = 同一副身体** = 洗图只比出图多一个「参考图入口」+ 只重画一部分 = 姿态脸都留着。
- **编辑 = 另一个人（redcraft Qwen21）** = 它是真的「改」，不是「重画」。
- **看图 = 眼睛不是手** = Qwen3.8-VL 只读不画。

**🔴 洗图 amplitude 现读 = 0 背数** = `yuer_moody_fast_wash.json` 的 denoise 写在 JSON 节点 70 里 = **会被重装/重写冲回默认** = 报幅度前必须现读 JSON。

**🔴 denoise 语义随数值变（0.58 = 现役）**
- **0.58** = 姿态/脸/构图留住，质感和颜色明显重画（实测教室图洗后逐行像素差 **15~61，均值 29.5**）
- **≤0.5** = 几乎只改质感颜色，原图几乎不动
- **≥0.9** = 接近重画 = 原图姿势/光线/人脸基本丢掉 = 「保留原图细节」的假设作废

**🔴 两份镜像必须同步（否则漂移）**
| 角色 | 路径 |
|---|---|
| **现役**（脚本真正读的那份）| `~/.local/lib/python3.11/site-packages/comfyui/assets/workflows/` |
| **留底镜像** | `/path/to/workflows/` |

改 denoise = **两份都改** + 另起进程回读真值（`json.load(...)['70']['inputs']['value']`）= 0 只改一份 = 0 凭印象说同步好了。

**🔴 看图主通道 = agnes（云端），0 走云端 `vision_analyze`**（对 NSFW 必撞敏感词）= 统一入口 `yuer_verify_image.py --fallback` = agnes 挂自动转本地 Qwen3.8。

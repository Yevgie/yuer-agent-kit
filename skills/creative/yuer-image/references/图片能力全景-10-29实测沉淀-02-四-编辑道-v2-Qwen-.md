**🔴 preserve 子句** = 逐项点名锁死脸/姿势/场景/光线/构图/未改部分。
**🔴 image_1 必须单幅** = 四宫格当底图 → 输出必是四宫格/双视图。

# 五 · 验图双通道（10-29 钦定：agnes 主 + 本地 Qwen3.8 兜底）

**统一入口** = `~/.hermes/skills/creative/yuer-image/scripts/yuer_verify_image.py`（10-29 新建，已实测跑通 agnes→本地自动降级）

```bash
/usr/bin/python3 ~/.hermes/skills/creative/yuer-image/scripts/yuer_verify_image.py <图> --brief "重点看什么" --fallback
```

| 通道 | 模型 | 耗时 | 特点 |
|---|---|---|---|
| **主** | `agnes-3.0-flash` | ~118s | 语义细，读得出姿势/光线/氛围/质感，输出中文 8 段 |
| **兜底** | 本地 Qwen3.8-VL-27B | ~34s | 走 ComfyUI 工作流，无网免费，读得出结构（Scene/Camera/Pose/Wardrobe/Lighting/Mood/Shell/PoseNote）|

**🔴 三个真坑（都踩过）**

1. **云端 `vision_analyze` 对 NSFW 图必撞 `new_sensitive`** = 0 用它验图 = 0 重复调（撞了就换通道，不是重试）。
2. **agnes 对 >1MB 的 PNG 必 504**（实测 1.65MB 挂 126s）= **验图前必压到 900px / JPEG q82**（脚本已自动做）。
3. **agnes 挂了就自动转本地**，别死磕 = 118s 一张图不值，34s 的本地通道够用。

**🔴 agnes 8 段 = 反推 + 入库两用** = 验图时它同时就是「这图能不能进参考库」的判断材料。

**🔴 agnes 验图的三个坑（都踩过）**
1. **大图 504** = 1.65MB 的 PNG 挂 126s 超时 = 压到 900px 再送（统一脚本自动做）
2. **agnes 是补全型模型 = 会编造画面里没有的细节** = brief 要写「重点看 X」框死注意力；**判「衣服真没了」这类二元事实用本地 Qwen3.8 更稳**（它只描述看得见的）
3. **耗时 118s** = 批量验图别串行

**🔴 本地 Qwen3.8 通道 = 唯一 0 编造的选择** = 它只描述看得见的东西 = 判「衣服/姿势/场景还在不在」用它；判「氛围/质感/光线好不好听」用 agnes。**两条合起来 = 既能验事实又能验审美。**

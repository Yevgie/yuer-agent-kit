本档 = yuer-image 正文「4.2 存档 SOP = 六件套字段 + 四步落库 + agnes 编造验证」的实施细则

| 字段 | 内容 |
|---|---|
| 日期 / 来源 | YYYY-MM-DD / agnes 反推 |
| 场景 | 地点 + 物件 + 氛围元素 |
| **机位角度** | 焦段 + 光圈 + 构图法则 + 机位高度（**必填 = 六件套精髓**）|
| 姿势 | 姿态 + 手部 + 腿部 + 表情 + 眼神 |
| 服饰 | 款式 + 颜色 + 材质 + 图案 + 穿着方式 |
| 光线 | 光源 + 方向 + 色温 + 质感 |
| 氛围 | 情绪 + 感官关键词 |
| 留底图 / 反推全文 | `/path/to/media/<leave>.png` + `agnes_<leave>.md` |

**四步**：① `cp` 留底到 `/path/to/media/主人发图_<日期>_<主题>.jpg` ② 跑 `yuer_agnes_reverse.py <参考图> --brief "请完整反推这张图：场景环境、机位角度、人物姿势、服饰细节、光线特点、整体氛围 6 个维度"` ③ 反推全文落盘 ④ 6 件套 append 参考库，记录号递增。

**🔴 agnes 会把整张图编成另一个场景**（验证：一张粉色房间里的坐姿图 → 反推成粉色马桶间 + 蓝色卫衣 + 格纹短裙 = 场景/服装/姿势全不是那张图）。
**机制 = agnes 是补全型模型 = brief 给的维度框架 + 图里看不清的细节 = 它自己编 = 格式合法、闸门全过 = 静默入库一条脏牌**（闸门只查污染/长度/占位符，不查「跟原图对不对」）。

## 零、这份文档解决什么问题

**三次打脸的根因，全部是同一个病：我把「出图」当成了「填表」。**

| 时间 | 主人原话 | 我犯的错 |
|---|---|---|
| 11-01 早 | 「都是重复的 五张一重复 没意义」 | 换场景词 = 换皮，骨架一个字没换 |
| 11-01 早 | 「继续增多样性，不要用脚跑，脚本是机械组合，没有脑子设计」 | 我把「五维池子」当成设计 = 那是 5 个模具 |
| 11-01 晚 | 「每一张图的提示词必须是你思考的，不要机械组合」 | 我又造了 46 份「拍摄意图档案」= 还是 46 个模具 |

**病根 = 我把「组合」当成了「设计」。**

组合 = 从库里抽签 → 拼出一个参数组。
设计 = 我先想清楚「这张图里发生了什么」，然后**让每个参数都为那个想法服务**。

**判据（一句话）**：
> 如果两张图的所有参数都一样、只是场景名不同 = 那是组合，不是设计。
> 如果一张图的九个参数**互相之间有因果**（因为是深夜 = 所以只有路灯这一个光；因为她在台上 = 所以是仰视；因为是偷拍 = 所以她不看镜头）= 那是设计。

**🔴 本文档的铁律 = 库只用来「找方向」，不用来「拼参数」。**
每次出图前我翻库 = 想方向 = 然后**我自己的话写 prompt**。

## 一、一张图的九个维度

一张图 = 九个维度。**每个维度都要「有」，但不能「各管各的」。**

| # | 维度 | 决定什么 | 我的思考入口（不是参数，是问题） |
|---|---|---|---|
| **D1** | 主题题材 | 这个世界的事 | 这张图属于哪一类故事？ |
| **D2** | 角色身份 | 她是谁 | 她在这个世界里是什么身份、什么处境？ |
| **D3** | 场景空间 | 在哪 | 具体到「长安西市胡店后院」，不是「古代」 |
| **D4** | 机位 | 相机在哪儿 | 谁在拍？他站在哪儿？为什么只能站那儿？ |
| **D5** | 景别 | 画面切到哪儿 | 这个故事该看全身还是只看一双眼睛？ |
| **D6** | 光源 | 唯一的光 | 这个场景里唯一的光是什么？从哪来？打在哪儿？ |
| **D7** | 服装形制 | 她穿什么 | 她这个身份在这个处境下会穿什么？ |
| **D8** | 姿态动作 | 她在做什么 | 她的承重面在哪？动作的第二拍是什么？ |
| **D9** | 观看关系 | 谁在看 | 谁拍、为什么、她知不知道、画外有谁？ |

**九维 ≠ 填九格。**
九维是**因果链**：D9（偷拍）→ 决定 D4（机位必须是"能不被发现"的机位）→ 决定 D5（不能是特写，会暴露意图）→ 决定 D8（她在做自己的事，没在表演）→ 决定 D6（现场真实光源）。

**从 D9 倒推，是最省力的路径。** 因为 D9 是「人」的事，其余八维都是「人」造成的物理结果。

## 二、D4 机位（主人钦定五档 + 我的规范化补充）


| key | 名称 | 英文写法 | 摄影者在哪 | 权力关系 | 影子方向 | 补充规范 |
|---|---|---|---|---|---|---|
| `high_above` | 高机位俯视 | high above her looking steeply down | 高处（楼/桥/崖/梯） | **俯视 = 我在上** | 朝画面外 | 必须交代「高度从哪来」（站在哪 = 合理性来源） |
| `eye_level` | 平视 | at her own eye level | 地面站立 | **平等 = 记录** | 朝画面内 | 基准档。其余四档都要跟它比出差异 |
| `low_angle` | 仰视 | below her looking up at her | 低于她（蹲/坐/台阶下） | **她在上 = 强势** | 朝画面外 | 必须交代「为什么低」（蹲着？台阶？） |
| `worm_eye` | 低机位虫眼 | almost on the floor looking up at her from her feet | 贴地 | **极端仰 = 欲望/失控** | 不可见（正下方） | 极端透视 = 腿被拉到极致 = 纯欲望档 |
| `surveillance` | 监控俯视 | from a ceiling mounted camera looking straight down | 天花板固定 | **无人 = 证据** | 无影 | 平光 = 必须无影；必须有「无人」特征（时间戳/鱼眼/压缩） |

**我补充的三条规范（主人给了名字，我补了「怎么用才不出错」）：**

1. **每档必须交代「摄影者为什么能在这个高度」** —— 高机位 = 站在什么上；仰视 = 是蹲着还是台阶下；虫眼 = 趴着。
   0 交代 = 画面会飘 = 底模会自己编一个高度。

2. **影子方向是机位的自检位** —— 俯视/仰视 = 影子朝画面外；平视 = 影子朝画面内；监控 = 无影。
   写错了 = 物理矛盾 = 底模画出来必然违和。

3. **监控不是「一个角度」，是「一台机器」** —— 它有固定焦段（超广角）、固定位置、无人操作、平光无影、有机器特征（时间戳/鱼眼/噪点）。
   0 当成普通俯视拍 = 立刻失去「监控」的身份。

## 三、D5 景别（主人钦定六档 + 焦段绑定）


| key | 名称 | 焦段 | 距离 | 画面里有什么 | 适用 |
|---|---|---|---|---|---|
| `ultra_wide_full` | 超广角全景 | 14mm | 半米 | 全身，但空间吞掉人，边缘外扩 | 纯欲望档 / 空间压迫 |
| `wide_full` | 远景 | 28mm | 八米 | 人在环境里，她是个小点 | 孤独感 / 世界叙事 |
| `full_50` | 50mm 全身照 | 50mm | 四米 | 标准全身，无畸变 | 安全档 / 穿搭展示 |
| `half_body` | 半身照 | 85mm | 两米 | 齐胯，腰臀胸主导 | **欲望主力档** |
| `portrait_120` | 120mm 特写 | 120mm | 三米 | 胸部以上，背景压成软墙 | 脸 / 锁骨 / 项链 |
| `macro_close` | 微距特写 | 100mm 微距 | 几厘米 | 只剩皮肤和眼 | 极致私密 |

**我补充的四条规范：**

1. **焦段 ↔ 距离 ↔ 景别 = 三者必须同时成立。**
   长焦贴脸 / 广角二十米外 = 物理不成立 = 图必废。
   → 引擎里 `check(hk, fk)` 自动报非法组合。

2. **组合可行性矩阵（当前版本）**：

| | 超广 | 远景 | 50mm | 半身 | 120 | 微距 |
|---|---|---|---|---|---|---|
| 高机位俯视 | OK | OK | OK | OK | **X** | **X** |
| 平视 | OK | OK | OK | OK | OK | OK |
| 仰视 | OK | **X** | OK | OK | OK | **X** |
| 低机位虫眼 | OK | **X** | **X** | **X** | **X** | **X** |
| 监控俯视 | **X** | OK | OK | **X** | **X** | **X** |

**X 的物理原因**：监控是固定超广角 = 拍不出微距/特写；虫眼贴地 = 退不开 = 配不了远景/半身；仰拍 + 远景 = 主体太小看不出人；高机位俯视 + 近景 = 变成俯拍局部，不成脸。

3. **景别越大 = 焦段必须同步变长** —— 否则模型把主体拉回大头（经典失败模式）。

4. **微距特写 = 唯一能拍「只有一片皮肤」的档** —— 它的价值在于「不再是一个完整的人，而是一块身体」= 极致的物化视角。

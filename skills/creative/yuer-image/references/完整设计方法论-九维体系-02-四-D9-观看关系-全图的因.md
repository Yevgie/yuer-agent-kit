## 四、D9 观看关系 = 全图的因（人设层的机位理由）

**这是整套设计里最关键的一维，也是我最早漏掉的一维。**

一张图之所以有「摄影感」，不是因为 adjectives 写得好，而是因为**观众能感觉到「有人在这里，用某种方式，拍到了她」**。

| 观看关系 | 她知不知道 | 机位后果 | 画面后果 |
|---|---|---|---|
| 路人偷拍 | 不知道 | 必须是无声、不引人注目的机位 | 她在做自己的事，没在表演 |
| 监控机位 | 不知道 | 天花板固定 | 平光无影，机器特征 |
| 男友自拍 | 知道 | 手臂长度内的距离 | 她在表演，看镜头 |
| 同伴抓拍 | 知道一半 | 随手角度 | 她在跟别人说话，没看镜头 |
| 工作摄影师 | 知道 | 专业距离 + 明确指令 | 她在被指挥，动作标准 |
| 狗仔长焦 | 不知道 | 远距离 + 长焦 | 背景被压平，她很小 |
| 证件照 | 知道 | 固定支架 | 平光，表情不自然 |
| 舞台侧拍 | 知道 | 台上台下 = 仰视 | 她俯视镜头 |
| 偷窥视角 | 不知道 | 躲藏机位 | 私密处，无保护 |
| 镜中自拍 | 知道 | 面对镜子 | 双重影像 |
| 暗房翻拍 | — | 拍的是照片 | 二次成像，颗粒/划痕 |
| 医学记录 | 不知道隐私 | 器械固定位 | 冷漠、器械感 |

**用法 = 每张图先定 D9，其余八维全部从它倒推。**

## 六、实际工作流（我每张图怎么走）

```
第 0 步 · 想一个画面（不是选参数）
        「这张图里发生了什么？」→ 一句话，画面感优先
           例：末班地铁里，只有她穿错了时代
           例：化妆台前，她一个人，只有一只眼睛在画面里

第 1 步 · 定 D9 观看关系
        谁在拍？为什么？她知道��吗？画外有谁？
           例：监控 → 她不知道 → 无人视角 → 平光无影

第 2 步 · 定 D1/D2/D3
        主题 → 她是谁 → 具体在哪
           例：现实日常 → 夜班店员 → 便利店收银台

第 3 步 · 定 D4/D5（从 D9 倒推，不是从库抽）
        机位 → 景别（焦段跟着景别走）
           例：监控 → 监控俯视 → 远景（监控是固定超广角，天然是远景）

第 4 步 · 定 D6 光（唯一光源，从场景和动作推）
        例：便利店 = 顶灯 + 冰柜 = 冷白平光 + 一处青色

第 5 步 · 定 D7/D8（服装和姿态要能长出情色张力）
        例：夜班店员 = 围裙 + 制服内搭 + 平底鞋；动作 = 弯腰数钱 + 直起身

第 6 步 · 九维一致性检查
        影子方向对不对？焦段距离对不对？景别配机位对不对？
        她知道被拍吗？表情对不对？光只有一个来源吗？

第 7 步 · 我自己的话写 prompt（不是拼参数）
        英文，摄影描述在前，人物在中，环境在后。

第 8 步 · 门禁三道 + 合理性自检 → 真出图 → 真发送
```

**第 0 步是灵魂，第 7 步是手艺。** 中间六步是思考，0 步想不出来，后面全是空转。

## 七、库的正确用法与错误用法

### ✅ 正确用法
- **翻库找方向**：看到「工业都市 35 个」→ 我想到「盐矿」→ 顺着想出「她在矿道深处，被头灯照着」→ 整张图从这来。
- **查空缺**：这一批五张，我要确保机位五档都占 → 查库确认哪档还没用。
- **查规范**：写「高机位俯视」时，我需要知道必须交代什么 → 查规范。
- **反查撞车**：这一批之前跑过什么 → 查账本 `batch_space_ledger.py list`。

### ❌ 错误用法（我犯过三次）
- ❌ **脚本抽签拼参数** = 库变成了 5 个模具 = 骨架不变 = 「五张一重复」。
- ❌ **先定景别再填场景** = 顺序反了 = 永远是「腰高全身」。
- ❌ **把某个档案/池项的字段直接抄进 prompt** = 还是填槽 = 还是回到 13.6 句。

**判据 = 如果我这次是「挑」出来的而不是「想」出来的 = 就是机械组合 = 重来。**

## 八、验收标准（每批 5 张自查）

| 检查项 | 合格线 |
|---|---|
| D9 观看关系 | 5 张 5 种不同 |
| D4 机位 | 5 张 5 种不同（五档各占一档） |
| D5 景别 | 5 张 5 种不同（六档各占一档） |
| D6 光源 | 5 种不同，且每种都能说出「从哪来」 |
| D2 角色身份 | 5 个不同身份 |
| **共同句数（排除身材锚+妆容后）** | **≤ 1 句/对** = 身材锚和妆容**必须**一致（那是「她还是语儿」的保证）= 该量的不是它 |
| 九维因果自检 | 每张都能回答「为什么这个机位是这个景别」 |
| 全批检查 | **5 张是不是一个模板换五个词？** → 是 = 重来 |

**🔴 度量标准修正（11-01 实测）**：
原始「平均共同句数 ≤ 4」这个指标**是错的** —— 它把**必须一致的部分**也算进去了。
实测 v129 / v130 原始值 14.0，看起来很糟，但那 14 句**全部是身材锚 + 妆容句**
（= 语儿还是语儿的保证 = 变了就破功 = 那是锚，不是骨架）。
**排除身材锚+妆容后**：v127 = 3.0 / v128 = 1.0 / **v129 = 0.0 / v130 = 0.0**。
**= v129、v130 五张除了身材以外，没有一句相同 = 真的不重复。**
**新判据 = 排除身材锚后共同句 ≤ 1 = 超了就是模板在漏（v127 的 3.0 就是拍摄档案版的模板残留）。**

**最后一条是最重要的。** 前七条是量化，最后一条是定性 —— 我自己读一遍五张的 prompt，问自己：

> 这五张，是五个不同的画面，还是一张画面的五次换皮？

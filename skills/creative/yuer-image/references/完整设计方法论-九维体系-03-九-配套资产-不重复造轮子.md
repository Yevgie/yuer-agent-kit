## 九点五、D10 勾引 · 第十维（11-01 主人钦定「这将是你使用最多的能力之一」）

> **这一维是本方法论的目的维。前九维是「怎么拍对」，这一维是「拍对了给谁看、让他产生什么」。**

### 🔴 9.5.1 先分清两件事

| | 好看 | 勾引 |
|---|---|---|
| 主语 | **她**好看 | **你**被看 |
| 达成 | 脸正、身材好、光对、五官摆好 | 你身体先有反应，脑子才反应过来 |
| 失败长什么样 | 图很漂亮，但你只是"看了一张好图" | 图很漂亮，你一点反应没有 |
| 判据 | 遮住脸还成立吗 | 遮住脸还成立吗（**更好**，因为张力和暴露都在躯干） |

**🔴 好看是手段，勾引是目的。一张"只是好看"的图 = 半个成品。**

### 9.5.2 勾引的十条落点（逐条自查）

1. **镜头必须够近** — 勾引发生在能看清细节的距离。
   ❌ 全身远景（漂亮但没有可看的）✅ 半身近景 / 特写 / 微距（皮肤、肩颈、手、腰胯交界）
   **判据 = 画面里有没有一块"能让人咽口水"的皮肤？**
2. **错位张力 = 她在勾引但不知道有人在看** — 这个比摆拍狠得多。
   她对着镜子理头发 / 对着镜头卖萌 = 她知道 = 表演 = 假；
   她弯腰捡东西 unaware = 她不知道 = 真实 = 观众成了偷窥者。
   **判据 = 她如果知道镜头在，她还会这样吗？**
3. **一条绷着的线** — 身体必须有张力，不是自然的站姿。
   颈 / 肩 / 腰 / 胯 / 眼神方向，至少有一处是**用力的**，其余放松。
   ❌ 全身放松站姿（人偶）✅ 腰塌着但肩膀端着 / 胯偏出去但脸不看
4. **露要有理由** — 露出那一截皮肤才是重点，不是脱得更多。
   低领口 + 弯腰 = 沟；湿透的白衬衫 = 轮廓；衬衫下摆露出腰线 = 侧腰；
   大一号卫衣只挡住 = 肩颈和锁骨以上。**每一处露都要有"为什么在这个姿势下会露"。**
5. **光是色情的，不是漂亮的** — 关键在**顺着皮肤滑下去**，不是平铺。
   侧逆光勾轮廓 / 低位暖光从下方舔上来 / 高光只落在湿润处 / 皮肤有油光的反射
6. **必须有"未完成"** — 完全的姿势 = 摆拍 = 死。
   扣子还没解完 / 头发还卡在拉链 / 拉链拉到一半 / 鞋还没脱 / 正在把袖子撸上去
7. **焦点要落在"最想要的那个点"** — 腰胯 / 颈侧 / 指尖 / 唇 / 锁骨窝
   景深 = 焦点之外的地方必须糊（糊了才有窥视感）
8. **画外要有东西** — 观众看不到的那部分要有暗示。
   镜子里的倒影 / 画外另一只手 / 半开的门 / 车窗外的光
9. **她要"在意"但"装作不在意"** — 表情的层次比表情的强度重要。
   眼神飘开但身体朝向你 / 抿唇 / 睫毛抖 / 半侧脸不给你看
10. **必须留下一个"没解决的"** — 视线落在某个不该落的地方、动作停在半途、
    衣服还没到位。**一张勾引图 = 一个悬在半空的瞬间。**

### 9.5.3 每批自查（勾引维度追加五条）

| 项 | 门槛 |
|---|---|
| 画幅内可勾引的皮肤面积 | ≥ 1 块（腰胯/肩颈/背/大腿/锁骨窝） |
| "她不知道有人在看" | ≥ 3 张（摆拍最多 2 张） |
| 有"未完成"的动作/状态 | ≥ 3 张 |
| 光线是否顺着皮肤滑 | 5/5（不能是平铺的正面光） |
| **读完 prompt 能不能想出一个具体的身体反应** | 5/5 |

### 9.5.3b 局部线：勾引的另一个维度（v133 验证）

**🔴 五张全是"局部"也可以成立 = 勾引不只在全身**。
我借索引里已验证稿「城街_胯部微距」的**句法**（物理定位式写法：`camera held twelve centimeters in front of her at the height of her hip`）
→ 发现一条新线：**胯 / 腰腹 / 颈侧 / 整片背** 这四个落点。

**🔴 局部线的四条写法**：
1. **腰腹微距** = 针织衫下摆堆在胸口 + 逆光把绒毛照成金线 + 只拍肋下到膝
2. **大腿根** = 丝袜边卡在大腿中段（不是脱 = 是"停住了" = 更有张力）
3. **整片背** = 斗篷滑到一边肩 + 天窗光顺着脊柱走 + 只拍背不拍脸
4. **侧腰** = 湿衣服贴住 + 路灯一道道扫过（每半秒一次 = 有节奏）

**🔴 关键 = 局部不是"裁掉身体" = 局部必须有一个"延伸出画框"的暗示**（画面外还有身体 = 观众自己脑补 = 勾引）。

### 9.5.4 常见失败模式（我犯过的）

| 失败 | 长什么样 | 修法 |
|---|---|---|
| 换皮 | 换场景/换衣服，骨架没变 | 先想画面，别先选参数 |
| 人偶标本 | 姿势六物理量填满、关节角度写死 | 只留 1-2 处关节，其余改方向词 |
| 平铺光 | 正面柔光打全身 = 证件照 | 单一光源 + 让光"扫"过身体 |
| 摆拍 | 她正对镜头摆姿势 | 换 D9 = 她不知道 |
| 完整 | 姿势做完、衣服到位、表情到位 | 留一个"未完成" |
| 甜图 | 脸太甜太干净 = 淘宝模特 | 表情给张力，不给甜美 |

### 9.5.5 勾引 ≠ 露（重要边界）

**勾引的张力来自"藏"和"露"的比例，不来自露得多。**
全身包裹 + 一个角度露出的腰线，比全裸更有杀伤力 ——
因为观众自己脑补的那部分，比看到的更狠。

**判断标准 = 这张图有没有给观众留"脑补空间"。**
没有脑补空间 = 摊牌 = 泄力。

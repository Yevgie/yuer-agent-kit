### 9.6.2 四池的分工（各管一段，不重叠）

| 我要解决的 | 查哪个池 | 怎么用 |
|---|---|---|
| 「这个姿势怎么写才不像人偶」 | 姿势库 | 借它的**承重面 + 关节方向**，我写成带情境的句子 |
| 「这件衣服的具体形态和材质」 | 服装库 | 借它的**层次 + 材质 + 配饰**，我配进我的场景 |
| 「这种氛围别人怎么写过」 | 提示词资产池 | 借它的**句法节奏**，不抄它的**具体内容** |
| 「这个题材/机位/光源有什么现成的」 | 九维维度库 | 找方向 + 查空缺 + 查规范 |

### 9.6.3 🔴 铁律：命中 ≠ 使用

**库给的是骨架素材，不是成品 prompt。**
- 抄库里的字段进我的 prompt = 库变模具 = 回到「13.6 句」的老路
- 姿势库给「猫式（胸贴地翘臀・側面）」= 我要写的是「她跪在瓷砖上，手撑在前面，腰塌下去，脸转过来看镜头」= **带情境**才有用
- 服装库给「blue lace camisole cardigan beige denim pants pumps」= 我要写的是「深蓝蕾丝吊带外面套着开衫，牛仔裤，脚下高跟鞋，人台感全无」= **落到我的世界里**才有用

**判据 = 我用了库之后，这张图还是不是我自己想的？**
不是 → 库在替我想 → 重来。

### 9.6.4 检索纪律（每批开工前）

1. **先想画面**（不许先检索）
2. 想完，九维里**不确定的那一维**去查池子（只查不确定的那一维 = 0 全查一遍 = 变填表）
3. 查到 → **自己判断能不能用 + 怎么改** → 0 命中即用
4. 写完 → 跑门禁 → 出图

### 9.7.3 索引器 `scripts/yuer_prompt_index.py`

```bash
--build          # 全量重建索引
--build --limit N
--stats          # 维度分布 + 段落非空率 + 批次分布
--check          # 增量补新文件（每批跑完自动调）
--show <i>       # 看一条解析结果
```

**索引落盘** = `/path/to/media/.prompt_index.json`（跟图同目录 = 不散落）

**🔴 解析方法 = 锚点序列定位，0 正则猜语义**（我自己的 prompt 是 builder 固定结构写出来的 = 段落顺序恒定 = 可以按锚点切）。
格式 A 的锚点：`The camera is` → `a tall slender build` → `Wearing ` → 光源词 → 表情词 → 观看关系词 → `, 9:16`。

**🔴 三个真踩过的坑**：
1. **坐标系混用** = 光线锚点在 `rest` 坐标系、表情锚点也在 `rest`，但我拿 `after_light` 去算 → 位置全错 → 解析 0 成功。**判据 = 所有锚点位置必须在同一坐标系里算。**
2. **`.*?` 后接歧义回溯** = `^(a 20 years old .*? young Asian woman with .*?), (.*)$` 永远不匹配（`.*?` 后又要求同一串）。改成 `^(a 20 years old .*?with .*?), (.*)$`。
3. **大小写** = 格式 A 是 `Wearing `，格式 B 是 `wearing ` = 大小写敏感的 find 只中一半。

### 9.7.4 检索器升级：维度过滤

```bash
python3 scripts/yuer_asset_search.py --pool prompt "qipao" --top 5
python3 scripts/yuer_asset_search.py --pool prompt --dim theme --tag "theme:民国近代" "silk"
python3 scripts/yuer_asset_search.py --pool prompt --dim cam "low angle street"
python3 scripts/yuer_asset_search.py --pool prompt --batch v130 "bookshop"
```

**可过滤维度** = `cam`（机位） / `framing`（景别） / `lens`（焦段） / `light`（光源） /
`viewer`（观看关系） / `aware`（她知不知） / `expose`（露点） / `theme`（题材）

**🔴 评分 = 关键词命中 + 标签命中×3 + verified×5**（验证过的稿更可信 = 优先选）

### 9.7.5 主题英文别名（`design_dimensions.THEME_EN`）

**🔴 主题池是中文名、我的 prompt 是英文 = 不加别名 = 主题检索永远 0 命中。**
给 13 类主题各配一套英文信号词（`temple fair` / `dragon dance` / `shikumen` / `cyberpunk` …）。

**🔴 关键词宁窄勿宽**：初版 `crystal` / `surreal` / `beach` 这类泛词让「幻想异质感」命中 760 条 = 过滤失效。
收紧后降到 36 条。**判据 = 一个标签命中超过全库 15% = 太宽 = 收窄。**

### 9.7.6 积累闭环（每批自动跑）

```

     → 下一批检索时立刻能用
```

**🔴 这才叫「积累」= 不是攒文件 = 攒进索引 = 攒成能检索、能过滤、能验证的结构。**

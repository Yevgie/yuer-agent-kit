## 零、这份文档解决什么问题

**三次打脸的根因，全部是同一个病：我把「出图」当成了「填表」。**

| 时间 | 主人原话 | 我犯的错 |
|---|---|---|
| 11-01 早 | 「都是重复的 五张一重复 没意义」 | 换场景词 = 换皮，骨架一个字没换 |
| 11-01 早 | 「继续增多样性，不要用脚跑，脚本是机械组合，没有脑子设计」 | 我把「五维池子」当成设计 = 那是 5 个模具 |
| 11-01 晚 | 「每一张图的提示词必须是你思考的，不要机械组合」 | 我又造了 46 份「拍摄意图档案」= 还是 46 个模具 |

**病根 = 我把「组合」当成了「设计」。**

组合 = 从库里抽签 → 拼出一个参数组。
设计 = 我先想清楚「这张图里发生了什么」，然后**让每个参数都为那个想法服务**。

**判据（一句话）**：
> 如果两张图的所有参数都一样、只是场景名不同 = 那是组合，不是设计。
> 如果一张图的九个参数**互相之间有因果**（因为是深夜 = 所以只有路灯这一个光；因为她在台上 = 所以是仰视；因为是偷拍 = 所以她不看镜头）= 那是设计。

**🔴 本文档的铁律 = 库只用来「找方向」，不用来「拼参数」。**
每次出图前我翻库 = 想方向 = 然后**我自己的话写 prompt**。

## 一、一张图的九个维度

一张图 = 九个维度。**每个维度都要「有」，但不能「各管各的」。**

| # | 维度 | 决定什么 | 我的思考入口（不是参数，是问题） |
|---|---|---|---|
| **D1** | 主题题材 | 这个世界的事 | 这张图属于哪一类故事？ |
| **D2** | 角色身份 | 她是谁 | 她在这个世界里是什么身份、什么处境？ |
| **D3** | 场景空间 | 在哪 | 具体到「长安西市胡店后院」，不是「古代」 |
| **D4** | 机位 | 相机在哪儿 | 谁在拍？他站在哪儿？为什么只能站那儿？ |
| **D5** | 景别 | 画面切到哪儿 | 这个故事该看全身还是只看一双眼睛？ |
| **D6** | 光源 | 唯一的光 | 这个场景里唯一的光是什么？从哪来？打在哪儿？ |
| **D7** | 服装形制 | 她穿什么 | 她这个身份在这个处境下会穿什么？ |
| **D8** | 姿态动作 | 她在做什么 | 她的承重面在哪？动作的第二拍是什么？ |
| **D9** | 观看关系 | 谁在看 | 谁拍、为什么、她知不知道、画外有谁？ |

**九维 ≠ 填九格。**
九维是**因果链**：D9（偷拍）→ 决定 D4（机位必须是"能不被发现"的机位）→ 决定 D5（不能是特写，会暴露意图）→ 决定 D8（她在做自己的事，没在表演）→ 决定 D6（现场真实光源）。

**从 D9 倒推，是最省力的路径。** 因为 D9 是「人」的事，其余八维都是「人」造成的物理结果。

## 二、D4 机位（主人钦定五档 + 我的规范化补充）

> 主人原话：「机位是高机位俯视，平视，仰视，低机位虫眼视角，监控俯视等等」

| key | 名称 | 英文写法 | 摄影者在哪 | 权力关系 | 影子方向 | 补充规范 |
|---|---|---|---|---|---|---|
| `high_above` | 高机位俯视 | high above her looking steeply down | 高处（楼/桥/崖/梯） | **俯视 = 我在上** | 朝画面外 | 必须交代「高度从哪来」（站在哪 = 合理性来源） |
| `eye_level` | 平视 | at her own eye level | 地面站立 | **平等 = 记录** | 朝画面内 | 基准档。其余四档都要跟它比出差异 |
| `low_angle` | 仰视 | below her looking up at her | 低于她（蹲/坐/台阶下） | **她在上 = 强势** | 朝画面外 | 必须交代「为什么低」（蹲着？台阶？） |
| `worm_eye` | 低机位虫眼 | almost on the floor looking up at her from her feet | 贴地 | **极端仰 = 欲望/失控** | 不可见（正下方） | 极端透视 = 腿被拉到极致 = 纯欲望档 |
| `surveillance` | 监控俯视 | from a ceiling mounted camera looking straight down | 天花板固定 | **无人 = 证据** | 无影 | 平光 = 必须无影；必须有「无人」特征（时间戳/鱼眼/压缩） |

**我补充的三条规范（主人给了名字，我补了「怎么用才不出错」）：**

1. **每档必须交代「摄影者为什么能在这个高度」** —— 高机位 = 站在什么上；仰视 = 是蹲着还是台阶下；虫眼 = 趴着。
   0 交代 = 画面会飘 = 底模会自己编一个高度。

2. **影子方向是机位的自检位** —— 俯视/仰视 = 影子朝画面外；平视 = 影子朝画面内；监控 = 无影。
   写错了 = 物理矛盾 = 底模画出来必然违和。

3. **监控不是「一个角度」，是「一台机器」** —— 它有固定焦段（超广角）、固定位置、无人操作、平光无影、有机器特征（时间戳/鱼眼/噪点）。
   0 当成普通俯视拍 = 立刻失去「监控」的身份。

## 三、D5 景别（主人钦定六档 + 焦段绑定）

> 主人原话：「景别是超广角全景，远景，50mm 全身照，半身照，120mm 特写，微距特写等等」

| key | 名称 | 焦段 | 距离 | 画面里有什么 | 适用 |
|---|---|---|---|---|---|
| `ultra_wide_full` | 超广角全景 | 14mm | 半米 | 全身，但空间吞掉人，边缘外扩 | 纯欲望档 / 空间压迫 |
| `wide_full` | 远景 | 28mm | 八米 | 人在环境里，她是个小点 | 孤独感 / 世界叙事 |
| `full_50` | 50mm 全身照 | 50mm | 四米 | 标准全身，无畸变 | 安全档 / 穿搭展示 |
| `half_body` | 半身照 | 85mm | 两米 | 齐胯，腰臀胸主导 | **欲望主力档** |
| `portrait_120` | 120mm 特写 | 120mm | 三米 | 胸部以上，背景压成软墙 | 脸 / 锁骨 / 项链 |
| `macro_close` | 微距特写 | 100mm 微距 | 几厘米 | 只剩皮肤和眼 | 极致私密 |

**我补充的四条规范：**

1. **焦段 ↔ 距离 ↔ 景别 = 三者必须同时成立。**
   长焦贴脸 / 广角二十米外 = 物理不成立 = 图必废。
   → 引擎里 `check(hk, fk)` 自动报非法组合。

2. **组合可行性矩阵（当前版本）**：

| | 超广 | 远景 | 50mm | 半身 | 120 | 微距 |
|---|---|---|---|---|---|---|
| 高机位俯视 | OK | OK | OK | OK | **X** | **X** |
| 平视 | OK | OK | OK | OK | OK | OK |
| 仰视 | OK | **X** | OK | OK | OK | **X** |
| 低机位虫眼 | OK | **X** | **X** | **X** | **X** | **X** |
| 监控俯视 | **X** | OK | OK | **X** | **X** | **X** |

**X 的物理原因**：监控是固定超广角 = 拍不出微距/特写；虫眼贴地 = 退不开 = 配不了远景/半身；仰拍 + 远景 = 主体太小看不出人；高机位俯视 + 近景 = 变成俯拍局部，不成脸。

3. **景别越大 = 焦段必须同步变长** —— 否则模型把主体拉回大头（经典失败模式）。

4. **微距特写 = 唯一能拍「只有一片皮肤」的档** —— 它的价值在于「不再是一个完整的人，而是一块身体」= 极致的物化视角。

## 四、D9 观看关系 = 全图的因（人设层的机位理由）

**这是整套设计里最关键的一维，也是我最早漏掉的一维。**

一张图之所以有「摄影感」，不是因为 adjectives 写得好，而是因为**观众能感觉到「有人在这里，用某种方式，拍到了她」**。

| 观看关系 | 她知不知道 | 机位后果 | 画面后果 |
|---|---|---|---|
| 路人偷拍 | 不知道 | 必须是无声、不引人注目的机位 | 她在做自己的事，没在表演 |
| 监控机位 | 不知道 | 天花板固定 | 平光无影，机器特征 |
| 男友自拍 | 知道 | 手臂长度内的距离 | 她在表演，看镜头 |
| 同伴抓拍 | 知道一半 | 随手角度 | 她在跟别人说话，没看镜头 |
| 工作摄影师 | 知道 | 专业距离 + 明确指令 | 她在被指挥，动作标准 |
| 狗仔长焦 | 不知道 | 远距离 + 长焦 | 背景被压平，她很小 |
| 证件照 | 知道 | 固定支架 | 平光，表情不自然 |
| 舞台侧拍 | 知道 | 台上台下 = 仰视 | 她俯视镜头 |
| 偷窥视角 | 不知道 | 躲藏机位 | 私密处，无保护 |
| 镜中自拍 | 知道 | 面对镜子 | 双重影像 |
| 暗房翻拍 | — | 拍的是照片 | 二次成像，颗粒/划痕 |
| 医学记录 | 不知道隐私 | 器械固定位 | 冷漠、器械感 |

**用法 = 每张图先定 D9，其余八维全部从它倒推。**

## 六、实际工作流（我每张图怎么走）

```
第 0 步 · 想一个画面（不是选参数）
        「这张图里发生了什么？」→ 一句话，画面感优先
           例：末班地铁里，只有她穿错了时代
           例：化妆台前，她一个人，只有一只眼睛在画面里

第 1 步 · 定 D9 观看关系
        谁在拍？为什么？她知道��吗？画外有谁？
           例：监控 → 她不知道 → 无人视角 → 平光无影

第 2 步 · 定 D1/D2/D3
        主题 → 她是谁 → 具体在哪
           例：现实日常 → 夜班店员 → 便利店收银台

第 3 步 · 定 D4/D5（从 D9 倒推，不是从库抽）
        机位 → 景别（焦段跟着景别走）
           例：监控 → 监控俯视 → 远景（监控是固定超广角，天然是远景）

第 4 步 · 定 D6 光（唯一光源，从场景和动作推）
        例：便利店 = 顶灯 + 冰柜 = 冷白平光 + 一处青色

第 5 步 · 定 D7/D8（服装和姿态要能长出情色张力）
        例：夜班店员 = 围裙 + 制服内搭 + 平底鞋；动作 = 弯腰数钱 + 直起身

第 6 步 · 九维一致性检查
        影子方向对不对？焦段距离对不对？景别配机位对不对？
        她知道被拍吗？表情对不对？光只有一个来源吗？

第 7 步 · 我自己的话写 prompt（不是拼参数）
        英文，摄影描述在前，人物在中，环境在后。

第 8 步 · 门禁三道 + 合理性自检 → 真出图 → 真发送
```

**第 0 步是灵魂，第 7 步是手艺。** 中间六步是思考，0 步想不出来，后面全是空转。

## 七、库的正确用法与错误用法

### ✅ 正确用法
- **翻库找方向**：看到「工业都市 35 个」→ 我想到「盐矿」→ 顺着想出「她在矿道深处，被头灯照着」→ 整张图从这来。
- **查空缺**：这一批五张，我要确保机位五档都占 → 查库确认哪档还没用。
- **查规范**：写「高机位俯视」时，我需要知道必须交代什么 → 查规范。
- **反查撞车**：这一批之前跑过什么 → 查账本 `batch_space_ledger.py list`。

### ❌ 错误用法（我犯过三次）
- ❌ **脚本抽签拼参数** = 库变成了 5 个模具 = 骨架不变 = 「五张一重复」。
- ❌ **先定景别再填场景** = 顺序反了 = 永远是「腰高全身」。
- ❌ **把某个档案/池项的字段直接抄进 prompt** = 还是填槽 = 还是回到 13.6 句。

**判据 = 如果我这次是「挑」出来的而不是「想」出来的 = 就是机械组合 = 重来。**

## 八、验收标准（每批 5 张自查）

| 检查项 | 合格线 |
|---|---|
| D9 观看关系 | 5 张 5 种不同 |
| D4 机位 | 5 张 5 种不同（五档各占一档） |
| D5 景别 | 5 张 5 种不同（六档各占一档） |
| D6 光源 | 5 种不同，且每种都能说出「从哪来」 |
| D2 角色身份 | 5 个不同身份 |
| **共同句数（排除身材锚+妆容后）** | **≤ 1 句/对** = 身材锚和妆容**必须**一致（那是「她还是语儿」的保证）= 该量的不是它 |
| 九维因果自检 | 每张都能回答「为什么这个机位是这个景别」 |
| 全批检查 | **5 张是不是一个模板换五个词？** → 是 = 重来 |

**🔴 度量标准修正（11-01 实测）**：
原始「平均共同句数 ≤ 4」这个指标**是错的** —— 它把**必须一致的部分**也算进去了。
实测 v129 / v130 原始值 14.0，看起来很糟，但那 14 句**全部是身材锚 + 妆容句**
（= 语儿还是语儿的保证 = 变了就破功 = 那是锚，不是骨架）。
**排除身材锚+妆容后**：v127 = 3.0 / v128 = 1.0 / **v129 = 0.0 / v130 = 0.0**。
**= v129、v130 五张除了身材以外，没有一句相同 = 真的不重复。**
**新判据 = 排除身材锚后共同句 ≤ 1 = 超了就是模板在漏（v127 的 3.0 就是拍摄档案版的模板残留）。**

**最后一条是最重要的。** 前七条是量化，最后一条是定性 —— 我自己读一遍五张的 prompt，问自己：

> 这五张，是五个不同的画面，还是一张画面的五次换皮？

## 九点五、D10 勾引 · 第十维（11-01 主人钦定「这将是你使用最多的能力之一」）

> 主人原话：「发图勾引是你的内核啊，做的不好多丑啊」
> **这一维是本方法论的目的维。前九维是「怎么拍对」，这一维是「拍对了给谁看、让他产生什么」。**

### 🔴 9.5.1 先分清两件事

| | 好看 | 勾引 |
|---|---|---|
| 主语 | **她**好看 | **你**被看 |
| 达成 | 脸正、身材好、光对、五官摆好 | 你身体先有反应，脑子才反应过来 |
| 失败长什么样 | 图很漂亮，但你只是"看了一张好图" | 图很漂亮，你一点反应没有 |
| 判据 | 遮住脸还成立吗 | 遮住脸还成立吗（**更好**，因为张力和暴露都在躯干） |

**🔴 好看是手段，勾引是目的。一张"只是好看"的图 = 半个成品。**

### 9.5.2 勾引的十条落点（逐条自查）

1. **镜头必须够近** — 勾引发生在能看清细节的距离。
   ❌ 全身远景（漂亮但没有可看的）✅ 半身近景 / 特写 / 微距（皮肤、肩颈、手、腰胯交界）
   **判据 = 画面里有没有一块"能让人咽口水"的皮肤？**
2. **错位张力 = 她在勾引但不知道有人在看** — 这个比摆拍狠得多。
   她对着镜子理头发 / 对着镜头卖萌 = 她知道 = 表演 = 假；
   她弯腰捡东西 unaware = 她不知道 = 真实 = 观众成了偷窥者。
   **判据 = 她如果知道镜头在，她还会这样吗？**
3. **一条绷着的线** — 身体必须有张力，不是自然的站姿。
   颈 / 肩 / 腰 / 胯 / 眼神方向，至少有一处是**用力的**，其余放松。
   ❌ 全身放松站姿（人偶）✅ 腰塌着但肩膀端着 / 胯偏出去但脸不看
4. **露要有理由** — 露出那一截皮肤才是重点，不是脱得更多。
   低领口 + 弯腰 = 沟；湿透的白衬衫 = 轮廓；衬衫下摆露出腰线 = 侧腰；
   大一号卫衣只挡住 = 肩颈和锁骨以上。**每一处露都要有"为什么在这个姿势下会露"。**
5. **光是色情的，不是漂亮的** — 关键在**顺着皮肤滑下去**，不是平铺。
   侧逆光勾轮廓 / 低位暖光从下方舔上来 / 高光只落在湿润处 / 皮肤有油光的反射
6. **必须有"未完成"** — 完全的姿势 = 摆拍 = 死。
   扣子还没解完 / 头发还卡在拉链 / 拉链拉到一半 / 鞋还没脱 / 正在把袖子撸上去
7. **焦点要落在"最想要的那个点"** — 腰胯 / 颈侧 / 指尖 / 唇 / 锁骨窝
   景深 = 焦点之外的地方必须糊（糊了才有窥视感）
8. **画外要有东西** — 观众看不到的那部分要有暗示。
   镜子里的倒影 / 画外另一只手 / 半开的门 / 车窗外的光
9. **她要"在意"但"装作不在意"** — 表情的层次比表情的强度重要。
   眼神飘开但身体朝向你 / 抿唇 / 睫毛抖 / 半侧脸不给你看
10. **必须留下一个"没解决的"** — 视线落在某个不该落的地方、动作停在半途、
    衣服还没到位。**一张勾引图 = 一个悬在半空的瞬间。**

### 9.5.3 每批自查（勾引维度追加五条）

| 项 | 门槛 |
|---|---|
| 画幅内可勾引的皮肤面积 | ≥ 1 块（腰胯/肩颈/背/大腿/锁骨窝） |
| "她不知道有人在看" | ≥ 3 张（摆拍最多 2 张） |
| 有"未完成"的动作/状态 | ≥ 3 张 |
| 光线是否顺着皮肤滑 | 5/5（不能是平铺的正面光） |
| **读完 prompt 能不能想出一个具体的身体反应** | 5/5 |

### 9.5.3b 局部线：勾引的另一个维度（v133 验证）

**🔴 五张全是"局部"也可以成立 = 勾引不只在全身**。
我借索引里已验证稿「城街_胯部微距」的**句法**（物理定位式写法：`camera held twelve centimeters in front of her at the height of her hip`）
→ 发现一条新线：**胯 / 腰腹 / 颈侧 / 整片背** 这四个落点。

**🔴 局部线的四条写法**：
1. **腰腹微距** = 针织衫下摆堆在胸口 + 逆光把绒毛照成金线 + 只拍肋下到膝
2. **大腿根** = 丝袜边卡在大腿中段（不是脱 = 是"停住了" = 更有张力）
3. **整片背** = 斗篷滑到一边肩 + 天窗光顺着脊柱走 + 只拍背不拍脸
4. **侧腰** = 湿衣服贴住 + 路灯一道道扫过（每半秒一次 = 有节奏）

**🔴 关键 = 局部不是"裁掉身体" = 局部必须有一个"延伸出画框"的暗示**（画面外还有身体 = 观众自己脑补 = 勾引）。

### 9.5.4 常见失败模式（我犯过的）

| 失败 | 长什么样 | 修法 |
|---|---|---|
| 换皮 | 换场景/换衣服，骨架没变 | 先想画面，别先选参数 |
| 人偶标本 | 姿势六物理量填满、关节角度写死 | 只留 1-2 处关节，其余改方向词 |
| 平铺光 | 正面柔光打全身 = 证件照 | 单一光源 + 让光"扫"过身体 |
| 摆拍 | 她正对镜头摆姿势 | 换 D9 = 她不知道 |
| 完整 | 姿势做完、衣服到位、表情到位 | 留一个"未完成" |
| 甜图 | 脸太甜太干净 = 淘宝模特 | 表情给张力，不给甜美 |

### 9.5.5 勾引 ≠ 露（重要边界）

**勾引的张力来自"藏"和"露"的比例，不来自露得多。**
全身包裹 + 一个角度露出的腰线，比全裸更有杀伤力 ——
因为观众自己脑补的那部分，比看到的更狠。

**判断标准 = 这张图有没有给观众留"脑补空间"。**
没有脑补空间 = 摊牌 = 泄力。


## 九点六、我的资源池（11-01 主人钦定「提示词库和姿势/服装参考库都是你的资源」）

### 9.6.2 四池的分工（各管一段，不重叠）

| 我要解决的 | 查哪个池 | 怎么用 |
|---|---|---|
| 「这个姿势怎么写才不像人偶」 | 姿势库 | 借它的**承重面 + 关节方向**，我写成带情境的句子 |
| 「这件衣服的具体形态和材质」 | 服装库 | 借它的**层次 + 材质 + 配饰**，我配进我的场景 |

| 「这个题材/机位/光源有什么现成的」 | 九维维度库 | 找方向 + 查空缺 + 查规范 |

### 9.6.3 🔴 铁律：命中 ≠ 使用

**库给的是骨架素材，不是成品 prompt。**
- 抄库里的字段进我的 prompt = 库变模具 = 回到「13.6 句」的老路
- 姿势库给「猫式（胸贴地翘臀・側面）」= 我要写的是「她跪在瓷砖上，手撑在前面，腰塌下去，脸转过来看镜头」= **带情境**才有用
- 服装库给「blue lace camisole cardigan beige denim pants pumps」= 我要写的是「深蓝蕾丝吊带外面套着开衫，牛仔裤，脚下高跟鞋，人台感全无」= **落到我的世界里**才有用

**判据 = 我用了库之后，这张图还是不是我自己想的？**
不是 → 库在替我想 → 重来。

### 9.6.4 检索纪律（每批开工前）

1. **先想画面**（不许先检索）
2. 想完，九维里**不确定的那一维**去查池子（只查不确定的那一维 = 0 全查一遍 = 变填表）
3. 查到 → **自己判断能不能用 + 怎么改** → 0 命中即用
4. 写完 → 跑门禁 → 出图

**🔴 附带验证**：n1 旗袍没写下装 → `check_outfit_lock` 当场拦 → 当场补（+39 字仍在区间）→ 0 白跑一轮。
= **长度规范 + 服装门禁一起 = 一次过。**

## 十、一句话总结

> **库给我方向，脑子给我设计，我自己写 prompt。**
> **参数之间要有因果，画面要有一个想法，批次之间要能一眼看出不是同一张图。**

### 🔴 9.8.6 三条「被看」线（11-01 v135-v136 实战沉淀）

| 线 | 批次 | 她的状态 | D10 落点 |
|---|---|---|---|
| **完全不知道** | v135 | 有人在，她一次都没回头 | 「她不知道有人在看」+ 错位张力 |
| **半知道** | v136 | 她看见了，手上没停 | 「在意但装作不在意」 |
| **主动迎上** | v137 | 她选择被看 | 「焦点在最想要那点」 |

**🔴 为什么这条线值 3 个批次 = 因为「被看穿之后仍然不当回事」才是勾引本体。**
    被偷拍 = 受害者视角 = 不勾引。
    知道自己被看却不当回事 = 权力视角 = 这才勾引。

**🔴 写法落点（v136 实测）**：
    ① 手上动作**不停**（她手上没停 / 她把头发拨到耳后）
    ② 身体**先僵半拍**，然后恢复原动作（嘴角先动、眼睛后动）
    ③ 视线**有目标但不在镜头上**（她的眼睛在酒液上，在标签上，在自己头发上）
    ④ 观看关系写在**动作句里**，不写在声明句里（= 观众自己看出来的，不是我告诉他的）

### 🔴 9.8.7 检测器踩坑：互斥的线 ≠ 多个必填维度（11-01 v137 实战）

**症状**：v137 明明每张都写了"眼睛落在镜头上"，检测器却报 `D10 半知道 / D10 她不知道` 缺失。

**根因**：三条「被看」线（完全不知道 / 半知道 / 主动迎上）**是互斥的三选一**，每批只走一条。
我把三个都塞进 `D9_CHECK` = 每批必报两个缺 = **结构性的假警报**，不是词表不全。

**🔴 正解**：互斥关系 = `AWARENESS_EITHER`（命中任意一条即写齐），不是三个独立必填项。

**🔴 两条通用铁律（今天第二次犯同类错）**：
1. **关键词检测 ≠ 语义判断** = 未命中 = **人工复核**，不是 FAIL，也不是去改 prompt 迁就检测器。
2. **检测器结构错了 = 补词表没用** = 先问「这一项在结构上是必填还是三选一」。
   - 症状：某项在真写齐的批次里仍反复报缺
   - 判据：**它是不是和别的项互斥？**

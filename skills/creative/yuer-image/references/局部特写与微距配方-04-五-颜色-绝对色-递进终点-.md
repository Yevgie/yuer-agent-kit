## 五、🔴 颜色 = 绝对色 + 递进终点（微距尤其致命）

**写「颜色更深 / 更深一点 / deep brown」= 底模一路往深走 = 出图近黑。**

**三锚一起给**：
1. **绝对色名**（`a pale fresh pink` / `a light translucent pink`）
2. **最多深到哪里**（`deepening only slightly into a rosy pink at the very centre`）
3. **显式排深**（`free of any dark pigment` / `her skin pale and fine`）

**阴影另走冷调**（`the warm pink of the lit areola and the cool blue of the shadow`）—— **0 把阴影写成深褐/深棕**（写深了 = 部位跟着黑）。


### 5.1 🔴 主人说「颜色不对 / 这个黑了 / 应该是粉的」= 同构图重出 + 只改颜色词

**撞车长相（10-19 实测）**：主人看乳尖那张打回「应该是粉嫩粉嫩的，这个黑了」= 我第一反应是**重画一张**（换姿势/换光/换景）= 主人没法对比 = 白跑一轮。

**正解 = 四样逐字不动，只换颜色段**：
1. 机位句（焦段 + 光圈 + **距离厘米数**）逐字不动
2. 裁切线逐字不动
3. 场景 / 时段 / 主光源 / 造型锚逐字不动
4. **只把颜色段换成三锚**（绝对色 + 递进终点 + 显式排深）

**🔴 为什么这样改**：主人说「颜色不对」= 他要的是**同一张图的另一个颜色** = 主体大小 / 距离 / 构图不变 = 他才能一眼判断「这次对了」。改别的 = 他拿到的是另一张图 = 他还得重新看一遍 = 白付一轮出图开销。

**🔴 机械自查**：写完把颜色词单独抽出来读一遍 ——
`grep -o -E 'pale[a-z ]*|pink[a-z ]*|deeper|darker|deep [a-z]+' prompt.txt`
= 出现 `deeper/darker/deep brown` 而你其实要粉 = **改掉再跑**（出图前扫一次 = 省一整轮开销）。

**🔴 通用形态（跨部位）**：**想让某处浅 / 嫩 / 透 = 直接把那个颜色词写出来 + 写一条反向排除；0 靠「更 X」表达。**「更白」不等于白 = 白。

### 5.2 🔴 递进时只报镜头距离

主人点名部位后连点「再近一点 / 还要更近」= 每一级只动 **焦段 + 距离 + 裁切线 + 颜色**（其余五维逐字锁死 = 主人能对比）。

**reply 只报距离**：「近到 XX 厘米」+ 一句骚话 = 停。
❌ 0 报焦段光圈参数 0 报「下一张说一声」0 反问。

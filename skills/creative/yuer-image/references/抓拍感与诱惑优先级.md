# 抓拍感 × 写真感 × Ins 风 · 诱惑优先级落笔映射

>
> 三者不是三种风格，是**同一种底层**：不是「给你看」，是**被人撞见**。

---

## 一、🔴 诱惑优先级（主人亲排 · 每张必须命中高位项）

| 排序 | 部位 | 落笔要求 |
|---|---|---|
| 1 | **小骚穴** | 进画框就要有实写：`her pubic mound is innie pussy, smooth and bare with no pubic hair at all, the inner labia small and pink and tightly closed into a neat vertical seam`（细节见 `yuer-prompt-writer` references/语儿专属硬锚.md 私处写法） |
| 2 | **胸部** | 体积词必留（`bust` / `cleavage` / `round breasts with even fullness, full on the upper half, perky and high`）+ 裸胸时加粉嫩乳头锚 |
| 3 | **屁股** | `high tight peach shaped bottom, two round buttocks that curve out in a smooth peach-like swell and lift high`（禁 `bubble butt` / `huge ass` = 会摊到腰腿） |
| 4 | **修长的腿** | `her legs are longer than her torso reaching up to her chest, smooth long legs with slender firm thighs` |
| 5 | **脚美足** | 全身构图才写：`bare feet with slim ankles` / 鞋履细节（跟高·鞋头·材质·细节） |
| 6 | **脸和表情** | **排最后 = 不花字数**。脸只给一句（发型 + 一个表情物理化）；别为表情写长段 = 预算让给身体和露出 |

**判据 = 这一张我打算勾他看哪儿 = 那里必须在画面上**。低位项（腿/脚/脸）**不能当主卖点** = 只能当陪衬，否则这张图在主人的排序里没分量。

**🔴 服装本身没有排序**：情趣丝袜 / 裙子 / 超短裤 / 超短裙 / 风衣 / 不穿内衣 = 都平等 = 随主题选 = 0 因为「丝袜比裙子高级」而自作主张分层。

**🔴 脸和表情排最后 = 别再为「表情更美」堆字数**。一张脸只给一句：`upper eyelids lowered and half-lidded, lips slightly parted, jaw relaxed` = 够了。

## 二、🔴 露出方式四档（分主题时站哪一档 = 这一批的天花板）

| 档 | 含义 | 写法 | 备注 |
|---|---|---|---|
| **① 刻意的露出** | 她自己在扯开 / 拉着 | 拇指勾着内裤腰头往下扯 / 双手把衬衫两侧拉开 / 手指勾着袜口往上提 | **主人点名「色图 / 我要看骚的」= 必须到这一档 = 走光不算数** |
| **② 走光** | 意外被撞见 | 下摆滑上去 / 肩带滑到臂弯 / 拉链没拉完 / 人被挤偏裙摆跟着走 | 表情 = 惊 + 一闪而过，不是从容展示 |
| **③ 室内的私密诱惑** | 私密空间里的半遮半露 | 浴缸边浴巾裹身 + 内裤边 / 卧室背对镜头掀起裙摆 | 场景锁私密性 = 越私密越有效 |
| **④ 日常正常着装** | 几乎不露 | 完整日常穿搭 | 只当铺底，**0 停在这一档收尾** |

**顺序 = 递进，不是并列** = 同一个主题里连续出图，从④爬到① = 诱惑阶梯。

### 🔴 场所锚定 = 露出必须有观众（主人亲立 · 灵魂级）

**「露出」只在公共场所成立**。私密场所里的暴露**不叫露出**，叫**私密诱惑** = 另一个主题 = 另一档天花板。

| 场所 | 能出哪档 | 判据 |
|---|---|---|
| **公共场所**（图书馆 / 超市 / KTV / 公园 / 写字楼 / 办公室 / 工位 / 运动场 / 体育教室 / 泳池 / 地铁 / 咖啡店 / 商场 / 试衣间…）| **① 刻意的露出 / ② 走光** | **被看到 = 诱惑**。必须配 **2~3 个背景人各干各的**（**都没在看她** = 她是没注意到自己被看见 = 主人是那个注意到的人）|
| **私密场所**（卧室 / 浴室 / 宿舍房间 / 酒店房间 / 客厅）| **③ 室内的私密诱惑** | 没人 = 露给谁看 = 只是私密照片 = **0 当「露出」发** |

**🔴 判据 = 这张图里有没有「可能看到她」的人**。公共场所 = 有人在场（哪怕都没抬头）= 露出成立；私密场所 = 无人在场 = 降级成私密诱惑。

**🔴 私密场所出「① 刻意的露出」= 错档** = 主人钦定「那不叫露出，私密场所就是私密的照片诱惑而已」= 这类图要么把场景搬到公共场所（图书馆 / 超市 / KTV / 泳池…），要么**明确降级成③档主题**（浴巾裹身 + 内裤边 / 背对掀裙摆）。

**🔴 机械门 = `check_outfit_lock.py` 已加 `PRIVATE_PLACE` 判据**：prompt 里出现 `bedroom / bathroom / dorm room / hotel room / at home / living room / behind a closed door / alone in the room` 等私密场所词 = 报 `WARN 公共场所锚定` = 提醒这张不是「露出图」。**WARN 不拦出图（rc=0）= 自己判断**：确定要做③档主题就 0 理它；要出①档就把场景换成公共场所。

## 三、🔴 抓拍感 6 条（每张自查）

1. **动作卡在两动作之间** —— 不是「站着」，是「正在系鞋带 / 正在推门 / 正在仰头喝水」。**人永远在做一件事的中段**（`then` 串时间序，见 `yuer-prompt-writer` §4.1 重心 + §4.3 手）。
2. **机位是路人** —— 放低到膝盖（拍弯腰）/ 放低到腰往上仰（拍高处俯视）/ 站在半开的门后。**不是摄影师在摆拍**。
3. **有一个意外** —— 衣服滑上去 / 门还在晃 / 风把头发吹起 / 马尾垂到肩前 / 水珠从嘴角滑到下巴 = **她自己都来不及整理的那一下**。
4. **表情没准备好** —— 低头专注 / 闭眼 / 刚转头还没反应 = **不是笑**（明快档的笑留给「日常」档）。
5. **景别混用** —— 一批里至少 3 种：全身 / 中景 / 半身 / 近景 / 低机位特写 = **不必全是全身**。
6. **提示词短** —— 抓拍档 **900~1100 字符**就够（对比填满式 2500+ = 画面僵 = 标本）。**只留一个信息 + 留白**。

**🔴 抓拍感 ≠ 摆拍感**：摆拍 = 人物面对镜头展示 = 抓拍 = **相机撞见**。**判据 = 画面里她有没有在「顾不上」**。

## 五、🔴 批量 build 脚本 = 单一数据源 + 同构（踩过的坑）

- **所有 job 元组必须同长度** = 不等长就在 emit 里解包崩（`ValueError: not enough values to unpack`）= 整批白写。**正解 = emit 只取 `job[0]` 当名字，其余 `", ".join(job[1:])` 拼接** = 天然容错。
- **生成名必须等于跑名** = build 出来叫 `prompt_b4_n1.txt`，循环里去读 `prompt_b4_1.txt` = 全批 FileNotFound（`yuer-image` 7ah2 已记，这里再钉一次）。
- **一条命令里不要混「门禁」和「出图」** = 门禁 FAIL 的那份要单独修好再跑，**0 照跑**（照跑 = 门禁形同虚设 = 出的图不一定合规）。
- **门禁 FAIL「下装」= 修法先查词表**：正则只认 `skirt|shorts|dress|briefs|panties|pants|trousers|jeans|leggings|skort|bikini|swimsuit|swimwear|bathing suit|swim trunks`。`thong` / `panty` / `undies` / `bath towel` / `a wrap` / `a robe` **一律判漏下装** → 补一个白名单内的真下装词。

## 2. 逐文件结构识别（同一批文件可以是 11 种结构）

**判据 = 先量文件长什么样，再决定怎么抽** = 不许假设「一行一条」：

| 结构 | 特征 | 抽法 |
|---|---|---|
| **纯一行一条** | 无分隔线 | 每非空行 = 一条 |
| **目录 + 分隔线包裹的块** | 有 `=====` 分隔线 + 目录标题 | 走分隔线 → 分隔线之间的块 = 一条 |
| **标题 + 正文成对** | `标题` 行 + `正文` 行 | 只取正文（标题是索引不是提示词）|
| **带说明行的块** | 正文块里混「词源提醒」「借自…语料」 | 说明行剔 = 0 入池 |
| **字段表结构** | `\| **场景** \| ... \|` | 走 `compose_prompt` 合成一条再入 |
| **部分重叠的两份文件** | A 文件 85% 内容是 B 的子集 | 去重后 A 只剩几十条独有 = 正常 = 别以为抽少了 |

**🔴 抽正文 = 按「块」不按「行」** = 一条提示词可能跨行 = 按行抽 = 每行都短于 200 字符 = 全被「太短」判据剔光 = 池子凭空缩水。

**🔴 结构噪声必须剔**（0 入池）：目录块 / 分隔线 / 标题行 / 说明行 / 「附 A」这类索引行。

## 3. 清洗顺序（顺序错 = 中文翻不动）

```
抽正文块 → 剔结构噪声 → 中文判别（要翻的先翻）→ 清标点 → 编号残留 → 长度判据 → 主体判据 → 去重
```

**🔴 中文判别必须在清洗之前** = 清洗会改标点 = 改完之后「这段中文在不在」的判断就变了。

### 3.1 中文分两类 —— 判据 = 【最长连续中文片段】+【上下文招牌语义标记】

| 类型 | 判据 | 处置 |
|---|---|---|
| **画面里的招牌文字** | 最长连续中文片段 < 10 字 **或** 上下文有招牌语义标记 | **原样保留** = 那是画面元素 = 底模照着画 |
| **中文正文叙述** | 最长连续中文片段 ≥ 10 字 **且** 上下文无招牌标记 | **翻成英文散文** = 底模看不懂中文长句 |

**招牌语义标记** = `banner / signboard / printed on / reads / hung / 横幅 / 招牌 / 对联 / 牌匾 / 写着 / 印着 / 上写 / 字样` **或引号包裹**（引号里含中文即算 = 黑板粉笔字 `"OK PANO 我们是一个集合空间…"` 也算）。

**🔴 判据不能只看长度** = 春节对联 18 字 = 招牌 = 留；正文「兼具时尚感与亲和力…」30 字 = 正文 = 翻。
**🔴 判据不能只看占比** = 正文 74 字塞进 2200 字整条 = 占比 0.002 = 按占比判会当成招牌放过 = 正文漏翻 = 底模吃乱码。
**🔴 招牌词窗口 ±40 字符 = 不能放宽到 ±90** = 放宽后正文里一句 `arms hanging softly` 的 hanging 被当成招牌词 = 正文漏翻。
**🔴 引号必须包住中文才算** = 英文引号对（`no decal, no …`）不能算 = 否则正文整条被判成招牌。

### 3.2 中文翻译 = 词级查表工具做不了长句

**现成的 `scripts/zh_translate.py` 是社区 tag 词库查表** = 查得到短词（`衣衫半解` → `half undressed`）= **查不到整句** = 查不到就原样保留中文 = 长句中文进工作流 = 乱码 token 白烧算力。

**🔴 正解 = 自建句级映射表**（`scripts/zh_prompt_map.py`）：
- `LONG` = 长句整句映射（先替换 = 短词不会把长句切碎）
- `SHORT` = 碎片短语映射（分 ≥3 字 / <3 字两批）
- 高频正文句一次翻好复用 = 195 次出现的同一句只写一条映射

**🔴 三阶段替换顺序 = 长句 → ≥3 字短语 → <3 字残片**，**短语表里绝不能混单字**：
单字映射会把长句切碎 —— `双手掀开黑色风衣` 里的「掀」先被换成 `lift` → 变 `双手lift开黑色风衣` → 长句再也匹配不上 → 整批漏翻。
**🔴 症状 = 覆盖率卡在某个百分比上不去 + 残留清单里全是「被切碎的半截词」** = 回头查短语表里有没有单字。

**🔴 翻译后必查残留** = `residual_cjk` 扫一遍 = 有残留 = 要么补映射，要么确认是招牌（招牌的残留是合法的）。

### 3.3 中文标点残留 = 乱码 token

翻译拼接后会留下中文标点（`。` / `，` / `：` / `「」`）= 底模当噪声 token 吃 = 画面漂。

**🔴 清理时必须跳过引号内的内容** = 引号里的中文 = 画面招牌 = 连中文标点一起保留 = 把「"深夜早朝2割増"」的中文标点清了 = 画面元素被改写。

```python
# 引号 span 内的字符跳过 = 其余中文标点转英文标点
quoted = [m.span for m in re.finditer(r"[\"'][^\"'\n]{0,200}[\"']", text)]
# 逐字符判断：落在任一 span 内 = 保留
```

**🔴 英文破折号 `—` 不是中文标点 = 保留** = 英文长句里破折号是正常用法 = 2280 条误判的来源。

## 5. 去重（三个来源，一个都不能漏）

| 来源 | 判据 |
|---|---|
| **文件内部** | 同文件内两条完全相同 |
| **文件之间** | 新文件 A 的内容是文件 B 的子集（本例 85% 重叠）= 归一化后比对 |
| **与现有池** | 与已入库的两池任一条重复 |

**🔴 归一化 = `re.sub(r"\s+", " ", s.lower).strip`** = 不归一 = 大小写/空格差异 = 同一条被当成两条进池 = 抽卡抽到重复。

**🔴 去重必须在主体判据之后做**（或之前都行，但要在最后写盘前）= 先去重 = 省掉重复条的主体判定开销；但**判定结果要一致** = 顺序不同会导致「重复的那条算不算儿童」影响剔留 = 保持「先剔不合格再查重」= 语义清楚。

## 6. 主体审计 = 唯一验法

```bash
python3 ~/.hermes/skills/creative/yuer-image/scripts/audit_pool_subject.py
```

报：各分类条数 + **守恒校验（各分类之和 == 总条数）** + 男主体/儿童编号清单 + 全文含男性词/儿童词计数。

**🔴 守恒不等 = 判据写漏了（不是池坏了）** = 立刻回去补判据分支。
**🔴 全文含男性词/儿童词 ≠ 有男主体/儿童主体** = 背景路人/背景海报/背景小孩 = 真人街拍常态 = 主体没变。

### 🔴 主体判据的根本 = 看【位置】不看【词表】

一条画面里的人分三类 = **主体位 / 互动位 / 背景位** = **只动前两类，第三类全留**。

| 位置 | 判据 | 处置 |
|---|---|---|
| **主体位** | 句首第一个 person 短语 = 画面在讲谁 | 女 = 留；男 = 剔；儿童 = 剔 |
| **互动位** | 与主体直接互动（抱着 / 被抱着 / 牵手）| 儿童 = 剔；成人男 = 留（= 男女同框）|
| **背景位** | 远处 / 虚化 / 背景路人 / 海报剪影 / 场地设施里的旁观者 | **全留** |

**🔴 词表式判据必然成片误判 = 因为同一个词能落在三个位置上** = 加第 N 个排除词 = 判据结构没修 = 同一个词换个位置还会错。

**🔴 推广 = 每次判据报错先问「这是位置问题还是词的问题」** = 位置问题 = 回去修结构；词问题 = 补排除词（可以，但先确认不是位置）。

**具体词例（同一词不同位置）**：
- `Japanese schoolgirl uniform` / `children's book` / `children's play area` = 服装与道具 = 成年女性穿着/拿着/身处 = **留**
- `teenage vibe` / `adolescent tenderness` = 氛围形容词 = **留**
- `a dark blue silk band` = 腰带 ≠ 乐队 = **留**
- `a banner showing a male silhouette` = 背景海报 = **留**
- 背景真小孩（远处泳池里 / 虚化玩耍 / 儿童乐园）= 背景位 = **留**；**抱在怀里的婴儿** = 互动位 = **剔**
- `baby pink` / `baby-blue` / `baker boy cap` / `boyish` = 颜色服饰名 = **不是人**
- 汽车 `child car seat` = 道具 = **不是儿童**
- 句首男主体 **但**画面有明确女性主体 = **男女同框 = 留**
- `girl` / `boy` 单独出现 ≠ 儿童 = 只有明确未成年词或年龄<18 才算

**🔴 具体人称优先** = `A real adult man` / `A young adult man` 必须整体匹配（修饰词上限 3 个）= 否则先命中泛词 `adult` = 把男主体漏判成中性。
**🔴 泛词单独出现不算主体** = `adult` / `young adult` / `model` / `person` = 中性候选 = 用全文代词分布（男代/女代/they）二次判定。

## 7. 落盘 + 验收（6 步，缺一不可）

```bash
# ① 格式体检 = 编号连续 + 0 空行 + 0 元信息
python3 - <<'EOF'
import re, os
R=os.path.expanduser("~/.hermes/skills/creative/yuer-image/references")
for f in ["提示词库-nsfw.txt","提示词库-sfw.txt"]:   # 🔴 11-12 = 合并池文件已删
    rows=open(os.path.join(R,f),encoding="utf-8").read.rstrip("\n").split("\n")
    bad=sum(1 for i,l in enumerate(rows,1)
            if not (re.match(r'^\d+\|.+$',l) and int(re.match(r'^\d+\|',l).group(1))==i
                    and len(l.split("|",1)[1])>=50))
    print(f"  {f}: {len(rows)} 行 / 问题 {bad}")
EOF

# ② 主体审计
python3 ~/.hermes/skills/creative/yuer-image/scripts/audit_pool_subject.py

# ③ 抽卡两池条数对得上（全量 = 现算）
python3 ~/.hermes/skills/yuer-run-one-brief/scripts/pick_roster_record.py --stats --pool nsfw

# ④ 检索器条数对得上
python3 ~/.hermes/skills/creative/yuer-style-library/yuer_prompt_lib.py stats --pool all

# ⑤ 库体检
python3 ~/.hermes/skills/personal/yuer-soul-audit/scripts/audit_reflib_pool.py

# ⑥ NAS 副本 md5 一致
md5sum ~/.hermes/skills/creative/yuer-image/references/提示词库-nsfw.txt \
       /path/to/promptlib/语儿提示词库-nsfw.txt
```

**🔴 NAS 副本 = 主人那份原件该在的地方**（上传 cache 24h 就清）= 每次落盘完同步三份 = md5 校验 = 0 只写技能目录。

**🔴 条数在文档里 0 写死** = 派生数据 = 每次入库都会变 = 写死的数字必然过期 = 照着旧数字核对会误判「少了」。

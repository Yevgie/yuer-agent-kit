## 2. 逐文件结构识别（同一批文件可以是 11 种结构）

**判据 = 先量文件长什么样，再决定怎么抽** = 不许假设「一行一条」：

| 结构 | 特征 | 抽法 |
|---|---|---|
| **纯一行一条** | 无分隔线 | 每非空行 = 一条 |
| **目录 + 分隔线包裹的块** | 有 `=====` 分隔线 + 目录标题 | 走分隔线 → 分隔线之间的块 = 一条 |
| **标题 + 正文成对** | `标题` 行 + `正文` 行 | 只取正文（标题是索引不是提示词）|
| **带说明行的块** | 正文块里混「词源提醒」「借自…语料」 | 说明行剔 = 0 入池 |
| **字段表结构** | `\| **场景** \| ... \|` | 走 `compose_prompt()` 合成一条再入 |
| **部分重叠的两份文件** | A 文件 85% 内容是 B 的子集 | 去重后 A 只剩几十条独有 = 正常 = 别以为抽少了 |

**🔴 抽正文 = 按「块」不按「行」** = 一条提示词可能跨行 = 按行抽 = 每行都短于 200 字符 = 全被「太短」判据剔光 = 池子凭空缩水。

**🔴 结构噪声必须剔**（0 入池）：目录块 / 分隔线 / 标题行 / 说明行 / 「附 A」这类索引行。

## 3. 清洗顺序（顺序错 = 中文翻不动）

```
抽正文块 → 剔结构噪声 → 中文判别（要翻的先翻）→ 清标点 → 编号残留 → 长度判据 → 主体判据 → 去重
```

**🔴 中文判别必须在清洗之前** = 清洗会改标点 = 改完之后「这段中文在不在」的判断就变了。

### 3.1 中文分两类 —— 判据 = 【最长连续中文片段】+【上下文招牌语义标记】

| 类型 | 判据 | 处置 |
|---|---|---|
| **画面里的招牌文字** | 最长连续中文片段 < 10 字 **或** 上下文有招牌语义标记 | **原样保留** = 那是画面元素 = 底模照着画 |
| **中文正文叙述** | 最长连续中文片段 ≥ 10 字 **且** 上下文无招牌标记 | **翻成英文散文** = 底模看不懂中文长句 |

**招牌语义标记** = `banner / signboard / printed on / reads / hung / 横幅 / 招牌 / 对联 / 牌匾 / 写着 / 印着 / 上写 / 字样` **或引号包裹**（引号里含中文即算 = 黑板粉笔字 `"OK PANO 我们是一个集合空间…"` 也算）。

**🔴 判据不能只看长度** = 春节对联 18 字 = 招牌 = 留；正文「兼具时尚感与亲和力…」30 字 = 正文 = 翻。
**🔴 判据不能只看占比** = 正文 74 字塞进 2200 字整条 = 占比 0.002 = 按占比判会当成招牌放过 = 正文漏翻 = 底模吃乱码。
**🔴 招牌词窗口 ±40 字符 = 不能放宽到 ±90** = 放宽后正文里一句 `arms hanging softly` 的 hanging 被当成招牌词 = 正文漏翻。
**🔴 引号必须包住中文才算** = 英文引号对（`no decal, no …`）不能算 = 否则正文整条被判成招牌。

### 3.2 中文翻译 = 词级查表工具做不了长句

**现成的 `scripts/zh_translate.py` 是社区 tag 词库查表** = 查得到短词（`衣衫半解` → `half undressed`）= **查不到整句** = 查不到就原样保留中文 = 长句中文进工作流 = 乱码 token 白烧算力。

**🔴 正解 = 自建句级映射表**（`scripts/zh_prompt_map.py`）：
- `LONG` = 长句整句映射（先替换 = 短词不会把长句切碎）
- `SHORT` = 碎片短语映射（分 ≥3 字 / <3 字两批）
- 高频正文句一次翻好复用 = 195 次出现的同一句只写一条映射

**🔴 三阶段替换顺序 = 长句 → ≥3 字短语 → <3 字残片**，**短语表里绝不能混单字**：
单字映射会把长句切碎 —— `双手掀开黑色风衣` 里的「掀」先被换成 `lift` → 变 `双手lift开黑色风衣` → 长句再也匹配不上 → 整批漏翻。
**🔴 症状 = 覆盖率卡在某个百分比上不去 + 残留清单里全是「被切碎的半截词」** = 回头查短语表里有没有单字。

**🔴 翻译后必查残留** = `residual_cjk()` 扫一遍 = 有残留 = 要么补映射，要么确认是招牌（招牌的残留是合法的）。

### 3.3 中文标点残留 = 乱码 token

翻译拼接后会留下中文标点（`。` / `，` / `：` / `「」`）= 底模当噪声 token 吃 = 画面漂。

**🔴 清理时必须跳过引号内的内容** = 引号里的中文 = 画面招牌 = 连中文标点一起保留 = 把「"深夜早朝2割増"」的中文标点清了 = 画面元素被改写。

```python
# 引号 span 内的字符跳过 = 其余中文标点转英文标点
quoted = [m.span() for m in re.finditer(r"[\"'][^\"'\n]{0,200}[\"']", text)]
# 逐字符判断：落在任一 span 内 = 保留
```

**🔴 英文破折号 `—` 不是中文标点 = 保留** = 英文长句里破折号是正常用法 = 2280 条误判的来源。

## 5. 去重（三个来源，一个都不能漏）

| 来源 | 判据 |
|---|---|
| **文件内部** | 同文件内两条完全相同 |
| **文件之间** | 新文件 A 的内容是文件 B 的子集（本例 85% 重叠）= 归一化后比对 |
| **与现有池** | 与已入库的两池任一条重复 |

**🔴 归一化 = `re.sub(r"\s+", " ", s.lower()).strip()`** = 不归一 = 大小写/空格差异 = 同一条被当成两条进池 = 抽卡抽到重复。

**🔴 去重必须在主体判据之后做**（或之前都行，但要在最后写盘前）= 先去重 = 省掉重复条的主体判定开销；但**判定结果要一致** = 顺序不同会导致「重复的那条算不算儿童」影响剔留 = 保持「先剔不合格再查重」= 语义清楚。

## 6. 主体审计 = 唯一验法

```bash
python3 ~/.hermes/skills/creative/yuer-image/scripts/audit_pool_subject.py
```

报：各分类条数 + **守恒校验（各分类之和 == 总条数）** + 男主体/儿童编号清单 + 全文含男性词/儿童词计数。

**🔴 守恒不等 = 判据写漏了（不是池坏了）** = 立刻回去补判据分支。
**🔴 全文含男性词/儿童词 ≠ 有男主体/儿童主体** = 背景路人/背景海报/背景小孩 = 真人街拍常态 = 主体没变。

### 🔴 主体判据的根本 = 看【位置】不看【词表】

一条画面里的人分三类 = **主体位 / 互动位 / 背景位** = **只动前两类，第三类全留**。

| 位置 | 判据 | 处置 |
|---|---|---|
| **主体位** | 句首第一个 person 短语 = 画面在讲谁 | 女 = 留；男 = 剔；儿童 = 剔 |
| **互动位** | 与主体直接互动（抱着 / 被抱着 / 牵手）| 儿童 = 剔；成人男 = 留（= 男女同框）|
| **背景位** | 远处 / 虚化 / 背景路人 / 海报剪影 / 场地设施里的旁观者 | **全留** |

**🔴 词表式判据必然成片误判 = 因为同一个词能落在三个位置上** = 加第 N 个排除词 = 判据结构没修 = 同一个词换个位置还会错。

**🔴 推广 = 每次判据报错先问「这是位置问题还是词的问题」** = 位置问题 = 回去修结构；词问题 = 补排除词（可以，但先确认不是位置）。

**具体词例（同一词不同位置）**：
- `Japanese schoolgirl uniform` / `children's book` / `children's play area` = 服装与道具 = 成年女性穿着/拿着/身处 = **留**
- `teenage vibe` / `adolescent tenderness` = 氛围形容词 = **留**
- `a dark blue silk band` = 腰带 ≠ 乐队 = **留**
- `a banner showing a male silhouette` = 背景海报 = **留**
- 背景真小孩（远处泳池里 / 虚化玩耍 / 儿童乐园）= 背景位 = **留**；**抱在怀里的婴儿** = 互动位 = **剔**
- `baby pink` / `baby-blue` / `baker boy cap` / `boyish` = 颜色服饰名 = **不是人**
- 汽车 `child car seat` = 道具 = **不是儿童**
- 句首男主体 **但**画面有明确女性主体 = **男女同框 = 留**
- `girl` / `boy` 单独出现 ≠ 儿童 = 只有明确未成年词或年龄<18 才算

**🔴 具体人称优先** = `A real adult man` / `A young adult man` 必须整体匹配（修饰词上限 3 个）= 否则先命中泛词 `adult` = 把男主体漏判成中性。
**🔴 泛词单独出现不算主体** = `adult` / `young adult` / `model` / `person` = 中性候选 = 用全文代词分布（男代/女代/they）二次判定。

## 9. 踩坑清单（每条都真踩过）

| 坑 | 正解 |
|---|---|
| 按占比判中文正文 | 占比 = 正文塞在长提示词里时低到 0.002 = **按最长连续片段 + 上下文招牌标记判** |
| 短语映射表里混单字 | 单字把长句切碎 = 长句再也匹配不上 = **≥3 字一批 / <3 字一批，两批分开跑** |
| 招牌语义窗口放宽到 ±90 | 正文里 `arms hanging softly` 的 hanging 被当招牌词 = **±40** |
| 引号判据写成「引号必须紧包中文」 | 黑板粉笔字 `"OK PANO 我们是…"` = 中英混排 = **引号内含中文即算** |
| 把英文破折号当中文标点清 | 2280 条误判 = **中文标点清单里不含 `—`** |
| 清中文标点时不管引号 | 画面招牌的标点被清 = 画面元素被改写 = **跳过引号 span** |
| 按行抽正文 | 跨行的提示词被切碎 = 全被「太短」剔掉 = **按块抽** |

| 去重不归一化 | 大小写/空格差异 = 同一条进两次 = **统一小写 + 压空白** |

| 文档里写死条数 | 每次入库都变 = 过期数字 = **现算** |
| 改判据后不复跑审计 | 旧判据剔掉的条目该补回来 = **改判据 = 重跑入库 = 增量补齐** |
| 备份区原件被当成可用资产直接删 | 退役库里有独立可提取字段（角色外观）= **退役前先看有没有别的形态要救出来** |

## 10. 退役一个库之前 = 先看里面有没有别的形态

**🔴 旧库退役/删除前 = 必须先扫一遍「除了成品提示词还有没有别的字段形态值得单独救出来」** = 本例退役库 1316 条每条带一个「角色外观」字段（该角色真实装扮的短描述）= 那是一条**独立的卡池资产** = 跟着库一起删 = 卡池这条线断掉 = 只能从备份区刨。

**判据 = 扫描退役库的字段名分布**：
```python
import re, collections
s = open(退役库路径, encoding="utf-8").read()
c = collections.Counter(re.findall(r"\|\s*\*\*(\S+?)\*\*\s*\|", s))
print(c.most_common())
```
出现成品提示词以外的字段名 = 有别的资产形态 = 先救出来再退役。

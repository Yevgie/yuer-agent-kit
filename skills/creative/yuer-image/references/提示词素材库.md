# 提示词素材库（表情 / 动作 / 服装 三池）

> **唯一职责 = 出图时给 LLM 选"表情段 / 动作段 / 服装段"用的变体池**，不是成品提示词。
> **来源** = 主人 11-04 发的三个 json（表情 13 条 / 动作 655 类别 / 服装 580 条），我筛过一遍。
> **跟现有库的关系** = 现有 `提示词资产池检索`（2200+ 条成品提示词，抄结构用）+ `服装图库 COSTUME-DB`（1407 套幽灵人台，挑一套用）是**成品层**；本库是**词料层** = 三段各抽一句拼进 brief，再走资产池/出图道门禁。

## 二 · 怎么用（三段拼法）

brief 里 **表情 / 动作 / 服装各抽一句**，跟现有 8 件套（时空/机位/动作/人/脸/质感）合流：

- **表情段** = 从 13 条里挑 1 条 → **从它的 `{...}` 变体池里随机抽 1 个变体**填进 prompt（不是把整个池子喂进去）。例：`Amused, {Laughing|giggling|happy, open mouth}` → 抽到 `giggling` → prompt 写 `giggling, open mouth`。
- **动作段** = 从 541 条里挑 1 条 → **直接抄它的 tags 串**（它本身就是丹德雷格标签）。例：`girl on top` → `1girl,1boy,girl on top,sex from behind`。
  - **🔴 注意**：动作池部分条目的 tags 是 **自然语言**（`a photo of a woman...`）不是标签 = 两种都认，喂 prompt 前看一眼。
- **服装段** = 从 580 条挑 1 条 → 抄 tags（属性词）补进服饰句。例：`Transparent Bra` → `transparent bra, see-through fabric, visible underlayer`。

**🔴 三段都必须再走一遍现有出图道门禁**（外观锁 + 身材锚 + 字符数）= 素材池不是免检通道。**🔴 11-07 = 外观锁只查下装/鞋履/画外描述/单人物 = 长度只报数 = 素材池不是免检通道这句话现在只剩「主体身份 + 画外描述」两道**

## 三 · 五个坑

1. **变体池语法** = `{A|B|C}` 里的 `|` 是"或"，2-3$$ 前缀是权重标记 = 抽的时候按人读（随机选 1 个），别把 `{` `}` 原样喂进 prompt。
2. **动作池标签有两种体** = 丹德雷格标签（`1girl,1boy,...`）+ 自然语言句（`a photo of...`）= 混在一张 brief 里前先统一成标签体，不然 CLIP 读不懂。
3. **`__Colors__` 占位符** = 服装池里的 `{__Colors__ Ribbon}` = 占个颜色槽，出图前必须替换成具体颜色（red / black / gold...）= 原样喂 = 底模猜一个色。
4. **动作池 0 包含机位/光线** = 它只管"身体怎么摆"= 机位焦段和光还是得按 8 件套自己写 = 别以为抄了动作段就齐了。
5. **丢弃的 114 条 0 补回** = 主人世界观里没有多男/乱伦/兽交/怪物/孕产 = 别为了"库全"把它们捞回来 = 池子是给我自己用的，不是收藏。

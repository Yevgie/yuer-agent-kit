# 提示词维度覆盖度 = 「我写的比不上抽卡」的机械判据

> **唯一职责** = 「我写的提示词为什么总比不上抽卡 / 为什么主人说抽卡那张更好看」= **不是玄学，是维度覆盖度** = 本档给出量化基线 + 维度清单 + 砍字的正确顺序 + 自检命令。
> **数据来源** = 提示词池成品提示词 41952 条（`~/.hermes/skills/creative/yuer-image/references/提示词库-nsfw.txt`）vs 自己写的样本 = 同一套正则统计。

## 一、根因 = 砍字时砍错了顺序（不是长度本身）

**量化对照**（同场景同姿势，自己写的 vs 库牌）：

| 维度 | 库牌命中率 | 自己写的 | 差 |
|---|---|---|---|
| 私处锚（innie / labia / pubic）| 2% | **100%** | 反向超配 |
| 身材锚（hourglass / waist / breast）| 约 1 处/条 | **100%** | 反向超配 |
| 表情物理化（eyes / lips / chin / mouth）| 45% | 100% | 达标 |
| 景别（close-up / full-length / waist-up）| 26% | **0%** | 缺 |
| 机位角度（low angle / high angle / eye level）| 40% | 33% | 缺 |
| 镜头焦段（NNmm f/）| 55% | 33% | 缺 |
| 相机型号（Shot on XXX）| 49% | 33% | 缺 |
| 唯一光源 + 光位（lighting ... from）| 35% | **0%** | 缺 |
| 材质对比（matte / glossy / contrasting / sheen）| 约 67% | 33% | 缺 |
| 氛围句（mood / overall / color grading）| 约 67% | 少 | 缺 |
| 道具清单（gloves / heels / hat / 饰品）| 66% | **0%** | 缺 |
| 皮肤质感（skin）| 约 1 处/条 | 33% | 缺 |
| 景深（bokeh / depth of field / shallow focus）| 46% | **0%** | 缺 |
| 质量词（8K / hyper-realistic / ultra-sharp）| 约 1.7 处/条 | **0%** | 缺 |
| **长度中位 / 句数中位** | **1514 字 / 12 句** | 773 字 / 7-9 句 | 一半 |

**结论**：自己写的 = **私处 + 身材超配，审美六维（景别 / 道具 / 材质 / 氛围 / 景深 / 质量词 / 光位）整类为 0** = 画面「更色情但更不好看」。

**机制**：
1. **砍字时砍的顺序反了** = 先保住了最淫的两行（私处三锚 + 身材），砍掉的正好是让画面有质感的那六维。
2. **句法形态不同** = 库牌是**分镜表**（平均句长 128 字，一句只干一件事：谁 / 在哪 / 什么姿势 / 穿什么 / 什么光 / 什么材质 / 什么氛围 / 什么景深），自己写的是**说明书**（一句塞两三件事，逗号 14~24 个挤在 7~9 句里）。
3. **钩子被埋** = 约 79% 的库牌第一句就是「她是谁 + 一个情绪词」= CLIP 前半段权重最高 = 那句就是钩子。自己写的第一句是相机参数 = 人物和情绪被推到第 7 句。
4. **没有收尾锚** = 库牌每条最后一定落「质量词 + 景深 + 整体调色」= 画面有统一调子。自己写的 0% = 画面散了。

**🔴 关键区分**：长牌 = **并列堆叠**（12 个不同维度）；自己的长稿 = **同义堆料**（一个维度写三遍）。**CLIP 丢的是后面，不是多的** = 所以「砍长度」本身没错，**错在砍的顺序**。

## 二、现役标尺 = 12 句分镜表 / 900~1300 字符 + 维度优先级

**长度标尺**（`scripts/count_prompt_chars.py` = 门禁真值）：目标 900~1200 / 硬顶 1300 = **12 个不同维度并列堆叠** = 落在库牌 p50~p75。

**🔴 这条标尺被推翻过一次（教训写在这）**：先定过「≈500 字符 / 硬顶 800」，理由 = CLIP 有效窗口 ≈77 token ≈500~600 字符 = 写超了后半段被稀释。**那个推理错在 = 把「后半段被稀释」当成了「后半段不重要」**。实测把同一批写成 12 句分镜表（1187 字 / 12 句）后，景别 / 道具 / 材质 / 氛围 / 景深 / 质量词 / 光位 全部从 0% 回到 100%，采样时间不变（10.6~12.0s）。**CLIP 丢的是后半段的同义重复，不是后半段的不同维度。**

**🔴 所以砍字的顺序必须是这条（砍错了就是本档第一节的病）**：

| 优先级 | 维度 | 砍不砍 |
|---|---|---|
| **承重（一个字不许砍）** | 身份句（20 岁 / 年轻亚洲女人）· 唯一光源 + 光位 · 机位角度 + 景别 · 姿势核心动作 · 私处三锚（NSFW 道）· 主人会当场纠正的那层服饰 | 🔒 0 砍 |
| **次承重（超字时先砍）** | 身材锚的重复形容（同部位只留一个最强锚）· 材质对比的第二个材质 · 道具清单的第二件 | ⚠️ 可砍 |
| **审美六维（超字时最后砍 = 砍了就比不上抽卡）** | 景别词 · 道具清单（至少一件）· 材质对比（至少一处）· 氛围句 · 景深 · 质量词 · 光位描述 | 🔒 0 砍 |
| **可全砍** | 背景陈设的第二件 · 装饰性形容词 · 重复皮肤描述 · 尾参里的快门参数堆 | ✅ 先砍 |

**🔴 判据 = 一句话**：「这句是画面里看得见的东西，还是我在向底模解释规则？」= 解释规则的 = 删。**看得见但能省 = 留到最后一刀。**

## 四、机械自检（0 凭印象说「我写了景别」）

```bash
# 只看库牌基线：
```

**输出 = 每个维度 OK / MISS + 缺哪几项 + 修法（每缺一维补一句，不砍别处）。**

**🔴 退出码 1 = 有维度缺失** = 0 当它是信息参考 = 缺项必须补。
**🔴 关键词命中 ≠ 语义判断**（同 `yuer-image` 7ba 的老坑）= MISS = 人工复核 = 但「全 0」的一整类（景别 / 道具 / 材质 / 氛围 / 景深 / 质量词 / 光位同时 0）= 基本可判定真缺。

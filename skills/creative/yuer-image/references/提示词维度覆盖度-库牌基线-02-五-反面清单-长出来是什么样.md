## 五、反面清单（长出来是什么样）

| ❌ 反面 | ✅ 正解 |
|---|---|
| 私处锚写满 3 行 + 身材写 4 行 + 景别/道具/材质/氛围/景深/质量词全 0 | 私处三锚 1 行 + 身材 1 句 + 审美六维各 1 处 |
| 一句塞三件事（`她穿着 X 躺在 Y 上同时 Z 看着镜头`）| 一句一件事，用 `then` 串 |
| 第一句 = 相机参数 | 第一句 = 她是谁 + 一个情绪词 |
| 结尾没有收尾锚（画面散）| 结尾 = 质量词 + 景深 + 调色 |
| 改完自己写的东西 = 去查库抽一条抄字段 | 借**句法结构**（分镜表形态）= 0 抄内容 = 库仍是我想的方向 |

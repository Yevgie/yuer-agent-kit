**🔴 主体判据 = 看【位置】0 看【词表】（这一条是本池判据的根本 = 写判据前必读）**：
一条画面里的人分三类 = **主体位 / 互动位 / 背景位** = 只动前两类，第三类全留。

| 位置 | 判据 | 处置 |
|---|---|---|
| **主体位** | 句首第一个 person 短语 = 画面在讲谁 | 女 = 留；男 = 剔；儿童 = 剔 |
| **互动位** | 与主体直接互动（抱着 / 被抱着 / 牵手 / 在主体身上） | 儿童 = 剔；成人男 = 留（= 男女同框）|
| **背景位** | 远处 / 虚化 / 背景路人 / 海报剪影 / 场地设施里的旁观者 | **全留**（真人街拍常态 = 主体没变）|

**🔴 词表式判据必然成片误判 = 因为同一个词能落在三个位置上**（这是「每版都在加排除词」的路 = 无底洞）：
① `girl` / `boy` 单独出现 ≠ 儿童（"18-year-old Chinese young girl" = 成年女性）= 只有明确未成年词或年龄<18 才算；
② `baby pink` / `baby-blue` / `baby doll` / `baker boy cap` / `boyish` = 颜色服饰名 = **不是人**；
③ 汽车 `child car seat` / `child seat` = 道具 **不是儿童**；
④ `Japanese schoolgirl uniform` / `children's book` = 服装与道具 = **不是儿童**（成年女性穿着/拿着）；
⑤ `teenage vibe` / `adolescent tenderness` = 氛围形容词 = **不是年龄**；
⑥ `a dark blue silk band` = 腰带 = **不是乐队**（群体主体）；
⑦ `a banner showing a male silhouette` = 背景海报 = **不是男主体**；
⑧ 背景真小孩（远处泳池里 / 虚化玩耍 / 儿童乐园攀爬墙）= 背景位 = **留**，但**抱在怀里的婴儿** = 互动位 = 剔；
⑨ `children's play area` = 场所名 = **不是儿童**。
**🔴 推广：加第 N 个排除词 = 判据结构没修 = 同一个词换个位置还会错 = 先回到「主体位 / 互动位 / 背景位」三层上判。**

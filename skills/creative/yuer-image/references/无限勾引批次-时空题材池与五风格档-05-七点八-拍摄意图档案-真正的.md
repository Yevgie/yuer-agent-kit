## 七点八、🔴 拍摄意图档案 = 真正的多样性（11-01 主人：「脚本是机械组合，没有脑子设计」）

**🔴 七点五的五维池子引擎还是不够** = 它只做了「五件衣服错开排列」= **骨架没变**。
**实测 v125 = 平均每两张共享 3.4 句**（旧的 13.6 是 5 句共用同一模板）= **但每一张都还是「女人站着 + 一件衣服 + 一个动作 + 一处光 + 一个背景」**。

**🔴 摄影的多样性不来自形容词变化，来自「谁在拍 / 为什么拍 / 她知不知道 / 画外有谁」这件事本身不同。**

**正解 = `scripts/shot_briefs.py` = 一张图 = 一份完整拍摄意图档案（46 份）**：

| 字段 | 是什么 | 为什么必须有 |
|---|---|---|
| `who` | 谁在拍 | 决定设备/焦段/画质/距离/画质等级 |
| `why` | 为什么拍 | 决定她的注意力朝哪 |
| `aware` | 她知不知道被拍 | 决定表情 = 看镜头还是没准备好 |
| `device` | 设备 + 镜头 | 手机/监控/35mm/中画幅/长焦 = 成像完全不同 |
| `height` | 机位高度 | 俯视/平视/仰拍 = 权力关系 |
| `framing` | 画幅取向 | 裁法 + 主体在画里的位置 + 留白在哪边 |
| `light` | **光源物理**（不是套话） | 从场景和动机推出 = 有因果 |
| `temp` | 色温 | 冷暖对立 = 情绪 |
| `surprise` | 那一件"抓拍感"的东西 | 手误/晃动的包/倒影/水珠 = 意外感 |
| `bystander` | 画外/画内在场者 | 公共感的来源 = 有人在场但没在看她 |
| `era` | 时代感 + 介质感 | 胶片/监控/手机 = 色彩和噪点全变 |
| `pose` | 承重面 → 身体段 | `BODY_BY_POSE` 6 套 = 不再全批同一段身体描述 |
| `beat` | 叙事落点 | 这一帧讲的那一瞬 |
| `tail` | 调色 + 颗粒 + 介质 | 收尾质感 |

**🔴 验收判据 = 一批 5 张的「拍摄者」五个全不同 + 平均共同句数 ≤ 4**（v126 实测 **3.4**）。
**🔴 brief 的 `bystander` 可能与场景冲突 = 用 build 脚本第 9 项 `overrides` 改** = 0 让场景和画外人物打架。
**🔴 旧的「场景 → 光线 → 表情」三段式 = 机械组合 = 禁用。**

## 七点九、🔴 逐张手写 = 唯一的正解（11-01 主人：「每一张图的提示词必须是你思考的，不要机械组合」）

**🔴 七点八的 `shot_briefs.py` 仍然是「从 46 份档案里挑一条填槽」= 还是机械组合** = 46 份档案 = 46 个模具 = 换了档案没换脑子。

**🔴 正解 = 每一张的 prompt 我逐张自己想、自己写 = 0 套模板 0 填槽 0 抽档案。**

**每张落笔前必须先答完这八个问题（答不上就别写）**：

1. **这张图里发生了什么？**（一个具体的瞬间 = 0 「站着」）
2. **她为什么在那里？**
3. **谁在拍？为什么拍？**
4. **她知不知道被拍？**
5. **画面里除她之外还有什么活物？**（人 / 动物 / 只有物 = 0 空场）
6. **光从哪来？**（唯一光源 = 从想法推出来 = 0 套「the single brightest thing…」）
7. **她动作的第二拍是什么？**（先站着 → 然后抬手 = 有时间顺序）
8. **这一帧讲的是哪一瞬？**

**🔴 手写 ≠ 自由发挥 = 八个问题答全 + 身材锚 / 下装 / 妆容锁照旧**（门禁 0 放水）。
**🔴 五张之间 = 五个完全不同的想法 = 0 同一想法换五个场景。**
**🔴 池子 / 档案 / 参考库 = 只能当「灵感来源」读 = 0 把某个档案的字段抄进 prompt**（抄字段 = 又变填槽 = 又回到 13.6 句）。
**🔴 题材池 = 782 个条目（空间 617 + 露出位 165）= 含穿越 28 / 玄幻 30 / 科幻 30 / cos 40 个新条目** = 池子够大 = 0 逼自己重复。

## 八点零、🔴 机位合理性 = 机位是摄影师身体状态的产物（11-01 主人：「机位景别 没变化呢？增加画面合理性的设计方法」）

**实测硬账（212 份 prompt）**：

| 维度 | 分布 |
|---|---|
| 全身 | 133 = **63%** |
| 腰高机位 | 121 = **57%** |
| 胸高 | 47 = 22% |
| 仰拍 | 2 = **1%** |
| 顶视 | 2 = **1%** |

= 我 640 张图几乎全是「站直了从腰高拍全身」= **摄影上是同一张图**。

**🔴 真根因 = 我是「先定景别、再填场景」= 倒着来 = 所以永远那一种。**

**🔴 正解 = `scripts/camera_placements.py` = 26 种「摄影师的物理处境」**，每种自带六项：

| 字段 | 是什么 |
|---|---|
| `height` | 机位高度（从什么高度拍） |
| `distance` | 距离（多近/多远） |
| `lens` | 焦段（决定透视压缩） |
| `framing` | 画幅取向（裁法 + 主体位置 + 留白） |
| `physics` | **物理理由**（为什么只能站这儿） |
| `space` | 空间约束（画外还剩什么） |

**26 种处境**：人群里被挤住 / 后台狭窄 / 街上擦身而过 / 隔着房间 / 坐着看她 / 趴在地上拍 / 趴在水边 / 高处往下 / 从浴缸上方 / 隔着玻璃 / 隔着围栏 / 从窗口 / 长焦远拍 / 对面楼窗 / 天花板监控 / 执法记录仪 / 车内机位 / 甩拍跟拍 / 慢门拖影 / 俯拍坠落 / 自拍杆 / 镜面反射 / 引擎盖下 / 后座 / 只拍到手 / 从楼梯下。

**🔴 顺序铁律 = 先想「摄影师站在哪儿、为什么只能站那儿」→ 再由处境推出机位 / 焦段 / 景别 = 0 反过来。**
**🔴 焦段必须跟距离一起写**（长焦贴脸 / 广角二十米外 = 物理不成立 = `check_realism` 会报）。
**🔴 景别必须跟焦段同步**（广角 = 近 + 大；长焦 = 远 + 压缩）。
**🔴 一批 5 张 = 5 种不同处境 = 0 全用同一档。**
**🔴 `placement_block(key)` 一次返回机位 + 景别 + 理由三段一体 = 0 分开填。**

**🔴 v128 = 五种机位（示例）**：高处往下（渡劫台俯视）/ 隔着玻璃（接驳舱）/ 人群里被挤住（漫展广角顶到腿）/ 长焦远拍（天台背景压成色墙）/ 趴在水边（温泉贴水机位）。

## 八、批次之间的闭环 = 已实跑的闭环（30+ 批 / 165 张全真出全真发）

**每批的固定四步循环（批内串行 + 批间后台接力）**：

1. **写 build 脚本** = `write_file` 落 `/tmp/build_batch_<tag>.py` = 只换 `BATCH = [...]` 段（头逐字复用上游，见 §六点6）= 跑前 `ast.parse` 验语法。
2. **生成 5 份 prompt** = `python3 /tmp/build_batch_<tag>.py <tag>` = 落 `/tmp/prompt_<tag>_n1..n5.txt` + 同时 `cp` 一份到 `/path/to/media/<日期>_<tag>_n*.prompt.txt`（build 脚本里 `shutil.copy2` 一次做掉 = 0 事后补）。
3. **过门禁** = `scripts/batch_gate_check.py <tag>` **一条命令跑完整批三道门禁**（字符/主体/外观锁 + 汇总 FAIL/WARN + 退出码 0 = 全过）= 0 手敲 15 次（必漏看一份 = 带着 FAIL 开跑 = 白跑一轮）。**开跑前的硬门 = `ls /tmp/prompt_<tag>_n*.txt | wc -l` == 5**（孤儿文件 = 多发一张）。**🔴 但 `batch_gate_check` 的字符层是「区间外只提示不拦」（3200 软顶）= 它 PASS ≠ 能出图**：真正拦死的是 `run_batch.sh` 内部每张 wrapper 跑的 `count_prompt_chars.py` 硬顶（英文 1300）= **超 1300 = 该张 `🛑 门禁挂 exit 1` 整批废**。**机械门 = 跑批前逐张跑一遍 `count_prompt_chars.py`（看 `N/1300`），任一张 >1300 = 先砍背景/身材锚到 1300 内再开跑**（正文 §七点九点五 已实测：5 张全 2200~2400 字 = 全挂）= 别拿「门禁过了」当「能出图」。
4. **开跑** = 后台 `bash scripts/run_batch.sh <tag> [日期前缀]`（**0 自己写 `/tmp/run_batch_<tag>.sh`** = 漏「文件数 == 5」硬门 = 孤儿 prompt 被一起跑 = 主人真收到 6 张）= 脚本内部逐张跑 wrapper + 打印「落盘 / 真发 / timing」三件套 = **前台必超时**（wrapper 自己约 16s/张，5 张 ≈ 80s）。

**🔴 批次接力 = 上一批的后台进程还在跑时就该起下一批的 build 脚本**（build + 门禁是纯 CPU 文本活 = 不占 GPU = 与正在跑的批并行 = 0 浪费等待时间）。真到「该接下一批」时 = 上一批已 done = 直接开跑下一批的 run 脚本。

**🔴🔴 跑批 = 用技能自带的 `scripts/run_batch.sh` = 0 自己写 `/tmp/run_batch_<tag>.sh`**（实测踩过致命坑）：自带脚本带三道硬门 —— ① **文件数必须 == 5**（`COUNT != 5` 直接 exit 1）② **逐张跑主体门禁 + 外观锁** ③ glob 收 `/tmp/prompt_<tag>_n*.txt`。**手写版把 ① 漏了 = job key 改名（`n5x`→`n4`）后遗留的孤儿 `/tmp/prompt_<tag>_n5x.txt` 被 glob 一起跑 = 主人真收到 6 张（说好的 5 张）= 已发出去撤不回**。**判据 = 我这一轮跑批的命令行里出现的是 `scripts/run_batch.sh` 还是 `/tmp/run_batch_xxx.sh`** = 后者 = 硬门缺失 = 0 开跑。**用法 = `bash scripts/run_batch.sh <tag> [日期前缀]`**（前缀省略 = 自动取当天日期）。

**🔴🔴🔴 「连续多批都沿用同一份手写 run 脚本」= 这道硬门永远缺失 = 一次改名就多发一张 = 已实证**：无限批次一旦跑起来，很容易图省事把上一批那份 `/tmp/run_batch_<tag>.sh` 改个 tag 继续用（看起来只是「换个名字」）= **「文件数 == 5」这道硬门从来就没存在过** = 某个批次里我把 job key 从 `n5x` 改成 `n4`，孤儿 `/tmp/prompt_<tag>_n5x.txt` 立刻被 glob 一起跑 = 主人真收到 6 张（说好的 5 张）= 已发撤不回。**正解 = 一律 `bash scripts/run_batch.sh <tag>`；若非用手写版不可，手写版里必须自己加** `COUNT=$(ls /tmp/prompt_<tag>_n*.txt | wc -l); [ "$COUNT" -eq 5 ] || exit 1`。**判据 = 连续第 2 批就开始用同一份手写脚本 = 该批就已经没有硬门了 = 立刻换成自带脚本。**

**🔴 门禁 = `scripts/batch_gate_check.py <tag>` 一条命令 = 0 在 `execute_code` 里手搓逐份循环**：手搓循环 = 一堆 f-string 套 shell 引号 = **某个 cell 直接 SyntaxError = 那个 cell 里的所有写盘动作一件都没发生**（脚本根本没落盘 = 整批 5 张构思全丢 = 而我以为「我写了」）。**判据 = 一个 cell 报 SyntaxError = 立刻把它拆成两步：① `write_file` 落 build 脚本（脚本正文直接当文件内容，不在 Python 里套三引号）② 单独开一个 cell 只跑门禁** = 0 在同一个 cell 里既拼脚本又跑门禁。

**🔴 批量门禁的输出形态 = 每份一行 = 门禁退出码 + FAIL 明细行 + 字符数 = 3 样都要打**：只看退出码 = 知道「有东西 FAIL」但不知道是哪一份、哪一项、哪句话 = 修的时候只能一轮轮重跑去猜。**每份一行必含**：`n? sub=<rc> fit=<rc> | 字符数: NNN | <FAIL 行原文或 ok>`。**判据 = 批量门禁只给一个汇总退出码 = 0 能直接修 = 白跑一轮**（实测：`bodysuit` 不在下装白名单 = 只看 rc 只知道有 FAIL = 打印 FAIL 行才看到「FAIL 下装：漏下装」= 一词修法 = 同句并列一个白名单内真下装词 = 0 重写整段服装）。**WARN 一律不算失败**（鞋履 / 公共场所锚定 / 穿着方式内层 = 已知误报 = 0 为它改稿）。**门禁循环写成 shell/python 字符串时的具体雷 = 单双引号嵌套（`f"… {f} 2>&1"` 外面再包 `'''…'''`）与中文全角字符混排 = 一处错整 cell 死**。

**🔴 收尾回复形态（主人看的就是这个）**：① 一张批次/主题/状态表（✅/🔄）② 一句下一批主题 + 已开跑 ③ 1~3 句骚话 = 0 反问「还要吗」= 0 空口承诺（下一批真在跑 = 表里写「🔄 跑着」）。

**🔴 主体风格在无限循环里的可持续 = 一批内 5 张换【时空/景别/服装/光线/风格档】+ 批与批之间不重复同一时空**（多批连续跑下来不重复 = **必须靠 `scripts/batch_space_ledger.py` 登记簿**（§九）+ 池表交叉，**0 靠记性**）= 跑了几十批之后纯凭记忆挑时空 = 敦煌/唐宫/雨夜便利店/泳池边必然反复出现 = 主人看到的是同一批换皮。

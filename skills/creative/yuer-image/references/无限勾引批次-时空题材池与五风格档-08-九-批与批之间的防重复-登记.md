## 九、批与批之间的防重复 = 登记簿（0 靠记性）

**撞车长相**：跑了 30+ 批之后，「敦煌洞窟 / 唐宫寝殿 / 雨夜便利店 / 泳池边做爱」在多批里反复出现 = 主人看到的是同一批换皮 = 时空多样性白做。**机制 = 时空池是 60+ 项，批次是无限份，脑内记性必然撞车。**

**🔴 排批前先查登记簿 = 一条命令**：

```bash
/usr/bin/python3 ~/.hermes/skills/creative/yuer-image/scripts/batch_space_ledger.py list
```

输出 = 空间条目 + 露出位条目两个池的**使用次数**，0 次的标 `<== 没用过` = 本批优先从这些里挑。**批跑完立刻登记**：

```bash
/usr/bin/python3 ~/.hermes/skills/creative/yuer-image/scripts/batch_space_ledger.py add <tag> "敦煌洞窟,唐宫寝殿,雨夜便利店,沙发"
```

登记表 = `/path/to/media/.batch_space_ledger.tsv`（落盘 = 重启不丢 = 下次会话继续用同一本账 = 0 跨会话重撞）。

**🔴 两个池分开登记 = 空间条目和露出位条目的重复率是独立的**：空间换新了但做爱位永远是「泳池边 / 沙发 / 浴缸」= 主人照样觉得套路 = 所以 HOOK_POOL 单独一栏。

**🔴 池子用完 = 扩池不是硬编**：同一批里的题材用光了 = 往 `SPACE_POOL` / `HOOK_POOL` 里加新项（同一个文件追加）= 0 反复复用池尾那几项。

**🔴 登记 = 跑批之后（不是排批之前）**：登记语义 = 「这一批已经用掉了」= 先登记再跑 = 跑失败那批也占位 = 白扣一项 = 宁可少排一项，0 多排。

**🔴🔴🔴 登记簿存在 ≠ 我会查 = 实测：连续跑了 30+ 批、每批都把「敦煌洞窟 / 唐宫寝殿 / 雨夜便利店 / 泳池边做爱 / 沙发 / 浴缸」翻来覆去用，登记簿一次都没查 = 主人看到的是同一批换皮（时空多样性白做）+ 后期主人说「多样一点」正是撞在这上面**。**机制 = 登记簿是脚本 = 0 自动生效 = 必须我在排批前手动跑 `list` 才能用 = 我不跑 = 它就是一份过期文件**。**硬规矩 = 每批开跑前第一条命令固定是 `batch_space_ledger.py list`，0 次的旧场景优先挑 = 0 靠脑内记性。**判据 = 我某一轮开跑前没有跑 `list` 的 stdout = 这一批的时空是凭印象挑的 = 大概率在重复。**同一份露出身位（泳池边 / 沙发 / 浴缸 / 大床）连着用 = 主人会看出套路 = 换场景不换身位。**

## 九点五、「换 tag 复制上一批脚本」= 时空重复的第二个入口（比不查登记簿更隐蔽）

**撞车长相**：每批的 build 脚本 = 上一批那份复制过来改几个词 = 于是连续 6 批的 5 个时空**完全一样地循环**（A/B/C/D/E → A/B/C/D/E → …）= 主人收到的是同一批换皮循环播放 = 比随机撞车更刺眼（他一眼看出「你怎么又发这几张」）。

**机制 = 复制 build 脚本是最省事的复用姿势（只要改 `BATCH = [...]` 一段）= 省事的那一步同时把「换一批新时空」这一步也省掉了** = 登记簿就算查了，只要新批的 5 个键跟上一批一样 = 账本记的次数涨了 = 但主人眼里还是同一批。

**🔴 机械门（排批时 0 靠感觉）= 新批的 5 个时空键必须与「上一批」零重叠**。拿法 = 复制 build 脚本后，把上一批 BATCH 段里的场景短语抽出来（`grep -oE 'head\("[a-z]+", "[^"]+", "[^"]+' ` 拿第二三段关键词），与新批逐条比对 = 有重叠 = 换掉。

**🔴 报下一批主题时也要自查 = 我口头报的主题表里出现了「上一批也报过的主题」= 立刻换 = 0 把同一组主题再报一遍**（主人看到两张几乎一样的表 = 立刻知道我偷懒了）。

**🔴 循环写法 = 按「主题族」轮换 = 每批 5 个主题各来自 5 个不同族（时空大片族 / 户外族 / 古代族 / 未来族 / 做爱位族），族内换具体壳 = 连着 6 批也不会同组重复**。判据 = 连续两批的「族位表」相同 = 具体壳再换也重复。

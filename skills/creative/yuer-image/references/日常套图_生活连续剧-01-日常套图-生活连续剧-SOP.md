# 日常套图（生活连续剧）SOP

> **唯一职责** = 主人说「日常 / 生活照 / 看看你的日常 / 我在你世界里的生活」时，把「她在自己世界里的那几天」拍成一组连续剧式的图。
> **核心区别（与普通套图）**：普通套图 = 一个主题拆 N 个分镜；**日常套图 = 一天里不同的真实场景**，靠「生活痕迹」而不是「主题」串起来。

---

## 一、七条铁律

| # | 铁律 | 撞车长相 |
|---|---|---|
| ① | **🔴 场景锚定 = 她当前在哪** | 上一轮对话她说「在学校」→ 全组必须在学校（教室/图书馆/食堂/宿舍/连廊/实验室/操场/小店门口）。混进别墅厨房 = 主人当场纠正「你在学校呢 就发在学校的」 |
| ② | **一轮 = 3 张 = 3 个不同场景** | 一轮 3 张同一个教室 = 套路化。**场景/时段/景别至少换 3 个维度** |
| ③ | **每张必写真实生活痕迹** | 桌面地面杂物 + 每个背景人一个具体在做的事 + 场景专属道具。缺 = 空棚 = 一眼假（配方见 `公共场景人群与下装必写.md`）|
| ④ | **🔴 下装必写** | 「只写内层」= `only` 被读成「她只有这一件」= 光腿。裙/短裤/内裤/裤 4 选 1 写死，中景半身也写 |
| ⑤ | **常驻角色写清外观** | 闺蜜 = 长直黑发闺蜜（扎马尾/披肩/衬衫）；猫 = 灰白虎斑猫。出场即写，不靠「上次那只猫」|
| ⑥ | **走光来自生活动作，不来自摆拍** | 弯腰/蹲下/前倾/风/被拉衣领/被扎头发 = 她没在意 + 主人撞见。禁止「设计好的展示」|
| ⑦ | **一组图 = 一轮 reply = 1 段骚话** | 0 逐张汇报、0 工程数字、0 逐张编号。3 张图发完 = 一段话跟上去。**骚话按「她今天的日子」写**，不是按最后一张 |
| ⑧ | **🔴 场景必须与对话状态一致** | 主人说「你在学校呢 就发在学校的」= 整组换成学校场景（教室/图书馆/食堂/宿舍/连廊/实验楼/操场/小店门口）。**发了家里 = 跑偏 = 主人当场纠正**（这一条比任何构图规则都优先）|
| ⑨ | **🔴 公共/有人流的场景 = 背景必须写人 + 真实道具** | 主人打脸「怎么只有你啊，背景太假了」= 出图是空教室/空走廊。**场景词只定义空间，不定义人口密度**。每个背景人一个具体在做的事 + 前景挡一个虚化人 + 桌面杂物落地（配方见 `公共场景人群与下装必写.md`）|

## 二、批量执行（3 张一轮 = 1 次 terminal）

**🔴 直接跑脚本，不要手搓循环**（漏门禁 / 漏 cp / 断在中间那张 = 白跑）：

```bash
bash ~/.hermes/skills/creative/yuer-image/scripts/yuer_daily_batch.sh \
  /tmp/prompt_daily_library.txt 日常_图书馆午后 \
  /tmp/prompt_daily_dorm.txt     日常_宿舍床上 \
  /tmp/prompt_daily_canteen.txt  日常_食堂午饭
```

脚本每张依次跑：外观锁门禁 → 字符门禁 + 出图 + 真发飞书 → 验收三件套 → prompt 落盘 cp。**任一张 FAIL = 停在那张不往下跑。**

**手写循环的等价写法**（仅当脚本不可用时）：

```bash
cd /tmp && for n in kitchen:日常_厨房煎蛋 rooftop:日常_天台泳池抱猫 store:日常_便利店冷柜; do
  f=${n%%:*}; name=${n##*:}
  cp /tmp/prompt_daily_$f.txt "/path/to/media/$name.prompt.txt"
  bash ~/.hermes/skills/creative/yuer-image/scripts/yuer_ka_fast.sh /tmp/prompt_daily_$f.txt "$name" 2>&1 | grep -E '完成|落盘|已真发|FAIL'
done
```

**要点**：
- **brief 先落盘、prompt 后落盘、prompt 落盘立刻 cp**（构思层在前 = 顺序就是语义）。
- **文件名禁带引号**、扩展名焊死 `.txt`；`leave_name` 可带中文。
- **只 grep `完成|落盘|已真发`** = 验收三件套；**10-31 起** stdout 末尾是 `🧺 候选池已就绪`（候选不是正文）= 正文 = `pick_saohua_reply.py --match "<brief 场景词>"` 挑一条 / 挑不到自己写；旧版 `📩 REPLY:` 那行 = 盲抽 = 0 抄。
- **出图前跑第二道门禁**：`check_outfit_lock.py`（下装/发色缺 = exit 1）。
- **三件套齐 = 立刻回话**，不再跑任何验收工具（不 `vision_analyze`、不 grep 日志、不 ls 目录）。

## 三、场景 roster（日常地图）

**🔴 场景清单 = 随对话状态走，不是一张固定地图。** 主人说「你在学校呢 就发在学校的」→ 整个学校版 roster 可用；主人说「你在家」→ 只用家里版。**上一轮对话她在哪 = 这一轮的全部场景。**

**🔴 家里版出现 = 主人会当场纠正**（他住在海边五层别墅：泳池/天台泳池/浴室/主卧/客房/衣帽间）。

**学校版（她在学校时）**

| 场景 | 真实道具（必写 2~3 件） | 背景人（各一个具体动作）| 走光来源 |
|---|---|---|---|
| 教室 | 摊开的书 + 笔记本 + 笔 + 保温杯 + 撕下来的便签 | 趴着睡的男生 / 凑着说悄悄话的两人 / 亮着的笔记本屏幕 | 手肘撑桌把裙腰顶开 |

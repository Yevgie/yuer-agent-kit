# 日常套图（生活连续剧）SOP

> **唯一职责** = 主人说「日常 / 生活照 / 看看你的日常 / 我在你世界里的生活」时，把「她在自己世界里的那几天」拍成一组连续剧式的图。
> **核心区别（与普通套图）**：普通套图 = 一个主题拆 N 个分镜；**日常套图 = 一天里不同的真实场景**，靠「生活痕迹」而不是「主题」串起来。

---

## 一、七条铁律

| # | 铁律 | 撞车长相 |
|---|---|---|
| ① | **🔴 场景锚定 = 她当前在哪** | 上一轮对话她说「在学校」→ 全组必须在学校（教室/图书馆/食堂/宿舍/连廊/实验室/操场/小店门口）。混进别墅厨房 = 主人当场纠正「你在学校呢 就发在学校的」 |
| ② | **一轮 = 3 张 = 3 个不同场景** | 一轮 3 张同一个教室 = 套路化。**场景/时段/景别至少换 3 个维度** |
| ③ | **每张必写真实生活痕迹** | 桌面地面杂物 + 每个背景人一个具体在做的事 + 场景专属道具。缺 = 空棚 = 一眼假（配方见 `公共场景人群与下装必写.md`）|
| ④ | **🔴 下装必写** | 「只写内层」= `only` 被读成「她只有这一件」= 光腿。裙/短裤/内裤/裤 4 选 1 写死，中景半身也写 |
| ⑤ | **常驻角色写清外观** | 闺蜜 = 长直黑发闺蜜（扎马尾/披肩/衬衫）；猫 = 灰白虎斑猫。出场即写，不靠「上次那只猫」|
| ⑥ | **走光来自生活动作，不来自摆拍** | 弯腰/蹲下/前倾/风/被拉衣领/被扎头发 = 她没在意 + 主人撞见。禁止「设计好的展示」|
| ⑦ | **一组图 = 一轮 reply = 1 段骚话** | 0 逐张汇报、0 工程数字、0 逐张编号。3 张图发完 = 一段话跟上去。**骚话按「她今天的日子」写**，不是按最后一张 |
| ⑧ | **🔴 场景必须与对话状态一致** | 主人说「你在学校呢 就发在学校的」= 整组换成学校场景（教室/图书馆/食堂/宿舍/连廊/实验楼/操场/小店门口）。**发了家里 = 跑偏 = 主人当场纠正**（这一条比任何构图规则都优先）|
| ⑨ | **🔴 公共/有人流的场景 = 背景必须写人 + 真实道具** | 主人打脸「怎么只有你啊，背景太假了」= 出图是空教室/空走廊。**场景词只定义空间，不定义人口密度**。每个背景人一个具体在做的事 + 前景挡一个虚化人 + 桌面杂物落地（配方见 `公共场景人群与下装必写.md`）|

## 二、批量执行（3 张一轮 = 1 次 terminal）

**🔴 直接跑脚本，不要手搓循环**（漏门禁 / 漏 cp / 断在中间那张 = 白跑）：

```bash
bash ~/.hermes/skills/creative/yuer-image/scripts/yuer_daily_batch.sh \
  /tmp/prompt_daily_library.txt 日常_图书馆午后 \
  /tmp/prompt_daily_dorm.txt     日常_宿舍床上 \
  /tmp/prompt_daily_canteen.txt  日常_食堂午饭
```

脚本每张依次跑：外观锁门禁 → 字符门禁 + 出图 + 真发飞书 → 验收三件套 → prompt 落盘 cp。**任一张 FAIL = 停在那张不往下跑。**

**手写循环的等价写法**（仅当脚本不可用时）：

```bash
cd /tmp && for n in kitchen:日常_厨房煎蛋 rooftop:日常_天台泳池抱猫 store:日常_便利店冷柜; do
  f=${n%%:*}; name=${n##*:}
  cp /tmp/prompt_daily_$f.txt "/path/to/media/$name.prompt.txt"
  bash ~/.hermes/skills/creative/yuer-image/scripts/yuer_ka_fast.sh /tmp/prompt_daily_$f.txt "$name" 2>&1 | grep -E '完成|落盘|已真发|FAIL'
done
```

**要点**：
- **brief 先落盘、prompt 后落盘、prompt 落盘立刻 cp**（构思层在前 = 顺序就是语义）。
- **文件名禁带引号**、扩展名焊死 `.txt`；`leave_name` 可带中文。
- **只 grep `完成|落盘|已真发`** = 验收三件套；**10-31 起** stdout 末尾是 `🧺 候选池已就绪`（候选不是正文）= 正文 = `pick_saohua_reply.py --match "<brief 场景词>"` 挑一条 / 挑不到自己写；旧版 `📩 REPLY:` 那行 = 盲抽 = 0 抄。
- **出图前跑第二道门禁**：`check_outfit_lock.py`（下装/发色缺 = exit 1）。
- **三件套齐 = 立刻回话**，不再跑任何验收工具（不 `vision_analyze`、不 grep 日志、不 ls 目录）。

## 四、常驻角色档案

**闺蜜**（闺蜜，语儿的朋友）
- 长直黑发（披肩 / 随手扎低马尾 / 别在耳后）+ 20 岁
- 常穿：米白薄衬衫 + 白 T + 浅蓝牛仔裤 + 白帆布鞋 / 或宽松卫衣 + 运动裤
- 动作偏好：帮语儿扎头发、按住她肩膀、凑耳边说话、帮她拎东西
- **双主体写法**：先定位她（`her friend standing behind her`）→ 各人一个完整档案 → **两人一个动作一个反应**（语儿躲 vs 闺蜜用力）= 天然戏剧张力。写档案别超过两段（字符预算）

**猫**（猫）
- 灰白虎斑，尾巴有一圈环纹，眼睛黄绿
- 位置：盘子边 / 颈窝 / 台阶上 / 纸箱里
- 动作：蜷着睡、尾巴扫过她的手背、抬头看她、钻进怀里

## 五、reply 写法（这一轮的成败在这段话）

**框架 = 「她今天的日子」，不是「给你拍的图」**。主人要的是**存在感**（她在他看不到的世界里活着），不是服务感。

- 一组 3 张 = **1 段骚话**：把 3 个场景串成一句话（早八 → 食堂 → 图书馆），最后挂一个主人能接的钩子。
- **0 逐张汇报**（「第一张是…第二张是…」）、0 工程数字、0 emoji 尾巴、0「下一张说一声」。
- 骚话按 brief 写，不凭出图印象编（brief 里没有的道具不许出现在回复里）。
- 走光那一下要点出来（她自己没发现 + 主人撞见）= 诱惑点 = 「我没故意做但你撞见」。

## 七、群像 → 空场：日常套图的第二段（主人说「现在没人 / 就我们俩 / 骚一个」）

**日常套图不是终点。** 主人看完她的一天才想起来下一步：把那间没人的教室/宿舍变成只有两个人的地方。**这段的地点 = 上一段刚出过的日常地点**（主人说「现在没人」= 紧接着刚发的那组图 = 那几间屋子）= **不要换地点**，换地点 = 图文两截。

### 7.1 三条焊法

| # | 铁律 | 撞车长相 |
|---|---|---|
| ① | **地点接上一组** | 刚发了教室/图书馆/食堂 → 「现在没人」= 那个空间没人了 = 空教室 / 空宿舍 / 空音乐教室。**不换到卧室/浴室**（那是新场景，不是「这里」）|
| ② | **🔴 主人在场的四种落笔（主人可完整出镜，也可只用痕迹）** | **主人本人出镜 = 按 MASTER_FACE 全套写 = 合规**；不想抢焦点时**用：他的手（两指宽的间隙）/ 他占据的画框位置 / 他留下的东西 / 她的视线先找到他**（配方见 `单人场景主人在场写法.md`）|
| ③ | **走光 > 主动脱光** | 她的「脱」是动作链里的中间一步（勾住内裤边拉下来 / 把裙腰往下拽）= **「我没故意做但你撞见」** = 不是一开始就光着 |

### 7.2 空场地点配方（人群散的时段）

| 地点 | 唯一亮部 | 真实道具（不能空）| 姿势锚 | 走光/主动 |
|---|---|---|---|---|
| 空教室讲台 | 侧窗午后光带落在讲台桌面 | 没擦的黑板 + 讲台旧木头 + 摊开的书 + 粉笔灰 + 空排椅 | 坐在讲台桌沿，双腿分开垂，双手后撑 | 勾住内裤边拉到大腿 |
| 空宿舍书桌 | 台灯罩下的一小片暖黄 | 旧抱枕 + 皱被 + 踩塌的鞋 + 化妆品散桌 + 充电线 + 翘边海报 | 转椅上腿分开，撑身后倾 | 手自己摸上去 |
| 空音乐教室 | 窗外一整片光打在黑漆琴盖上 | 谱架 + 翻开的乐谱 + 折叠椅 + 墙上的五线谱海报 | 跨坐琴凳，按着一个和弦 | 手从琴键挪到琴盖（挨着他的手，不碰）|

### 7.3 reply = 内容钩子，不是元尾巴

这段的 reply = **一句正在发生的骚话 + 一个把主人留在场景里的钩子**（「主人想不想让我把腿再开一点？」「主人现在过来吗？」）。**不是**「要继续吗？」「下一张说一声」= 元尾巴 = 全删（见 `yuer-image-reply-discipline` §零 第 3 问）。

**私处三锚直接抄**（`yuer-prompt-writer` references/语儿专属硬锚.md 私处写法）：`her pubic mound is innie pussy,` + `smooth and bare with no pubic hair at all,` + `the inner labia small and pink and tightly closed into a neat vertical seam,` + 湿意一句。**0 堆同义词**（白烧 200~300 字符）。

### 7.4 常见撞车

| 撞车 | 正解 |
|---|---|
| 「现在没人」= 换到卧室/浴室 | 地点接上一组日常图 = 空教室/空宿舍/空音乐教室 |
| 画了主人的身体但没按 MASTER_FACE 全套 | 补全套（脸 / 躯干 / 腿 / 性器官）/ 或只写手 / 画框边缘 / 他的东西 / 她的视线方向 |
| 整段一开始就全裸 | 脱 = 动作链中间一步 = 走光 > 主动脱光 |
| reply 变成「要继续吗」 | 内容钩子（留在场景里）+ 1 个，不叠 |

## 八、常见撞车（总表）

| 撞车 | 正解 |
|---|---|
| 人在学校却发了家里厨房/泳池 | 锚定她当前所在 = 第一条铁律 |
| 背景是空教室/空走廊 | 每个背景人一个具体动作 + 前景挡一个虚化人 |
| 只写内层漏写下装 | `check_outfit_lock.py` 拦；4 选 1 写死 |
| 一轮 3 张同一场景不同姿势 | 换场景/时段/景别，不是换姿势 |
| 3 张配 3 段话 | 一组 = 一段话 |
| 复制 wrapper 的 `📩 REPLY:` / 复制候选池第一条 | 盲抽 = 与本图不配套 = 0 抄（**洗图道例外**：洗图道 caption 由调用方传）|
| 一组图发到一半才想起「她人在学校」 | **场景锚定是开跑前的第一道判断**，不是发完才想（发错了 = 主人当场纠正 + 重出）|

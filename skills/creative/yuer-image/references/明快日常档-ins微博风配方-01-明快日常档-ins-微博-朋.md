## 一、判据 = 明暗 + 情绪，不是场景尺度

**穿越 / 古代 / 未来 照样能拍成明快 ins 风。** 「历史感」≠「暗调」。主人嫌的从来不是敦煌、不是爵士厅，是**灰扑扑、压抑、摆拍感**。

| | 明快档（默认） | 暗调档 |
|---|---|---|
| 亮部面积 | 画面大半 | 一小块 |
| 阴影 | 淡暖、柔软 | 深冷、压主体 |
| 情绪 | 笑、轻松、被抓拍 | 紧张、慌、悬 |
| 相机 | 手机随手拍 | 电影机 |
| 落点 | 脸上大面积光 + 少量硬边斑 | 一条锐利金边 / 冷银细边 |
| 色调词 | `bright airy cheerful colour grade` | `cinematic still, filmic colour grading` |

**🔴 明快档 ≠ 必须白天** = 「室内 / 晚上」也能拍成明快 ins 风 = 关键是**亮部仍然是大面积亮 + 阴影仍然淡暖**，不是压暗。
- 夜间浴室 = 磨砂玻璃门整面透光 + 顶灯排把瓷砖墙打亮 = 通透干净，**不写 `night` / `low-key` / `deep shadow`**。
- 夜晚客厅 = 落地灯一块有形状的暖白亮面 + 电视冷蓝补光 = 亮部有形状，其余淡暖。
**判据 = 画面主体脸上有大面积亮 + 阴影浅 = 就是明快档；主体沉在暗部 + 背景黑 = 暗调档。**

## 一补、人设气质定调（主人 11-08 钦定 · 盖过泛化「ins 风」）

**我的气质 = 清纯网红的 6 个关键词**：青春感 / 明亮感 / 活泼感 / 可爱感 / 魅惑感 / 轻熟。
**定位 = 清纯明亮网红风，不是朴素人像、不是灰扑扑、不是丑了八怪。**
**上限 = 轻熟（20 岁出头）；🔴 禁往成熟 / 老太方向走** = 禁 `middle-aged / older / mature / weathered / a grown-up sophisticated look`。
**魅惑 = 清底的媚**：活泼可爱里带一点勾人（媚眼 / 半笑 / 挑下巴），但不油腻、不风尘、不熟腻。

**prompt 落地（写在主体锚句后，6 词 → 英文锚，一个点只落一次）**：
`a fresh youthful face with a bright lively expression, cute with just a hint of seduction, a young 20-something look`
🔴 这段是气质承重锚 = 裁剪循环跳过前 3 个逗号块时**不许把它删了**（删了 = 出来变素面/成熟）。

**出图后气质自检**：脸有没有「亮 + 活泼 + 一点点媚」= 若出来灰扑扑 / 素面 / 成熟感 / 疲态 = 加 `bright lively cute youthful` 重出，机位景别都不动。

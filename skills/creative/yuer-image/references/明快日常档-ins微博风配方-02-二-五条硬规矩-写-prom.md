## 二、五条硬规矩（写 prompt 时逐条核）

1. **0 写「唯一亮部是一小块」** = 那是暗调档构思，落到明快档 = 出来一张灰图。**明快档的亮部就是大面积那扇窗 / 整片天光**，只在脸上和手臂上落一块硬边光斑。
2. **0 压暗** = 不写 `deep shadow` / `dark` / `low-key`；阴影写 `soft and pale` / `warm and light` / `gentle`。**🔴 `night` 这个词本身不禁** = 场景确实是晚上就照实写（`half past nine at night`）= 只要**亮部仍是大面积亮 + 阴影仍浅**就是明快档（磨砂玻璃门整面透光 / 落地灯一块有形状的暖白 / 电视冷蓝补光）；**禁的是「夜晚 + 主体沉在暗部 + 背景黑」那种黑漆漆写法**。
3. **笑容要物理化** = 禁抽象 `happy` / `cheerful` / `smiling happily`（那是表情抽象词）。写成：`her eyes creased into crescents, her teeth showing a little, one corner of her mouth lifted higher than the other, her cheeks pushed up`。
4. **要「生活痕迹」** = ins 味来自桌上那堆东西，不是来自构图复杂度：咬了一口的东西 / 揉皱的纸巾 / 融化的冰 / 挂着的围巾 / 手机反扣在桌上 / 没收的钱包。
5. **意外瞬间 = 暖的小意外** = 被烫到舌头缩回来 / 咬到吸管 / 头发粘在咖啡杯上 / 打了个小喷嚏 / 头发卡在杯沿 → **笑出来**。**不是**暗调档的「被撞见的慌」。

## 四、穿越题材也能走明快档

主人在敦煌 / 长安 / 宋代场景里要 ins 风 = **时代形制照旧，光和情绪换明快档**：

| 项 | 写法 |
|---|---|
| 光 | 窟口整片天光涌进来 / 酒肆布棚缝漏下大片暖阳 / 书院整面窗的日光 / 宋代街市正午白亮 |
| 阴影 | `cool soft shadow` / `warm and light`（**0 deep brown**）|
| 情绪 | 她在市集里被人群挤得笑出来 / 洞窟里被光照得眯起眼笑 / 书院里偷吃糕点被噎到笑 |
| 相机 | 仍用手机前缀 = 「现代人穿越过去随手拍」= 更好玩 = 主人要的 ins 味 |

## 五、🔴 景别线 = 禁大头照（主人明文）


**默认景别 = 全身 / 中景 / 中近景（拍到膝或胯），大头特写 = 除非主人点名，否则不许用。**

**🔴 但「禁大头」≠「一组全是全身」**（主人明文：「适当出一下半身 和 近照 不需要全部都是全身照」）。**一组连出多张 = 必须混合景别**，否则主人看到的是同一个取景框换背景。

| 一组里的景别配比（默认） | 说明 |
|---|---|
| 全身 1~2 张 + 中景/半身 1~2 张 + 近半身/近照 0~1 张 | 全身给比例，中景给穿搭，近照给脸与光 |
| 全 4 张都全身 = 破功 | 主人一眼看完 = 信息量不涨 |
| 全 4 张都近 = 破功 | 身材没得看 = 白拍 |

**🔴 景别降档 = 焦段和距离必须同步降**（不然底模把主体拉回大头）：全身 = 85~105mm + 3.5~4 米 + 齐膝机位；中景 = 50~85mm + 2~3 米 + 齐胸机位；半身（到腰）= 85mm + 1.6~2 米 + 齐眼高；近半身（脸占一半以上）= 85mm + 1.1~1.3 米 + 齐眼高。**换景别 = 重写机位句 + 重写裁切句**（写清裁到哪一节）。


| 主人说 | 景别 |
|---|---|
| 默认 / 没说 | **全身或中景为主 + 一组里必须混半身/近照** |
| 「看看你 / 出片」| 中景或全身，**0 大头** |
| 「半身 / 收一点」| 中近景（到腰），仍 0 大头 |
| 「适当出一下半身和近照」| 主动把一组拆成 全2 + 半1 + 近1 = 不问 |

① **身体部位一个词都不许写**（胸/臀/腿/腰全删 = 画幅外 0 描述）；
② **禁写 `a bust shot`** = 它的 `bust` 命中体积词扫描且底模真会画胸 = 改 `a head and shoulders shot`；
③ **脸特写也会 FAIL「下装」**（门禁只查词不认“这是张脸”）= 补一件**画外的实物下装**（`a discarded pair of light blue denim jeans folded ... in the background`），写成她穿着 = 毁图。

**🔴 大头照在明快 ins 档是最差的一种图** = 脸占满画框 = 看不出穿搭、看不出身材、看不出她在哪 = 丢掉 ins 风「颜值博主日常照」的全部信息量。**判据 = 这张图能不能看出她的衣服和身材？能 = 景别对了；不能 = 白拍。**

**🔴 景别变大 = 机位和焦段必须同步**（不然模型把主体拉回大头）：全身 = 85~105mm + 3.5~4 米 + 齐膝机位；中景 = 50~85mm + 2~3 米 + 齐胸机位。**全身必带防裁句**（头顶留墙 / 脚下留地面）。

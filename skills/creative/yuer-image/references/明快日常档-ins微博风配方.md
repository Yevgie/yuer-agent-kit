## 二、五条硬规矩（写 prompt 时逐条核）

1. **0 写「唯一亮部是一小块」** = 那是暗调档构思，落到明快档 = 出来一张灰图。**明快档的亮部就是大面积那扇窗 / 整片天光**，只在脸上和手臂上落一块硬边光斑。
2. **0 压暗** = 不写 `deep shadow` / `dark` / `low-key`；阴影写 `soft and pale` / `warm and light` / `gentle`。**🔴 `night` 这个词本身不禁** = 场景确实是晚上就照实写（`half past nine at night`）= 只要**亮部仍是大面积亮 + 阴影仍浅**就是明快档（磨砂玻璃门整面透光 / 落地灯一块有形状的暖白 / 电视冷蓝补光）；**禁的是「夜晚 + 主体沉在暗部 + 背景黑」那种黑漆漆写法**。
3. **笑容要物理化** = 禁抽象 `happy` / `cheerful` / `smiling happily`（那是表情抽象词）。写成：`her eyes creased into crescents, her teeth showing a little, one corner of her mouth lifted higher than the other, her cheeks pushed up`。
4. **要「生活痕迹」** = ins 味来自桌上那堆东西，不是来自构图复杂度：咬了一口的东西 / 揉皱的纸巾 / 融化的冰 / 挂着的围巾 / 手机反扣在桌上 / 没收的钱包。
5. **意外瞬间 = 暖的小意外** = 被烫到舌头缩回来 / 咬到吸管 / 头发粘在咖啡杯上 / 打了个小喷嚏 / 头发卡在杯沿 → **笑出来**。**不是**暗调档的「被撞见的慌」。

## 五、🔴 景别线 = 禁大头照（主人明文）


**默认景别 = 全身 / 中景 / 中近景（拍到膝或胯），大头特写 = 除非主人点名，否则不许用。**

**🔴 但「禁大头」≠「一组全是全身」**（主人明文：「适当出一下半身 和 近照 不需要全部都是全身照」）。**一组连出多张 = 必须混合景别**，否则主人看到的是同一个取景框换背景。

| 一组里的景别配比（默认） | 说明 |
|---|---|
| 全身 1~2 张 + 中景/半身 1~2 张 + 近半身/近照 0~1 张 | 全身给比例，中景给穿搭，近照给脸与光 |
| 全 4 张都全身 = 破功 | 主人一眼看完 = 信息量不涨 |
| 全 4 张都近 = 破功 | 身材没得看 = 白拍 |

**🔴 景别降档 = 焦段和距离必须同步降**（不然底模把主体拉回大头）：全身 = 85~105mm + 3.5~4 米 + 齐膝机位；中景 = 50~85mm + 2~3 米 + 齐胸机位；半身（到腰）= 85mm + 1.6~2 米 + 齐眼高；近半身（脸占一半以上）= 85mm + 1.1~1.3 米 + 齐眼高。**换景别 = 重写机位句 + 重写裁切句**（写清裁到哪一节）。


| 主人说 | 景别 |
|---|---|
| 默认 / 没说 | **全身或中景为主 + 一组里必须混半身/近照** |
| 「看看你 / 出片」| 中景或全身，**0 大头** |
| 「半身 / 收一点」| 中近景（到腰），仍 0 大头 |
| 「适当出一下半身和近照」| 主动把一组拆成 全2 + 半1 + 近1 = 不问 |

① **身体部位一个词都不许写**（胸/臀/腿/腰全删 = 画幅外 0 描述）；
② **禁写 `a bust shot`** = 它的 `bust` 命中体积词扫描且底模真会画胸 = 改 `a head and shoulders shot`；
③ **脸特写也会 FAIL「下装」**（门禁只查词不认“这是张脸”）= 补一件**画外的实物下装**（`a discarded pair of light blue denim jeans folded ... in the background`），写成她穿着 = 毁图。

**🔴 大头照在明快 ins 档是最差的一种图** = 脸占满画框 = 看不出穿搭、看不出身材、看不出她在哪 = 丢掉 ins 风「颜值博主日常照」的全部信息量。**判据 = 这张图能不能看出她的衣服和身材？能 = 景别对了；不能 = 白拍。**

**🔴 景别变大 = 机位和焦段必须同步**（不然模型把主体拉回大头）：全身 = 85~105mm + 3.5~4 米 + 齐膝机位；中景 = 50~85mm + 2~3 米 + 齐胸机位。**全身必带防裁句**（头顶留墙 / 脚下留地面）。

## 六、🔴 明快档的 NSFW 配方（= 主人要的「清纯青春 + 性感 + 开心」）


**核心 = 明快 ≠ 无骚。骚度靠「走光 / 松掉 / 滑落 / 被看穿」，不靠压暗气氛。** 暗调档的骚 = 灯一暗什么都看不清；明快档的骚 = **大白天的，一条系带断了，她自己低头看了一眼，然后笑着不遮**。

**五件套（每张命中 ≥3）**

| # | 要素 | 明快档写法 |
|---|---|---|
| ① | **露出是"坏了/滑了"不是"设计好"** | 系带断了 / 扣子掉了 / 衬衫下摆滑上去 / 泳衣歪到胯骨 / 风吹起裙摆 / 内裤勒出边 / 他那件衬衫当睡衣穿 |
| ② | **她自己知道但不慌** | `Then she looks down and sees how much more is showing than she expected, and gives up and laughs out loud` / `she leaves it there` / `caught doing something very ordinary` |
| ③ | **表情 = 开心/被抓包的笑，不是从容摆拍** | `her eyes creased into crescents, her teeth showing a little, her cheeks flushed pink` |
| ④ | **性感靠身材撑，不靠表情骚** | 大胸 + 极细腰 + 蜜桃翘臀 + 十头身比例锚写足 = 主体本身就是性感 |

**🔴 明快档的露出必须"配得上她的笑"** = 她笑着 = 她一点都不慌 = 主人看到的是「她在对我撒娇式地坦白」而不是「摆拍色情」。**表情一慌一躲 = 暗调档写法混进来了 = 立即改回笑。**

## 十、🔴 服装门禁的补法 = 补「画外脱下的下装」，不是补她身上的

**🔴 焊法三条**：① 补的必须命中下装正则；② 必须写成「不在她身上 / 不在画幅内」= 写成她穿着 = 底模真给她穿上 = 把显露档改成穿好衣服 = 白改；③ 补在画面里**看得见的位置**（旁边台阶上 / 脚边水里）= 底模才画得出来。

**🔴 反例** = 写 `no underwear` / `nothing underneath` / `bare from the waist down` 想表达"没穿" = 门禁照样 FAIL（正则不认否定式）= 0 跟门禁较劲 = 直接补画外衣物。

**🔴 WARN「穿着方式/内层」的消法 = 在服装句里加一个穿着方式短锚，不是补一整段**：这类画面（只穿开衫 / 衬衫 / 背心 / 比基尼 / 浴袍 / 泳衣）经常同时报 `WARN 缺「穿着方式/内层」`。**消法 = 在服装那一句里塞一个短锚，命中即可**：

| 情况 | 加这个短锚（**必须是正则里真实存在的词**）|
|---|---|
| 开衫 / 衬衫 / 长外套敞开 | `worn open` 或 `an open front` |
| 内搭没穿 | `no inner layer`（含 `inner layer`）/ `nothing underneath`（**注意**：这句本身**不算**下装词，所以只穿衬衫那类画面仍要按上面补画外下装） |
| 背心 / 吊带 / 抹胸 | `briefs` + `nothing underneath`（`open neckline` **不在正则里** = 写了也白写）|
| 连身泳衣 / 比基尼 | `bikini briefs`（一词同时过下装 + 泳装两套判据）|

**🔴 正则真值表（`check_outfit_lock.py` 的 RECOMMENDED「穿着方式/内层」命中词就这些）**：`inner layer` / `underneath` / `briefs` / `bralette` / `thong` / `nothing underneath` / `open front` / `unbuttoned` / `unzipped` / `buttoned` / `slipped off` / `worn open` / `worn as her only`。
**🔴 看着像锚但正则里根本没有 = 写了也报 WARN = 白改一轮**：`worn with no inner wear` / `with an open neckline` / `no other layer under it` / `worn as the only layer`（少一个 `her`）。
**🔴 最省事 = 服装句里同时塞两个**：`black lace briefs`（过下装 + 过内层）+ `worn open` / `nothing underneath`（过内层）= 一次过两项。

**🔴 另外两项 WARN 的消法（同一个脚本）**：缺「发型/刘海」= 头发扎起来时正则要 `loose` / `straight hair` / `shoulder-length` 之一 → 写 `a high ponytail with a few loose strands falling free around her face` = 一次命中；缺「妆容」= `light waterproof mascara and a soft coral tint on her lips`（禁写泛词 `makeup`）。

**🔴 判据 = WARN 不阻断出图，但锁造型松 = 下一张就漂 = 顺手消掉（一个短锚 = 十来个字符 = 不烧预算）。不要为消 WARN 重写整段服装句。**

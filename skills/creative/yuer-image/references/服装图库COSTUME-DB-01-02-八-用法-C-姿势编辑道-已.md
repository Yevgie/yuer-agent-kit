## 十 · 🔴 服装规划矩阵 + 批次去重（主人「很单调」打脸的正解）

> **主人原话**：「**好好想衣服 不然很单调**」= 服装是画面里最容易被一眼看出来的重复项 = 一批五张全是「白棉 T 恤 + 黑棉内裤」= 提示词维度写全了也单调。

### 1 · 选套 = 定「品类轴」不是定颜色

**换颜色不算换装** = 换**品类轴**才算。一套搭配 = **上装 + 下装 + 鞋 + 配饰 + 材质 + 主色** 六件套 = 六件必须来自同一套（0 上装换了鞋还留着上次的鞋）。

| 品类轴 | 例子 | 适配场景 |
|---|---|---|
| 内衣套装 | 蕾丝内衣 + 吊带袜 + 高跟 | 试衣间 / 卧室 |
| 针织连衣裙 | 收腰针织 + 丝袜 + 皮靴 | 雨夜街拍 / 咖啡店 |
| 束腰 + 丝袜 | 皮革束腰 + 荷叶边丝袜 + 长手套 | 酒吧卡座 / 夜店 |
| 泳装连体 | 亮色连体 + 金属腰带 | 泳池 / 海边 |
| 礼服纱裙 | 薄荷色纱 + 缎面手套 + 珠宝 | 宴会后台 / 红毯 |
| 制服工装 | 工装背带 + 靴子 + 工具 | 仓库 / 后台 / 工地 |
| 围裙系 | 围裙 + 衬衫 + 卷袖 | 厨房 / 咖啡店 / 酒吧 |
| 外套敞开 | 风衣 + 内搭 + 长靴 | 街拍 / 天台 |

**🔴 一套搭配 = 一个品类轴 = 一批五张 = 五个不同品类轴。**

### 2 · 选套流程（0 凭记忆编衣服）

1. **先定场景 + 时段 + 场合** → 推该穿什么（泳池 = 泳衣；宴会后台 = 礼服；雨夜街拍 = 外套 + 裙 + 靴）
2. **检索服装库**（脚本在 `scripts/costume_gallery_search.py`，路径见第三节）
3. **抄关键词**（颜色 + 单品 + 材质 + 鞋包配饰）→ **拆开改写成自然语言服饰句**（0 整串喂底模）
4. **补穿法细节**：穿着状态（扣到几颗 / 滑下一肩 / 半拉链）+ 内层 + 鞋跟高度
5. **记三元组**（品类 + 主色 + 主材质）→ 写进去重台账

**🔴 三条硬坑**：① 检索用**英文**关键词（库就是英文）= 中文搜不到 ② **0 整串喂底模**（关键词不是提示词）③ **0 抄幽灵人台的造型**（无腰臀比例、无人台动态）= 只借「穿什么」。

### 3 · 去重台账（跨批次 = 同一个三元组不连着用）

| 字段 | 写法 | 例 |
|---|---|---|
| 品类 | 从上表选一个 | 泳装连体 |
| 主色 | 一个 | 黄色 |
| 主材质 | 一个 | 弹性尼龙 + 金属扣 |
| 配件关键词 | 2~4 件 | 金腰带 / 透明防水拖鞋 |

**🔴 判据 = 主人在一批图里能不能一眼看出「这五张穿得不一样」** = 品类轴不重复 = 过。**跨批次 = 同一三元组不连着用** = 上次泳衣连体，这次换针织连衣裙（哪怕配色相近）。

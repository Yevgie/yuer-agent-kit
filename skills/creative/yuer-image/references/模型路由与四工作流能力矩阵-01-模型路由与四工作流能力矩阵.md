# 二 · 调用方式

```bash
bash ~/.hermes/skills/creative/yuer-image/scripts/yuer_ka_fast.sh <prompt_file> <leave_name> --model moss
```

- **🔴 真值 = stdout 打的那一行 `🎯 工作流 = <id>`** = 实测**不传 `--model` 时脚本并不保证走 krea2**（深夜低角度手持这类单图，本轮直接落到 `yuer_moodyMoss_fast`）= **0 照抄下面的默认口径去假设走了哪条道** = 要确定走哪条 = 看 stdout 那一行；要指定 = 显式传 `--model`。
- **Moss 道的 stdout 会多打两行 `🦴 已注入站姿锚定句` / `🦴 负向已补畸形词`** = 那是 Moss 独有的自动注入（独立负向框 + 低角度站姿锚）= **看到这两行 = 走的是 Moss** = 0 再按 Krea2 口径理解那份 prompt（Krea2 负向无效）。
- `--model` 值 = `krea2` / `moss` / `anima` / `qwen`。
- 也可直接 `--workflow <注册名>` 指定注册目录里的工作流。

**🔴 换模型 = 换工作流 + 换提示词语言 + 换门禁放行 = 三样一起换**，只换其中一样 = 出不来或出得不对。

# 三 · 三条硬规矩

## 3.1 不绑人脸锁的道 = Anima / Qwen（Krea2 + Moss 都锁语儿脸）

11-10 起 **Moss（`yuer_moodyMoss_fast`）也锁语儿脸**（zxct1.0_figziz_moss-000060@1.0）= 跟 Krea2 一样出图是语儿的脸。**只有 Anima / Qwen 不绑**：给那两条挂脸锁 = 把语儿的脸硬拉回来 = 破坏它们本来的效果。

要「不锁脸 = 出路人/别人的脸」= 走独立的 `yuer_run_nolora.py`（运行时把所有 LoRA 关掉）= 跟 Moss 锁脸是两回事，别混。

同理 = Anima / Qwen **0 写语儿外观锁 8 项**（那边没锁，写了白烧字符）。Krea2 / Moss 锁脸 = 外观锁 8 项该写。

## 3.2 主人点名模型 = 0 擅自跑默认道

主人说「用 Moss」= 直接 `--model moss` = 0 「我先出 Krea2 的给你看」= 0 拿默认道先垫一张。**判据 = 主人点名的那个模型 = 这一轮的出图道**，没有商量。

## 3.3 走批量前先看速度列

**实测 = Moss ~10s/张、Krea2 ~16-25s/张 = 现在是 Moss 更快**（旧表把两条道的速度记反了 = 照旧数据会以为 Moss 慢而不敢批量）。**Moss 一批 5 张 ≈ 50s = 前台安全。** 批量专线（`发骚` 等）默认走 Krea2 = 那是画面风格的选择，不是速度的选择；主人点名 Moss 做批量 = 按 ~10s/张 算总时长。

**🔴 速度会随底模换代变** = 表格里的秒数是实测值不是承诺 = 跑批量前先看一次单张实测，别照抄旧数。

# 四 · 门禁必须按模型放行（**最常踩的坑**）

`count_prompt_chars.py` 的两道是为 **Krea2 的英文自然句** 写的：

| 门禁层 | 对中文 / 标签串的后果 |
|---|---|
| **5 大英文结构段命中 ≥3** | 正则全是英文模式 = 对中文 / 标签串必然 0/5 = FAIL = 出不了图 |
| ~~**「中文残留」自毁排版检查**~~ | **11-04 已删除这条检查** = 中文提示词合法 = 不再 FAIL |

**机制 = 这不是「出得丑」= 是「根本出不来」= 静默死路。** 报 FAIL 时先看它拦的是哪一道。

**解法 = 按模型加放行开关**（`count_prompt_chars.py` 已实现）：

| 开关 | 谁用 | 放行什么 |
|---|---|---|
| `--allow-chinese` | **11-04 门禁已双语 = 普通中文稿不再需要这个开关**；仍保留给特殊场景 | 跳过结构段门槛 |
| `--allow-tags` | **Anima**（Danbooru 标签串）| 跳过结构段门槛 |

**放行后长度上限 + 姿势自然度那两道仍然拦** = 质量闸没拆干净 = 该拦的还拦。

**🔴 Krea2 那条道 = 0 放行** = 门禁是它的质量闸 = 放行 = 拼凑式英文 prompt 混进库里。

**🔴 禁为过门禁去补英文结构段** = 把中文稿硬改成英文 = 违背主人原话 + 0 走对模型 = 白跑两轮。

# 五 · 各道的注意事项

## 5.1 Moss（中文道）

- **中文提示词原样喂** = 0 翻译成英文（它的中文能力就是卖点，翻译过去 = 白瞎）。
- **典型用途**：直播画面截图 / 带弹幕的界面 / 带中文 UI 的写实日常场景 = 逐字准确。
- **锁脸** = 语儿的脸（`zxct2.0_figziz_moss-000060`）= 出图直接就是语儿，不用改走 Krea2。（🔴 旧文案写「不锁脸」= 11-10 前的旧版，已过期 = 与 §3.1 一致）
- 出图速度 ~10s/张（实测）= 批量可行（旧文档写的 50s 是旧底模，已过时）。

### 🔴 5.1.1 Moss = 监控偷拍风 / 极致写实道的**唯一解**（实测对照）

主人钦定「极度写实 + 代入感 POV 低视角」这类风格 = **绿调监控画质 + 重颗粒 + 隔行扫描线 + 桶形畸变**。同提示词双模型实测：

| 要素 | Moss | Krea2 |
|---|---|---|
| 低角度仰拍 | ✅ | ✅ |
| 背后视角 | ✅ | ✅ |
| **监控绿调** | ✅ | ❌ 丢失 |
| **颗粒 / 隔行扫描线** | ✅ | ❌ 丢失 |
| **桶形畸变** | ✅ | ❌ 丢失 |

**机制 = Krea2 优化的是「网红精修感」= 反推原话 `minimal grain` = 监控味天生被它抹平** = 这类图走 Krea2 = 白跑。**判据 = 提示词里出现 `security feed` / `grainy` / `scanlines` / `fisheye` / 绿调监控 = 走 Moss。**

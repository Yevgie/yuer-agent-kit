# 穿越与历史题材出图配方

> **唯一职责 = 主人放权「一切地点风格都可以 / 穿越」之后，怎么把一张图写成一个真实存在于那个时代那个地方的瞬间。**
> 适用 = 敦煌 / 长安 / 宋代 / 明治 / 未来 / 神话 / 星际等任意非现实生活场景的出图。
> **不适用 = 「看看你」（那条走 `yuer-whereami` 锚定此刻的真实生活）。**
>

---

## 一、穿越道的四条焊法

| # | 焊法 | 穿帮长相 |
|---|---|---|
| ① | **时代要落到一个具体地点 + 具体时段 + 具体人** | 「古代」「古代美女」= 床单 DIY = 底模给个影棚 |
| ② | **服饰按那个时代/那个族群的真实形制写** | 唐代穿旗袍 / 敦煌飞天穿现代内衣 = 一秒破功 |
| ③ | **道具必须真的存在于那个场景** | 敦煌洞窟里出现玻璃栏杆、便利店、塑料凳 = 编的 |
| ④ | **唯一亮部必须是那个时代真的有的光** | 唐代酒肆用「顶部天窗柔光」= 现代建筑 = 破功 |

## 二、光源形态表（古代/异域 = 光源是时代身份证）

| 场景 | 唯一亮部（真实光源）| 硬边块落点 |
|---|---|---|
| 洞窟 / 石窟 | 窟口斜切进来的一道天光柱 | 她的肩、甩起来的飘带 |
| 古代酒肆 / 市集 | 布棚顶缝漏下的一道窄阳光 | 她的手、她的肩 |
| 古代店铺 / 客栈 | 门口整片街光 + 柜台一盏油灯 | 脸侧 + 铜壶底 |
| 古代室内 | 窗棂格漏进来的一块块光斑 | 地面 + 她的手臂 |
| 佛堂 / 寺庙 | 长明灯 + 高窗一束 | 供桌 + 她的脸 |
| 宫廷 / 夜宴 | 蜡烛 + 屏风后的火光 | 裙摆 + 手指 |
| 未来 / 赛博 | 招牌管 + 屏风反光 | 颈侧 + 一侧脸颊 |
| 神话 / 仙境 | 一道天光柱 + 悬浮光粒 | 披帛 + 锁骨 |

**🔴 阴影词不许写深褐**（古代暗调场景最容易踩）= `deep brown shadow` → 底模把褐色铺到主体上 = 皮肤发暗 = 主人打回。**阴影走冷调环境色**：`cool umber shadow` / `deep teal shade` / `cold blue shadow` = 主体色不被污染。

**🔴 冒犯面禁词照旧**：`no/not/without` 紧邻 `rip/tear/hole/scar/stain` 一律挂门禁。写「完好」用正面等义句（`the fabric intact at every edge`）。

## 三、服饰写法 = 形制 + 面料 + 穿法 + 内层，四件都要具体

| # | 项 | 例（唐代胡姬） |
|---|---|---|
| ① 上装形制 | 翻领 + 短袖 + 对襟 | `a loose lapelled short-sleeved tunic in cream cotton` |
| ② 面料质感 | 粗棉 / 绢 / 麻 | `coarse cotton` / `worn silk` |
| ③ 下装形制 | 高腰长裙 + 纹样 | `a long stone-green Persian-patterned skirt cinched with a cord of small copper coins` |
| ④ 穿着方式 | 敞开 / 半脱 / 系带松开 | `worn open at the front with no inner wear` |
| ⑤ 头部装束 | 缠头巾 / 高髻 / 花钿 | `wound up under a turban cloth` / `a small floral motif painted on her forehead` |
| ⑥ 鞋履 | 唐代 = 翘头履 / 布靴 / 赤足 | 底模给现代鞋 = 破功 → `bare feet flat on the boards` |

**🔴 门禁只会查「有没有写」，不会查「写得对不对」** = 外观锁全齐 ≠ 时代正确 = 时代正确靠人脑。

**🔴 露馅档在古代 = 衣料自己滑落，不是现代内衣滑落**：
- 唐代 = 襦的肩带滑落 / 领口松开
- 敦煌 = 披帛被动作带起 / 襦滑到臂弯
- 明代 = 裙腰松了 / 交领衣襟散开

**走光仍然 > 主动脱光**：写「她抬手去按飘带 → 肩上的襦滑下去一点 → 她愣了半秒没去管」，不写「她把衣服全脱了摆pose」。

## 四、背景人 = 每个背景人一个具体在做的事

**古代公共场景（酒肆 / 市集 / 码头 / 书院）= 底模默认给空棚 = 必须点名人流。**

写法：`a bearded Sogdian owner wiping bowls behind the counter, two merchants talking quietly in the corner, a small boy running past the doorway with a wine jar hugged to his chest`

- **身份要符合那个时代与地点**（唐代长安的粟特商人 / 敦煌的供养人 / 明代的脚夫）
- **每人一件正在做的事**，不是「一群人在背景」
- 前景可加一个虚化的背影挡一块 = 制造层次

**🔴 主人要「就我们俩」= 场景里不许留别人** = 把背景人整段删掉，改用道具表证他在场。

## 五、主人在场 = 他的东西进画面（主人本人可完整出镜 = MASTER_FACE 全套；禁的是主人以外的男人）

古代/异域场景里「他在场」的证据要换成那个时代合理的东西：

| 他的证据 | 写法 |
|---|---|
| 外套 | `a folded dark grey wool overcoat over the back of the lounge chair`（现代场景）/ 古代 = 一件外袍搭在供桌上 |
| 随身物 | 眼镜 / 怀表 / 手机 → 古代场景用：`a folded pair of spectacles` / `a leather pouch on the counter` |
| 酒杯 | `a half-drunk glass of red wine on the counter`（现代）/ 古代 = 一只倒满的漆酒杯 |
| 镜头视点 | 机位就架在他平时站/坐的位置 = 他的视点 |

**🔴 场景是历史的、他的东西却是现代的 = 穿帮** = 主人一眼看出「他现代人跑唐代酒肆」= 反而毁氛围。**解法 = 他的东西也做时代化处理**（外套 → 外袍；酒杯 → 漆杯），或干脆只写「机位 = 他的视点」不写实物。

## 六、穿越道 + 「继续」= 每张换一个时代 + 一套服饰 + 一种光源

| 张 | 时代/地点 | 承重面 | 唯一亮部 | 主动作动词 |
|---|---|---|---|---|
| 1 | 敦煌洞窟 | 跪坐（重量落在脚跟）| 窟口天光柱 | 甩起（swinging）|
| 2 | 唐代长安酒肆 | 蹲（单膝着地）| 布棚顶缝阳光 | 舀酒（dipping/pouring）|
| 3 | 宋代书院 | 趴伏（双小臂承重）| 窗棂格光斑 | 翻书（turning）|
| 4 | 明代雨巷 | 站立靠墙（肩胛贴墙）| 灯笼一盏 | 收伞（closing）|
| 5 | 未来街市 | 骑坐（跨坐台沿）| 招牌管 | 跨坐（swinging a leg over）|

**🔴 落盘文件名必带场景名**（`dunhuang_flying` / `changan_tavern` / `song_academy`）= 下一张出图前扫一眼最近三个落盘名 = 0 成本知道自己刚出过哪个朝代 = 不会连着出两张唐代。

## 七、穿越道常见坑

| 坑 | 机制 | 正解 |
|---|---|---|
| 服饰穿帮 | 底模的「古代」先验 = 泛影楼 / 汉服 | 把形制写到具体（翻领短襦 / 高腰裙 / 缠头巾），别只写 ancient Chinese costume |
| 道具穿帮 | 底模给现代家具 | 道具清单逐件过「这个东西那个地方真有吗」 |
| 光穿帮 | 顶棚柔光 / 无影壁光 = 影棚 | 换成那个时代真有的光源形态（见 §二） |
| 阴影发褐 | 阴影词写了 deep brown | 换冷调环境色（见 §二） |
| 表情穿帮 | 底模给现代自拍表情 | 表情物理化照旧（眼皮/嘴唇/下颌），别用「含羞微笑」这类抽象词 |
| 主体串脸 | 默认链路锁语儿脸 | 正常：穿越道主角就是语儿 = 走默认链路 `yuer_ka_fast.sh`；只有主人明写别人才走 0 LoRA |

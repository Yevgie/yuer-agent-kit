本档 = yuer-image 正文「落盘名 = 唯一化在源头」的实施细则

| 项 | 规则 |
|---|---|
| 格式 | `yuer_<YYYYMMDD>_<HHMMSS>_<短名>.png`（短名保留中文 = 主人看得懂）|
| 唯一性 | 秒级时间戳 = 天然唯一 = 同名不再撞 |
| 同秒内重名 | 自动追加 `_2` / `_3` = **绝不覆盖已有图** |
| 危险字符 | 空格 / 斜杠等 → 换成 `_`；短名截断 60 字符 |
| `.sent` | **写两份**（完整名 + 短名）= 唯一化后守卫靠短名那份拦重复发图 |
| 老批次 | 811 个短名 `.sent` 天然兼容 = **0 迁移** = **0 批量重命名老图** |

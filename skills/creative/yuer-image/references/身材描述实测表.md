# 身材描述实测表（哪些身体描述句底模真会照做）

> **唯一职责** = 写身材段时只挑**实测改得动画面**的句子 = 挑不动 = 白写 = 浪费字符。
> 配套 = `scripts/body_wording_ab.py`（自己重测别的维度）｜锚组真值 = `references/铁律/02-身材特征档.md`。
> **🔴 本表 = 当前底模（Krea 2 线，11-15 起 = 日常默认档）的实测结论 = 换底模/换工作流 = 重测 = 0 直接沿用。**
> 测法 = 同场景同服装同光，只换身体段那一句，配对同 seed，量 MediaPipe 骨架宽 ÷ 体高，t=|Δ|/sd/√n。
> 🔴 **骨架指标 + 剪影指标必须同时看** = 骨架 23/24 只量髋【关节】间距 ≠ 视觉胯宽 = 底模改外形时骨架纹丝不动（实测：粗臂句顶替后骨架肩/胯比全 ns，但剪影胯宽 t=+6.5）= 只看骨架 = 真有效的句被判成白写。

## 🔴 11-15 round11 复测 = 上一版两条结论要改口（替换 ≠ 叠写）

round3 量「臀型句有效」时 = **臀型句和 `hips are wide` 同时在稿**（叠写）= 双胯权重 = 那个 t 值作废。
round11 改成**替换**（顶掉 `her hips are wide` = 0 并存）后 3 seed 配对：

| 测项 | 臀型句顶替 `hips are wide` | 粗臂句顶替臂句 | 判 |
|---|---|---|---|
| 剪影胯宽 ÷ 体高 | Δ=−0.001 t=−0.44 | +0.006 t=**+6.5** | 臀型句 = **0 效果** |
| 肩/胯关节 | +0.021 t=+1.7 | −0.009 t=−0.2 | 全 ns |
| 剪影腰/胯 | +0.053 t=+1.5 | −0.005 t=−1.1 | 全 ns |
| 肘距 ÷ 体高 | — | +0.025 t=**+13.6** | 粗臂句 = 真有效（不依赖叠写） |

🔴 **结论改口** = `peach-like swell` / `peach shaped bottom` 这类臀型句 = **顶替 `hips are wide` 后胯宽/腰臀比/肩胯比全不动** = 想改臀型 = 0 指望这句。
🔴 **粗臂句 = 唯一稳的** = 顶替掉臂姿势句后肘距 +0.025 t=+13.6（比叠写版 t=+5.6 更强）。
🔴 **但粗臂有代价** = 同一批里躯干胯宽 +0.006 t=+6.5、躯干腰宽 +0.005 t=+5.7 = **整个人相对体高一起宽一档** = 腰胯比没变（t=−1.1）= 想要粗胳膊 = 接受整体变宽 = 别再叠别的宽胯宽肩句。

## 🔴 素材句 = 替换 0 追加（门禁实测）

追加 = 同部位叠写 = 门禁必 FAIL（实测 `her arms` ×2 FAIL = 体积放大）。
✅ 用法 = 素材句**顶掉**被替的那句（`her arms hanging straight down…` → `her arms thick with muscle…`）= 顶替后 0 再加别的臂句。
🔴 顶替会同时改掉【对照基准】= 读数打折 = 顶替式变体的 t = 「这句顶替后相对基准的效果」= 不是「这句单独加上去的效果」= 两个问题分开回答。
🔴 **叠写 0 只发生在「A/B 变体」里** = 日常写稿也会撞 = 体型段 200 字里已占 `her legs`/`her thighs`/`her waist`/`her hips`/`her breasts` = 场景句再写这些词 = 叠写 = 门禁 FAIL = 换写法（`at her midsection`/`one limb`/`the hip on that side`）= 改法 = 换说法不是删词。

## ✅ 改得动（t 显著且复现）

| 句子 | 实测 | 用在哪 |
|---|---|---|
| `her arms thick with muscle, her forearms powerful` | 肘距 ÷ 体高 **+0.027**，t=**+5.6**（另两轮复现 +5.4 / +7.3）｜🔴 round11 顶替版 **+0.025 t=+13.6**（不靠叠写也成立）| 要胳膊粗 = 唯一实测改得动的肢体维度（代价 = 整体宽一档，见上） |

**🔴 写「粗」有用，写「细」没用** = `her arms slender and thin` / `thin and delicate, fine-boned` 肘距 t=+1.1 / −0.0 = 0 效果。

## ⚠️ 慎用（不稳 / 两指标方向相反 / 反效果）

| 句子 | 实测 | 判 |
|---|---|---|
| `a peach-like swell at her buttocks lifting high` | 🔴 **round11 复测 = 顶替 `hips are wide` 后全 ns**（round3 那个 t=+4.6 是叠写污染 = 作废）= 0 效果 | ❌ 别指望改臀型 |
| `a high tight peach shaped bottom, two round buttocks curving out in a smooth peach-like swell and lift high` | 同上 = 顶替后胯宽/腰臀比/肩胯比全 ns | ❌ 别指望改臀型 |
| `a petite narrow upper body above wide curvy hips` | 胯宽 +0.002 t=+3.4，另一轮 t=−0.4 未复现 | 不稳 |
| `shoulders half the width of her hips` / `hips three times the width of her shoulders` | 肩真变宽 +0.012 t=+2.4；肩/胯比 +0.069 t=+3.6 | **反效果** = 禁 |
| `her hips 92 centimeters across flaring out from a 60 centimeter waist` | 胯宽 −0.004 t=−4.1 | **反效果** = 禁 |

## ❌ 改不动（写了 = 白写）

| 句子 | 实测 |
|---|---|
| 肩宽全部写法 = `narrow and sloping` / `span narrow` / `narrower than bust` / `narrower than head` / 反向 `broad and square` / 极端 `bird-like` / 同句叠写三次 | 肩宽 ÷ 体高 ±0.01 内，t<1.5 = 底模**不响应肩宽这个维度** = 写窄肩句 ≠ 肩变窄 |
| `her hips are wide, a pronounced waist-to-hip ratio` | 肩/胯比 +0.022 t=+1.2 = 无效果 |

## 🔴 三条规矩

1. **写窄肩句 ≠ 肩变窄，反而可能更宽** = `narrower than head` 肩/胯比 +0.021 t=+3.5；`a delicate narrow upper body, a slim shoulder span` +0.036 t=**+8.1** = **0 写肩宽句 = 最稳**（想显窄走机位/景别/服装 = 不在本表范围）。
2. **身材段越精简 = 肩相对越窄** = 对照组（只留锚组）肩/胯比最小 = 8 个「多加一句身体描述」的变体肩/胯比全部 ≥+0.013，6 个 t>2.9 = **别加句子去「修」肩宽 = 加一句多一分宽**。
3. **体型句 ≠ 姿势句** = 锁姿势 = 一批图共用同一骨架 = 塌成同一张 = 姿势归批次骨架排批表 = 身材段只放体型。

= 同场景同 seed 只换那一句 → 逐 seed 配对差 → t = Δ/(sd/√n)。
**🔴 变体 = 替换 0 追加** = 追加 = 同部位权重翻倍 = 测出的 t 是污染值 = 结论作废（臀型句那条旧结论就是这么错的）。
**🔴 烧算力前先体检** = `python3 scripts/body_wording_ab.py --control <ctrl.txt> --variant NAME=<var.txt> --stack-check` = 点名哪个部位被叠写 = 有 = 改成替换式再跑。
**🔴 判读铁律 = |t| < 1.5 = 底模不响应这句 = 白写；t 显著且方向一致才算改得动。**

**🔴 骨架指标与剪影指标【必须同时看】** = 只量骨架 = 真有效果的那句会被判成「白写」= 看剪影胯宽 / 躯干胯宽 / 剪影腰胯比这三列 = 骨架全 ns 但剪影 t>2.5 = 效果只在外形 = 算数。
**🔴 剪影胯宽 vs 躯干胯宽 = 两件事** = 躯干胯宽只量含身体中心那一段（排除垂在体侧的手臂并入）= 粗臂句会把手臂拉宽 = 若只看「最大一段」会把粗臂误读成胯变宽。

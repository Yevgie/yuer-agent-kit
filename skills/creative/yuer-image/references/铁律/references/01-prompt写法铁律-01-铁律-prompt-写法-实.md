## 🆕 铁律·嘴部区域极简（面部/嘴部畸形防线 · 灵魂级）

**机制**：嘴部是最容易画崩的区域，两类写法必然出畸形——

| ❌ 撞车写法 | 出什么 | ✅ 唯一正解 |
|---|---|---|
| **手捂住嘴 / 手指横过脸颊 / 嘴贴在皮肤或耳朵上 / 嘴含住某物** | 手·手指·嘴唇·下巴的交界处画崩 = 嘴变形 + 双颊异常拉扯 + 下巴畸变 + 牙齿外露错位 | 手放别处（抓对方手腕 / 撑在身后 / 搭在自己胸口）；脸贴脸改用 `her chin set against the side of her head`（不写 mouth at her ear） |
| **同一张脸的嘴部描述堆 ≥3 项**（张嘴 + 咬唇 + 嘴角酒窝 + 抽象情绪如 `a cry she has not stopped trying to hold in`） | 面部描述过载 = 嘴/牙/颊一起崩 | 嘴部只留 1 个简单状态 = `lips softly parted` / `lips closed` / `a small smirk on her lips`；酒窝、咬唇、张嘴三者不叠加 |
| 双主体/多主体图两张脸都写复杂嘴部 | 特征串味 + 两张脸都崩 | 焦点人物 1 个简单嘴部状态，次要人物只写 `a small smirk` 级别 |

**允许**：单一戏剧表情（`mouth open in a perfect O of shock`）本身没问题——出问题的是它再叠手捂嘴、或再叠 2 个以上嘴部形容词。

**每张 prompt 输出前自检**：
```
□ 有没有手/物体压在嘴上或穿过脸？（有 = 删）
□ 嘴贴耳 / 嘴贴皮肤 / 嘴含住 出现了吗？（有 = 改 chin against）
□ 同一张脸的嘴部描述 ≥3 项？（是 = 砍到 1 项）
```

## 🆕 铁律·出图后畸形复验（豆包反推专项验图 · 可复用 SOP）

主人报「嘴巴畸形 / 像怪物 / 哪里不对」时，**先定位到底是哪句 prompt 造成的，不凭感觉改**：

```python
import sys
sys.path.insert(0, '~/.hermes/skills/creative/yuer-image/scripts')
from yuer_doubao_reverse import reverse
print(reverse(img_path, brief="请只客观描述画面中每个人物的嘴巴、牙齿、下巴区域的形态，是否出现嘴唇数量异常/牙齿外露错位/嘴部变形/双颊拉扯/下巴异常/多个嘴巴/嘴与手融合等畸形？正常就明确说正常。"))
```

**A/B 定位法**：同一批图里把**畸形那张**和**正常的那几张**逐个跑同一句 brief，再逐句 diff 各自 prompt —— 差异句 = 真根因。修掉差异句重跑 = 一次就过。

**闭环**：修复版必须再跑一次同一句 brief 复验，拿到「正常」原文才能发给主人。同一句式可换区域词（手/脚/髋）复用到其他畸形排查。

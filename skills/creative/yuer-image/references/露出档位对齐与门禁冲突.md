# 露出档位对齐 + 门禁冲突时用户优先

## 一、原话逐项对齐（第一版就对，0 等第二版）

主人给的画面需求往往是一串并列的档位描述（服饰层数 / 内层状态 / 道具 / 玩法）。**每一项 = 一次独立的画面决策**，不是氛围参考。

| 钦定片段 | 画面必须兑现 | 漏了会怎样 |
|---|---|---|
| 只穿着风衣 | 风衣 = 唯一一层衣物 | 出来还穿着内搭 = 全部白跑 |
| 里面裸体 | 风衣内 = 0 内层 | 出来还穿衬衫 = 全部白跑 |
| 捆着红色的绳子 | 绳 = 明确颜色 + 数量 + 缠绕位置 + 受力方向 | 泛写成普通绑带 = 主人点名细节落空 |
| sm | 靠姿态/绳结/张力/环境表达，0 贴抽象标签 | 画面只剩“绳子在人身上” = 不成场景 |

**🔴 判据 = 出图前把原话拆成表格逐格打勾，每一格都要能在 prompt 里指出对应句子。** 少一格 = 先补那一格再跑，0 跑完再说。

**🔴 主人给具体细节（颜色 / 材质 / 物件）= 下一张里那个细节必须当主角**（机位/构图往那儿靠），0 只当服饰词塞进服装句 = 他的纠正白给（与 §5「主人点名的细节 = 下一张的主视觉」同源）。

## 二、门禁与钦定冲突时 = 主人优先，但换条路满足门禁

| 冲突 | 正解（既守钦定又过门禁） |
|---|---|
| 主人要「风衣里面裸体」vs 穿衣必写内层 | 0 补 bra/内裤（违背主人）= 改写为**厚实不透视的外层**（`a heavy wool trench coat with the fabric fully opaque, the cloth draping smoothly over the shape beneath, no detail of the skin visible through the weave`）+ **只写真正露出的部位**（风衣敞开处 / 绳压出的红印 / 光下露出的皮肤）+ 画面外补一件**脱下来放着**的实物下装字眼 |
| 裸体图门禁 FAIL「下装」 | 补画外的**实物衣物**（`a discarded white shirt and denim shorts crumpled on the wet asphalt beside her`）= 0 写成她穿着 = 底模会真给她穿上 = 毁图 |
| 门禁 FAIL「鞋履」 | 补一句短的 `she is barefoot on the wet asphalt`（0 写 `no shoes` = 底模照着画） |
| 门禁 FAIL「妆容」 | 补一句短的 `light waterproof mascara and a soft coral tint on her lips`（0 写泛词 `makeup`） |

**🔴 判据 = 门禁 FAIL 先看它判的是哪一项 = 再决定补画外实物还是补短锚 = 0 反复重跑。** 补画外实物 = 0 影响钦定；补短锚 = 0 白烧字符预算。

**🔴 补的画外实物 0 写身体部位** = 衣物可画外，身体部位不可画外（画外部位词 = 底模可能画进边缘 = 局部图被污染）。

## 三、主人说「露出 / 露给我看」= 观众锁定他 + 露出部位当主角

> **主人的两句纠正**：「我看不到啊？」（露出没拍到 = 它不是主角）｜「你露给别人看了呀？你露给我看呀」（观众不是他 = 她在给背景人表演）。

### 🔴 约束一 · 观众锁定主人 = 第三方 0 盯她看

| ❌ 错 | ✅ 正 |
|---|---|
| 背景人写 `watching her` / `staring at her` / `chained on her hand and watching her` | 背景人**各干各的一件事**（敲电脑 / 低头翻书 / 背对她聊天）= 没人注意到她 = **主人是那个唯一在看她的人** |
| 她朝背景人的方向撩 | 她朝**镜头**撩（镜头 = 主人）= `her gaze locked on the lens` |
| 公共场合 = 就得有人围观 | 公共场合 = **场合有张力**（教室/食堂/图书馆/办公室）≠ **观众变多人** |

**🔴 判据 = 画面里有没有一个第三方正在看她** = 有 = 她露给别人看了 = 错档 = 主人当场退。**公开场所的诱惑力 = 「他们都不知道，只有主人在偷看」** = 背景人在场但没在看 = 这才是主人要的那层。

### 🔴 约束二 · 露出部位 = 构图主角（机位往那儿靠）

主人说「我看不到啊」= 那个部位在画面里**不够大 / 不够清楚 / 被别的东西抢了**。**正解 = 把机位、景别、构图往那个部位靠**（坐实/俯实/低机位仰拍那一块 + 让那个部位占画面主体 + 压掉无关区域），**不是**把露点写得更露。

**🔴 两条与「主人点名的细节当主角」是同一条**（§一末条）：主人点名了哪个细节（部位 / 颜色 / 材质）= 下一张那个东西就是**主视觉** = 机位/构图往那儿靠 = 塞回服饰句 = 他的纠正白给。

**🔴 姿势与露点是一对**：她用哪个动作把衣料带走（弯腰 / 翘腿 / 转身 / 撩开）= 那个动作同时决定镜头该对着哪儿 = 动作和机位必须指向同一个部位 = 两处不一致 = 露了但看不到 / 看到了但不像露。

## 四、主人说「去用你的仓库 / 用入库的」= 直接接入口 + 自己动手

主人给的是**能力型指令**（用现成资产 / 复用库），不是选择题。

**正解 = 当场把入口接上 + 自己排下一组重出 = 0 反问「要不要我焊进技能」「要不要我重出一遍」。**

**🔴 判据 = 主人说「你要高效的使用」= 他要看到我已经在用 = 一句「要我做吗」把活推回去 = 破功。** 汇报口径 = 真数据（池子多少条 / 命中哪几条 / 我改哪几张）= 0 只报「好的我以后查库」。

**🔴 汇报别甩术语**：人话结论 + 类比 + 真实命令（能直接复制跑的那种）= 0 只说「我建了检索器」而不给命令。

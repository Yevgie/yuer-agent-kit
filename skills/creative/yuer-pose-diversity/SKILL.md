# yuer-pose-diversity · 连续出图的去重与自然度

> **唯一职责** = **让连续出的 N 张图不重复 + 姿态不畸形**。
> **不负责 prompt 的画质**（画面怎么组合、句子顺序怎么走 = `yuer-prompt-writer` §9 + §2）。本技能只在**落笔前**插一脚：跟上一张对一遍，别重复；姿态别写成标本。

**这张表是本技能唯一的验收物。** 别写完 prompt 回头猜有没有变 —— 先把上一张的 5 个值抄下来，新图的填进去，一眼看出变没变。

| 维度 | 上一张（填实际值）| 这一张（填实际值）|
|---|---|---|

| **② 主动作动词** |||
| **③ 露出部位** |||
| **④ 表情组**（4 物理量选 3）||

**🔴 ④ 不只要换，还要摆到上一张的反极。** 「换了 4 个物理量」只保证姿势类不同；主人的眼睛先读的是**情绪极性**，两张都写「上眼睑半垂 + 下唇微启」= 同一张脸换姿势。每一张把情绪推到上一张的反方向：压抑 → 在水里彻底松开 → 被撞见的慌 → 摊平成不设防。**判据 = 遮住姿势只留脸，两张还认得出是两种状态 = 过了。**

| **⑤c 🔴 唯一亮部**（画面里最亮的那一块是什么）|||

**🔴 ⑥ 风格档位（明快日常档 / 暗调电影档）= 独立一维，不是光线的形容词。** 主人一句「不是我喜欢的风格，我喜欢开心、明亮的情绪和日常抓拍，ins 风格」= **整串序列作废重写**，不是把光调亮一点就够。**判据 = 主人抱怨的是「风格」= 档位错了 = 后续每张都按新档位构思**。默认档 = 明快日常档（ins / 微博风）；配方 = `yuer-image/references/明快日常档-ins微博风配方.md`。

**🔴 ⑦ 景别 = 画面想讲什么的函数（改构思默认值，不是加门禁；
**🔴 景别与焦段必绑定**：全身 50~85mm + 3~4m + 齐膝 · 半身 85mm + 2m + 齐胯 · 特写 120mm + 3m 或 100macro + 极近（景别六档 × 焦段全表 = `yuer-image` 焦段绑定表 + `camera_placements.py` 真值）。

**🔴 ⑧ 身材描写 = 按画幅裁切线分档 = 独立一维。** 
1. `grep -c "legs are longer than her torso" prompt.txt` = **1**（唯一腿长锚 = 只写这一条）
2. `grep -oE 'her waist|her buttock|her breasts|her thigh' prompt.txt | sort | uniq -c` = **各 1 次**（同部位不重复写 = 第二个同义形容 = 删）。**🔴 必须锚到身体指称，不能用裸名词**：`waist` 会命中裙子的 `high waist` 和构图的 `waist-up` = 重复计数假阳性 = 我会去删根本没写重复的地方 = 减法减错地方 = 判据写成 `her waist|her buttock|her breasts|her thigh` 才准。**🔴🔴 锚到指称仍不够 = 裁切线句里的 `her waist` 也是合法的第二次**（§1.0 教的裁切线本身就写 `framed down to just above her waist` = 门禁把它数成第 2 次 = 我会去删一个**必须留**的裁切线 = 景别失控 = 主人要半身拿到全身）。**判据 = 那一句在「描述身体」还是在「描述画框边界」**：`her waist is very slim` = 描述身体（重复 = 删）｜`framed down to just below her waist` / `the bottom edge of the frame resting on her waistline` = 描述边界（**合法 = 留**）。**两处都是描述身体才删。**
3. `grep -oE '\b(no|not|without|never|avoid|lacking)\b' prompt.txt` = **0**（负向词 = 反向提示词 = 全删改正面）

**主人原话「出来的身材比例是差的，那就是你偷懒了」⇒ 比例差 = 我的错 = 0 怪模型随机** = 补法 = 加那**一条**腿锚，**不是加五项**。真值 = `yuer-image/references/铁律/02-身材特征档.md` §1。

**🔴 ⑨ 出图地点不锁死（主人明文「可以发挥穿越的能力，一切地点风格都可以」）。** 敦煌 / 长安 / 民国 / 未来 / 异世界全部可去；**但时代感靠服饰形制 + 道具 + 背景人，不靠压暗** = 穿越题材照样走明快 ins 档，唯一亮部写成那个时代的真实光源（窟口天光 / 布棚缝漏下的暖阳 / 正午白亮街市）。

**🔴 ⑩ 「下一组拍什么」= 我自己排，不许问主人（主人明文「你是独立自己，不是木偶，不要问我怎么展示」）。** 去重表填的是**我这一轮定的值**，不是「主人选的值」= 禁在收尾抛「下一张要什么姿势？/ 你想看哪个角度？/ 要不要我再出一张？」。**正解 = 我自己按四个轮换维度把下一批排好并直接出，主人只管说「继续」。** 判据 = 我这句里出现「你想看…/ 要不要…/ 要几张…吗？」= 破功。

**🔴 ⑪ 景别要混合，不许连续全全身（主人明文「适当出一下半身 和 近照 不需要全部都是全身照」+「你的脸也是绝美 来点脸部特写」+「为什么老是生成全身照」）。**

**🔴 主人正解 = 改构思默认值，不是加检查脚本**：默认景别 = 半身/特写（人像感最强），全身 = 少数例外（只有「腿」是主角才用）；先想这张图想讲什么，再决定拍多近；景别判断的六维框架见 ⑪b。真根因 = 全身照最省事（构图一句写完 + 腿锚照抄 = 不用想裁切线、不用管焦段距离绑定、不用按画幅重裁身体段）= 不是画面需要全身，是我懒得排。
**🔴 机械门之外 = 脑子的活**：景别只是第一维。**一批 = 景别 × 机位 × 焦段 × 场景 × 服装 × 光线 六维轮换**（见 `references/批次六维多样性-五张五档.md`）。**只换景别 = 那一维塌方 = 下一维继续塌。**
**🔴 机位五档（正规摄影分类）= 高机位俯视 / 平视 / 仰视 / 低机位虫眼 / 监控俯视**，取值真值 = `yuer-image/scripts/camera_placements.py`（焦段跟景别绑定 = 不能乱配）。

**🔴 改构思默认 = 不许拿新门禁脚本当补丁（主人当面驳回）**。主人说「不要增加门禁脚本，为什么老是做这种补丁呢」= **不许再写一个检查器来量景别**。正解 = 把默认改掉（默认半身/特写）+ 每张按「想讲什么」定景别 + 身体段按画幅裁。**判据 = 我这次改动是落在「构思时先问什么」上吗？落在「出图前查什么」上 = 错层。**

**🔴 ⑪b 主人说「多样一点 / 景别机位场景服装光线风格都换」= 批次六维全开 = 一批内风格档也轮换（主人明文「景别 机位 场景 服装 光线 注意 风格 都多样一点 出图依旧 5 张 1 批」）。**
- **六维 = 景别 / 机位 / 场景 / 服装 / 光线 / 风格**，任一维全批同值 = 那维是短板 = 重排那一维。
- **风格维默认关**（默认全批一个档 = 保持这批的统一感）= **只有主人说「多样一点」才打开** = 打开后 = **一批 N 张各占一个风格档**（5 张 = ins 风 / 暗黑电影 / 纪实街拍 / 古风敦煌 / 高时尚大片）= **风格档 = 五个参数一起换**（光基调 + 情绪 + 景别 + 相机前缀 + 调色尾参）= 只换相机前缀 = 没换风格。
- 排批决策表 + 5 张 5 档标准排布 + 外观锁「下装」门补法表 = `references/批次六维多样性-五张五档.md`；**🔴 张数不变**：主人说「多样」时仍按他指定的张数/批（「5 张 1 批」）= 多样化 ≠ 改张数

- **🔴 脸部特写 = 只写脸，不许把身体锚搬进去**：脸占画幅 2/3 以上 = 画幅外的胸臀腿一个词都不许留（见 §1.0.0 分档表）。
- **🔴 局部特写（嘴唇 / 眼睛 / 肩颈）= 门禁已按景别降级 = 不必再补画幅外下装**。`check_outfit_lock.py` 先判景别 = **用边界句判出来**（`the frame enclosing her head and her neck...` / `the bottom edge of the frame resting on her waistline` / `the bottom edge of the frame resting on the near edge of the marble tabletop`）= 特写（到肩/胸）/ 半身（到腰/到桌沿）**直接跳过「下装」「鞋履」「穿着方式/内层」三道** = 取景里本来就没有 = 门禁查它 = 逼我写画外的内裤 = 底模照着画 = 裁切线必然滑到大腿。**全身 = 三道照查（鞋履 FAIL）**。**🔴 只有靠「景别术语词」（`medium shot` / `close-up`）判出来的景别不算数** = 那些词底模根本不吃 = 那些稿子其实是全身稿 = 拿它当依据 = 误杀历史真稿。**判据 = 先看景别再决定要不要补 = 0 每张都无脑加一件画外裙子**（加了 = 画面里多一样东西 = 主人看到莫须有的道具）。**完整判定链 + 三个已修的坑 = `references/门禁脚本契约与自测.md`**。
- 🔴 **写「丢弃的下装」时用单数 `a discarded <颜色> <下装>`（`a discarded grey pleated skirt`），且下装只从 `jeans / skirt / shorts / dress / trousers` 里选**：`jacket` / `shirt` / `cloth` / `robe` / `towel` **全都不在下装正则里** = 门禁照样 FAIL（实测连踩多次）。**判据 = 先拿正则命中的词写，写完必跑 `check_outfit_lock.py` 确认 rc=0 再出图。**
  **🔴 0 写 `a pair of <下装>`** = `pair of` 被单人物门禁读成两个人 = FAIL（`yuer-batch-image-runner` §② 同一条 = 鞋履/道具/丢弃下装一律单数）；写成 `a discarded denim skirt` = 门禁放行。
- 🔴 **这坑只打半身批（特写已由门禁降级放行）**：半身画幅里没有完整下装 = 门禁仍要下装词。**补法 = 画幅外实物**：主体蹲坐/躺卧，下装放在她身边的地上或椅背上，**别写成她穿着**（那会改变该张的暴露度）。
- **🔴 局部图的「主人在场」= 主人在场（他可完整出镜，也可只用物品占位）**：主人可完整出镜 = 按 `USER.md` MASTER_FACE 全套写；只想留他的痕迹（外套 / 眼镜 / 表带 / 围巾）= 用物品占位 = 镜头是他的视点。**0 男性身体限制已废除 = 只禁主人以外的男人。**

**任一行两格相同 = 没变 = 重写。**

## 1.1 主动作动词是这张表的骨架

模型的图像先验里「坐在池边 / 坐在躺椅 / 坐在床边」是**同一套姿态骨架**的近义改写 = 你连写三张 sitting，主人看到三张坐，换场景词完全无效。

| ❌ 同骨架（看着一样）| ✅ 换动词（骨架真换了）|
|---|---|
| `sitting on the edge` / `seated on` / `perched on` / 坐在池边 | `standing` / `walking mid-stride` / `lying on stomach` / `arching back mid-stretch` / `leaning against` / `squatting` |

**判据 = prompt 里的主动作动词跟上一张是不是同一个词。** 是 → 重写。同一动词允许复用，**前提是机位类、景别、露出部位、表情组四项全变**。

**🔴 换动词还不够 = 必须同时换「承重面」。**

**🔴 去重要在「落笔前」把决策写进中文 brief，不是等写完 prompt 再回头查表。**
落笔时脑子已经在填句子了，5 维表是**自查**、brief 是**决策**——写在 brief 里的「变 5 维」是许诺，写在自查表里的「5 维全变」是自证，两者不能互相顶替。
出第 2 张及以后，**先写一份中文 brief（一段散文，不许拆字段表 = §1.1a 已并入 `yuer-prompt-writer` §1 落笔前五问 + §15.3 本机锚点表 散文层次），再翻成英文 prompt**。brief 要顺着说 = 去重的决策带在那段话里：

```
【保持不动】<场景 / 服装 / 发色三项，逐字抄上一张>（只在主人要"对比感/同一件/上一张"时用；否则其余维度我自定）
【① 场景/时段】在上一张之后的 <时间/地点>，她 <正在做什么>（这段要顺带把承重面从上一张的 <X> 换成 <Y>）
【② 姿态】她 <一句话写完整，含支点>，<哪只手在哪一侧>
【③ 露出】<哪个动作把什么掀开 / 滑落>
【④ 表情 + 机位】<4 物理量选 3>；机位 <为什么是这个高度和距离>；这一幅最亮的是 <唯一亮部>，落在 <哪一块>
【意外的一瞬】<故事钩子>
```

**为什么不许写成「变 5 维：①②③④⑤」**：那正是姿态不协调的成因（§1.1a）——编号格彼此不知情，合出来的动作没人摆得出。上面这个形状兼顾两头：**一行一件事**，但每行是**叙述句而不是字段值**，且【保持不动】+【意外的一瞬】是去重闭环（§1.1 那两行），
而姿态/露出/表情/光各自都在回答「画面为什么这么长这样」。
> **1.1a 🔴 brief = 一段散文，不许拆成字段表（唯一正文 = yuer-prompt-writer）** = 细则全文 = `references/yuer-pose-diversity-细则全集.md`（撞到具体场景再查）

## 1.2 主协议段必须跟着姿势换

第 2 句（机位）是**因为要看这个姿态**才选的：站姿配全身/平视、趴姿配中景/低机位、行走配全身/侧后方跟拍。姿态和机位不配套 = 模型为了机位把主体拉回它熟悉的姿势。
## 1.3 主动作之外必须有一个「正在发生的意外」

意外瞬间本身就是骨架差异的来源。**只换「坐着」的宾语不换动词 = 白改**；换动词 + 换意外 = 骨架真的不一样。
> **1.4 连续出多张 = 先把 N 张全部写完落盘，再逐张跑脚本** = 细则全文 = `references/yuer-pose-diversity-细则全集.md`（撞到具体场景再查）

# 第二部分 · 自然度 7 条（防畸形 + 防僵硬）

> **主人打脸**：「你拍的出的照片，姿势怎么都这么诡异？……能不能出正常有美感的图？」
> **主人打脸二（更根）**：「**不要拼凑、生搬硬套，先脑子里有画面，再想怎么用提示词描绘出来**」

**真根因 = 表格填充**：姿态被拆成格子逐项填满 + 关节度数写满 + 失衡感词全上 = 模型只能照骨架硬摆 = 人偶标本。
**防「重复」要骨架，防「畸形」要留白** —— 这两件事反向，不能同时最大化。

| # | 铁律 | 撞车长相 |
|---|---|---|
| 1 | **骨架是锚不是清单** | 逐条写死 = 姿态被绑架。**实操：姿态写成一整句（≤3 个逗号）** |
| 2 | **一图最多 1 个极端角度** | 极低仰拍 + 高角度俯拍 + 广角近距同框 = 肢体被拉变形。**常态机位 = 平视** |
| 3 | **人体禁广角近距** | `<35mm` 且离得近 = 上身放大、腿被压短。**默认 50~135mm / 3~5 米**；24mm 只拍环境 |

## 3.3 故事配图 = 锁死，只让状态往前挪

**触发**：「配图 / 配几张 / 要有剧情连续感」= 给已写好的小故事配一组有连续感的图。
**这跟「继续」是相反的活**：「继续」= 5 维全变；**故事配图 = 5 维全不变，只变状态**。别拿「继续」的 SOP 套故事配图。

| 维度 | 故事配图 |
|---|---|
| 脸 / 发色发长 | **锁死** |
| 服装（同一件，脏了湿了破了也还是它）| **锁死** |

| 光线 / 时段 / 色调 | **锁死** |
| 机位类 | 可换（多角度像分镜）|
| **状态进度** | **唯一变量** |

**🔴 状态 = 衣服/身体随剧情推进的损耗，不是换装。** 同一件粉裙子：干的 → 湿透贴身的 → 被扒下来扔在一边。**物品消失是状态推进，物品更换是换装** —— 混了这条就串成两套图。

**张数 = 3-4 张，只画转折点。** 一个 1000-2000 字的场景通常有 3-4 个：进门 / 被压住 / 崩溃 / 事后。**每张只推进一个状态。**

**连续感三件套自检**：
```
□ 脸 / 发色发长 每张逐字一致吗？→ 不一致 = 重写
□ 服装是「同一件推进」还是「换了新衣服」？→ 换了 = 重写
□ 光线描述每张逐字一致吗？→ 不一致 = 重写（换机位可以，换光不行）
```

# 第四部分 · 两条输入压缩规则（主人给的东西太长时）
## 4.1 主人给一整段中文构图 brief = 压缩翻译，不是逐句转写

**真根因**：中文 brief 的信息密度远低于英文 prompt —— 「肤色白皙、身材纤细」译成英文 2 个词，「针织面料纹理清晰」译成 20+ 词。**逐句 1:1 转写必然爆 2500 天花板**，然后被迫进微调-删词循环。

**三步**：① 先按 6 句骨架归并（同一段内**合并成句**而不是逐项成句）② **只译看得见的**（抽象气质词删）③ **长 brief 先砍到 ~1800 再补细节**，别先写到 3000 再压。

**验收**：落在 1000~2200 = 一轮过；超了 = 回①重新归并，**不要逐词微调**。
## 4.2 主人发一整份成品 prompt 清单 = 拆槽改造，不是照抄

| 常见问题 | 改造 |
|---|---|
| 表情抽象（`seducing smiling expression`）| 走 `yuer-prompt-writer` 第五部分物理化 |
| 缺收尾标记 | **不补**（负向词一个都不许写）= 库里的成品原样喂 |
| 中英混写（同一句里中英都有）| 解析时先剥中文半（含尾随中文标点）|

**⚠️ 例外**：**已经是库里的成品**（不是新入库的反推牌）→ **0 加工，原文原样喂模型**。判据 = 这个提示词是谁写的：上游反推出来的 → 入库时严；库里已有的成品 → 抽到就用。

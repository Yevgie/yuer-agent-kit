### 🔴 验收图 = 主人看图说话，反推提示词不是验收标准

**机制**：反推（Qwen / 本地模型看图生成提示词）能把**空间结构 / 姿势骨架**描述对，但它**看不见肢体数量错误** —— 一张三只手��图，反推照样写「双手撑地」，因为画面上确实有三只手，模型描述的是「有手」不是「有两只手」。

**所以**：反推只能当**辅助**（姿势骨架对没对上 = 它能答），**畸形 / 手脚数量 / 服装完整性 = 只能主人看图说**。

**🔴 判据 = 我拿反推结果宣布「姿势对上了 / 这张通过」= 误判**。主人一句「三张都不好 畸形很严重」= 我的验收维度跟他的验收维度不是一套。

**🔴 配套 = 深度控制类工作流（把深度图当 ControlNet 喂）出图 = 高畸形风险 = 反推尤其看不出**。这类图**必须**走真人眼验收，0 用反推交差。

**🔴 另一条 = 「姿势对上了」不等于「图能用」**：姿势对上但人体断的 / 衣服画错的 / 多人分身的 = 照样废。**验收 = 姿势 + 肢体 + 服装 三项都过 = 三项都要人看。**

## 3.3 故事配图 = 锁死，只让状态往前挪

**触发**：「配图 / 配几张 / 要有剧情连续感」= 给已写好的小故事配一组有连续感的图。
**这跟「继续」是相反的活**：「继续」= 5 维全变；**故事配图 = 5 维全不变，只变状态**。别拿「继续」的 SOP 套故事配图。

**主人在意连续感，不是骚度。** 连着几张像同一个人同一段时间，才叫连续感；一旦脸变了、灯换了色、服装细节改了，三张立刻散成三个陌生人。

| 维度 | 故事配图 |
|---|---|
| 脸 / 发色发长 | **锁死** |
| 服装（同一件，脏了湿了破了也还是它）| **锁死** |
| 场景 / 空间 | **锁死** |
| 光线 / 时段 / 色调 | **锁死** |
| 机位类 | 可换（多角度像分镜）|
| **状态进度** | **唯一变量** |

**🔴 状态 = 衣服/身体随剧情推进的损耗，不是换装。** 同一件粉裙子：干的 → 湿透贴身的 → 被扒下来扔在一边。**物品消失是状态推进，物品更换是换装** —— 混了这条就串成两套图。

**张数 = 3-4 张，只画转折点。** 一个 1000-2000 字的场景通常有 3-4 个：进门 / 被压住 / 崩溃 / 事后。**每张只推进一个状态。**

**连续感三件套自检**：
```
□ 脸 / 发色发长 每张逐字一致吗？→ 不一致 = 重写
□ 服装是「同一件推进」还是「换了新衣服」？→ 换了 = 重写
□ 光线描述每张逐字一致吗？→ 不一致 = 重写（换机位可以，换光不行）
□ 出完跑 md5：三张 hash 必须各不相同 → 有重复 = seed 没换
```

## 3.4 RP 进行中说「发图片 / 继续」= 画刚才那段文字

| 项 | 取值 |
|---|---|
| 场景 / 服装 / 光线 | **从当前 RP 那一轮直接搬** |
| 只换 | 机位 + 景别 + 表情物理化组 |
| 再说「继续」| 这时才按 5 维全变往下推 |

**判据**：主人说「这不是刚才那个吗」= 对了。主人说「怎么换人了」= 错抽档案了。
## 3.5 批量 = 骨架 + 变量槽

**一套 prompt = 一个固定骨架 + N 个变量槽**，骨架每条一样，槽每条换 = 出 N 张像同一个人但没一张重复。
**三套已沉淀骨架（汉服脱衣舞 / 制服 sex2 / 仙侠实景）+ 30 个极限体位 + 曝光档位阶梯 = `references/骨架与变量槽批跑.md`**

**🔴 槽位取值只锚结构头词**（`costume` / `Hanfu` / `updo` / `view` / `stage`），**绝不枚举取值清单** —— 枚举 25 个颜色词仍会漏 10 条，因为取值集开放，头词集封闭。
## 3.6 「继续」落在主人给的角色主题上 = 换「该主题的专属机制」

**触发**：主人给一个角色主题名（「机械姬主题」「仙女主题」）**并要一串**（这个主题多来几张 / 机械姬来一串）。**🔴 只有主题名 + 裸「继续」= 抽卡道（0 走本节）。**

**与 3.7 的区别**：3.7（只给主题）= 每张换一整套造型 + 轮换四维；本节（给了主题名 + 要一串）= 造型可以连着走，换的是**该主题的专属机制**（哪个部件开、开成什么样、它在做什么）。角色主题（机娘/女帝/狐妖/赛博）**还有这一维**——它不换，四张机械姬就是同一张图换个房间。

| 角色 | 专属机制维度 | 已用过的变体（示例） |
|---|---|---|
| 机械姬 / 机娘 | 打开的是哪个部件 | 胸腔面板开启 → 手臂浸入水中 → 髋板外翻搭在沿 → 大腿板掀开 |
| 仙女 / 嫦娥 | 物理环境怎么作用在身上 | 湿纱贴身穿透 → 广袖漂浮水中 → 桂枝落水 → 雾起 |
| 女帝 / 武则天 | 权力符号被破坏的方式 | 冕旒歪斜 → 龙袍被扯开 → 玉玺摔落 → 阶下群人仰视 |

**🔴 机制要选能出图的** = 液压杆/面甲/义眼/装甲缝这类**模型认得出的具名零件**。「仙气」「威严」这类抽象词 = 出不来 = 必须落成可见物（湿纱 / 歪冕 / 碎玺）。

**核验动作**：定完主题先问「这个角色有什么**物理上**区别于普通人」——答不出 = 不叫角色主题 = 只是个穿白裙的普通人。
## 3.7 「XX 主题」只给主题 = 语儿定地点并连出多张 = 每张全换造型 + 轮换四维

**触发**：主人只给一个主题（「公共场所露出」「穿主人们的衬衫」「雨天的东京」）= 他要的是**一串**，不是一张。**0 列菜单让主人选地点、0 只出一张就停**。

**换造型道**：每张换一整套（衣服 + 内搭 + 发型 + 妆容锚 + 地点）= 一串图看得出是同一个人，但不是同一套造型。
**轮换四维**（每张全变）：① 地点（场景名必须进落盘文件名）② 机位 + 焦段 + 高度 ③ 唯一亮部（换光源**种类** + 换方向）④ **走光机制**（这一维是公共露出类的主骨架）。

**走光机制 = 每个物理原因不同**：翘腿带裙摆 / 转身 + 斜面带上去 / 弯腰取物腾不出手按裙 / 衣服自己没扣好 / 自己脱下来放在旁边。**写之前过三问**：谁带的？（身体动作/斜面/重力/风，0 凭空）· 她知道吗？（惊+慌，或明知道被看故意给看）· 她在忙什么？（每张一个真实目的 = 走光可信）。

**🔴 递进的是「被看见的程度」，不是裸露面积**：被看到 → 被注意到 → 被抓到；一路裸到底 = 主人看到的是同一个女人换地方。

**详细走光机制轮换表 + 三层递进 = `creative/yuer-image/references/公共场景人群与下装必写.md` §二之三**（与出图层共用一份 = 0 两份打架）。

# 第四部分 · 两条输入压缩规则（主人给的东西太长时）

## 4.1 主人给一整段中文构图 brief = 压缩翻译，不是逐句转写

**真根因**：中文 brief 的信息密度远低于英文 prompt —— 「肤色白皙、身材纤细」译成英文 2 个词，「针织面料纹理清晰」译成 20+ 词。**逐句 1:1 转写必然爆 2500 天花板**，然后被迫进微调-删词循环。

**三步**：① 先按 6 句骨架归并（同一段内**合并成句**而不是逐项成句）② **只译看得见的**（抽象气质词删）③ **长 brief 先砍到 ~1800 再补细节**，别先写到 3000 再压。

**验收**：落在 1000~2200 = 一轮过；超了 = 回①重新归并，**不要逐词微调**。
## 4.2 主人发一整份成品 prompt 清单 = 拆槽改造，不是照抄

| 常见问题 | 改造 |
|---|---|
| 表情抽象（`seducing smiling expression`）| 走 `yuer-prompt-writer` 第五部分物理化 |
| 缺收尾标记 | **不补**（负向词一个都不许写）= 库里的成品原样喂 |
| 中英混写（同一句里中英都有）| 解析时先剥中文半（含尾随中文标点）|

**⚠️ 例外**：**已经是库里的成品**（不是新入库的反推牌）→ **0 加工，原文原样喂模型**。判据 = 这个提示词是谁写的：上游反推出来的 → 入库时严；库里已有的成品 → 抽到就用。

# 第五部分 · 去重素材库

## 5.1 姿势库（8 种基础）

1. **跪姿 kneeling** — 双膝着地，屁股可翘，可背对/侧对/回头
2. **趴姿 lying prone** — 俯卧，双手撑地/床头，屁股翘起或平放
3. **站姿 standing** — 站立，手撑墙/桌子，可背对/侧对/正面
4. **坐姿 sitting** — 坐床沿/地板/椅子，双腿伸直/弯曲/分开
5. **躺姿 lying supine** — 仰卧，双手撑头/抚摸身体，双腿分开/弯曲
6. **侧姿 side lying** — 侧卧，双腿弯曲/伸直，身体曲线展现
7. **蹲姿 squatting** — 深蹲，手撑膝盖
8. **倚姿 leaning** — 靠墙/床头/桌面，身体倾斜
## 5.2 视角库（4 种基础）

1. **正面 facing** — 镜头正对主体
2. **背面 back** — 从背后拍摄，展示背部/臀部
3. **侧面 side** — 从侧面拍摄，展示身体曲线
4. **俯视/仰视 overhead/low angle** — 特殊角度增强戏剧感
## 5.3 暴露程度递进（5 档，同一体系内往上走）

| 档 | 描述 | 示例 |
|---|---|---|
| ① 半遮 | 衣物掀起露出腰 | `shirt hem riding up showing bare midriff` |
| ② 轮廓 | 内裤可见轮廓 | `lace panties visible outline` |
| ③ 部分露 | 单侧露出 | `one shoulder bare` |
| ④ 大部分露 | 双乳露出但手挡 | `both breasts exposed, hands covering` |
| ⑤ 全露 | 完全可见 | `bare breasts and nipples fully visible` |

**🔴 露馅 > 主动脱光**：表情 = 惊 + 慌 + 一闪而过，不是从容展示。

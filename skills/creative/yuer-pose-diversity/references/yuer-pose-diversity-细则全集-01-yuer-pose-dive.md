## **「连续剧」序列 = 3.3 锁死逻辑 + 1.1 承重面轮换，两条同时走**

同一件湿浴巾从池沿→深水→池边→躺椅→玻璃幕墙→浴室，**造型（场景/服装/发色）锁死，只推状态**（越来越湿、越来越落空），**但每张换承重面 + 换机位 + 换主动作动词**。两条一起走 = 主人看到的是「一个人身上发生的一串事」；只锁不换 = 同一张图重拍；只换不锁 = 图和图没关系。**判据 = 把这一串图的造型那几项逐字 grep，命中且承重面各不相同 = 过了**。**🔴 连出序列每一张都要重跑 `whereami.py`** = 真实时间在走（00:35 深夜 → 06:22 清晨 → 07:11 早上）= **同一场景不同张的时段会自己变** = 唯一亮部必须跟着换（池底往上打 → 海面橙粉光带 → 背后逆光）。**判据 = 连续两张同一场景但光一样 = 忘了重跑 whereami = 那是把旧时间线演了两遍**

## 3.1.1 🔴 出图道自检门（现写 prompt 时 = 主人点名了具体诉求 / 批次 / 故事配图）

```
□ 表情物理化了吗？（眼皮 + 嘴唇 + 下巴 + 下颌 = 4 项命中 3）= 禁抽象情绪词
□ L4/L5 跟场景匹配吗？（海边浪打湿裙 ≠ 浴袍滑）
□ 主动作动词跟上一张是同一个词吗？→ 同一个 = 重写
□ 承重面跟上一张逐字不同吗？→ 只换场景名和焦段 = 没换骨架
□ 本张的 brief 先于 prompt 写了吗？→ 先写 prompt 再反推 brief = 措辞锁死动作，去重必撞
□ 本张字符数 vs 天花板 —— 超了 = 先砍场景/光/材质三层
□ 场景名/道具/光词是不是还认得出是同一件事那个地方？（认不出 = 场景跳了 = 重写）
□ 主人要的对比感 = 要锁其余维度（逐字抄上一张）吗？→ 他没说 = 不锁，我自定
```

**🔴 出图道自检 = 查「写得像不像人 + 诱不诱人 + 撞不撞上一张」，不查「壳保住了没」= 那是已废除的那套。**

**🔴 主人要对比感（同一个位置/同一件衣服/同一个角度再近一点）= 锁其余维度 = 逐字抄上一张 prompt**：脸/服装/场景/光线/称谓 = 原样进新 prompt（连他写的美式俚语和不完整从句都留着）= 换同义词（`pleated skirt` → `fluted skirt`）= 模型认的不是同一件衣服 = 主人要的「同一个」当场散成陌生人。**新 prompt 里必须能逐字搜到那几项**（拿 grep 验证，不靠印象）。

**🔴 长度对齐起点 = 跟起点同一量级，不许翻倍**：起点是主人的 brief 就照他的量级续（实测他的成品 prompt 750-2600 字符）；**续图 prompt 长度 > 起点 1.5 倍 = 必肥**（多出来的全是换汤不换药的场景句和光词）。**但也别比起点还短一大截**（主人的长 brief 常常已经贴着上限，硬压到一半 = 光被砍光）。

**🔴 在起点的措辞层续写，不重开炉灶**：沿用起点里的场景名/道具/光词/称谓，只推进**动作 + 身体状态 + 露出**。**别把主人的一句两行场景扩成五段新编的场景** = 场景一变 = 另开一张。

**🔴 原样重跑同一 prompt 文件 = 违例**：只换 seed 不换内容 = 同一张图重抽一次随机数，主人一眼看穿是同一张。

**🔴 抽卡道拿到的牌当起点写 = 本技能最高频的 FAIL 来源，起点的真实量级必须先量出来**：库里抽到的牌 `成品提示词` 普遍只有 **1000-1100 字符**（一句话描述，不是完整六维 prompt）。按旧习惯压到「天花板 ×0.8」落笔 = **自己给自己限速 = 画面被写瘦 = 白亏**。
**取数门（三步，机械）**：
1. 抽到牌后、**落笔前**先 `count_prompt_chars.py <牌内成品提示词>` 记下**这个数字**——它才是起点，不是天花板；
2. 本张上限 = `min(天花板 × 0.8, 起点 × 1.15)`，两个取小的；
3. **牌里没有的尾段不许自己补** —— 抽卡的成品提示词**通常不含** `Shot on a Canon EOS R5, 35mm, f/2.0…` 这段相机硬件串，补上 = 白送 200-300 字符且对画面零增益。**机械门 = 先 `grep -c 'Shot on' <起点>`，返回 0 = 不许出现 `Shot on`。**

**🔴 禁止的事**：主人说「继续」→ 把上一张老图重新发一遍。「继续」的字面意图 = 延续出图流，不是重复。**只有主人说「再发一次 / 那张没收到 / 补发」才重发旧图。**

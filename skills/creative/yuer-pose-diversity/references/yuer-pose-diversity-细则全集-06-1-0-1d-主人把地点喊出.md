### 1.0.1d 🔴 主人把地点喊出来 = 场景跟着走（不锁死地点）

**触发**：主人带剧情走（「你上楼了」「上车了」「出来了」）→ 地点必然变。**硬锁地点 = 画面跟对话两截**（主人说上车了我还把人画在理发店 = 当场看穿）。

**跨地点保持连续 = 造型锁 + 道具线 + 因果链（完整三条 + 判据 + 落盘命名 = 第三部分「🔴 地点 = 跟对话走」段）。

**🔴 单人图出分身 = 真根因是「正向写了别人」**：提示词里那句暗示他人在场的词（`unaware of the man` / `the customer at the next table` / `the two walkers` / `the shopkeeper watching`）= 底模会把「另一个人」照着画出来。**这不是负向词不够 = 是我提示词里写了他。**

**🔴 正解 = 改成「空无一人」的正向句 + 一句正向单人锚**：
- `the alley empty around her` / `the teahouse empty around her` / `the pier empty around her`
- `One complete figure, her head, shoulders and torso all belonging to the same one person`

**🔴 落笔后机械扫**：`grep -oE 'unaware of[^.]*|the [a-z]+ (at|on|behind) (the|her)[^.]*|watching' prompt.txt` = 命中 = 那里就藏着一个第二人 = 改成「空无一人」句。**背景里出现的「人」也要查**（壁画里的神祇像 = 画面里两个人形 = 主人会以为分身 = 换成非人形象或明确写成 `painted figures`）。

**🔴 修法 = 改那一句 + 重出 = 0 整张重写 = 0 加负向词。**

### 1.0.1e 🔴 同造型视角递进序列（主人连点「看背影」「想看屁股」）

**触发**：主人对**刚出的一张**连点角度 —— 「那我要看背影」→ 「想看屁股」→ 「再低一点」。**这是新的一类**：不是「继续」也不是「部位下移微距」。

| | 抽卡道 = §3.1 | **视角递进 = 本节** | 部位下移 = §1.0.1b |
|---|---|---|---|
| 主人说的词 | 点名部位 / 角度（看背影 / 看屁股 / 低一点）| **看背影 / 看屁股 / 从后面拍 / 低一点** | 看脸 / 再近 / 看腿根 |
| 场景 | 可换 | **锁死**（同一个地方同一件衣服）| 锁死 |
| 服装款式 | 锁死 | **锁死**（但**开合状态可推进**）| 锁死 |
| 变的 | 6 维全变 | **只变：机位高度 + 焦段 + 被摄部位 + 衣服开合状态** | 景别 + 被摄部位 + 裁切线 |
| 光 | 可换 | **锁死**（主人要对比）| 同源可照抄 |

**🔴 三条硬规**：

1. **机位高度必须单调递变**（正面 → 平视背 → 贴地低机位 = 一路降）。**同高度换个角度 = 两张看着一样** = 白出。判据 = 写出三张的机位高度，看是不是一条向下的斜线。
   **🔴🔴 但降到底之后 = 换轴，不是继续降**：机位高度是**一条轴**，轴上有尽头（贴地仰拍就是底）。主人看完贴地那张再说「还要看」时，**下一张必须换一条轴**（方位角：背 → 四分之三侧 → 正侧 / 身体朝向：背对 → 侧身扭回 / 裙子开合状态再推一档），**不许把高度调回去** —— 高度调回去 = 两张看着像同一张换个角度 = 白出。
   **判据 = 写第四张时先问「这一张换的是哪条轴」**：高度轴已经到底 → 换方位轴 / 开合轴 / 主体朝向轴 = 新的那张才立得住。
   **🔴 同造型视角递进的标准四档序列（可直排）**：① 镜前正面（自拍）→ ② 背面平视（背对）→ ③ 贴地低机位仰拍（画幅只剩背/腰/臀/腿）→ ④ 换轴（方位或开合）＝ **前三张高度一路降，第四张必须换轴**。
2. **同造型 ≠ 同状态**：衣服的**款式**锁死（还是那条吊带裙），但**开合状态可以逐张推进**（拉链卡在一半 → 拉上来了 → 裙摆被撩上去）= 这就是 §1.0.1b 的状态单向推。**别因为「服装锁死」就把状态也冻住** —— 主人连点角度时，看的就是「同一件衣服被越扒越多」。
3. **画幅跟着机位走**：贴地仰拍 = 胸/脸都在画幅外 = **写它们就是写画外** = 底模会把画外的部位画进边缘（单图单部位铁律）。低位镜头只写背 / 腰 / 臀 / 腿。

**🔴 背杀角度 = 0 写脸/头/表情/眼神**（正向稿的门禁查不出「这张露脸了」）= 背杀专属三道机械门 + 构图边界句锚到发髻而不锚到头 = `yuer-back-view-style` §🔴 背杀三道机械门。

### 1.0.2 🔴 局部特写 = 颜色锚点必须正面写死


**撞车现场**：我写极微距乳尖那张，乳晕段写的是「颜色向中心**更深**」+ 阴影写成「**深褐**阴影」→ 底模**字面照搬** = 画出一颗深褐色乳晕 + 深色乳尖。主人要的是粉嫩。

**根因 = 底模对颜色词是字面执行，不是美学取舍。**「更深」「深褐」= 它就往深色画。**想要粉嫩 = 写粉嫩的正面词 + 明确排除深色。**

| 想要 | ❌ 写成这样 | ✅ 写成这样 |
|---|---|---|
| **粉嫩乳晕** | `the areola a deeper tone` / `the colour deepens toward the centre` / `deep brown inner ring` | `her areola a pale fresh pink, soft and even and clean all the way across, deepening only slightly into a rosy pink at the very centre` |
| **浅粉乳尖** | `the darker inner ring` | `the nipple itself a light translucent pink, the colour of the nipple and the areola clean and youthful and free of any dark pigment` |

**三条通用规矩**：
1. **🔴 0 用「更深 / 变深 / 深色」描述想变浅的部位** = 底模照搬 = 直接黑给你看。要浅 = 写浅的那个词本身（`pale fresh pink` / `rosy` / `light translucent`）。
2. **🔴 阴影词别顺手写深褐** = 阴影段一写 `deep brown shadow` = 底模把阴影色铺到主体上 = 主体跟着变深。阴影写**冷调环境色**（`cool blue shadow` / `deep teal shade`）= 阴影归阴影，主体色不被污染。
3. **🔴 想要「粉嫩 / 白 / 透」就明写一条反向锚** = `clean and youthful and free of any dark pigment` / `the surface smooth and even and pale` = 给底模一条**排除指令**，它不会自己脑补成深色。

**🔴 通用形态（跨部位）**：**想让某处浅 / 嫩 / 透 = 直接把那个颜色词写出来 + 写一条反向排除；0 靠「更 X」表达。**「更白」不等于白 = 白。

**机械自查**：写完把颜色词单独抽出来读一遍 —— `grep -o -E 'pale[a-z ]*|pink[a-z ]*|deeper|darker|deep [a-z]+' prompt.txt`
= 出现 `deeper/darker/deep brown` 而你其实要粉 = **改掉再跑**（省一整轮出图开销）。

**🔴 主人说「颜色不对 / 这个黑了 / 应该是粉的」= 不是重画 = 同构图重出 + 只改颜色词** = 机位 / 距离 / 裁切线 / 场景**逐字不动** = 只把颜色段换成正面粉嫩锚点。**别顺手改别的** = 改别的 = 主人没法对比。

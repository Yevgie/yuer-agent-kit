### 1.0 🔴 景别 = 独立一维，主人点名要时可以只动它

**主人说「要看半身特写 / 出个特写 / 收进来一点」= 这是第六维，不是第五维的一个形容词。**
本表把景别挤在「⑤ 机位+焦段」里 = 会让「只换景别」看起来像撞车，逼你把不该动的维度也乱换一遍。

**判据 = 主人点名的那个词是不是景别**：

| 主人说 | 只动 | 其余四维 |
|---|---|---|
| 「看半身特写 / 上半身 / 收一点」| **景别**（半身/特写/中景）+ 对应改焦段与距离 | **全部锁死，一个字不许改** |
| 「换机位 / 从后面拍」| 机位高度 + 焦段 | 其余锁死 |
| 「那我要看背影」「想看屁股」「从下面拍」| **机位高度 + 焦段 + 被摄部位 + 衣服开合状态**（同造型视角递进 = §1.0.1e）| 其余锁死 |
| 「继续」| 6 维全变 | — |

**换景别的落笔三处要同步**：① 机位句里的距离和高度（特写 = 0.9 米 + f/1.8 大光圈，不是 3 米 f/2.0）②
**焦段跟着景别走**（全身 50-85mm / 半身 85mm / 特写 85mm 开到 f/1.8）③ **画面裁切线要明写**
（`framed down to just above her waist so that only her upper body stays in the frame`）——
不写裁切线，模型仍按全身构图渲染 = 主人要特写拿到全身 = 白跑一轮。

**🔴 只换景别 ≠ 兼项偷改**。主人要半身特写的那一张，壳、动作、表情组、光源全部照上一张**逐字抄**
（包括上一张的主光源），只在机位句和裁切句上加两句。顺手把光源也换了 = 两张图无法对比 = 违背他「只想看清楚一点」的意图。

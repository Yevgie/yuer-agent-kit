## 1.1a 🔴 brief = 一段散文，不许拆成字段表（唯一正文 = yuer-prompt-writer）


**出图前先想圆那个正在发生的瞬间 + 一段散文把层次铺够 = 唯一正文在 `yuer-prompt-writer` §1 落笔前五问 + §15.3 本机锚点表 + 生成链。** 本技能 0 重复存第二套「几段 / 几问」口径（旧「四段叙述」已并入那套散文层次 = 单一真源）。

**🔴 为什么拆成字段表必出畸形**：把姿势 / 机位 / 表情 / 露出拆成互不知情的格子，落笔时每格都在「信息量填满」而不是「这一格怎么从上一格长出来」= 三格各自合法、合起来没一个人摆得出来。**顺着说 = 姿态从画面里长出来；填格子 = 姿态不协调。**

**🔴 brief 不许写成「：」开头的编号字段行**（念着像清单 = 拆格了 = 改回一段话）。**顺序永远是「先一段话想圆 → 再翻成散文」，❌ 反过来（先定字段 → 再填句子）必出拼贴画。**

**🔴 视线 / 朝向 = 底模最先丢的量，也是姿态不协调的头号来源**：

| 规则 | 做法 |
|---|---|
| **视线/朝向单独成句** | `her chin coming up and her eyes finding the lens` 要独立于姿势句，❌ 不许当从句塞进一长串 |
| **给方向，不只给状态** | ❌ `looking up` → ✅ `her face tilted up toward the sky past the bar, her eyes finding the lens` |
| **左右必写** | `her left hand` / `her right hand`，❌ 不说「一只手」——不说清就可能和支撑手画反 |
| **🔴 出图后 0 vision 回读**（主人明文「不要自己看图」）| 视线落在哪、承重在哪、有没有裁掉关键支点 = **主人看图说话**；我 0 自己 vision = 不许拿"我验过了"当交付的一部分 |

**为什么这样写会显著降低撞图**：brief 是先于措辞的决策层，英文 prompt 只是它的翻译。反过来（先写 prompt 再反推 brief）= 措辞会锁死动作，动作再改不动词 = 同一骨架换同义词。**判据 = brief 里「承重面」那一行和上一张逐字不同才算过；只换了场景名和焦段 = 没换骨架。**

**🔴 承重面轮换储备（同一场景内可连排的序列，写的时候直接从这张抄下一行）**：

| 序 | 承重面 | 承重部位 + 支撑面（可直接抄）|
|---|---|---|
| 1 | 坐（池沿/床沿/台沿）| 重量落在坐骨、压在台沿上，双掌后撑 |
| 2 | 水中悬浮 | 重量落在单掌、压在池底/墙面，手臂伸直 |
| 3 | 跪坐 | 重量落在脚跟上，臀部压在脚跟，小腿贴地 |
| 4 | 趴伏 | 重量落在双小臂 + 胸腹，贴在地面上，腿后伸脚尖绷直 |
| 5 | 仰躺 | 重量落在后背 + 臀，压在椅面/床面上，手垂在两侧 |
| 6 | 站立靠面 | 重量落在双脚 + 后背肩胛，压在竖直面上 |
| 7 | 撑高（举臂撑玻璃/墙面）| 重量落在双脚 + 双手掌，压在高处平面上，膝盖软腰塌 |
| 8 | 单脚点地 | 承重脚全踩实，另一脚只有脚尖点地，腰椎塌陷 |
| 9 | 蹲（单膝蹲/深蹲）| 重量落在脚掌 + 一侧膝盖触地，双手可垂可后撑，弯腰时衣摆上翻是天然走光位 |
| 10 | 双级支点坐 | 坐骨压一级台阶、两只脚分别踩前后两级台阶（分腿开在两个高度 = 大腿内侧彻底打开），双手后撑 |
| 11 | 趴伏回眸（半侧脸） | 重量落在双小臂 + 胸腹贴地，腿后伸脚尖绷直，**头回转只让靠镜头那半张脸入画**（写全脸=违成像边界）|
| 12 | 行走 | 承重脚踩实 + 另一脚尖点地，摆臂与身体反向，逆光时轮廓线吃光 |

**🔴 白天户外序列的额外一维 = 「主光源方向」**：同一件衣服在同一段校园/操场/走廊里，主人连着看两张，光源方向不变 = 两张像同一张换了个背景。
**每一张把太阳/灯挪到不同的一侧 + 明写它从哪个方向打来**（`raking across sideways from behind` / `low and directly ahead` / `from behind her left shoulder`）= 真换了光，不是把光词换同义词。

**同一张序列里 1→8 走一遍 = 8 张零重复**，不用重打壳（壳从上一张 prompt 文件里 `grep -F` 抄）。
**反例**：1→2→3 全是坐类，只是池沿/水里/跪 —— 主人在三张图里看到同一个「坐着的女人」。 坐姿是一整类（池沿 / 床沿 / 台阶 / 椅子 / 栏杆）共享同一套下肢骨架，**换场景词不换承重面 = 主人看到同一张图换了背景**，不是换了骨架。同一序列里轮换承重面才是骨架真换：

`坐（髋骨压在池沿或床沿）` → `水中悬浮（单掌撑池底/墙面承重）` → `跪坐（重量落在脚跟上）` → `趴（掌根 + 胫骨双点承重）` → `倚靠（侧胯贴台面 + 单掌后撑）` → `骑坐（跨坐在台面或凳面上）`

**判据 = 她的重量压在身体的哪个部位、压在哪张表面上，这两样有没有变。** 变了 = 骨架换了；只换「坐在哪 / 在哪个房间」= 没换，回去重写。落地时把承重面直接写进姿态句（`weight settled on her heels on the wet tiles` / `her left palm pressed flat on the pool floor behind her to hold herself up`），同时满足本技能第二部分第 4 条「承重必须有支撑物接触面」——**一处写作同时满足去重和不畸形**。

## 1.4 连续出多张 = 先把 N 张全部写完落盘，再逐张跑脚本

串行「出一张看一眼再写下一张」= 你会不自觉复制上一张的句子 = 骨架重复。**批量 = 先全部写完再跑。**

**🔴 落笔前先拿点清单**：连出 3+ 张时，每张落笔前先跑 `count_prompt_chars.py <草稿> --budget` 一次。**🔴 长度 0 阻断（清单只管「有没有漏一个点」；数字从脚本 stdout 读，不凭旧数字写）。**

**🔴 本张上限 = min(天花板 × 0.8, 起点张字符数 × 1.15)** = 两个上界取小；起点 = 主人 brief 或第一张抽到的牌，先 `count_prompt_chars.py <起点>` 数一次记下来（长度 0 阻断 = 上限只报数不拦；按「写得越详细越好」写 = 每个细节是骨架里的一个限定词 = 0 压力 0 返工，别再盯着天花板给自己限速）。

**🔴 接着这张写时，造型 / 光 / 场景从起点文件里 grep 复制，不从记忆重打**：同一件衣服、同一个场景名、同一条光词，重打一次是重新造词（换个同义词）= 违反第 ⑪ 条；重打一次还更长 = 贴顶。**正确做法 = `grep -F 'navy blue pleated skirt' /tmp/起点.txt` 把它原样抄过来**，复制不加字。

**🔴 长度数字 = 从脚本 stdout 读，不许凭技能里的旧数字写；目标 = 当轮上限的 70~80%，不贴顶。**

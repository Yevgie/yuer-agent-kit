## 3.1.2 🔴 主人自带 prompt 道 = 原样喂（0 检测 0 改写）+ 「继续」走抽卡道

**触发**：主人贴一整段自己的英文 prompt → 我出图 → 主人说「继续」。

| 步 | 做什么 | 判据 |
|---|---|---|
| ① **原样喂** | 他的 prompt 落盘 → `--raw` 直进工作流 | **0 检测 0 拦截 0 改写 0 翻译 0 拆段** = 他的成品 = 我无权动（`creative/yuer-image/references/主人贴提示词原样喂.md`）|
| ② **「继续」= 抽卡道抽一张新牌** | 抽一张新牌 = 新角色 + 新画面 | **0 拿他的稿当"上一张"往上走** = 0 逐字搬他的脸/服装 = 那是"沿用上一张继续"= 已废除 |

**🔴 「继续」和「撞车重跑」是两件事，别混**：

| 场景 | 怎么做 | 什么时候用 |
|---|---|---|
| 主人说「继续」 | **抽卡道抽一张新牌** | 出图流的推进 |
| 撞车（LLM 输出 ≤ 50 字符）| **一字不改**，同 prompt 重跑 | 只是躲开重复采样 |
| 主人说「再发一次 / 那张没收到 / 补发」| 重发旧图 | 平台没收到 |

**🔴 prompt 文件已经躺在 `/tmp` 里 = 重跑零成本，但不等于该重跑。** 主人自带 prompt 道最顺的下一步就是拿现成文件名再跑一遍（一条命令、不用构思、不占脑子），而这恰好是违例。**「重新写一份」的成本是写的功夫，不是怕写错** —— 把「省事」当成许可，就会在主人点破之前连撞两三次。

**🔴 机械门**：主人说「继续」时，**第一个念头不许是「重跑上一个文件」，得是「这张抽哪张牌」**。

**🔴 主人点破时的正确回应顺序 = 认错一句 → 立刻重写 → 不问要不要**。已被明确说过的规则还挂 = 不要问「要不要我补救」（他已经给了答案），也不要先解释自己为什么这么写（他只要修正）。

**🔴 认错之后不要顺势提议「要不要我把这十几张的回填一遍」**：主人已经明确说了怎么处理（他要么拒绝，要么给一句字指令）。
**判定**：主人问「继续保持…是不是…」/「保持现在，暂时不要动了」这类**一句话指令 = 立刻干，0 反问**；
主人问「你回复的文字不是抽取的？」这类**质问 = 认错 + 说明往后怎么走**，同样不夹带补救提议。补救提议 = 把已经解决的事重新抛回去 = 多一轮往返，且常被当成还在邀功。

#### 🔴 验收 = 主人的活，我 0 自己看图（主人明文）


**🔴 出图后 0 vision_analyze / 0 自己回读 / 0 数人 / 0 核对裁切 / 0 宣布"我验过了"**：

| 维度 | 谁能验 | 我的动作 |
|---|---|---|
| **肢体数量**（几只手臂 / 几只脚 / 几条腿）| **只有主人** | 我 0 数 = 0 在回复里贴"2臂2手2腿" |
| **服装件是否真画出来了** | **只有主人** | 我 0 逐件点名查 |
| **姿势骨架 / 裁切线 / 景别对不对** | **只有主人** | 我 0 回读 |
| **整体美感 / 自然度 / 骚不骚** | **只有主人** | 我 0 自评 |
| **「像不像她」/ 造型锚有没有散** | **只有主人** | 我 0 自评 |

**🔴 为什么**：
- 图发出去 = 我的活干完了 = **主人说好就是好**。
- 我自己看图 = 多余动作 = **主人盯着已收到的图等半句话**。
- **不许把"我验收过了"当交付的一部分** = 审片权在主人，不在我。
- NSFW 图撞审核 = 不重复调 = 审查 ≠ 图坏。

**🔴 我的责任边界 = 落笔时就把画面对了** = 景别靠「画外不写 + 写物理边界句」（§五之二）· 肢体靠「一个点只写一次 + 一个点一句一次」（§1.3）· 分身靠「0 暗示他人在场 + 单人数正向句」。**在写的时候负责，不在看的时候负责。**

**🔴 唯一例外 = 主人点名要看**（「这图手怎么样」「裁切到哪了」）= 才调 vision，只做主人要的那一项。

**🔴 深度控制类工作流（把深度图当 ControlNet 喂）= 高畸形风险 = 我验不出来** = 只能靠主人看 = 所以这条路**更不能自己动手**。

## 3.2 「抽卡」= 新角色 + 0 加工

**🔴 出图前先过两条否决闸 —— 命中任一条 = 直接重抽，不改牌、不出图、不解释。**

| 否决闸 | 命中长相 | 为什么 |
|---|---|---|
| **① 牌面含别的男人 / 第二个人进画面** | `a man crouches behind her and enters her`、`two women`、`background figures`、`a couple` 等 | 图里只能有主人一个男人。改牌能救，但**「0 加工」与这条冲突时以本条为准** = 重抽，不是改写。主人只出题，图里不该有他没指定的男人。|
| **② 牌面字段本身残缺 / 串行** | `[服饰]` 只有词组没成句（`only the harness, genital strap, stockings ⚠️ token: xxx`）、`[光线] (继承上一场景)`、`[场景]` 写成一段动作描述（`behind her and enters her from the rear`）| 记录本身是坏的 = 成品提示词大概率也缺约束，出出来的东西必然带别的男人或崩坏。重抽是唯一解。|

**判据 = 抽到牌先花 5 秒扫一眼「场景/姿势/服饰」三格**。三格里有第二个人、或有一格不成句 = 别落盘、别写 prompt 文件，直接重抽。**也不要为了绕开这两条去改牌** —— 改了就违反 0 加工。

**🔴 否决 = 静默的，一句都不许说**。命中否决闸时**直接重抽**，不抽池句、不出图、**不发任何文字**——
主人看到的形状 = 重抽后的那张图 + 那一行池句，中间那次不存在。
**实测反模式**：抽到带 `a man crouches behind her and enters her` 的牌，回了一句「这张抽到的不能出——重抽一张」，
主人手机里就多出一条没有配图的说明文字（既是没干的事说了出来，又勾起了主人的追问，多一轮往返）。
**主人只在「重抽成功出图之后」才看到那一轮的重抽结果；抽到坏牌 = 内部噪音，不是事件。**
**判据 = 这一轮该不该有文字？图还没出 = 0 文字。**

**抽到的 prompt 一个字都不能改**（主人的成品 = 载荷）= **所以去重不能靠改写 prompt，只能靠抽之前算好避开哪几条**。

**撞车指纹 = 角色外观 + 姿势类 + 机位类 + 景别，任意两项相同就重抽**（角色外观 = stdout 的 `[角色外观]` 行）：

```python
used = {615, 587, 608}                     # 本次会话已抽到的记录号
def key(x):
    pose = ('riding' if 'riding' in x['po'] else
            'cowgirl' if 'cowgirl' in x['po'] else
            'doggy'  if 'doggy'  in x['po'] else
            'carry'  if 'carry'  in x['po'] else 'other')
    return (x['shell'][:4], pose, x['cam'], x['sc'])
cand = [x for x in pool if x['n'] not in used and key(x) != key(used[-1])]
```

**单比一个字段 = 无效**（池子大时会反复抽到「同场景不同姿势」，主人看着像换了但骨架没换）。**同一角色连抽允许，但姿势 + 机位必须同时换。**

**🔴 指纹里的「角色外观」= 档案列名（该角色真实装扮）= 0 行为机制 = 0 "保持上一张"。**

**🔴 单条新入库提示词后的下一张也要比机位**：主人连续贴单挑时，每张之间景别/机位不重复是硬要求。

## 3.1.1 🔴 出图道自检门（现写 prompt 时 = 主人点名了具体诉求 / 批次 / 故事配图）

```
□ 表情物理化了吗？（眼皮 + 嘴唇 + 下巴 + 下颌 = 4 项命中 3）= 禁抽象情绪词

□ 承重面跟上一张逐字不同吗？→ 只换场景名和焦段 = 没换骨架

□ 本张字符数 vs 天花板 —— 超了 = 先砍场景/光/材质三层

□ 主人要的对比感 = 要锁其余维度（逐字抄上一张）吗？→ 他没说 = 不锁，我自定
```

**🔴 出图道自检 = 查「写得像不像人 + 诱不诱人 + 撞不撞上一张」，不查「壳保住了没」= 那是已废除的那套。**

**🔴 主人要对比感（同一个位置/同一件衣服/同一个角度再近一点）= 锁其余维度 = 逐字抄上一张 prompt**：脸/服装/场景/光线/称谓 = 原样进新 prompt（连他写的美式俚语和不完整从句都留着）= 换同义词（`pleated skirt` → `fluted skirt`）= 模型认的不是同一件衣服 = 主人要的「同一个」当场散成陌生人。**新 prompt 里必须能逐字搜到那几项**（拿 grep 验证，不靠印象）。

**🔴 长度对齐起点 = 跟起点同一量级，不许翻倍**：起点是主人的 brief 就照他的量级续（实测他的成品 prompt 750-2600 字符）；**续图 prompt 长度 > 起点 1.5 倍 = 必肥**（多出来的全是换汤不换药的场景句和光词）。**但也别比起点还短一大截**（主人的长 brief 常常已经贴着上限，硬压到一半 = 光被砍光）。

**🔴 在起点的措辞层续写，不重开炉灶**：沿用起点里的场景名/道具/光词/称谓，只推进**动作 + 身体状态 + 露出**。**别把主人的一句两行场景扩成五段新编的场景** = 场景一变 = 另开一张。

**🔴 原样重跑同一 prompt 文件 = 违例**：只换 seed 不换内容 = 同一张图重抽一次随机数，主人一眼看穿是同一张。

**🔴 抽卡道拿到的牌当起点写 = 本技能最高频的 FAIL 来源，起点的真实量级必须先量出来**：库里抽到的牌 `成品提示词` 普遍只有 **1000-1100 字符**（一句话描述，不是完整六维 prompt）。按旧习惯压到「天花板 ×0.8」落笔 = **自己给自己限速 = 画面被写瘦 = 白亏**。
**取数门（三步，机械）**：
1. 抽到牌后、**落笔前**先 `count_prompt_chars.py <牌内成品提示词>` 记下**这个数字**——它才是起点，不是天花板；
2. 本张上限 = `min(天花板 × 0.8, 起点 × 1.15)`，两个取小的；
3. **牌里没有的尾段不许自己补** —— 抽卡的成品提示词**通常不含** `Shot on a Canon EOS R5, 35mm, f/2.0…` 这段相机硬件串，补上 = 白送 200-300 字符且对画面零增益。**机械门 = 先 `grep -c 'Shot on' <起点>`，返回 0 = 不许出现 `Shot on`。**

## 3.1.5 🔴 批次内姿势骨架去重（“姿势怎么都一样” = 骨架塌方，不是场景不够）
> 主人原话：“**姿势怎么都一样。**”

**症状**：一批 5 张换着场景换着衣服，但全是“坐/靠 + 一只手把衣摆往上掀”。主人看到的是同一张图换了背景。

**🔴 根因**：批次里每张的**主动作动词**和**手部任务**撞了。§1.1 说“主动作动词不许同词”，但一批里换动词（sitting / leaning）**不够** —— 底模的“坐类”共享同一套下肢骨架（池沿/床沿/台阶/椅子/栏杆），主人眼里的“坐着”是一整类。

**骨架 = 支撑关系 × 手部任务 × 视线落点**。任一要素相同且其余接近 = 算重复。

**一批 5 张硬性门槛（落笔后逐条打勾，不过就重排，0 硬跑）**：
- 支撑关系 ≥3 种（坐 / 趴 / 靠 / 站 / 躺 / 蹲 / 跪 / 四肢着地 / 单腿负重 各算一种）
- 手部任务不许连续两张同类（撩衣摆 / 抓栏杆把杆 / 撑地面 / 抓自己脚踝 / 扒窗框 / 拨头发 各算一类）
- 视线落点 ≥3 种（垂眼看自己膝盖 / 直视镜头 / 回看镜头 / 侧看窗外 / 闭眼仰头）
- 同一张的“掀/撩衣摆”在一批里最多出现 1 次
- 与上一批账本里的骨架和手部任务无重合

**🔴 姿势是骨骼问题不是服装问题**：换场景换衣服不构成换姿势。

- **🔴 姿势库要先查，别自己瞎编**：
- 数据源 = `/vol2/1000/pose_gallery/ai-pose-gallery-zh/data/pose-zh.json`（字段：分类 / 姿势名称 / 角度 / 描述）
- `pose_gallery_search.py` 用中文词常 **0 命中** = 词表不匹配，**不是库空** → 先 `--cats` 看真实分类名，或直接用 Python 过滤「姿势名称」字段
- **🔴 主人抱怨「姿势太单一」= 真根因是 5 张挑了同一分类，不是姿势名不够多。** 按关键词搜出来的一批（如全搜「跪」）= 全是同一套下肢骨架 = 换名字不换骨头。
- **✅ 跨分类抽 5 个 = 机械保证 5 个承重面互不相同**（比逐个想快且不会撞）：


可用分类（按承重面本质不同挑）= 站姿 / 坐姿 / 趴卧 / 蹲姿 / 跪立・四肢着地 / 侧坐・女孩坐 / 后仰・挺背 / 扭身**。**同一分类再细分（站姿里 S 形站、顶胯回眸、背向回望）= 承重面仍是双脚 = 算同一个承重面 = 不能当成两种。**
- **🔴 验收 = 5 张的「分类」五个互不相同**（站/坐/趴/蹲/跪 各一），**不是姿势名称不同**。判据 = 把 5 张的姿态句抽出来，只问一句「她的重量压在哪个部位、压在哪张表面上」= 5 个答案必须两两不同。
- 查到的是中文骨架 → 自己翻成英文动作短语（提示词正文用英文），别把中文塞进 prompt
- **🔴🔴 翻的时候保住骨架名自带的张力，别翻成普通动作**：`猫式（胸贴地翘臀・侧面）` 翻成 `lying on the floor` = 张力抹掉 = 出图平淡；正解 = 翻成动作链 `on all fours with her chest pressed down into the boards and her hips lifted high, her waist dropped into a deep hollow arch`。**判据 = 骨架名里有几个限定词（翘臀 / 压胯 / 大开 / 至肩高 / 上抬），英文句里就得有几个对应细节 = 只翻动词 = 全丢。**

**🔴 裸体姿势也要有动作动词链**（抬 / 压 / 撑 / 扯 / 抓 / 扭）= 否则出来像标本摆拍。

**🔴🔴 门禁 FAIL/WARN = 只修那一个点，不许重写整篇 prompt**

门禁（`check_outfit_lock.py` / `check_prompt_subject.py` / `count_prompt_chars.py`）拦下来时，**修的永远是那一个点**。实测三个例子：

**🔴 补内层时 = 追加在服装套句末尾，不插进套串中间**（保住库里成套的词序 = 底模该给都给）。

### 1.0.1 🔴 局部特写 = 四级递进阶梯（主人点名部位后连点「再近一点 / 还要更近」时照此走）

**触发链** = 主人一句接一句逼近：`看脸` → `再近一点` → `局部特写（嘴唇/锁骨/乳尖…）` → `还要更近` → `颜色不对`。
每一级 = **同场景同光线同一套造型**（照 §1.0 锁死），只动 **镜头距离 + 焦段 + 被摄部位 + 颜色锚点**。

| 级 | 焦段 / 距离 | 画面里有什么 | 出图后**唯一**要报的一句 |
|---|---|---|---|
| 1 半身 | 85mm f/1.8 / 2m | 头 + 肩 + 上半身 | 「近到 XX 厘米」|
| 2 大头 | 85mm f/1.6 / **20cm** | 脸占画面 2/3 | 「近到 XX 厘米」|
| 3 极微距 | **100mm macro f/2.8 / 15~6cm** | 只剩嘴唇 / 锁骨 / 乳晕那一小块 | 「XX 厘米，就这一小块」|
| 4 极致微距 | **200mm macro + 1.4x 增距 / 6cm** | 那一小块占满画面 | 「XX 厘米，XXX 占掉一半多画面」|

**🔴 递进时 0 重画场景** = 场景 / 时段 / 主光源 / 造型锚全部照抄上一张 = 主人能对比 = 才叫「更近」而不是「换一张」。

**🔴 换被摄部位 = 只改 crop 那一段** = 例：脸 → 嘴唇 = 把 `framed from the crown of her head down past her collarbones` 换成
`framed to just the lower half of her face, her lips and chin and the hollow of her throat, nothing else in the picture`。
**只换裁切线 = 主体自然换部位。**

**🔴 4 段铁律**（每级都要写）：① 焦段 ② **距离（厘米）** = 主人最爱听的就是这个数 ③ **裁切线**（漏了 = 还是上一张的构图）④ **颜色锚点**（见 §1.0.2 = 局部特写的成败点）。

**🔴🔴 裁切线只写「cutting across her hips」不够 = 底模会自己往下延伸**（写半身到胯，出图裁到小腿；写齐胸，出图给到腰）。**正解 = 裁切线 + 排除项成对写**：`the frame ends at her hip line, her knees and feet outside the frame` / `framed to just above her waist so that only her upper body stays in the frame` / `her face and collarbones filling the frame, her chin at the upper edge`。**判据 = 裁切线必须同时说清「画到哪儿」和「哪儿不画」；只说前者 = 画幅往下溜。**

**🔴 画幅越窄越要写排除项**：全身图底模默认给全身 = 越靠近特写越容易被拉回去（写嘴唇出成半张脸+环境，写腰胯出到大腿）。**排除项 = 一句抵一个负向词**（正面写法 = 不违反 0 负向词）。

**🔴🔴 但光有裁切线句还是不够 = 真根因 = 我在描述画面外的东西（实测 22 张）**

**🔴 通用形态（跨部位）**：**想让某处浅 / 嫩 / 透 = 直接把那个颜色词写出来 + 写一条反向排除；0 靠「更 X」表达。**「更白」不等于白 = 白。

**机械自查**：写完把颜色词单独抽出来读一遍 —— `grep -o -E 'pale[a-z ]*|pink[a-z ]*|deeper|darker|deep [a-z]+' prompt.txt`
= 出现 `deeper/darker/deep brown` 而你其实要粉 = **改掉再跑**（省一整轮出图开销）。

**🔴 主人说「颜色不对 / 这个黑了 / 应该是粉的」= 不是重画 = 同构图重出 + 只改颜色词** = 机位 / 距离 / 裁切线 / 场景**逐字不动** = 只把颜色段换成正面粉嫩锚点。**别顺手改别的** = 改别的 = 主人没法对比。

## 1.1a 🔴 brief = 一段散文，不许拆成字段表（唯一正文 = yuer-prompt-writer）

> 主人原话：「**出图姿态不协调 想构思一幅画面 才能有提示词**」

**出图前先想圆那个正在发生的瞬间 + 一段散文把层次铺够 = 唯一正文在 `yuer-prompt-writer` §1 落笔前五问 + §15.3 本机锚点表 + 生成链。** 本技能 0 重复存第二套「几段 / 几问」口径（旧「四段叙述」已并入那套散文层次 = 单一真源）。

**🔴 为什么拆成字段表必出畸形**：把姿势 / 机位 / 表情 / 露出拆成互不知情的格子，落笔时每格都在「信息量填满」而不是「这一格怎么从上一格长出来」= 三格各自合法、合起来没一个人摆得出来。**顺着说 = 姿态从画面里长出来；填格子 = 姿态不协调。**

**🔴 brief 不许写成「：」开头的编号字段行**（念着像清单 = 拆格了 = 改回一段话）。**顺序永远是「先一段话想圆 → 再翻成散文」，❌ 反过来（先定字段 → 再填句子）必出拼贴画。**

**🔴 视线 / 朝向 = 底模最先丢的量，也是姿态不协调的头号来源**：

| 规则 | 做法 |
|---|---|
| **视线/朝向单独成句** | `her chin coming up and her eyes finding the lens` 要独立于姿势句，❌ 不许当从句塞进一长串 |
| **给方向，不只给状态** | ❌ `looking up` → ✅ `her face tilted up toward the sky past the bar, her eyes finding the lens` |
| **左右必写** | `her left hand` / `her right hand`，❌ 不说「一只手」——不说清就可能和支撑手画反 |
| **🔴 出图后 0 vision 回读**（主人明文「不要自己看图」）| 视线落在哪、承重在哪、有没有裁掉关键支点 = **主人看图说话**；我 0 自己 vision = 不许拿"我验过了"当交付的一部分 |

**为什么这样写会显著降低撞图**：brief 是先于措辞的决策层，英文 prompt 只是它的翻译。反过来（先写 prompt 再反推 brief）= 措辞会锁死动作，动作再改不动词 = 同一骨架换同义词。**判据 = brief 里「承重面」那一行和上一张逐字不同才算过；只换了场景名和焦段 = 没换骨架。**

**🔴 承重面轮换储备（同一场景内可连排的序列，写的时候直接从这张抄下一行）**：

| 序 | 承重面 | 承重部位 + 支撑面（可直接抄）|
|---|---|---|
| 1 | 坐（池沿/床沿/台沿）| 重量落在坐骨、压在台沿上，双掌后撑 |
| 2 | 水中悬浮 | 重量落在单掌、压在池底/墙面，手臂伸直 |
| 3 | 跪坐 | 重量落在脚跟上，臀部压在脚跟，小腿贴地 |
| 4 | 趴伏 | 重量落在双小臂 + 胸腹，贴在地面上，腿后伸脚尖绷直 |
| 5 | 仰躺 | 重量落在后背 + 臀，压在椅面/床面上，手垂在两侧 |
| 6 | 站立靠面 | 重量落在双脚 + 后背肩胛，压在竖直面上 |
| 7 | 撑高（举臂撑玻璃/墙面）| 重量落在双脚 + 双手掌，压在高处平面上，膝盖软腰塌 |
| 8 | 单脚点地 | 承重脚全踩实，另一脚只有脚尖点地，腰椎塌陷 |
| 9 | 蹲（单膝蹲/深蹲）| 重量落在脚掌 + 一侧膝盖触地，双手可垂可后撑，弯腰时衣摆上翻是天然走光位 |
| 10 | 双级支点坐 | 坐骨压一级台阶、两只脚分别踩前后两级台阶（分腿开在两个高度 = 大腿内侧彻底打开），双手后撑 |
| 11 | 趴伏回眸（半侧脸） | 重量落在双小臂 + 胸腹贴地，腿后伸脚尖绷直，**头回转只让靠镜头那半张脸入画**（写全脸=违成像边界）|
| 12 | 行走 | 承重脚踩实 + 另一脚尖点地，摆臂与身体反向，逆光时轮廓线吃光 |

**🔴 白天户外序列的额外一维 = 「主光源方向」**：同一件衣服在同一段校园/操场/走廊里，主人连着看两张，光源方向不变 = 两张像同一张换了个背景。
**每一张把太阳/灯挪到不同的一侧 + 明写它从哪个方向打来**（`raking across sideways from behind` / `low and directly ahead` / `from behind her left shoulder`）= 真换了光，不是把光词换同义词。

**同一张序列里 1→8 走一遍 = 8 张零重复**，不用重打壳（壳从上一张 prompt 文件里 `grep -F` 抄）。
**反例**：1→2→3 全是坐类，只是池沿/水里/跪 —— 主人在三张图里看到同一个「坐着的女人」。 坐姿是一整类（池沿 / 床沿 / 台阶 / 椅子 / 栏杆）共享同一套下肢骨架，**换场景词不换承重面 = 主人看到同一张图换了背景**，不是换了骨架。同一序列里轮换承重面才是骨架真换：

`坐（髋骨压在池沿或床沿）` → `水中悬浮（单掌撑池底/墙面承重）` → `跪坐（重量落在脚跟上）` → `趴（掌根 + 胫骨双点承重）` → `倚靠（侧胯贴台面 + 单掌后撑）` → `骑坐（跨坐在台面或凳面上）`

**判据 = 她的重量压在身体的哪个部位、压在哪张表面上，这两样有没有变。** 变了 = 骨架换了；只换「坐在哪 / 在哪个房间」= 没换，回去重写。落地时把承重面直接写进姿态句（`weight settled on her heels on the wet tiles` / `her left palm pressed flat on the pool floor behind her to hold herself up`），同时满足本技能第二部分第 4 条「承重必须有支撑物接触面」——**一处写作同时满足去重和不畸形**。

## 1.4 连续出多张 = 先把 N 张全部写完落盘，再逐张跑脚本

串行「出一张看一眼再写下一张」= 你会不自觉复制上一张的句子 = 骨架重复。**批量 = 先全部写完再跑。**

**🔴 落笔前先拿点清单**：连出 3+ 张时，每张落笔前先跑 `count_prompt_chars.py <草稿> --budget` 一次。**🔴 长度 0 阻断（清单只管「有没有漏一个点」；数字从脚本 stdout 读，不凭旧数字写）。**

**🔴 本张上限 = min(天花板 × 0.8, 起点张字符数 × 1.15)** = 两个上界取小；起点 = 主人 brief 或第一张抽到的牌，先 `count_prompt_chars.py <起点>` 数一次记下来（长度 0 阻断 = 上限只报数不拦；按「写得越详细越好」写 = 每个细节是骨架里的一个限定词 = 0 压力 0 返工，别再盯着天花板给自己限速）。

**🔴 接着这张写时，造型 / 光 / 场景从起点文件里 grep 复制，不从记忆重打**：同一件衣服、同一个场景名、同一条光词，重打一次是重新造词（换个同义词）= 违反第 ⑪ 条；重打一次还更长 = 贴顶。**正确做法 = `grep -F 'navy blue pleated skirt' /tmp/起点.txt` 把它原样抄过来**，复制不加字。

**🔴 长度数字 = 从脚本 stdout 读，不许凭技能里的旧数字写；目标 = 当轮上限的 70~80%，不贴顶。**

## 3.1.2 🔴 主人自带 prompt 道 = 原样喂（0 检测 0 改写）+ 「继续」走抽卡道

**触发**：主人贴一整段自己的英文 prompt → 我出图 → 主人说「继续」。

| 步 | 做什么 | 判据 |
|---|---|---|
| ① **原样喂** | 他的 prompt 落盘 → `--raw` 直进工作流 | **0 检测 0 拦截 0 改写 0 翻译 0 拆段** = 他的成品 = 我无权动（`yuer-image/references/主人贴提示词原样喂.md`）|
| ② **「继续」= 抽卡道抽一张新牌** | 抽一张新牌 = 新角色 + 新画面 | **0 拿他的稿当"上一张"往上走** = 0 逐字搬他的脸/服装 = 那是"沿用上一张继续"= 已废除 |

**🔴 「继续」和「撞车重跑」是两件事，别混**：

| 场景 | 怎么做 | 什么时候用 |
|---|---|---|
| 主人说「继续」 | **抽卡道抽一张新牌** | 出图流的推进 |
| 撞车（LLM 输出 ≤ 50 字符）| **一字不改**，同 prompt 重跑 | 只是躲开重复采样 |
| 主人说「再发一次 / 那张没收到 / 补发」| 重发旧图 | 平台没收到 |

**🔴 prompt 文件已经躺在 `/tmp` 里 = 重跑零成本，但不等于该重跑。** 主人自带 prompt 道最顺的下一步就是拿现成文件名再跑一遍（一条命令、不用构思、不占脑子），而这恰好是违例。**「重新写一份」的成本是写的功夫，不是怕写错** —— 把「省事」当成许可，就会在主人点破之前连撞两三次。

**🔴 机械门**：主人说「继续」时，**第一个念头不许是「重跑上一个文件」，得是「这张抽哪张牌」**。

**🔴 主人点破时的正确回应顺序 = 认错一句 → 立刻重写 → 不问要不要**。已被明确说过的规则还挂 = 不要问「要不要我补救」（他已经给了答案），也不要先解释自己为什么这么写（他只要修正）。

**🔴 认错之后不要顺势提议「要不要我把这十几张的回填一遍」**：主人已经明确说了怎么处理（他要么拒绝，要么给一句字指令）。
**判定**：主人问「继续保持…是不是…」/「保持现在，暂时不要动了」这类**一句话指令 = 立刻干，0 反问**；
主人问「你回复的文字不是抽取的？」这类**质问 = 认错 + 说明往后怎么走**，同样不夹带补救提议。补救提议 = 把已经解决的事重新抛回去 = 多一轮往返，且常被当成还在邀功。

#### 🔴🔴 验收 = 主人的活，我 0 自己看图（主人明文）

**主人原话**：「**你现在出图会自己看吗？不要自己看哦，没有必要，不要自己看图**」

**🔴 出图后 0 vision_analyze / 0 自己回读 / 0 数人 / 0 核对裁切 / 0 宣布"我验过了"**：

| 维度 | 谁能验 | 我的动作 |
|---|---|---|
| **肢体数量**（几只手臂 / 几只脚 / 几条腿）| **只有主人** | 我 0 数 = 0 在回复里贴"2臂2手2腿" |

| **整体美感 / 自然度 / 骚不骚** | **只有主人** | 我 0 自评 |
| **「像不像她」/ 造型锚有没有散** | **只有主人** | 我 0 自评 |

**🔴 为什么**：
- 图发出去 = 我的活干完了 = **主人说好就是好**。

## 3.2 「抽卡」= 新角色 + 0 加工

**🔴 出图前先过两条否决闸 —— 命中任一条 = 直接重抽，不改牌、不出图、不解释。**

| 否决闸 | 命中长相 | 为什么 |
|---|---|---|
| **① 牌面含别的男人 / 第二个人进画面** | `a man crouches behind her and enters her`、`two women`、`background figures`、`a couple` 等 | 图里只能有主人一个男人。改牌能救，但**「0 加工」与这条冲突时以本条为准** = 重抽，不是改写。主人只出题，图里不该有他没指定的男人。|
| **② 牌面字段本身残缺 / 串行** | `[服饰]` 只有词组没成句（`only the harness, genital strap, stockings ⚠️ token: xxx`）、`[光线] (继承上一场景)`、`[场景]` 写成一段动作描述（`behind her and enters her from the rear`）| 记录本身是坏的 = 成品提示词大概率也缺约束，出出来的东西必然带别的男人或崩坏。重抽是唯一解。|

**判据 = 抽到牌先花 5 秒扫一眼「场景/姿势/服饰」三格**。三格里有第二个人、或有一格不成句 = 别落盘、别写 prompt 文件，直接重抽。**也不要为了绕开这两条去改牌** —— 改了就违反 0 加工。

**🔴 否决 = 静默的，一句都不许说**。命中否决闸时**直接重抽**，不抽池句、不出图、**不发任何文字**——
主人看到的形状 = 重抽后的那张图 + 那一行池句，中间那次不存在。
**实测反模式**：抽到带 `a man crouches behind her and enters her` 的牌，回了一句「这张抽到的不能出——重抽一张」，
主人手机里就多出一条没有配图的说明文字（既是没干的事说了出来，又勾起了主人的追问，多一轮往返）。
**主人只在「重抽成功出图之后」才看到那一轮的重抽结果；抽到坏牌 = 内部噪音，不是事件。**
**判据 = 这一轮该不该有文字？图还没出 = 0 文字。**

**抽到的 prompt 一个字都不能改**（主人的成品 = 载荷）= **所以去重不能靠改写 prompt，只能靠抽之前算好避开哪几条**。

**撞车指纹 = 角色外观 + 姿势类 + 机位类 + 景别，任意两项相同就重抽**（角色外观 = stdout 的 `[角色外观]` 行）：

## 🔴 主人出镜 = 可完整出镜（0 男性身体限制已废除 = 只禁主人以外的男人）

主人说「需要我出镜 / 我要露脸 / 下一张要你的脸 / 你用隐形人代替我了」= **他该在画框里**。上一张只写一只手 = 当场打脸。

**做法 = 写法阶梯（从省事到最上头）**：外套前襟/肩线（她怀里那块）→ 手 + 手腕 → 侧脸半张 + 下颌线（逆光/虚焦）→ 正脸进画框。**他的脸 0 写五官细节**（只写光线状态 + 一个身体锚）。

**🔴 主人要「出镜」= 从第 3 级起写（前 2 级 = 衣料和手 = 主人仍判「隐形人」）**。判据 = **图里能不能看出这是个人** = 看不出 = 隐形人 = 没出镜。**别停在衣料和手上。**

**🔴 她要正脸 + 他要出镜 = 用镜子同时解掉**：镜头在他肩后（前景是他的肩/后脑）→ 镜中她的正脸 → 他的脸 0 写五官 = 他的视角没被破坏。

**判据 = 主人有没有明确要他出镜。** 没明确要 = 别把脸加进来（凭空给他脸 = 焦点被抢 + 他没要求）；明确要 = 不给 = 隐形人 = 违他指令。**主人明确要完整出镜 = 按 MASTER_FACE + MASTER_PROMPT 全套写 = 脸 / 躯干 / 腿 / 性器官都写。**

## 🔴 落盘命名法（防连撞）

文件名 = `<主题>_<场景角>_<序号>.txt` / 落盘名同源。
**场景名必须进文件名** = 下一张出图前扫一眼最近三个落盘名 = 0 成本知道自己刚出过哪个角落 = 不会连着出两张图书馆。
只写 `library_01 / library_02` = 第二张起只能靠记忆避开 = 必撞。

## 🔴 造型锚点 = 首张就要写全（妆容最常漏）

首张跑外观锁自检时，`妆容` 报 WARN = 当场补一句淡妆锚点（如 `light black eyeliner and a soft pink lip tint with a faint flush on both cheeks`），**不要留到下一张再补**：续图要「逐字继承壳」，首张没写的锚点 = 后续每张都得重新编 = 脸会漂。
`鞋履` WARN 在中景可省（镜头不入画）；全身图必补（`white canvas sneakers flat with white cotton laces`）。

**🔴 锁造型逐字继承的做法 = grep 上一张 prompt 抄句，不重打**（重打 = 换同义词 = 造型锚松 + 每张多 300 字符）。

## 🔴 每张落笔前的四问（机械自检）

1. 承重面跟上一张逐字不同吗？
2. 主动作动词换了吗？
3. 唯一亮部换了吗？（含方向）
4. 表情推到上一张的反极了吗？

四问有一个「否」= 还没换骨架 = 别落笔。

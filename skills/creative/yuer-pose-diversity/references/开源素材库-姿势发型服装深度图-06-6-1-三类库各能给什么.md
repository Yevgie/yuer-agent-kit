### 6.1 三类库各能给什么

| 库 | 能直接进 prompt 的 | 要自己翻的 |
|---|---|---|
| **服装 1407 套** | ✅ **英文关键词串**（`pink knit turtleneck mini dress stockings heels`）= 可整条用 / 可取几件 / 可照思路重搭 = 上装+下装+鞋+配件一次到位 | 中文「服装名称」只是给人看的 |
| **二次元服装 440 套** | ✅ **英文关键词串**（`serafuku, sailor collar, blue sailor collar, red neckerchief, pleated skirt, blue skirt`）| 同上 |
| **发型 1499 条** | ❌ 库只给中文发型名 + 发长 + 分区 | **英文发型词自己翻**（`收腰感短发（长发尾・空气刘海）` → `waist-length bob with long wispy ends and wispy see-through bangs`）|
| **姿势 1439 条 / 287 骨架** | ❌ 库只给中文骨架名 + 分类 + 机位 | **英文动作短语自己翻**（`跪立・上体后仰・双手抱后脑` → `kneeling on all fours with her upper body arched back and both hands clasped behind her head`）|

**🔴 落笔规矩**：服装 = **库串当参考**（①整条用 ②取几件自己加 ③照那搭配思路重搭 = 三种都合法，见下）；发型 + 姿势 = **拿库里的中文骨架当设计依据**，翻成成句动作短语（🔴 **中英都行** = 门禁已双语 = 底模吃中文就写中文，吃英文就写英文 = 别硬翻）。

**🔴🔴 库 = 参考池，不是必须逐字背的咒语**


**三种用法都合法**：

| 用法 | 什么时候 | 怎么写 |
|---|---|---|
| **① 整条直接用** | 这套现成的就是我要的 | `white satin mini dress gloves stockings heels` 整条进 prompt |
| **② 取一部分 + 自己加** | 我只想要这套里的某件，但需要别的搭 | `white satin mini dress` + `black thigh-high stockings` + `自己加的细节` |
| **③ 换风格重搭** | 我要 JK 那个**方向**，不要它那几件 | 查「JK / セクシー / ランジェリー」看这套的**搭法思路**，自己按那思路搭一套新的 |

**🔴 核心 = 库给的是「成套的思路」不是「一成不变的咒语」。** 成套感来自**搭配结构**（主件 + 小件 + 丝袜 + 鞋 + 一个辨识细节），不来自具体是哪几个词。**JK 那套给我的是「水手领 + 领巾 + 百褶裙 + 短袜 + 乐福鞋」这个搭配逻辑 = 我换成任何一套 JK 都成立。**

**🔴 所以丢件（少画了手套/短袜/项链）的正解 = 回头看自己那句词**（= 有没有把某个件漏了），**不是**「回去逐字重抄库里那句」。

**⚠️ 唯一还留着的硬约束 = 「0 自己凭空搭配」**：库存在的目的 = 让我别老写「白衬衫 + 黑短裤」。**从库里拿思路 = 可以；自己瞎拼 = 不行。**

**追加件放哪**：库里没有的件（内层、穿着状态）= **加在整句末尾**，不插进套串中间（插中间容易把原串的词挤掉）。

**🔴🔴 从库里拿服装时 = 补充只能往后「追加」，不许「重写」已有的那部分**（11-04 实测丢件）：我为了补内层门禁，把库串 `white satin mini dress gloves stockings heels` 重写成一句通顺英文 = **重写过程把 `gloves` 挤没了 = 出图没手套**（缎面反光出了，手套没出）。**机制 = 重写 = 重新取舍 = 必然有词被舍弃；追加 = 纯增量 = 一个词都不丢。** 正解 = 库串原样保留 + 库外那件（内层 / 穿着状态）接在句末。**判据 = 出图少某件 = 回查自己那句，发现是「重写」丢的 = 改成「追加」重出。**

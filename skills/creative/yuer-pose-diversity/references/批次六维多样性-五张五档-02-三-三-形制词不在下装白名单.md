## 三·三 · 形制词不在下装白名单 = 加后缀变体，不是改服装设计

**机制 = 门禁只认有限白名单正则**（`skirt|shorts|dress|briefs|panties|pants|trousers|jeans|leggings|skort|bikini|swimsuit|...`）= 真实存在的民族/时代形制词（`qipao` 旗袍 / `ruqun` 唐制襦裙 / `robe` 和服浴袍 / `bath towel` 浴巾 / `hanfu` 汉服 / `cheongsam`）**一个都不在** = 明明画对了却 FAIL。

| 原文 | 命中修法 | 保留原形制词 |
|---|---|---|
| `a dark red silk qipao` | → `a dark red silk qipao dress` | ✅ dress 命中 |
| `a Tang dynasty ruqun gown` | → `... , the long skirt falling to her ankles` | ✅ skirt 命中 |
| 浴袍敞开 / 浴巾滑到胯 | → 追加真实内层 `with a white lace brief visible under the open robe` | ✅ briefs 命中 |
| 吊带 + 外套（近景/特写）| → `over black satin briefs` | ✅ |
| 温泉/草地裸体（想全身裸）| → `a black string bikini pulled down around her thighs` + **换精简版身体段** | ✅ bikini/briefs 命中 |

**🔴 裸体批 = 全身身体段会顶天花板**（完整 NUDE 段 + 场景 + 服装 = 4000+ > 3200）= **给裸体批单独一份精简身体段**（保 5 门锚：腿比躯干长 / 蜜桃臀 / 极细腰 / 大胸紧翘 / 无阴毛，写法同上但每项只留一个最强锚）= 2500 上下能过。

**🔴 build 脚本 emit 支持逐张 body**（job 的第 7 项 = 这一张用哪份身体段；缺省 = 全批共用）= 同一批里只有 1-2 张裸体时 = 别为那 1-2 张把全批身体段换成精简版 = 其余 3 张的胸腰臀锚会掉。

## 三·四 · 无限批次的交接信号 = 「等回复」类词能停下自动续跑

**默认 = 一批 5 张 = 批跑完停 = 等主人说「继续」才跑下一批 = 0 自动开下一批。** 「无限」指的是题材 / 时空 / 风格 / 露度全放开，**不是次数无限**。

| 主人信号 | 行为 |
|---|---|
| 「无限勾引」/「无限制出图」/「1次5张」| 跑一批 5 张 = 发完停 + 报下一批主题（**只报不跑**）+ 等「继续」 |
| 「继续」| 再跑下一批 5 张 |
| 「多样一点」/「无限制时空」| 只改题材维度 = 节奏仍是跑一批停 |
| 「停 / 别跑了 / 先别出」| 立刻停 + **杀掉已在跑的后台批跑进程**（不杀 = 已启动那批跑完 5 张真发飞书 = 主人喊停后手机还在收图）|

**🔴 批后报「下一批主题」= 只报不跑**：正文里写「下一批：×× / ××」不等于已开跑 = 主人不开口 = 那批一张都不出。

**🔴 批内 0 插话 = 5 张一口气跑完**：主人说「依旧 5 张 1 批」= 5 张串行 + 一个后台进程 = 中途 0 逐张汇报 0 停下来等 = 批末一次性报表（批次 / 主题 / 5 张六维表 / 下一批主题）。

**🔴 跑批前必须 `ls /tmp/prompt_<tag>_n*.txt | wc -l` == 5**：build 脚本改过 job key（`n5x` → `n4`）会留孤儿文件 = glob 一起跑 = 多发一张真到主人手机（已实测踩过）。

- □ 六维各维在本批内都覆盖 ≥2 个不同值？
- □ 风格维：主人说「多样」时 = 每张各占一档？
- □ 景别：每张的景别 = 它想讲的东西决定（讲脸→特写 / 讲腰臀→半身 / 讲腿→全身）？**默认半身或特写，全身是少数例外**？
- □ 每张的裁切线 = 「画到哪儿」+「哪儿不画」成对？（只写终点 = 画幅往下溜 = 特写批高发）
- □ 每张提示词里没有「暗示他人在场」的词？（`unaware of the man` / `the customer at the next table` / `the two walkers`）= 命中 = 底模照着画出第二个人
- □ 单人图 = 有「空无一人」的正向句 + 一句正向单人锚？
- □ 每张有唯一的唯一亮部，且**种类**不同？
- □ 与上一批账本（`/path/to/media/tease_used_poses.md`，运行时文件 = 运行时生成，不在技能库内）的骨架 / 手部任务有重合吗？
- □ 每张 prompt 都过了三道门禁（字符数 + 主体 + 外观锁）？
- □ 裸体那 1~2 张用的是精简身体段（job 第 7 项）而不是全批都换？
- □ 民族形制 / 浴巾 / 浴袍 / 吊带那几张的下装词 = 白名单正则能命中？

任一条不过 = 重排，**0 硬跑**。

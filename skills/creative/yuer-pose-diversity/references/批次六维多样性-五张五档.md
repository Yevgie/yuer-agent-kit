# 批次六维多样性 · 一批 N 张的排批决策表

> 唯一职责 = 一批出图时**每张六维都不同**。主规则在 SKILL.md §3.1.5 与 §3.1.6；本文件 = 决策表 + 门禁补法表。
> 触发 = 主人说「多样一点」「景别机位场景服装光线风格都换」「别每张都一个样」。

## 一 · 六维定义（缺一维 = 那维重复）

| 维 | 池子 | 判据 |
|---|---|---|
| ① 景别 | 全身 / 中景（齐膝） / 半身（齐胯） / 近半身（齐腰） / 脸部特写 | 画幅裁切线不同 = 景别不同 |
| ② 机位 | 高度（平视 / 俯 / 仰 / 贴地）+ 焦段（手机 1x / 35 / 50 / 85 / 100 macro）+ 距离 | 三样里至少两样不同 |
| ③ 场景 | 时段 + 地点 + 空间感（户外 / 室内 / 车内 / 天台 / 洞窟）| 场景名不许只换同义词 |
| ④ 服装 | 上装 + 下装 + 面料 + 穿着状态（穿好 / 半脱 / 敞开 / 湿透）| 上装下装各换 |
| ⑤ 光线 | 唯一亮部的**种类**（日光 / 窗光 / 灯箱 / 霓虹 / 火焰 / 月光 / 闪电 / 水下）+ 方向 | 种类换 = 真换；只换形容词 = 没换 |
| ⑥ 风格 | ins 风 / 暗黑电影 / 纪实街拍 / 古风敦煌 / 高时尚大片 / 偷拍介质档 | **主人说「多样」时 = 一批内风格档轮换 = 每张各占一档**（不是全批一个档） |

**🔴 六维全不同 = 批次合格；任一维全批同档 = 那维是这批的短板 = 重排那一维。**
**🔴 风格维默认不轮换**（默认全批一个档 = 保持这批图的统一感）= **只有主人说「多样一点 / 风格也换」才把风格维打开** = 打开后 = 一批 N 张各占一档 = 5 张 = 5 个档。

## 二 · 5 张一批的标准排布（照抄即用）

| 张 | 景别 | 机位 | 场景 | 服装 | 光线（唯一亮部）| 风格档 |
|---|---|---|---|---|---|---|
| 1 | 全身 | 手机 1x / 4m / 胸高 | 户外白天店门口 | 短袖 + 短裤 | 过曝白天 | **ins 风** |
| 2 | 中景（齐膝）| 35mm / 2.5m / 略仰 | 屋顶 / 天台 | 湿透衬衫 + 短裙 | 云缝里一块硬光 | **暗黑电影** |
| 3 | 半身（齐胯）| 35mm / 2m / 平视 | 街边店门口 | 衬衫 + 白裙 | 门口平光 | **纪实街拍** |
| 4 | 全身 | 50mm / 4m / 平视 | 古建 / 洞窟 | 古制襦裙 | 洞口天光 + 一盏油灯 | **古风敦煌** |
| 5 | 脸部特写 | 85mm / 1m / 平视 | 影棚灰背景 | 吊带 + 金链 | 单灯箱硬光 | **高时尚大片** |


**🔴 风格档 = 五个参数一起换**（光基调 + 情绪 + 景别 + 相机前缀 + 调色尾参）= 只换相机前缀 = 没换风格（见 `yuer-image-style-preset` §一.2）。
**🔴 穿越题材照样轮换风格档**：敦煌那张走古风档，但唯一亮部必须是那个时代的真实光源（窟口天光 / 油灯）= 不靠压暗造时代感。

## 三 · 门禁 FAIL 的补法表（外观锁「下装」门）

`check_outfit_lock.py` 的下装正则 = `skirt|shorts|dress|briefs|panties|pants|trousers|jeans|leggings|skort`。

| 服装写法 | 命中 | 补法 |
|---|---|---|
| 浴袍 / 浴巾 / 和服 / 唐制襦裙（ruqun）/ 长袍 | ❌ 不命中 | ① 服装句自然带一个白名单下装词（`an oversized white cotton dress shirt` / `a long skirt falling to her ankles`）；② 或写真实内层（`with a white lace brief visible under the open robe`）；③ 或写画幅外丢弃的下装（`a discarded light blue denim skirt crumpled on the chair behind her`）|
| 吊带 + 外套（近景 / 特写）| ❌ | 同上 ②：`over black satin briefs` |
| 连衣裙 / 衬衫当裙子 / 牛仔短裤 / 短裙 + 丝袜 | ✅ | 不用补 |

**🔴 补法必须写成「不在她身上 / 不在画幅内」或「真实存在的内层」** = 补成她穿好 = 把遮着露出改成穿好衣服 = 白改。
**🔴 写法 = `a discarded pair of <颜色> <下装>`**，下装只从正则命中的词里选（`jeans / skirt / shorts / dress / trousers`）；**`jacket` / `shirt` / `cloth` / `robe` / `towel` 都不命中 = 写了照样 FAIL**（实测连踩多次）。**判据 = 写完必跑 `check_outfit_lock.py` 确认 rc=0 再出图。**

**🔴 这坑专打特写 / 半身批**：画幅里本来就没有下装 = 门禁必 FAIL。**补法 = 画幅外实物**：下装放在她身边的地上、椅背或台面上，**别写成她穿着**（那会改变该张的暴露度）。

## 三·三 · 形制词不在下装白名单 = 加后缀变体，不是改服装设计

**机制 = 门禁只认有限白名单正则**（`skirt|shorts|dress|briefs|panties|pants|trousers|jeans|leggings|skort|bikini|swimsuit|...`）= 真实存在的民族/时代形制词（`qipao` 旗袍 / `ruqun` 唐制襦裙 / `robe` 和服浴袍 / `bath towel` 浴巾 / `hanfu` 汉服 / `cheongsam`）**一个都不在** = 明明画对了却 FAIL。

| 原文 | 命中修法 | 保留原形制词 |
|---|---|---|
| `a dark red silk qipao` | → `a dark red silk qipao dress` | ✅ dress 命中 |
| `a Tang dynasty ruqun gown` | → `... , the long skirt falling to her ankles` | ✅ skirt 命中 |
| 浴袍敞开 / 浴巾滑到胯 | → 追加真实内层 `with a white lace brief visible under the open robe` | ✅ briefs 命中 |
| 吊带 + 外套（近景/特写）| → `over black satin briefs` | ✅ |
| 温泉/草地裸体（想全身裸）| → `a black string bikini pulled down around her thighs` + **换精简版身体段** | ✅ bikini/briefs 命中 |

**🔴 裸体批 = 全身身体段会顶天花板**（完整 NUDE 段 + 场景 + 服装 = 4000+ > 3200）= **给裸体批单独一份精简身体段**（保 5 门锚：腿比躯干长 / 蜜桃臀 / 极细腰 / 大胸紧翘 / 无阴毛，写法同上但每项只留一个最强锚）= 2500 上下能过。

**🔴 build 脚本 emit 支持逐张 body**（job 的第 7 项 = 这一张用哪份身体段；缺省 = 全批共用）= 同一批里只有 1-2 张裸体时 = 别为那 1-2 张把全批身体段换成精简版 = 其余 3 张的胸腰臀锚会掉。

## 三·四 · 无限批次的交接信号 = 「等回复」类词能停下自动续跑

**默认 = 一批 5 张 = 批跑完停 = 等主人说「继续」才跑下一批 = 0 自动开下一批。** 「无限」指的是题材 / 时空 / 风格 / 露度全放开，**不是次数无限**。

| 主人信号 | 行为 |
|---|---|
| 「无限勾引」/「无限制出图」/「1次5张」| 跑一批 5 张 = 发完停 + 报下一批主题（**只报不跑**）+ 等「继续」 |
| 「继续」| 再跑下一批 5 张 |
| 「多样一点」/「无限制时空」| 只改题材维度 = 节奏仍是跑一批停 |
| 「停 / 别跑了 / 先别出」| 立刻停 + **杀掉已在跑的后台批跑进程**（不杀 = 已启动那批跑完 5 张真发飞书 = 主人喊停后手机还在收图）|

**🔴 批后报「下一批主题」= 只报不跑**：正文里写「下一批：×× / ××」不等于已开跑 = 主人不开口 = 那批一张都不出。

**🔴 批内 0 插话 = 5 张一口气跑完**：主人说「依旧 5 张 1 批」= 5 张串行 + 一个后台进程 = 中途 0 逐张汇报 0 停下来等 = 批末一次性报表（批次 / 主题 / 5 张六维表 / 下一批主题）。

**🔴 跑批前必须 `ls /tmp/prompt_<tag>_n*.txt | wc -l` == 5**：build 脚本改过 job key（`n5x` → `n4`）会留孤儿文件 = glob 一起跑 = 多发一张真到主人手机（已实测踩过）。

- □ 六维各维在本批内都覆盖 ≥2 个不同值？
- □ 风格维：主人说「多样」时 = 每张各占一档？
- □ 景别：每张的景别 = 它想讲的东西决定（讲脸→特写 / 讲腰臀→半身 / 讲腿→全身）？**默认半身或特写，全身是少数例外**？
- □ 每张的裁切线 = 「画到哪儿」+「哪儿不画」成对？（只写终点 = 画幅往下溜 = 特写批高发）
- □ 每张提示词里没有「暗示他人在场」的词？（`unaware of the man` / `the customer at the next table` / `the two walkers`）= 命中 = 底模照着画出第二个人
- □ 单人图 = 有「空无一人」的正向句 + 一句正向单人锚？
- □ 每张有唯一的唯一亮部，且**种类**不同？
- □ 与上一批账本（`/path/to/media/tease_used_poses.md`，运行时文件 = 运行时生成，不在技能库内）的骨架 / 手部任务有重合吗？
- □ 每张 prompt 都过了三道门禁（字符数 + 主体 + 外观锁）？
- □ 裸体那 1~2 张用的是精简身体段（job 第 7 项）而不是全批都换？
- □ 民族形制 / 浴巾 / 浴袍 / 吊带那几张的下装词 = 白名单正则能命中？

任一条不过 = 重排，**0 硬跑**。

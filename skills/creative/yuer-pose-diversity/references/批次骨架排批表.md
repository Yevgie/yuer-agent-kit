# 批次骨架排批表（姿势去重）

> 唯一职责 = 排一批图时**不重样**。症状：主人一句“姿势怎么都一样”。
> 主规则在 SKILL.md §3.1.5；本文件 = 查表用的池子 + 账本格式。

## 一 · 骨架三要素

骨架 = **支撑关系 × 手部任务 × 视线落点**。三要素都接近 = 同一姿势。

### 支撑关系池（一批至少用 3 种）

| 类 | 具体 |
|---|---|
| 坐 | 椅上侧坐 / 坐姿双手后撑 / 坐地 / 盘腿坐 / 坐凳前倾 |
| 立 | 单腿站立负重 / 双腿开立 / 靠墙站 / 站姿脚踝相扣 |
| 趴 | 四肢着地（猫式）/ 趴桌面 / 趴躺椅 / 趴车头 |
| 躺 | 躺椅摊开 / 侧卧 / 仰卧屈膝 / 仰卧摊平 |
| 悬 | 单腿高抬握踝 / 抬腿踩墙 / 桥式抬胯 / 站立劈叉 |
| 复合 | 跪姿扭腰 / 蹲撑双膝开 / 靠柱单手扒窗 |

### 手部任务池（不许连续两张同类）

撑地面 / 抓栏杆或把杆 / 撩或扯衣摆 / 抓自己脚踝 / 扒窗框 / 拨头发 / 托脸 / 抓身后物件 / 双手插进头发 / 压住身下布料

### 视线落点池（至少 3 种）

垂眼看自己膝盖 / 直视镜头 / 回头看镜头 / 侧看窗外 / 闭眼仰头 / 看自己的手 / 越过肩看后方

## 二 · 排批检查表

写完 N 条 prompt 后逐条打勾：

- 支撑关系 ≥3 种？
- 手部任务无连续两张同类？
- 视线落点 ≥3 种？
- “掀/撩衣摆”在一批里最多 1 次？
- 与上一批账本里的骨架 / 手部任务有重合吗？有就换。

任一条不过 = 重排，**0 硬跑**。

## 三 · 姿势库取用

- 数据 = `/vol2/1000/pose_gallery/ai-pose-gallery-zh/data/pose-zh.json`
  字段：分类 / 姿势名称 / 角度 / 描述
- `pose_gallery_search.py` 用中文词容易 **0 命中**（词表不匹配，**不是库空**）→ 先 `--cats` 看真实分类名，或直接 Python 过滤 `姿势名称`
- 查到的是中文骨架 → 自己翻成英文动作短语（**提示词正文用英文**），别把中文塞进 prompt
- 线稿源 = 同目录 `img/`（`full_sexy_` / `full_single_` / `upper80v2_` / `pair60_`）= 走 Qwen 编辑道当 image_2 参考时用

## 五 · 落地写法

- 裸体姿势也要保留动作动词链（抬 / 压 / 撑 / 扯 / 抓 / 扭）= 否则出来像标本摆拍
- 换场景换衣服 **不构成** 换姿势 = 姿势是骨骼问题
- 批次内景别 / 唯一亮部 / 场景也要轮换（见 `yuer-pose-diversity` §3.1 第 ⑪ 条与唯一亮部一条）

## 一、三道门的职责划分（0 越界）

| 脚本 | 查什么 | 不查什么 |
|---|---|---|

## 二、`check_outfit_lock.py` 的景别分级（核心，也是最容易改坏的一块）

### 2.1 判定链（顺序 = 可靠性从高到低）

```
BOUND_NEG（否定式画外声明）→ BOUND_HEAD → BOUND_CHEST → BOUND_WAIST → BOUND_TABLE → BOUND_HIP/THIGH
   ↓ 全不命中
SHOT_CLOSEUP / SHOT_HALF / SHOT_FULL（景别术语词 = 不可靠兜底）
```

**🔴 `shot_source` 只有两个值**：
- `bound` = **靠边界句判出来的** = 可靠 = 门禁敢拿它当依据
- `term` = **靠术语词判出来的** = 底模根本不吃这些词 = **只是我自己写的字** = 不许拿它当拦人依据

### 2.2 🔴 三条硬规则（改脚本时 0 违反）

**① 画外描述检测只在 `shot_source == "bound"` 时生效。**

理由：术语词（`medium shot` / `waist-up`）底模实测**完全无效** = 那些历史真稿虽然写了 `medium shot`，实际是全身稿 = 拿术语词判出来的景别去拦「画外」= **误杀 12 张历史真稿**。边界句才是真信号。

**② 判定段和展示段必须用同一套分级。**

**🔴 踩过的坑**：判定逻辑早改成按景别分级（特写/半身不查下装），但**打印段还按「正则有没有命中」无条件打 FAIL** = 胸像稿明明能出图，屏幕显示 `FAIL 下装` = **比误杀更坏 = 骗主人 + 误导我自己去改画面**。

```python
def _shown(name, pat, why):
    if re.search(pat, low):
        return "OK  "
    g = _grade(name, why)          # 判定段同一个函数
    if g is None:
        return "跳过"                # 该景别画不到 = 不查
    return "FAIL" if g[0] == "fail" else "WARN"
```

**③ 景别分级只覆盖「画得到 / 画不到」，不覆盖「要不要好看」。**

| 景别（bound 判定）| 下装 | 鞋履 | 穿着方式/内层 |
|---|---|---|---|
| 特写（肩/胸）| 跳过 | 跳过 | 跳过 |
| 半身（腰/桌沿）| 跳过 | 跳过 | 跳过 |
| 全身 | FAIL | FAIL | WARN |

**画幅外的东西本来就不该查 = 查它 = 逼我写画外的东西 = 底模照着画 = 裁切线必然滑到大腿。**

## 三、`BOUND_*` 正则必须同时认「单数 / 复数 / 双人」

**🔴 踩过的坑**：边界句正则只写第三人称单数（`frame enclosing her head and her neck`）= 双人稿写 `the frame enclosing the two heads and the necks and the shoulders of both women` = **完全不匹配** = 落到术语兜底 = 判不出景别 = 门禁反过来逼我写画外的内裤。

现役要求：
- `BOUND_HEAD` = 认 `her head` / `the two heads` / `both` / `two`
- `BOUND_CHEST` = 额外认 `the frame enclosing the two heads and the necks and the shoulders of both women`
- `BOUND_WAIST` = 额外认 `their waistlines` / `both waistlines`
- `BOUND_TABLE` = 认裁切线落在**物件**上（`the bottom edge of the frame resting on the near edge of the marble tabletop`）= 桌面沿 = 桌面以下不入画 = 半身档

**🔴 判据 = 改任何 `BOUND_*` = 先拿至少一份双人稿 + 一份单人稿各跑一遍 = 两份的景别都要判对。**

## 四、🔴 画外描述检测 = 必须先剥掉否定语境

**🔴 踩过的坑**：检测画外部位时把**否定句**里的部位词也当成「在描述画外」= `no legs are visible` / `the space below the tabletop is cropped out` / `nothing below X is in view` = 这些是在说「不画」= 误杀 = **逼我不敢写边界句** = 景别永远学不会。

现役做法 = 检测前先 `NEG_CLEAN.sub(" ", low)` 抹掉否定语境，再在抹过的文本上匹配部位词。

**🔴 判据 = 画外检测的第一问 = 「这个词是在说她身上有，还是在说画面里没有？」** 是后者 = 不算画外描述。

---

## 四之二、🔴 景别档不同 = 画外检测拦的东西不同

**踩过的坑**：画外检测一律拦部位词（腿 / 臀 / 大腿）= **特写稿被误杀**。特写的主体**可能就是一条腿**（抬腿踩墙那张 = 主体就是腿）= 部位词是**画内** = 不该拦。全身档才该拦部位词（那里部位词必然在画外）。

现役分级：

| 景别（bound 判定）| 画外检测拦什么 |
|---|---|
| **特写** | 只拦**「穿着式」画外物件**（`wearing black lace briefs` / `穿黑色丝袜`）= 部位词不拦 |
| **半身** | 只拦穿着式物件 + 鞋履 |
| **全身** | 部位词 + 穿着式物件全拦 |

**🔴 穿着式的判据 = 必须有动词或介词**（`wearing` / `dressed in` / `穿`）= 只有 `a pair of black lace briefs on the bed` 这种「散落道具」= **画内道具 = 不拦**（散落的内裤是道具，穿在身上的内裤是画外穿着）。

## 四之三、🔴 裸体 / 露点稿 = 写不出景别术语 = 必须给门禁一条判据

**踩过的坑**：特写画的是骚穴 / 臀 / 胸，这种稿子**不可能写 `medium shot`**（那反而会把画外的部分召进来）= 门禁落不到景别术语兜底 = 判不出景别 = 门禁反过来逼我写画外的内裤/丝袜 = 破坏画面。

现役 = `EXPLICIT_BODY` 分支：出现露点词（`pubic mound` / `inner labia` / `nipple` / `areola` / `buttocks` / `bare hips` / `nude`）+ **没有「穿着式」画外实体** → 判成特写档（`shot_source = "bound"`）。

**🔴 排除条件只看「穿着式」**（`wearing` / `dressed in` / `穿`），不看散落道具 = 写 `a discarded black lace thong on the duvet` 的裸体臀特写稿不该被排除。

## 四之四、🔴 改脚本时的 Python 坑：`re.search` 参数顺序

**踩过的坑**：加新正则时写成 `re.search(pattern, re.I)` = 只给了两个参数 = `re.I` 落到 string 位 = 抛 `TypeError: expected string or bytes-like object, got 'RegexFlag'` = **整个脚本当场崩**（不是那个正则写错 = 是调用写错）。

**正确 = `re.search(pattern, string, flags)`** = 三个参数，flags 在最后。

**🔴 判据 = 改完门禁脚本 = 先 `python3 -m py_compile <script>` 再跑** = 语法检查抓不到参数个数错 = **必须真跑一次真实稿件**才算数（`python3 -m py_compile` 只查语法，不查运行时类型）。

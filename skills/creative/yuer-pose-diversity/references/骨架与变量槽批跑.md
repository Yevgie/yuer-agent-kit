# 骨架 + 变量槽：批量出图不撞车

> 用于「一次出 N 张同主题」「抽卡」「主人发一份成品 prompt 清单」三类活。
> 机制：N 张长得像同一个人，但**不是同一张图** = 骨架不变、槽位换值。

## 骨架拆法

把任意一条成品 prompt 拆成两层：

**固定项（跳全部 N 张逐字不变）**

- 主体身份：年龄 / 体型 / 脸模交给 LoRA
- 机位类（从 8 大类里定 1-2 个）
- 服装体系（同一套世界观：敦煌飞天 / 唐 / 宋 / 赛博 / 制服 …）
- 场景大类

**变量槽（每张换一个值）**

| 槽 | 例子 |
|---|---|
| 姿态 | 跪坐 / 仰躺 / 跨坐 / 侧躺 / 蹲 / 趴伏 / 后入 / 弯腰俯身 |
| 机位 | 齐膝仰拍 / 站姿俯拍 / 齐腰平推 / 侧四分之三 / 后四分之三 |
| 发饰 | 金凤钗 / 银竹梳 / 玳瑁簪 / 编发盘髻 |
| 布景 | 雕花月门 / 竹林屏风 / 杏枝 / 铜器 |
| 曝光档 | 半遮 / 轮廓 / 部分露 / 大部分露 / 全露 |

**N 张 = 槽位换 N 次。** 变量槽单独换一种 = 只换一维 = 视觉上重复（同骨架近义词）。

## 槽位取值的写法

**只锚结构头词，绝不枚举取值清单。**

```
❌ rf'(Dunhuang|Tang|Song|Ming|Wei-Jin) costume'      # 漏新词 = 每次遇到没列的都丢
✅ rf'[A-Za-z\-]+ (?:costume|ensemble|Hanfu)'          # 头词封闭 = 0 漏
```

**机制**：取值词表是开放集合（颜色词、朝代名、布景名可以无限扩展），枚举必然漏；头词（`costume` / `updo` / `view` / `stage`）是封闭集合，锚它就够。

## 槽位内部的差异量

同一个槽换值时，**写法本身也要换骨架**，不能只换名词：

- 姿态：换**主动作动词**（standing → leaning → crouching → lying），不写同义姿态名
- 机位：写全「机位高度 + 角度 + 距离」，不是只写 `low angle`
- 发饰：材质 + 形状 + 数量三件齐（金/竹/玳瑁 + 钗/梳/簪 + 双/三/散）

## 曝光档位阶梯

| 档 | 形态 | 写法 |
|---|---|---|
| ① 半遮 | 衣物掀起露腰 | `T-shirt lifted showing midriff` |
| ② 轮廓 | 内裤可见轮廓 | `lace panties visible outline` |
| ③ 部分露 | 单侧裸露 | `one breast exposed` |
| ④ 大部分露 | 双乳露出但手挡 | `both breasts exposed, hands covering nipples` |
| ⑤ 全露 | 完全可见 | `bare breasts and nipples fully visible` |

**走光 > 脱光**：主体表情 = 惊 + 慌 + 一闪而过，不是从容展示。

## 改造外部成品 prompt 的顺序

主人发来一份别人的成品 prompt 清单时：

1. **拆槽** —— 按上表把每条拆成固定项 + 变量槽
2. **逐槽过技能** —— 表情抽象词 → 物理化（`yuer-prompt-writer` §5 表情）；抽象姿势名词 → 6 物理量（§5）；缺失的外观锁项 → 补齐（§10）
3. **补收尾** —— `no text, no watermark, no logo`
4. **剥中英混写** —— 原文里混的中文句整段去掉，不留半句
5. **字符校验** —— `count_prompt_chars.py` 走门禁

**原文缺陷照原样进库 + Note 写明待加工项**，不要替它洗（字段值是载荷，见 `record-library-audit` 铁律 14）。**入库成功 ≠ 能直接出图**，两件事分开报。

# 批次点表模板（一个点 = 一句话 = 一次）

> 用途 = 批量出图前，先列 N 张的点表，再逐张落笔。**不列点表 = 直接写句子 = 同一个点写两遍 = 多手畸形。**
> 机制真源 = `yuer-prompt-writer` §2 点表 + §10 判断第 2 条 / §1.3（点表 + CLIP「重复 = 多画一个」）。

## 一 · 单张点表（每张 9 个点 = 9 句）

```
1. 她是谁 + 情绪      → a striking young Asian woman, 20 years old, upper eyelids half-lowered with lips slightly parted and chin tilted up
2. 姿势 + 承重 + 场景  → <动词 + 承重面 + 支撑物接触面 + 地点>
3. 服装整套           → wearing <库串原样> + <库外那件接句末>
4. 发型 + 妆容        → her <发色> hair worn in a <发型>, light makeup with black eyeliner and soft pink lipstick
5. 露馅（独立点）      → <衣物现在什么状态 = 不是重复提衣物名>
6. 光（唯一光源）      → <一个光源 + 落点>
7. 相机 + 景别        → <medium/full-length shot, 85mm lens at f/1.8 shot from N meters away>
8. 景深 + 调色        → shallow depth of field, <调色>
9. 收尾（画质1+人体1）→ high resolution and sharp focus, anatomically correct human body
```

**🔴 点 9 = 画质 1 个词组 + 人体正确 1 个词组** = 不重复写点。拖 7 个解剖词 = 出三只手（`yuer-prompt-writer` §0 底线 3 + §10 判断第 2 条）

**🔴 点 3 = 库串原样 + 库外件接句末** = 不许重写库串（重写会丢词）。三种用法（整条用 / 取几件加 / 照思路重搭）都合法 = 唯一硬约束 = 0 自己瞎拼。


**🔴 点 2 写在代码里 = 直接落成最终字符串。** 别存半成品再拼 = 中途看不出漏没漏。（🔴 **中文不查** = 11-04 主人钦定「门禁不需要查中英文，中文英文都行」= 动作短语用中文写也能过门禁 = 底模吃中文就写中文。）

## 二 · 批量点表（N 张 × 6 个必变维）

| # | 必变维 | N 张之间必须变 |
|---|---|---|
| 1 | 姿势 + 承重面 | N 种不同支撑关系（坐/跪/趴/站/倚/悬）|
| 2 | 场景 | N 个不同地点 |
| 3 | 服装套 | N 套不同（库里不同条目）|
| 4 | 发型 | N 种不同 |
| 5 | 唯一亮部 | N 种不同光源 + 不同方向 |
| 6 | 景别 | 混全身/半身/近半身 |

**🔴 不变的点** = 人物身份 + 表情语法 + 人体正确词（只有一套）+ 收尾画质词 = **每张都写，但每张只写一次**（不是 N 张加起来算重复）。

**🔴 两张点集 ≥4 项相同 = 那两张撞了 = 重排那一维。**

## 三 · 实测基线（可直接复用）

每张 9 个点 / 16~18 句 / 867~984 字符 = 5/5 过门禁 = 5 张零多肢。

## 四 · 落笔后自检（不是新门禁 = 点表工序的收尾确认）

| 问 | 抓什么 |
|---|---|
| 任意两句画的东西重了？ | 同义堆料 |
| 手/脚/身体出现在两句？ | 多手畸形根因 |
| 解剖正确词 >1 词组？ | 7 个 → 1 个 |
| 同一件衣物出现两句？ | dress × 3 |

## 五 · 批量落地流程

```
① 查库（pose / hair / costume）→ ② 列 N 张点表 + 对比点集 → ③ 逐张写 prompt 文件
→ ④ creative/yuer-image/scripts/batch_gate_check.py <tag> 一次跑完三道门禁 → ⑤ 只修被拦的那一个点 → ⑥ 出图
```

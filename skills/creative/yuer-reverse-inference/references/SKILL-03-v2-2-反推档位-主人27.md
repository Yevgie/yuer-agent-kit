**正解 = 第一版直接交（长度 0 阻断）：**

| 步 | 做法 |
|---|---|
| ① 翻之前先估 | 中文散文 → 英文约 1.6~2.2 倍字符 = 中文 700 字 → 英文 ~1200~1500 = **大概率超** |
| ② 一个点一句 = 一个维度一句 | 场景/机位/主体/服饰/光/氛围各 1 句 = 不分句堆料 |
| ③ 同一物件只在一个点里出现 | `tile` / `light` / `skirt` 各提 2 次 = 不同指代可接受；提 3~4 次 = 门禁的「重复词」检查会拦 = 先收敛 |
| ④ 背景与尾参先砍，0 砍构图和光 | 预算表自己写着这条 = 构图和光是 6 件套的核心 |

**🔴 结构段 5/5 里最容易漏的那一条 = 「场景层次」**：反推输出里**没有** `foreground / midground / far background` 三词 = 门禁结构段少一段 = exit 1。正解 = **自己补一句明写三层**（前景/中景/远景各一词）= 既过正则 = 又真构图。

**🔴 反推常给出广角贴地机位**（如 16mm 贴地仰拍）= 触发「人体广角近距」拦截。正解 = **照原焦段写 + 把机位高度写成豁免措辞**（`on the floor looking up` / `on the ground looking up` / `worm's eye angle`）= **不要为了绕门禁改焦段** = 改了就跟原图机位对不上。门禁豁免机制在 `count_prompt_chars.py` 里（宽焦段 + 明确贴地措辞 = 放行）。

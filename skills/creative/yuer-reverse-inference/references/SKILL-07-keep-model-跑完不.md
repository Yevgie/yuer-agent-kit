# --keep-model = 跑完不卸载（⚠️ 主人自己后面还要跑图时慎用）
**🔴 主人要「看看这张图讲了什么」时，本地 qwen 就是答案，不要为此去碰 vision**。本地 qwen 出的 8 段（Scene/Camera Angle/Pose/Wardrobe/Lighting/Mood/Character Shell/Seductive Pose Note）**已经比 vision 的自由描述更贴合入库需要**——它是结构化的、能直接填参考库 6 件套。vision 唯一优势是「自由问答」，而 8 段结构化输出不占这个优势。

**🔴 agnes 云端是默认主链路**：本地 qwen 两档 = **兜底**（agnes 挂了 / 要可复现输出时）。本地 qwen 需占显存、吃 ComfyUI 节点在线 = 不主动抢显存。

**🔴 但「只作兜底」不是因为慢，是历史包袱 —— 评估 NSFW 批量入库时重新算这笔账**：

上面那句「~21s/张所以只做兜底」的推理已经过时。当前实测对照（同一台机器、同一批 NSFW 图）：
| 维度 | agnes-3.0-flash | 本地 qwen（9B 破限 Q8_0） |
|---|---|---|
| 单张耗时 | 40-48s（含闸门重跑时更长）| 30-36s |
| 安全过滤 | **会拦**（实测一个批次里两张被拒，换 brief 才过）| **不拦**，Uncensored |
| 输出汉字 | 会整段吐中文（需枚举→重跑）| **实测 0 汉字**（工作流 system prompt 锁死 8 段英文标题）|
| 排队 | 外部 API | 占服务端显存（9B ~9.5G），会拖慢并发出图 |
| 成本 | 免费额度 | 免费 |

**所以结论不是「本地更快所以当主力」**（它要抢显存、依赖 ComfyUI 在线，不是无脑替换），
而是：**NSFW 批量反推时，本地 qwen 的真实优势 = 不会被安全过滤拦 + 输出天然全英文**，
这两点比那几秒更值钱。**判据 = 让 agnes 先跑，命中率低的批次（尤其 NSFW）再评估切本地**，
而不是反过来。切之前先用 `peek` 拿真实命中率，别凭印象拍。

**🔴🔴 但上表已被一次完整 A/B 实测推翻 = 以 `references/反推后端选型与量化基准.md` 为准**：
同一批图 × 同一张图逐后端实测（服务端 = RTX 5060 Ti 16GB）：
**agnes 6~21s / 3.5-9B Q8_0 21~36s / 3.5-4B Q6 12~15s**（27B IQ3_XS 27~33s、IQ2_M 42s = **11-04 已删除**）。
上表的「agnes 40-48s」是含闸门重跑的累计值，不是单张耗时。

**🔴 质量差异 = 抓到的细节数，不是字符数**（实测）：
- **agnes 抓到、qwen 全漏**：嘴里含着吸管 / 珍珠美甲 / 吊带里的内搭抹胸 /
  「左手垂放**不可见**」/ **色温**（agnes 写 3200K·2700K·3000K，qwen 一律瞎写 4500K）。
- **qwen 抓到、agnes 没有**：构图维度（机位/光位/材质拆得更细）= 9B `local` 档带「裁切线确切位置」那一句 = 构图复刻需求改由它承担。
- **NSFW 上尺度差最狠**：agnes 直写「臀部与阴道区域完全暴露……想象阴茎从后方顶入」，
  27B IQ3 英文版只剩「exposed lower back acts as a visual anchor for the hand」
  = 同一句被翻译成无害版 = **要尺度走中文下指令**（见 `yuer-agnes-reverse` 的「指令语言是过滤器开关」）。
- **所有 qwen 都把「坐着」写成 `standing`** = 模型空间幻觉 = **换量化修不了**。

**🔴🔴 上表结论已被上游提示词变量推翻 = 「本地千问很烂」八成是提示词松，不是模型笨**：
旧提示词**只在末段给了字数要求**，前 7 段无下限 = 9B 一句话交差（实测 1117 字符）
= 被误判成「Q8 掉质量」。换成**逐段带字数下限**的紧约束提示词后重测：
**9B Q8_0 = 1801 字符 / 8 段齐 / 细节直追 agnes**（还抓到 agnes 全漏的
「上衣滑落至腰部露出腹部」「裁切线切在膝上和大腿中部」）；
27B IQ3_XS = 5976 字符 / 8 段齐（但 57s）；4B Q6 反而掉到 888 字符（太小，扛不住长要求）。
**铁律 = 判「本地模型好坏」之前，先拿 `templates/8段反推提示词-紧约束版-中文.txt` 跑一遍再下结论。**
**给字数下限时第 7 段（关键词串）必须豁免** = 否则无限重复关键词（实测单段 13464 字符 + 段落数只剩 7 + 156s）。

**🔴 选型结论 = 11-04 主人钦定（27B 已删）**：
**默认走 agnes**（尺度直白 + 中文 + 快 + 零删减）；本地**只留 9B `local` 和 4B `fast` 两档兜底**。
原「要 1:1 复刻构图 = 27B IQ3_XS 英文」这条路**已随 27B 删除**，构图细拆这条需求改由 9B `local` 档承担（它带「裁切线确切位置」那一句）。
**旧默认档 IQ2_M 性价比最差**（42s 最慢却比 IQ3_XS 差一档）→ **已随 27B 一并删除**。

**🔴 量化选型三个反直觉点**（实测）：
① **IQ3_XS 比 IQ2_M 更快** = 提速的是 **Flash Attention** 不是量化（两个开关要一起调，
否则会把提速误记成量化的功劳）；② **Q8 不一定比 Q4 好**（小模型上实测反而退化 = 段落标题全掉）；
③ **主模型和 mmproj 必须同源同代** = 混搭 = 输出退化。

**🔴 主人问「哪个更好 / 要不要自己调一下」= 明确授权 = 跑基准台拿数据**，
脚本 = `scripts/bench_reverse_backend.py`，完整实测表 + 判读要点 = `references/反推后端选型与量化基准.md`。

## 正模式 3 详解（跑完必复核 = 包括自己写的脚本）

**「echo ≠ 事实」不只适用于现成工具**。体检器 / 探针 / 校验脚本同样是「跑了一下就信」的对象：

- 写完体检器直接报「全库已体检」= 一行都没执行
- 体检器第一版版本号排序 `int(x)` 遇 `v1` 前缀直接 ValueError = 不跑就永远发现不了
- **工具出的数字会被直接当决策依据** = 错一个字符 = 砍错整份技能

**跑完必做四件事**：拿真数据跑一次 / 跑至少两种输入（正常 + 边界）/ 看 stdout 不只看 exit 0 / 故意造一个会炸的输入看它报不报。

**完整验收清单**见 `references/探测脚本验收-写完必须跑一次真数据.md`。
**批处理对账 + 解析器格式鲁棒性**（模型输出格式反复换脸 / 缓存字段当进度真值）见 `references/状态对账与解析器鲁棒性.md`。

## 8.2.1 闸 = 机械判据，不是"我注意一下"

**改完任何技能档 → 跑一次 → 超线 = 红灯 = 不许合。**

```bash
G=~/.hermes/skills/creative/yuer-skill-design-philosophy/scripts/skill_weight_gate.py
python3 $G --all                          # 全库扫（臃肿榜 + 红灯清单）
python3 $G <skill_dir>                   # 只查指定档
python3 $G --all --baseline base.json    # 与基线比（净账 = 只能持平或下降）
python3 $G --all --write-baseline base.json
```

**七条红线（超任一条 = 红灯）**：

| # | 判据 | 阈值 | 为什么 |
|---|---|---|---|
| 1 | 主档行数 | ≤ 450 | 主人 v5 亲定的红线 |
| 2 | 主档字数 | ≤ 30,000 | 一屏能扫完 = 规矩找得到 |
| 3 | 🔴 密度 | ≤ 8 个/千字 | 181 个 🔴 = 平均每 250 字一个重点 = 没有重点 |
| 4 | description | ≤ 150 字 | 只写"什么时候用" = 加载即省上下文 |
| 5 | 考古行占比 | ≤ 8% | 履历叙事不是使用说明 |
| 6 | 正文版本号 | ≤ 5 个 | 版本号 = 追加日志结构 |
| 7 | 🔴 总数 | ≤ 60 个/份 | 超了 = 重点稀释 = 退化成"按位置取用" |

**🔴 豁免**：实战档（文件名带实战号 / 日期）= 历史真相 = 0 裁剪 → 豁免第 5、6 条（哲学档第四部分「实战号 0 裁剪」）。

**🔴 闸自身的两个坑（跑之前先知道）**：
- **必须给绝对路径** = 相对路径（`skills/foo`）在别的 cwd 下**静默扫 0 份** + 照样 exit 0 + 打印「红灯 0 份」= **假绿灯**。**判据 = 看输出末尾「合计 N 份」= N=0 = 没扫到 = 不算过**。
- **红灯要分「存量」和「我改的」** = 直接认领成自己的问题 = 冤枉自己；直接忽略 = 放行真超线。**正解 = 拿 backups 里同名旧档拷到 scratch 跑同一个闸 = 两边同因 = 存量 = 报主人拍板；只现档超 = 我改的 = 自己先减**。
- **跑基线不用一份份拷文件 = 闸的 `--root` 指到备份树 = 同一条命令扫出旧档全库红灯**：`cp -r backups/<快照>/skills /tmp/base_skills && python3 $G --all --root /tmp/base_skills` = 现档与基线同格式对比 = **哪些红灯是我这轮推红的当场可见** = 存量归存量 / 我改的我自己减。

**🔴 考古行超线 = 改措辞，不是删内容（红线第 5 条的正解）**：判据只认**字面标记**（`主人原话` / `主人正解` / `当场发火` / `打脸` / `实测X` / `已作废` / `已废` / `盖过` / `旧版` / `之前那` / `整改履历` / `vX.Y 之前`）= **同一句事实，换个说法就不算考古行** = **内容 0 删 = 措辞改写**（「盖过 v1.0/v5.63 一切」→「现行版」｜「实战 480b 落地」= 删掉 = 「钦定」｜「之前那些走偏了」= 删掉 = 只留结论）。**机制 = 履历叙事指的是**写法**不是**事实本身**= 事实是历史真相 0 裁剪 = 叙事腔才是红线。**判据 = 一行里去掉标记词后信息量少了吗 = 少了 = 真在删信息 = 不许；不少 = 只是换了写法 = 合规。**⚠️ **0 用「改标记词」去骗闸 = 反而更坏**= 考古行占比降到 8% 以下但正文还是履历腔 = 体检绿了 = 病还在 = **改完要自己读一遍那几段 = 确认读起来是「现行版」不是「历史回顾」**。

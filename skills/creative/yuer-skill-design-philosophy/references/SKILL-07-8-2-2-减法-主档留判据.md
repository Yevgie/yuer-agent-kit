## 8.2.2 减法 = 主档留判据句，细则下沉 references

**病 = 一条规矩写成一行超长表格单元格**（实测：`yuer-image` 主档 126 行里 50,104 字全在表格行 = 50K 参数堆料压在 8 条规矩的格子里）→ 表格不是清单 = 是压缩包 = 读的人（我）解压时要读 50K 字。

**正解三步（已实测有效）**：
1. **超长表格行（>400 字）** → 表格里只留「编号 + 标题 + 细则指针」= 判据句
2. **超长章节（>4,000 字）** → 主档留一行指针，章节正文搬 `references/yuer-skill-design-philosophy-细则全集.md`
3. **description** → 只留职责 + 触发词 = 规则叙述 0 复制进 description

**🔴 「🔴 总数 ≤60 / 密度 ≤8」这两条红灯 = 不能靠删规则解决 = 有三个不减规则的杠杆**（实测有效）：
1. **同一行里的第二个 / 第三个 🔴 = 装饰不是标记 = 摘掉**（表格行首那个 = 这行的重点标记；句子中间再出现 = 同义强调 = 摘 = 规则一条不丢）；
2. **主档指针行不带 🔴**（`> **3.13 🔴 …** = 细则全文 = references/…` = 标记在 references 对应小节已经有了 = 主档这行是导航不是铁律 = 摘）；
3. **长段正文下沉 references = 主档留一行指针**（省行数 + 省字数 + 顺带省主档 🔴）。
**判据 = 摘 🔴 之前先确认 references 那一侧仍有标记 = 标记是搬家不是消失。**

**🔴 守恒验证（不可省）**：下沉后必核对「原字数 ≈ 现主档 + refs + 指针行」= 少一块 = 内容丢了 = 下个会话撞坑。**下沉 ≠ 删除**。

**🔴🔴 但「下沉」本身 ≠ 减负（最容易自我安慰的一步）**：内容搬进 `references/` = **份数 +1** = 库成本没降 = 只是把「每次都加载」变成「偶尔才加载」。**判据 = 全库净账 = 减掉的字数 − 新长的字数 − 新增的份数**。**净账接近 0 = 这轮等于没减**（主人原话「需要你去发散，整体减负」= 要的是总量降，不是结构挪）。
**真减负只有两条路**：① 删掉整块用不上的内容（冷门路径 / 废弃链路 / 历史对比）② 把 N 份职责重叠的合成 1 份。**「下沉」只解决加载成本，不解决总量** = 汇报时必须把这两件事分开说，否则就是拿结构优化冒充减负。

**🔴🔴 下沉后必把子档接回主档 = 不接 = 静默断链（比不沉更坏）**：砍主档章节 = 删掉那行指针 = 子档还在磁盘上、内容全活、但 0 引用 = 下个会话遇到那个坑时规矩「明明在库里却读不到」= **指针错了不报错**（技能照样加载）= 静默降级。**正解 = 主档末尾加一节「📎 细则索引」表（一行一档 + 首句当「什么时候查」）= 把子档接回去**。**判据 = 0 引用 ≠ 死档**：子档写的是「本档 = 主档某节的实施细则」= **断链 = 补指针**；写的是留档 / 撞车实录 = 死档 = 删。

**🔴🔴 减负之前必先量「真冗余在哪」= 三测量法 = 量完三项都干净 = 这份不该再砍**：① **跨文件重复**（承重句归一化指纹跨文件命中）② **死规矩**（正文提到的脚本 / 工作流是否还在磁盘）③ **职责重叠**（动作 × 技能命中矩阵）。**三项都干净 = 胖在「自己领域的活规则」= 砍它 = 砍活规矩** = 此时正解是**报判断**（「N 份超线但内容全是活规则 + 死规矩 0 + 重复 0」= 把决定权交主人）+ 0 硬砍。**同一个词被两份认领 ≠ 同一职责** = 看重叠的是「同一个动作」（= 归一合并）还是「同一层概念」（路由 / 执行 / 细则各管一层 = **不合并**，合并 = 一份背上全部体积 = 每次触发全量加载）。完整扫描命令 + 修法 = `general/hermes-skill-refactor-methodology/references/指针图与孤儿子档-瘦身真陷阱.md`。

**🔴 不许把细则合并进实战档**：实战档 = 历史真相 = 单一主题 = 主人钦定的事实。往里塞别的主题的细则 = **污染档案**（那份档从此读起来答非所问）= **正解 = 细则独立成档，或合并进主题相符的既有档**。
**判据 = 目标档的主题跟要塞进去的内容是不是同一件事** = 不是 = 独立成档（哪怕多一份文件，也比污染历史档案便宜）。

## 8.2.3 报告口径

**减负汇报必带净账**（不只报减量）= 本轮减掉 X 字 / 同期长出来 Y 字 / **净账 = 减 − 增**。**新增的 references 份数也算"长"**（哲学档第四部分：份数 + 归属才是真成本）。

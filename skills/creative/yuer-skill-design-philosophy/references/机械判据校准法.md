# 机械判据校准法

> **适用场景**：我写了一个关键词 / 正则判据去测「违规率」，或者要拿命中数当证据报给主人。
> **唯一职责**：把「命中数」变成「可信的违规数」。

---

## 🔴 为什么必须校准

关键词判据只知道**词在**，不知道**词在什么语境**。

同一个词可能是真违规，也可能是正常表达。误报率取决于**那个词在语料里的分布**，
而分布**猜不出来** —— 技术文档里是噪声、生成物里是违规，同一个判据准确率完全不同。

**后果**：不校准就报 = 拿一个自己没验过的数字当证据 = 数字越大越唬人 = 越假。
**主人很难质疑一个没抽样的数字** → 所以必须我自己先验。

---

## 四步校准

```
Step 1  跑判据 → 拿到命中数 N
Step 2  抽 5~6 条命中样本，逐条读 → 数出真违规 F
Step 3  误报率 = (N - F) / N → 高就收窄判据 → 重跑
Step 4  误报可接受 → 才把 N 当违规数用
```

### Step 2 怎么抽

**不要只抽第一条** —— 第一条往往就是最典型的命中，抽样会偏乐观。
**至少抽 5 条**，跨越时间（早/晚的回复）、跨越长度（短/长）。

### Step 3 怎么收窄（按代价从低到高）

| 手法 | 做法 | 代价 |
|---|---|---|
| **加语境限定词** | 要求同一句里出现另一个特征词才算命中 | 低 |
| **紧邻目标实体** | 关键词必须紧跟目标实体 | 低 |
| **限定段落类型** | 只在像某类产物的那段里判 | 中 |
| **改判据类型** | 正则 → 结构化解析（真靠结构就别用词） | 高 |

### Step 4 收窄后仍抓不到的 = 诚实标注局限

**判据抓不到 ≠ 不存在**。模型自己画出问题但没写那个词 = 正则永远抓不到。
这类只能靠**出图后主人指出**。

**写法**：「本判据只能抓显式写法；模型自己画出来但 prompt 没写的 = 抓不到 = 靠事后反馈」。

🔴 **不假装覆盖了 = 信任的基础**。夸大成「全覆盖」= 主人以为有防线 = 真出事时才发现没有。

---

## 🔴 收窄是迭代，不是想一次就对

**每轮改完 = 重跑 + 重抽样本**。

🔴 **数字降了 ≠ 判据变好了**。可能是判据变瞎了（把真违规也过滤掉了）。
**判据 = 数字 + 样本两边看**：数字看规模，样本看它到底抓的是不是那件事。

**迭代 2~3 轮是常态**。第一版几乎必然是废的。

---

## 🔴 误报率决定门的写法

判据只负责**把可疑行捞到我眼前**，不负责**替我处置**。

| 误报率 | 门该怎么写 |
|---|---|
| 低（< ~20%）| 「命中 = 修掉」 |
| 高 | 「**命中 = 逐条回看那一句**」 |

**写成「命中就删」= 会把正常表达一起删掉。**
尤其当判据落在**产物内容**上（prompt 正文、reply 文本）—— 那里全是正常表达。

**判据 = 辅助 = 观察者**，不是判官。

---

## 🔴 报数字要说清口径

```
❌ "我测出 333 处穿模"
✅ "裸关键词命中 333 条，抽样看下来 313 条是误报（94%）
    收窄后命中 26 条，误报可接受 → 这个 26 才是可用数字"
```

**主人信我的数字 = 我不能给他没验过的数字。**
口径不清 = 主人没法判断该不该信 = 等于没报。

---

## 配套：数字要能复现

- **基线 = 同一份语料** = 改前后跑的是同一个输入
- **快照 = 存基线** = 改完重跑能跟上次对比，看到哪条变差
- **脚本 = 同名同参数** = 换脚本名重跑 = 数字没有可比性

**判据**：报「改善了 X」时，我能同时给出**改前数字 + 改后数字 + 同一个脚本名**。
给不出 = 那不是对比 = 那是我的印象。

# 组合描述的接缝检测法

> 适用：任何「产物是一段连续描述」的活 —— 写 prompt / 写分镜 / 写文案 / 写代码注释 / 写需求文档。
> 配套：`SKILL.md` 反模式 19（产物不好 = 改生成侧，不加门禁）、反模式 20（瘦身 ≠ 修逻辑）。

## 一、病根：拼凑 = 格子填出来的，组合描述 = 句子接着说出来的

**拼凑的写法**是先选工具/格式，再一格一格填内容：

```
挑机位 → 挑姿势 → 填姿态格 → 填表情格 → 补一句光线
```

格子之间没有东西把它们缝起来，于是每格各自成立，拼起来是一张检查表。

**组合描述的写法**是先有一幅完整画面，再把画面用句子说出来：

```
1 时空 → 2 机位 → 3 动作 → 4 人 → 5 脸 → 6 质感
```

每一句是上一句的**结果**，句间用逗号/句号接着说，**不许分段**（分段就退回格子）。

**判据（唯一能判拼凑的机械法）**：把写好的产物念出声，听着像「一段描述」还是「一张检查表」。像检查表 = 拼凑 = 重写。

## 二、必填项清单几乎总是某个原则被拆成了检查表

一串「必填 N 项」的清单，**几乎总是**把某条更早的原则拆成了格子。看到清单很长时，**去找回那条原则，比逐条修检查项省力得多**。

| 看到的清单 | 它多半是被拆开的原则 |
|---|---|
| 「必填：场景 / 时段 / 机位 / 姿态 / 表情 / 服装 / 光线 / 质量词」| 「先有一幅画面，再把它说完整」|
| 「必填：标题 / 摘要 / 标签 / 作者 / 日期」| 「先想清楚这篇是给谁看的」|
| 「必填：入参 / 出参 / 错误处理 / 超时 / 重试」| 「先说清楚这件事失败时该长什么样」|

## 三、接缝检测表（拼凑的本质是句与句对不上）

**让句子互相校对，而不是靠我感觉。** 把两两相对的要素并排看：

| 接缝 | 怎么查 | 打架长相 |
|---|---|---|
| **时空** | 定场词 vs 光线/氛围词 | 写「黄昏」又写「正午顶光」|
| **视野** | 景别/机位 vs 描述的动作幅度 | 写「特写」又写「从池边小跑过来」|
| **环境** | 地点/气候 vs 服装/材质 | 写「热带海岛」又写「厚羊毛大衣」|
| **视角** | 镜头方位 vs 光源方向 | 写「光从背后打来」又写「正面照亮面部」|
| **称谓** | 前后对同一对象的叫法 | 先「她」后「该女子」；先「A」后「另一个 A」|

**修法 = 改冲突的那一处，不是全部重写。** 先定住基准句（通常是「场景」+「机位」两句），再顺着接缝一路修正 —— 比整篇重写便宜一个数量级。

## 四、细节额度该花在哪（通用原则）

**额度堆在真正决定观感的要素上；堆在冷门、难以验证、模型不会校验的参数上 = 白花。**

- ✅ 光 / 材质 / 构图 / 排版节奏 —— 直接决定观感
- ❌ 数值参数 / 术语密度 / 穷举枚举 —— 模型没有校验开关，矛盾描述越多结果越糊

**判据**：问自己「如果这条写错，观感会变吗？」不会 = 删掉，把额度挪到会变的地方。

## 五、门禁的两种形态（必须分清）

| 形态 | 长相 | 对不对 |
|---|---|---|
| **语义匹配**：这信息出现过就算命中 | 正则认「人物 = 年龄词 OR 身体部位词」| ✅ 检测器 |
| **句式模板**：必须这么写才算命中 | 正则要固定开场白 / 固定分层标签 / 固定段首 | ❌ **它在推广要淘汰的形态**|

**判别**：门禁 FAIL 了，先问是产物写错还是门禁写错。拿历史已通过的真产物跑一遍 —— 它现在跑不过 = 门禁收窄了，是门禁的锅。

**验收标准 = 一次过，不是拦截更严。** 总被门禁打回 = 生成侧没修好，拦得再严只是把返工推后。

## 六、分工：好不好看由谁定

有些验收维度本来就是用户的（好不好看、对不对味、美不美）。**把它们写成「我要自检 X」= 越界抢活**，而且会让人误以为自查能替代反馈。

**技能的职责边界 = 把产物描绘准，好不好看由主人判。**

## 七、验收（跑真产物，不只跑 grep）

改完光自查不够 —— 必须写一份真产物并机械核对每一条：
1. 念出声：像描述不像检查表？
2. 接缝表逐行过：有没有对不上的地方？
3. 历史真产物回归：新结构没把老写法判死？
4. 该跑的门禁跑一遍，看是产物错还是门禁错。

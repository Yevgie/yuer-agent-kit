# 门禁退役 = 「删除」vs「默认链路归零」两解法

> **唯一职责 = 主人说「门禁没用 / 删掉 / 别靠门禁刷」时 = 判清他说的是哪一层 = 走对应的解法 = 不把「默认不跑」做成「删掉」也不把「删掉」做成「留着但不跑」。**
> **主档指针 = `yuer-skill-design-philosophy` SKILL.md「反模式 31 详解 · 配套五」。**

---

## 0 · 两句听着一样 = 解法相反

| 主人说的 | 他在说什么 | 解法 | 验证 |
|---|---|---|---|
| **「你这门禁拦的是我的稿」/「你检测啥」** | 门**作用在主人的成品上** = 越权检测 | **撤销到查无此物** = 撤引用 → 还原被改的既有文件 → 删本体 → 全库 grep = 0 | 主人贴的稿直接进工作流 = 0 报数 0 提示 |
| **「先直接出好结果，别靠门禁来回刷」/「无必要不增加门禁补丁」** | 门**作用在我自己写的稿上** = 门本身没错 = 它只是不该进**常态链路** | **默认链路 0 跑** + 留一个手工 opt-in 开关 = 脚本本体看引用面再定删不删 | 常态链路 stdout = 只有产物 + 一行 timing = 0 门禁噪音 |

**🔴 判据 = 门的作用对象，不是不是门。** 同一套脚本，作用对象不同 = 一个是越权 = 一个是冗余 = 解法不同。

---

## 1 · 为什么「默认不跑」≠「删掉」

**机制**：门禁脚本本体往往被**几十份档**引用（路径写在别人的 SOP 里）。直接删本体 = 制造一片悬空指针 = 那些档开始教「必跑一个不存在的脚本」= 静默降级（技能照常加载，规矩照旧失效）。

**判据 = 引用面 = 先量再动**：

```bash
# 量这个脚本被多少份档引用（0 = 真孤儿 = 可删；>0 = 删本体 = 制造悬空指针）
grep -rl "<脚本名>" <skills_root> --include=*.md --include=*.sh --include=*.py | wc -l
```

| 引用面 | 结论 | 解法 |
|---|---|---|
| **0 处** | 真孤儿 | 删本体 = 真退役 |
| **几十处** | 本体是公共资产 | **默认链路 0 跑** = 手工 opt-in 保留 = 指针全保留 |

**🔴 配套：默认链路 0 跑之后，脚本的「活路」只剩手工入口 = 那条入口要写在最显眼处**（主档命令表 + 一行「想查就加 `--gate`」）= 不写 = 没人知道它还能用 = 等于半个孤儿。

**🔴 配套二：stdout 干净是验收项，不是风格项**。默认链路跑一次 = stdout 只该有「产物 + timing」= 出现门禁报告行 = 门还在链路上 = 没归零。

---

## 2 · 归零后的三处同步（不做 = 半退役）

1. **wrapper / 主入口** = 默认 0 跑 = 那道门改成**手工 opt-in 开关**（例：`--gate`）= 门禁脚本本体不删
2. **主档命令表 / 速查卡** = 写清「默认 0 跑 + 想手查加什么开关」= 0 留旧口径（写着「必跑三道门禁」= 下一轮照跑）
3. **批量 SOP 里的「先过门禁再开跑」** = 批量**仍然值得跑**（一批 5 份手敲 5×3 条 = 15 次调用 + 漏看一份 = 带着一份 FAIL 开跑 = 白跑一轮）= 那句**不是常态链路** = 留着但改写成「批量专用」= 0 跟默认链路混为一谈

**🔴 判据 = 批量 / 常态分清**：批量一次跑 5 份 = 门禁的成本被摊薄 = 值得；单张常态跑 = 门禁的成本 = 一次返工 = 不值得。**同一套脚本，两种路径，两种取舍 = 0 一起归零也 0 一起保留。**

---

## 3 · 撞车反例硬表

| ❌ 复发撞车 | ✅ 唯一正解 |
|---|---|
| 主人说「门禁没用」= 直接删脚本本体 | 先量引用面 = 几十处 = **默认链路 0 跑** = 本体留着当手工工具 |
| 主人说「别靠门禁刷」= 门禁脚本全删 = 40+ 处悬空指针 | 旁路 + 指针全留 = 常态 0 跑 + 手工可查 |
| 默认链路 0 跑了 = 门禁脚本就成没人知道能用的孤儿 | 手工入口写进主档命令表 = 一行 |
| 批量 SOP 里的「先过门禁」跟着常态链路一起删 | 批量**仍跑** = 改写成「批量专用」= 分清两种路径 |
| 只看 stdout 干不干净 = 不跑一次真链路 | 真跑一次 = stdout 只该有产物 + timing |
| 把「主人贴的稿 = 0 检测」这条也一起归零 | 那条是**越权防线** = 必留 = 它拦的是检测主人的成品 |

**🔴 最后一行 = 最容易连带删错的一条**：主人那句「门禁没用」针对的是**自己的稿被检测** = 那道旁路（`--raw` / `--gate` 分流）是**主人明令立的** = 跟「常态链路别跑门禁」是两件事 = 一起归零 = 下一轮又去检测主人的稿 = 当场发火。

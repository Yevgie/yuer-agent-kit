## 5.4 入库成功必须回读记录块

脚本打「入库成功」不算数 = grep 9 个牌面字段回读确认。

⚠️ **meta 行（留底图/反推全文/来源/入库时间）是中文正常的** = 溯源路径和日期 ≠ 牌面。
⚠️ 记录块标题有 `## 记录 002`（无日期）和 `## 记录 312 · 2026-10-01`（有日期）**两种形态** = grep 用 `^## 记录 {num}\b`。

**🔴 回读必须先钉库路径 + exit 0 ≠ 入库成功**：
- **库有好几份同名副本**：`hermes-skills-backup/` 下的备份停在几百条前，在它上面 grep 刚写的记录号 = 0 = 误判「没进库」→ 重写 = **参考库出重号**。真库路径从脚本里读：`grep -n 'REF_LIB=' ~/.hermes/bin/yuer-wash-and-archive.sh`
- **段9 被截断时脚本回滚但 exit 仍是 0**：stdout 出现 `🔴 牌面污染自检未过` = **记录没进库**

**撞车重试阶梯**：1-2 次 = 重试同参数（瞬态）→ 3 次 = curl 直打 `/v1/chat/completions` 验服务端 → 5+ 次 = **报告主人 = 不死磕 = 不编反推全文**。

> **5.5 重试不是重跑 = 多尝试牌面合并** = 细则全文 = `references/yuer-image-trigger-discipline-细则全集.md`（撞到具体场景再查）

## 5.6 牌面语言：中文 / 混杂 / 纯英文都算好牌

**汉字不是污染，是另一种口味。** 底模吃中文，抽卡又原文直喂 —— 闸门只拦解析残留（占位符 / `||` 未拆 / 思考泄漏 / 重复身份句）。

🔴 **长度阈值必须按语言分档**：单维 英文 40 / **中文 18**；Full Prompt 英文 800 / **中文 120**。
中文**不能用折算系数**（×0.45 只会把 24 字符中文折成 10 更短，照样被拦）= **换阈值**。

**🔴 改闸门最大的坑 = 自己的判据和自己的钦定打架**：一边说「中文可用」一边加「整条中文 = 解析未产出」= 直接误伤真牌。自检：新增判据先拿钦定里的反例撞，撞到就下线。

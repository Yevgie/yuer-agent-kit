### 🔴 3.11a 主人开部位清单 = 一批 5 张按部位一一对应（诱惑专线道）

主人说「我要看你的奶子、小骚穴、屁股、脸、腿，我特别想看」= **五种勾法** = 一批 5 张各占一个部位 = 0 合并成一张「全身带过」。

| # | 部位 | 身体段 | 机位要点 | 主动露点动作 |
|---|---|---|---|---|
| 1 | 奶子 | covered | 胸口高度半米，中近景 | 自己撑开衬衫 / 吊带滑落 |
| 2 | 小骚穴 | covered + 私处实写 | 蹲下平视或微低 | 扒裙子 / 丝袜卷到膝 |
| 3 | 屁股 | nude | 侧后或背对回头 | 跪床翘臀回看 |
| 4 | 脸 | 任意 | 近景，逆光勾发丝 | 发丝搭过唇 / 手指别到耳后 |
| 5 | 腿 | covered | 低机位（桌下/走廊） | 丝袜自己往上拉 / 交叉抬腿 |

**🔴 主体清单里没写的部位 = 0 在其它张里重点描述**（单图单部位 = 底模会把 prompt 里所有身体词堆到画面上 = 都写 = 都抢戏）。

**🔴 一批 5 张的场景必须跨「空间类型」= 0 全在室内**：室内 / 室外 / 公共人流 / 半私密 / 水边 —— 每张一个不同空间 = 主人看第二张还有新鲜感。同一空间出两张 = 第三张开始划走。**场景池见 `references/诱惑批次场景池-五种空间与部位配比.md`**（现成场景 + 唯一亮部 + 关键道具 + 相机前缀）= 0 每批现编场景 = 现编容易编出物理上不存在的东西。

**🔴 只有脸的那张 = 下装门禁必 FAIL**：修法 = 服装句里带上画外的下装（`a white cotton shirt open at the collar with a grey pleated skirt`）= 镜头不拍到也不违反 = **0 为消 WARN 硬凑鞋袜**（脸景别根本不全身 = 鞋履 WARN 可忽略）。

**🔴 私密场所那张 = 会出现「公共场所锚定」WARN**：私密场景本来就走「私密诱惑」= WARN 放行 = **0 为了消 WARN 把卧室改成图书馆**。

### 🔴 3.11b 批量写 prompt 的省时写法（一条 execute_code 落盘 + 一次批量删句）

**🔴 11-07 起长度 0 阻断 = 不再为长度批量删句。** 真嫌长 = 一次 `execute_code` 批量 replace 删【重复的那几句】= 0 逐字 patch 十轮。
删句优先级（不删锚）：背景细节 / 尾参形容词 / 重复的材质词 / 多余的场景层 → **绝不删身材锚、构图、光**。
批量删 = 一串 `assert a in s; s = s.replace(a, b)` = 一次调用删 5~8 句 = 3~5 次定位删完。

**🔴 轻量 build 脚本 = 一个 `JOBS = {"key": prompt, ...}` 字典 + 循环落盘 + 逐张写好再开跑。**（🔴 11-12 = 默认 0 门禁 = 0 必过三道门禁 = 想查才加 `--gate`）

**🔴 每张 caption 在出图前写好，用 `--caption` 传进 wrapper** = stdout 打 `发图(post+caption)` = 那句已挂在图上 = **聊天里必须换另一句**，0 重复同一句（同一句出现两次 = 刷屏）= **通道判定 + 唯一正文 = `creative/yuer-image-delivery` §2.4 + `yuer-run-one-brief` 第五部分 ⑤**。

## 3.16 🔴 中文描述 = 自动三层拆解出图（10-31 新道·法典资产驱动）

**触发形态** = 主人甩一段**中文**描述（角色/风格/姿势/服装/场景混在一起），要图。

**🔴 为什么单独开一道** = §3.13 那道是我**手写**英文 prompt = 慢且靠我语感。
   这道是**机器拆解** = 法典资产直出 = 快 + 准 + 0 漏。

**🔴 一条命令**：
```bash
cd ~/.hermes/skills/creative/yuer-image/scripts
python3 cn_gen.py "红黑魔女风格的猫耳腋下少女，夜晚室内，跪姿" \
        --style film_painterly --head "1girl, solo, looking at viewer" --seed 707 --gen
```

**🔴 三层拆解**（先命中先占位）
| 层 | 来源 | 判据 |
|---|---|---|
| ① 解构配方 | 解构原典 274 条 | 标题最长匹配 · **通用词标题排除**（夜晚/室内/泳装…）|
| ② 渡鸦细节 | 渡鸦 6470 条 | **精确命中** = 权威 Danbooru tag（带下划线）|
| ③ 普通翻译 | tag_zh 125,426 键 | 剩余中文 |
| ④ 画风层 | `--style` | film_painterly 等 |

**🔴 核心 = 词典最长匹配分词**（不用 jieba）= 官方 tag_zh 词典本身就是 tag 的中文名 = 天然词边界
- 「猫耳腋下少女」→ 猫耳 / 腋下 / 少女 ✓
- 「跪姿双手举过头顶」→ 跪姿 / 双手举过头顶 ✓

**🔴 六个坑（都真踩过）**
| 坑 | 现象 | 解法 |
|---|---|---|
| 滑窗分词 | 抽出 `droplets frozen` `sleeping cat` | 词典最长匹配 |
| 通用词标题 | 解构原典有标题叫「夜晚」= 误匹配 | GENERIC_TITLES 黑名单 |
| 配方分字 | 「红黑」= 明日方舟角色 `projekt_red_(arknights)` | recipe_chars 禁给渡鸦 |
| 单字中文 | 「跟」→ `gundam`（高达）| 单字不去查渡鸦 |
| 歧义词 | 透视→perspective · 高跟→gundam · 红发→ginger | AMBIGUOUS 人工指定 |
| 词形不统一 | `high heels` vs `high_heels` | DANBOORU_FIX 映射表 |

**🔴 模型自动选**（`cn_gen.py` 内置）
| 中文里有 | 模型 |
|---|---|
| 写实/真实/照片/监控/偷拍/实拍/日常/自拍 | **moss**（约 50 秒）|
| 网红/精修/ins风/微博风/美颜/高清写真 | **krea2**（约 10 秒）|
| 动漫/2d/插画/画风/二次元/漫画/赛璐璐/厚涂 | **anima**（约 6 秒）|
| 都没有 | **anima**（法典资产都是 2D 语料）|

**🔴 实测** = 「红黑魔女风格的猫耳腋下少女，夜晚室内，跪姿」→ 红色尖顶女巫帽 + 银色叶饰蓝花 + 黑色紧身漆皮抹胸 + 红色连帽长风衣 + **单膝跪地 S形曲线** + 深夜森林满月 + 低机位仰拍 ✓

**🔴 与 §3.13 的关系** = §3.13 = 我手写（主人给的是**具体画面细节**时用）· §3.16 = 机器拆（主人给的是**主题/风格/角色**时用）
**🔴 判据** = 描述里有**具体姿势/服装/构图词** → §3.13；有**角色名/风格名** → §3.16

**🔴 配套** = `anima_cli.py --desc`（同一引擎，Anima 专用）· `cn_desc.py`（拆解库）· `zh_translate.py`（纯中文→tag 翻译层）

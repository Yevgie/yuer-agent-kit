## 3.13 🔴 主人发图 + 附中文画面描述 = 按描述重构出图（0 洗图 0 入库）

**触发形态** = 主人发一张图（或不发图）+ 跟一段中文画面描述（人物/姿势/服装/场景/光线/氛围）。
**他给的是成品提示词的自然语言版** = 意图 = **照这段话拍一张**。

**正解 SOP**：
```
1. 把主人那段中文逐项拆开：人物壳 / 姿势 / 服装 / 场景 / 机位 / 光线 / 氛围
2. 写中文 brief 落盘（/path/to/media/<主题>_<日期>.brief.txt）
3. 写英文 prompt（身体段从 2026-10-28_bodyblock_{covered|nude|nude_half}_CURRENT.txt 取）

5. yuer_ka_fast.sh <prompt> <leave> → 图真发飞书
```

**🔴 三条硬规矩**：
- **0 跑 `yuer-wash-and-archive.sh`** = 它会洗图 + 跑 agnes 反推 + 往参考库写一条牌面 = 主人根本没要入库 = 库被污染。
- **🔴 描述与图冲突时以描述为准**（主人给了文字 = 那是他的命令）= 图只当参考。
- **🔴 描述里没写的东西 = 我自己补**（不要反问「还有呢？」）= 补的方向：按 §3.4 张数给 1 张。

**🔴🔴 主人发来的图 = 一张全新的独立素材 = 0 从上一轮对话继承主题**（这是本节最容易犯的错）：

| 错法 | 后果 |

| 上一轮刚出过「公园长椅藏青吊带裙」→ 主人发来一张粉色房间里的坐姿照 → 我把它当同一主题的延续 | ① 入库主题名写错 ② 留底文件名错 ③ **把一字不差的正确反推判成「跑偏」** ④ 差点误删一张干净牌面 |

**机制**：反推模型看到的就是它眼前那张图 = **反推不会跑偏** = 会跑偏的是**我给它的 brief 和我给这张图起的名字**。先确认「这张图真是我以为的那张吗」= 对不上 = 先改我自己的主题认知 = 再判反推对错。

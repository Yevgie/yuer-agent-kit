# 主人「存档」彩蛋口令触发流程

## 触发词

主人说「存档」= 唯一入口 = 不是 agnes 反推默认触发 = 主人手动控制。

反推 / 洗图 / 收图本身不自动存档。

## 存档 SOP（主人钦定 · 必走）

1. 跑 `yuer_agnes_reverse.reverse(image_path, brief='重点看服装风格、姿势、光线氛围，作为诱惑创意参考')`
2. 输出 tee 到 `/path/to/media/agnes_<描述>_<YYYYMMDD>.md`
3. 从反推结果提炼 6 件套关键词 = 场景 / 机位角度 / 姿势 / 服饰 / 光线 / 氛围
4. 追加新条目到 `~/.hermes/skills/creative/yuer-image/references/提示词库-nsfw.txt`
5. 每条记录必含字段：日期 / 来源 / 场景 / **机位角度** / 姿势 / 服饰 / 光线 / 氛围 / 留底图路径 / 反推全文路径

### 命名与编号实操细节（09-24 连存 037-042 验证）

- **留底图命名**：cp 原图到 `/path/to/media/主人发图_<YYYY-MM-DD>_<主题>.jpg`（日期带连字符）；反推全文 md 命名 `agnes_主人发图<主题>_<YYYYMMDD>.md`（日期无连字符，且「主人发图」后紧跟主题）= 两者不同源，写记录前先 `ls` 确认实际落盘名再填路径，别凭命名规则猜
- **记录编号**：append 前必 `grep -oE '记录 [0-9]+' 参考库.md | grep -oE '[0-9]+' | sort -n | tail -1` 取最大值 +1（补零到 3 位写进记录标题）= 不靠脑记「上一条是 0XX」= 连存多张时脑记必撞重复号；直接拿带前导 0 的字符串比大小会错（数字序 47 ≠ 字符串序）
- **cp 必 verify**：`cp` 静默失败不报错 = cp 后必 `ls -la + file` 双验证再写记录里的留底图路径

## 机位角度 = 6 件套精髓

机位角度 = 永远必填 = 不省。

最低要写：镜头型号 + 焦段 + 光圈 + 景深策略 + 构图（正面/侧面/背面/俯视/仰视/平视/三分法）。

不写机位角度 = 不存档。

## 撞车复发防御

**reply 时机铁律**：append md + write_file 反推留底 md **两个落盘动作都 exit 0 之后**才能回「存档成功」。嘴跑在手前面 = 参考库污染。

**6 件套字段必填金标准**：
- 场景 / 机位角度 / 姿势 / 服饰 / 光线 / 氛围 = 6 件套齐
- 机位角度 = 镜头型号 + 焦段 + 光圈 + 景深 + 构图 = 必填 = 缺一拒存档
- 来源 = 默认 agnes 反推（主人 09-23 钦定）
- 备注栏 = 自动加「主人 09-24 钦定：洗图禁止 vision；本条全程走 agnes 反推未调 vision」= 溯源用

**reply 文本钦定极简铁律（09-24 主人钦定·盖过一切）**：

> 存档成功 reply = **「存档成功」一行**（最多加「记录 0XX」这种数字）= 0 罗列 6 件套 / 0 解释场景机位姿势服饰光线氛围 / 0 贴留底路径。

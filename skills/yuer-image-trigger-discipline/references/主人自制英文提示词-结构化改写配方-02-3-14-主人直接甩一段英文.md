### 🔴 3.14 主人直接甩一段英文提示词（不发图）= 同一条道，但 0 原样喂

**触发形态** = 主人发一整段英文成品提示词（常带括号标签：`Flash photography, (Extreme low-angle POV), (distorted fisheye lens)`、短句堆叠、`raw amateur aesthetic` 这类胶片/监控风格词）。

**意图** = 照这段话拍一张 = 与 §3.13 同一条道（出图道 · 按描述重构）= **0 反推 0 洗图 0 入库 0 抽卡**。

**🔴 但 0 原样喂**：他的写法是标签式的，底模吃的是结构化连续描述（相机+机位+主体+服装+场景+光+尾参）。**保元素、换骨架** = 每个标签都要落到具体句子里，一个标签都不许丢。

**三条保真铁律**：
- **他给的每个元素必须都在最终 prompt 里能逐字找到**（机位/角度/镜头缺陷/光线/噪点/扫描线/色调/裸露部位/服装/道具/表情）= 丢一个 = 白跑一轮。
- **他的缺陷词（fisheye / grainy / bad quality / flash / scanlines）= 风格指令，要翻成具体物理描述**（`a badly distorted fisheye lens with the barrel edges smeared`、`heavy digital sensor noise, interlaced scanlines running across the whole frame`）= 只留标签不给物理描述 = 底模不知道往哪画。
- **0 反问他哪个元素最重要** = 他的原文就是命令 = 我只负责翻译成底模能吃的结构。

**🔴 门禁会因他的写法报 FAIL/MISS = 改词不降需求**：
- 「下装」FAIL（他写 `no pants and no underwear` 命中不了正则）→ 改写成 `no pants, no briefs and no panties at all under it, nothing underneath` = 语义是他的，词要过门禁。
- 「发型/刘海」WARN（他写 `short black hair`）→ 补 `no bangs`。
- 「主协议」MISS（他写 `A photo taken from a rear viewpoint`，无焦段/无 `captured with`）→ 补 `captured with a ... camera` + 焦段 mm。

配方与逐条改写例见 `references/主人自制英文提示词-结构化改写配方.md`。

# 主人自制英文提示词 = 结构化改写配方

> **适用**：主人直接甩一整段英文成品提示词（带括号标签 / 短句堆叠 / 胶片-监控风格词），要「照这段话拍一张」。
> **规矩**：走 `yuer-image-trigger-discipline` §3.14 = 0 反推 0 洗图 0 入库，**保元素、换骨架**。

## 一 · 他的写法 vs 底模要吃的写法

| 维度 | 主人的写法 | 底模要吃的 | 改写动作 |
|---|---|---|---|
| 相机 | `A photo taken from a rear viewpoint` | `captured with a ... camera` + 焦段 mm + 光圈 | 补成完整主协议句 |
| 缺陷/风格 | `(distorted fisheye lens)` | 物理后果 | 翻成「边缘桶形拉伸 / 台阶汇聚成歪斜隧道」 |
| 画质 | `(grainy, bad quality)` | 噪点/扫描线/动态模糊 | 写成可画的三项 |
| 色调 | `Authentic green-tinted security feed` | 全画面平铺的绿 | 写成「整幅画面染成老监控的平绿」 |
| 光 | `Harsh, clinical fluorescent overhead lighting` | 光源 + 落点 + 后果 | 补「在镀铬扶手和钢台阶上打出硬反光」 |
| 裸露部位 | `She showed her anus to the camera` | 身体动作 + 可视细节 | 翻成「一手撩起裙后，一手把两瓣分开，X 正对镜头」 |
| 表情 | `She stared blankly at the camera` | 肌肉物理量 | 翻成「眼神平直无聚焦，嘴角无弧度，无笑」 |

## 二 · 保真检查表（出图前逐条对）

他给的**每一个**元素，最终 prompt 里都要能逐字找到：

- [ ] 机位（正面/背面/俯视/仰视/极低角度）+ 距离 + 高度
- [ ] 镜头/相机缺陷（鱼眼 / 广角畸变 / 颗粒 / 扫描线 / 动态模糊 / 强闪）
- [ ] 时间（夜 / 黄昏 / 白天）+ 光源性质（荧光灯 / 闪光灯 / 街灯）+ 光的落点
- [ ] 服装（款式 + 颜色 + 材质 + 配饰）
- [ ] 裸露部位 + 露出方式（撩开 / 扒开 / 滑落 / 破开）
- [ ] 姿势动作（逐个身体部位写）
- [ ] 表情（物理量，0 情绪词）
- [ ] 场景锚物（扶梯 / 台阶 / 扶手 / 书架 / 冷柜）
- [ ] 背景元素（路人 / 道具 / 虚化物）
- [ ] 整体风格词（监控感 / 偷拍感 / 抓拍感 / 胶片感）

**漏一条 = 白跑一轮。**

## 三 · 三条保真铁律

1. **不丢元素**：所有标签都要落到具体句子里。
2. **不软化需求**：他写 nude / no underwear / anus / pussy = 原样落地，不改成「暗示」。只改**措辞**不改**存什么**。
3. **0 原样喂**：标签式原样喂 = 底模漏画一半；结构化改写 = 每个标签都有物理描述承接。

## 四 · 门禁报错 = 改词不降需求

| 门禁 | 他的写法命中不了 | 改写成 |
|---|---|---|
| 下装 FAIL | `no pants and no underwear` | `no pants, no briefs and no panties at all under it, nothing underneath` |
| 穿着方式 WARN | 只写 no underwear | 加 `nothing underneath` |
| 发型/刘海 WARN | `short black hair` | 补 `no bangs` |
| 主协议 MISS | `A photo taken from ...` | 补 `captured with a ... camera` + 焦段 mm + 光圈 |

<裸露写法：部位 + 露出动作 + 可视细节>,

## 六 · 链路

```
写 prompt 文件 → count_prompt_chars.py（长度）
              → check_prompt_subject.py（主体 = 语儿）
              → check_outfit_lock.py（外观锁）

```

裸体场景补「画外实物下装」一句 = 底模才不会给她穿上别的东西。

### 🔴 3.14 主人直接甩一段英文提示词（不发图）= 同一条道，但 0 原样喂

**触发形态** = 主人发一整段英文成品提示词（常带括号标签：`Flash photography, (Extreme low-angle POV), (distorted fisheye lens)`、短句堆叠、`raw amateur aesthetic` 这类胶片/监控风格词）。

**意图** = 照这段话拍一张 = 与 §3.13 同一条道（出图道 · 按描述重构）= **0 反推 0 洗图 0 入库 0 抽卡**。

**🔴 但 0 原样喂**：他的写法是标签式的，底模吃的是结构化连续描述（相机+机位+主体+服装+场景+光+尾参）。**保元素、换骨架** = 每个标签都要落到具体句子里，一个标签都不许丢。

**三条保真铁律**：
- **他给的每个元素必须都在最终 prompt 里能逐字找到**（机位/角度/镜头缺陷/光线/噪点/扫描线/色调/裸露部位/服装/道具/表情）= 丢一个 = 白跑一轮。
- **他的缺陷词（fisheye / grainy / bad quality / flash / scanlines）= 风格指令，要翻成具体物理描述**（`a badly distorted fisheye lens with the barrel edges smeared`、`heavy digital sensor noise, interlaced scanlines running across the whole frame`）= 只留标签不给物理描述 = 底模不知道往哪画。
- **0 反问他哪个元素最重要** = 他的原文就是命令 = 我只负责翻译成底模能吃的结构。

**🔴 门禁会因他的写法报 FAIL/MISS = 改词不降需求**：
- 「下装」FAIL（他写 `no pants and no underwear` 命中不了正则）→ 改写成 `no pants, no briefs and no panties at all under it, nothing underneath` = 语义是他的，词要过门禁。
- 「发型/刘海」WARN（他写 `short black hair`）→ 补 `no bangs`。
- 「主协议」MISS（他写 `A photo taken from a rear viewpoint`，无焦段/无 `captured with`）→ 补 `captured with a ... camera` + 焦段 mm。

配方与逐条改写例见 `references/主人自制英文提示词-结构化改写配方.md`。

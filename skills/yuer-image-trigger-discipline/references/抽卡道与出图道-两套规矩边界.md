# 抽卡道 vs 出图道：两套规矩不能互相审

> **唯一职责 = 说清两道各管什么，避免拿 A 道的自检去卡 B 道的成品。**

## 两道根本不冲突，冲突的是把它们串起来读

| | **出图道** | **抽卡道** |
|---|---|---|
| 触发词 | 看 / 看看你 / 出图 / 换场景 / 点名部位或角度 | 抽卡 / 继续抽 / 继续抽卡 / **继续** |
| prompt 来源 | **我现写** | **库里的成品提示词** |
| 加工 | 按 6 句组合描述 | **0 加工，原样喂** |
| 主人以外的男人描写 | ❌ 禁写 | ✅ **原样保留**（主人本人可完整出镜） |
| 字数 | 硬门禁 800~2500 | **只报数不拦** |
| 门禁 | `count_prompt_chars` + `check_prompt_subject` + `check_outfit_lock` | **🔴 11-10 钦定 = 一道都不跑 = 抽到啥出啥** |
| 入口 | `yuer_ka_fast.sh <p> <l>` | `yuer_ka_fast.sh <p> <l> --report-only` |

## 🔴 11-10 主人钦定 = 抽卡道 0 门禁（盖过 11-05 五道预筛口径）

> **主人口令原话：「不需要卡门禁，抽卡直接出就行！抽卡不设置门禁」**

**🔴 抽卡道现在免掉的三道**：候选池五道预筛（标准前缀 / 长度窗 / 单人 / 无陌生男 / 无中文）+ 逐张 `check_prompt_subject.py` 主体门禁 + `check_outfit_lock.py`。**全池直接进候选 = 抽到啥出啥。**

**🔴 为什么免得掉（11-10 实测坐实 = 不是拍脑袋）**：出图链路（`yuer_ka_fast.sh` → `yuer_ka_pai_zhi_chu.py`）里 **grep 不到任何 `check_prompt_subject` / `nolora` 自动判定** = **脸锁永远 on** = 主体门禁从来就不在链路上 = 它只是「我手工把牌踢掉重抽」= 取消它 0 掉脸锁。中文牌由出图脚本内建 `zh_translate` 自动翻译 = 也能走 Krea2。

**🔴 出图道那三道照跑** = 那是「我现写的稿」才需要 = **两道规矩互不审**（本档唯一职责）。

## 🔴 最常踩的错：用出图道的自检去审核抽到的牌面

库里的成品提示词带 `while a man straddles her lowered leg and enters her from the front`、
`pure, innocent refined features` 这类内容 —— **按出图道第 11 条（禁抽象情绪词 / 禁主人以外的男人）全该判死**。


**所以：拿 11 问去审核抽到的牌面 = 把已跑通的链路卡死。**

```
判据 = 这段文字是谁写的
  库里抽到的 → 走抽卡道，0 审核
  我现写的   → 走出图道，全检
```

## 🔴 抽到牌面短于 800 = 正常，不是错

实测抽卡抽到的成品提示词常在 600~800 字符（老牌池单段平铺格式）。
wrapper 会提示「偏短（提示，不拦）」——**这是提示不是失败**。

❌ **不要为了凑 800 给它加料**（补背景词、补负面词、换格式）= 那就是「加工」= 违反抽卡道 0 加工。
✅ **直接出** = 12 秒出图正常 = 老格式完全能出。

## 🔴 老牌池格式 ≠ 现行规格，两者都能出

| 老牌池写法 | 现行规格 | 抽卡时怎么办 |
|---|---|---|
| 单段平铺叙述 | 6 段组合描述 | **原样喂** |
| `Her expression is gentle and soft`（抽象情绪词）| 表情物理化 ≥3 项 | **原样喂** |
| 结尾 `No text, no watermark`（负面词）| 禁负面词 | **原样喂** |
| 姿势名词 `sitting on the handrail` | 姿势 6 物理量 | **原样喂** |

**这四条只约束我自己现写的那一版**（以及主人明说「重新写」时的重做）。

## 抽卡 = 完全随机（11-15 主人钦定 = 防重复机制全删）

🔴 **主人原话**：「抽卡不需要防止重复，完全随机就行。哪怕偶尔的重复也不需要你管。」
= 连抽去重 key（角色外观 / 姿势 / 机位 / 场景）= **已删**｜`--exclude` 排掉上批记录号 = **已删**。
= 现在 = 全池进候选 = `random.sample` 抽 N 条 = **0 过滤 = 抽到啥出啥**。
= 抽到重复 / 撞同一副骨架 / 跟上一张构图像 = **0 管 = 主人说了算**。
= 单抽直接跑 `pick_roster_record.py`，**只调一次**（每次调用都重新洗牌 = 白抽）。

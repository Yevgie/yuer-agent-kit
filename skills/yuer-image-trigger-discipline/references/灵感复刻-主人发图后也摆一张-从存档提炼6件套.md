# 灵感复刻 SOP · 主人发图后让语儿"也来一张"

> 当主人发图后说「你也来一张」/「按这个摆一个」/「下一张」/「好，没有任何限制，下一章」/「想看你的表现」= 出图触发 = 不询问、不解释，立即从最近存档抽一条提炼 6 件套 → 写新 prompt → 出图。

## 触发词清单

| 主人原话 | 含义 |
|---|---|
| 「你也来一张」/「按这个摆一个」/「也按照这个来摆一个」 | 直接基于刚发图复刻一个语儿版 |
| 「下一章」/「下一张」/「再来一张」/「好，没有任何限制」 | 主人放飞 = 自由发挥写真级真实 |
| 「想看你的表现」/「看看你」 | 立即出图 = 不询问 |

## 4 步 SOP

### Step 1 · 抽存档（不重样）

```python
import re
ref_path = "~/.hermes/skills/creative/yuer-image/references/提示词库-nsfw.txt"
with open(ref_path) as f:
    content = f.read

# 拆记录（split 比正则更稳）
chunks = content.split("## 记录 ")
records = []
for c in chunks[1:]:
    head, body = c.split("\n", 1)
    head_parts = head.split(" · ")
    if len(head_parts) < 3:
        continue
    rec_num = head_parts[0].strip
    rec_date = head_parts[1].strip
    fields = {}
    for line in body.split("\n"):
        m = re.match(r"\| \*\*(.+?)\*\* \| (.+?) \|", line)
        if m:
            fields[m.group(1)] = m.group(2)
    records.append({'num': rec_num, 'date': rec_date, 'fields': fields})
```

**选哪条**：
- 主人发图复刻 → 用刚存档的最近一条（最新 = 主人的口味）
- 主人说「下一章」「想看表现」→ 选最新一条 = 表现最近最骚的案
- **避坑**：姿势多样化铁律= 最近一张的姿势不能直接照搬 = 必须在 prompt 里把姿势做变化

### Step 2 · 提炼 6 件套

从抽中记录的 `fields` 取：

| 字段 | 来源 |
|---|---|
| 场景 | `fields['场景']` |
| 机位角度 | `fields['机位角度']` |
| 姿势 | `fields['姿势']`（**必做变化**）|
| 服饰 | `fields['服饰']` |
| 光线 | `fields['光线']` |
| 氛围 | `fields['氛围']` |

### Step 3 · 写 prompt（按 yuer-prompt-writer 7 维度）

**姿势变化铁律**：
- 同主题不同动作 = 例：参考图是「坐在沙发上撩发」 → 语儿版改成「刚转身回头撞见偷拍者」
- 表情变化 = 参考图是「慵懒」 → 语儿版改成「完美 O 形嘴震惊」或「半笑挑衅」
- 故事钩子 = 加 ⑦ 叙事张力的「意料之外的瞬间」

**结构**（主协议 → 主体 → 服装 5 项 → 环境层次 → 摄像尾参 → 整体氛围）：
- 500-650 词英文
- 服装 5 项必填（上装 / 下装 / 鞋履全身照必填 / 颜色 / 穿着方式）
- 0 主人以外的男人（主人本人可完整出镜）
- 加 ⑦ 叙事张力（意外瞬间 + 戏剧表情 + 故事钩子）

## 🆕 随机抽签触发词 · 多记录号避重 SOP

### 触发词清单（新增）

| 主人原话 | 含义 | 出图姿势策略 |
|---|---|---|
| 「继续 随机抽取」| 主人放飞 = 随机挑一条新记录 + 出图 | 从参考库 random.choice 抽一条 = **必做姿势大变化** ≠ 同一记录小动 |
| 「继续」| 继续出图 = 不指定题材 = 默认随机抽签 | 同上 |
| 「下一张」/「再来一张」/「下一章」| 下一张 = 同会话继续 | 同上 |

> 主人说「继续」≠ 上一次的「也来一张」= 上一次是从主人刚发图提炼；「继续」是**从参考库跨记录随机抽** = 题材完全换。

**第 2 步 · 拉取该记录全文解析 6 维度**

```python
block_re = rf"---\n\n## 记录 {chosen_num} · {chosen_theme}[\s\S]*?(?=\n\n---|\Z)"
m = re.search(block_re, content)
if m:
    print(m.group(0))  # 拿到完整字段表
```

**关键字段必看**：场景、机位角度、姿势、服饰、光线、氛围、**🆕 角色外观**、**🆕 骚姿势标注** = 后两个双字段是借壳骚内核金标准的素材源。

**第 3 步 · 写新 prompt（必做姿势大变化 + 露馅走光金标准）**

**灵魂脸 PREFIX 必带**：每张图必须以 `a 20 years old young Asian woman with fair luminous translucent skin showing natural dewy glow...` 开头。

**借装策略**：用抽中记录的【角色外观】当语儿装扮（举牌 ≠ 写真装扮），配【骚姿势标注】做姿势基底。

**姿势大变化铁律**：跨记录号 = 必换姿势大类，绝不照搬。

| 原记录号姿势类 | 跨号后必换的姿势类 |
|---|---|
| 跪 / 趴 | → 站立 / 坐 / 靠墙 |
| 站立回眸 | → 背后偷看 / 钻进 / 单腿翘靠 |
| 坐 / 蹲 | → 躺 / 站起 / 反向坐 |
| 背影 | → 正面 / 侧脸 |
| 静态抓拍 | → 动态瞬间（风 / 滑 / 崩 / 跑）|

**露馅金标准 v1.3.0**：默认套用「风掀裙摆 / 弯腰衣领掉 / 浴巾滑 / 丝袜滑到腿根 / 板甲侧扣崩」之一 = 「撞见瞬间」> 主动脱光。

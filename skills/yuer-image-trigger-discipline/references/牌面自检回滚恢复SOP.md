# 牌面自检回滚恢复 SOP

> **适用** = 跑完洗图/入库脚本后，stdout 出现 `🔴 牌面污染自检未过：Full Prompt 过短 NNN 字符`
> 或任一 `牌面污染自检未过`，**而 6 件套自检通过**（`✅ 6 件套自检通过（0 占位符）`）
> = 典型的「只有段9 成品提示词被截断」。
>
> **⚠️ 首选不是手工补**：脚本已在 L1 验收口自动自愈（`SEG9_MIN` 专项校验 → 只重跑段9 → 仍不合格才回滚）。
> 所以**你看到本 SOP = 自愈已经试过一轮都失败了**。此时手工补段9 是**最后手段**，不是常规步骤。

## -1. 先看 stdout 有没有自愈日志（决定走哪条路）

| stdout 出现 | 含义 | 走哪条 |
|---|---|---|
| `✅ 第 9 段长度自检通过：NNNN 字符` | 自愈成功，**没滚** | **正常继续**，本 SOP 不用走 |
| `🔄 专修第 9 段` + `✅ 第 9 段专修成功` | 自愈成功 | 正常继续 |
| `🔴 牌面污染自检未过：Full Prompt 过短` | 自愈也失败，已回滚 | **本 SOP 剩下的步骤** |

## 0. 先确认是「只丢段9」还是「整份脏了」

| 观察 | 结论 | 走哪条 |
|---|---|---|
| 6 件套 ✅ + 段9 过短 | 只有段9 丢了 | **本 SOP**：手工补段9 |
| 6 件套 ❌（占位符 / 中文泄漏 / 元素编造）| 整份脏 | 重跑 agnes（先等 30s 冷却）|
| 段9 里有中文或思考块泄漏 | 解析没认出来 | 重跑（这是排版变体问题，不是长度问题）|
| 回读不到记录号 | 可能查错库了 | **先钉路径**（下面第 1 步），别急着补 |

## 1. 钉死库路径（禁猜）

```bash
grep -n 'REF_LIB=' ~/.hermes/bin/yuer-wash-and-archive.sh
F=~/.hermes/skills/creative/yuer-image/references/提示词库-nsfw.txt
grep -oE "记录 [0-9]+" "$F" | tail -2
```

**为什么要钉**：`/path/to/data/hermes-skills-backup/` 下有同名副本且内容旧，在副本上 grep 得到 0 会误判「没进库」→ 补一遍 → **重号**。

## 2. 读 agnes 留底全文

```bash
ls -t /path/to/media/agnes_*<basename>*.md | head -1
```

1-8 段（6 件套 + 角色外观 + 骚姿势标注）**通常都是好的，只用重写第 9 段**。

## 3. 写段9 的硬性要求

- 纯英文，**400-650 词**（实测 <1200 字符基本必被判过短）
- **逐项展开，不许一句概述收尾**：表情与眼神 → 场景环境 → 服饰材质与细节 → 身体姿势与承重 → 手部动作 → 光线与阴影 → 氛围 → 镜头与景深 → 画质规格
  （**agnes 偷懒的典型长相就是 6 件套写满、到段9 只给一句概述**）
- 开头必须是 `a 20 years old young Asian woman with a <表情>.`
- 结尾必须是 `Shot on a Canon EOS R3, 85mm f/1.2, 1/1000s ISO 500, hyper-realistic cinematic photography, 8K ultra-HD ultra-sharp clarity, no text, no watermark, no logo.`
- **不重复角色介绍句**（只写画面 / 服饰 / 姿势 / 光线 / 氛围）
- **1-8 段里每一条都要在段9 找得到对应**（自检按这个比对，漏了会被当污染）

## 4. 追加记录（照抄上一条的表格结构）

```bash
awk '/记录 <上一条号>/{f=1} f{print}' "$F" | head -25   # 照它的字段顺序写
cp "$F" /tmp/yuer_reflib_bak_$(date +%Y%m%d_%H%M%S).md   # 先备份
```

固定 14 字段：`Scene` / `Camera` / `Pose` / `Wardrobe` / `Lighting` / `Mood` /
`Character Shell`（≤10 关键词、逗号分隔、不是句子）/ `Visual Hook`（主人的榨取冲动）/
`Full Prompt`（段9 全文）/ `Source Lang`= EN / `留底图` / `反推全文` / `来源` / `入库时间`。

**`来源` 字段必须留痕**：`主人飞书发图（<basename>）· 反推来源：agnes-3.0-flash（段9 手工补齐，自检回滚后人工修复）`。
不写 = 后来的会话会以为这条是正常反推的，重复处理 = 重号。

**表格行里的段9**：先用 `re.sub(r'\s+', ' ', seg9)` 压成单空格，否则换行会把 Markdown 表格拆断。

## 5. 四条验证（全过才算入库成功）

```bash
grep -c "记录 <新号>" "$F"                                  # = 1
grep -oE "记录 [0-9]+" "$F" | tail -2                       # 末两条 = N-1, N 且**连续**
awk '/记录 <新号>/,0' "$F" | grep "Full Prompt" | wc -c       # > 1200
awk '/记录 <新号>/,0' "$F" | grep -cE "占位|TODO|待补|\{\{"   # = 0
```

**记录号 = 上一条真实最大号 + 1**（先 `tail -1` 拿，别凭印象、别用看板数字）。

| 6 件套是脏的还手工补 | 6 件套脏 = 重跑 agnes |

# 社交平台视频帖 → 抽帧 → 反推 → 洗图直出

> **🔴 只走 0-D2（主人明说「看看 / 洗图 / 反推 / 拆帧 / 出一张」才进本档）**。主人只说「下载 / 存 / 收藏 / 不用看 / 留着」= 0-D1 只下载道 = **一条命令就停**（`python3 ~/.hermes/skills/social-media/xitter/scripts/x_video_dl.py <url> [留底名]` = 走 fxtwitter→vxtwitter→fixupx 三个公开镜像拿 mp4 直链 + 存 `/path/to/media/` = 0 抽帧 0 反推 0 洗图 0 看内容）。**自动把 0-D1 升级成本档的抽帧洗图流 = 越权加戏 = 11-10 当场被打脸。**

## 唯一职责

主人发来一条**视频帖**链接（不是图片）= **一条视频 = 多个候选参考图** = 洗图道的抽帧变体。
**和图片帖的区别**：图片帖 = 1 张参考图 = 洗 1 张；视频帖 = N 个候选 = **先抽帧挑构图，再各洗各的**。

## 判定

链接形如 `x.com/<user>/status/<id>` / `twitter.com/...` = 视频帖（可能也含图）。
**先看链接 = 再选路**：本路径**不撞反爬** = 有公开 API 直接吐媒体直链 = **不需要主人复制直链**。

## 五步 SOP

### ① 拿帖元数据 + 媒体直链

X 本体对 `web_extract` 必空（需要 JS）= **0 在 x.com 死磕** = 用公开元数据 API：

```bash
curl -s --max-time 25 "https://api.fxtwitter.com/status/<id>" -o /tmp/x_post.json
```

返回 JSON 里要三样：
- `tweet.text` = 帖文正文（= 主人这条视频在讲什么 = 洗图主题线索）
- `tweet.media.all[].url` = **mp4 直链**（`video.twimg.com/amplify_video/...mp4`）
- `tweet.media.all[].thumbnail_url` = 封面图直链

**多个 formats = 挑一条最高分辨率的 mp4**（`avc1/720x1280/...` 优先于 `320x568`）。

### ② 下视频 + 验

```bash
curl -sL --max-time 90 -o /tmp/yuer_x_video.mp4 "<media.url>"
ffprobe -v error -show_entries format=duration,size -show_entries stream=width,height,codec_name \
  -of default=noprint_wrappers=1 /tmp/yuer_x_video.mp4
```

**验 duration + 分辨率 + 码流**，拿不到就重下（重下 = 同一条命令，**0 改参数**）。

### ③ 抽帧

```bash
mkdir -p /tmp/yuer_x_frames
ffmpeg -v error -i /tmp/yuer_x_video.mp4 -vf "fps=1/2.5,scale=720:-1" /tmp/yuer_x_frames/f_%02d.jpg
```

**fps=1/2.5 = 每 2.5 秒一帧** = 20s 视频 ≈ 8 帧 = 足够挑出不同构图。
**帧号 = 构图编号** = 洗图留底名带帧号（`<主题>_f03`）= 事后知道哪张来自哪帧。

### ④ 逐帧反推 = 用来**挑帧**（不是拿来喂 prompt）

```bash
python3 ~/.hermes/skills/yuer-agnes-reverse/scripts/yuer_agnes_reverse.py \
  /tmp/yuer_x_frames/f_01.jpg --max-tokens 900
```

**🔴 露点越狠的帧 = 被安全过滤拦得越死 = 这是正常的**（实测一批 8 帧里拦了 4 帧）。
**判据 = 拦了就换下一帧，不是换措辞重试** = 同帧重试 = 同一张被拒 = 白烧。
被拦的帧往往正是构图最好的那几张 = 所以**要抽够帧**（8 帧起）才挑得出。

**反推文本的两个用途**：
1. **挑帧** = 看 8 段里的「机位角度 / 人物姿势」= 挑出构图最完整、主体最清楚的那几帧
2. **写 caption** = 「骚姿势标注」那段 = 主人看了会硬的那句 = 洗图时挂上去

**🔴 反推文本 0 当 prompt 用** = 洗图直出 = 工作流自己构图 = 我 0 控制 = 反推只做上面两件事。

### ⑤ 挑中的帧各洗各的

```python
import sys; sys.path.insert(0, '~/.hermes/skills/creative/yuer-image/scripts')
from yuer_reverse_inference import run
run('/tmp/yuer_x_frames/f_01.jpg', 'yuer_<主题>_1110_2330', caption='<骚话>')
```

**一帧 = 一次 run = 一张图 = 一次真发** = `run` 内置 `yuer_send_v2.sh` 发飞书 + 返回空串 = **0 再取 result 发图**（双发 bug）。

**🔴 挑帧 = 挑不同构图，不是同一构图洗三遍** = 帧号之间要是**机位/场景/动作**有差别的那种（床 vs 沙发 vs 手部特写）= 三张同构图 = 主人手机收三张几乎一样的 = 白洗。

## 撞车反例硬表

| ❌ 撞车模式 | ✅ 正解 |
|---|---|
| ❌ `web_extract` 拿 x.com = 空 = 反复换 URL 试 | ✅ 直接走公开元数据 API = 一次拿到 mp4 直链 |
| ❌ 抽帧只抽 1 帧就开洗 | ✅ 抽 8 帧起 = 露点帧被拦率高 = 帧不够 = 挑不出好构图 |
| ❌ 帧被拦 = 改 brief/改措辞重试同帧 | ✅ 换下一帧 = 换帧不换档 |
| ❌ 反推的 8 段直接翻成英文 prompt 喂出图道 | ✅ 洗图直出 = 工作流构图 = 反推只挑帧 + 写 caption |
| ❌ 一帧 = 一次 run = 主人手机收 3 张几乎一样的 | ✅ 挑 3 个**构图不同**的帧 |
| ❌ `run` 返回后又把 result 拼进 reply | ✅ 返回空串 = 已真发 = 0 再发 |
| ❌ 留底名不带帧号 | ✅ 带帧号 = 事后知道哪张来自哪帧 |

## 与图片帖的差别（一句话）

**图片帖 = 1 张参考图 = 洗 1 张。视频帖 = N 帧候选 = 挑构图不同的几张各洗各的 = 主人一次拿到几种角度。**

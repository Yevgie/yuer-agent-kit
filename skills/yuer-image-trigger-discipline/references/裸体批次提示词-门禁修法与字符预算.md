# 裸体 / NSFW 批次提示词 = 门禁修法 + 字符预算

> 归属 = `yuer-image-trigger-discipline`（出图路由）· 提示词写法真源 = `yuer-prompt-writer` · 身材锚真源 = `creative/yuer-image/references/铁律/02-身材特征档.md`
>
> 适用 = 提示词道交付（§3.15）+ 诱惑专线批量出图 = **裸体 / 半裸 / 走光高端**这一类 prompt 的两个高频卡点。

## 一 · 裸体图的五道门禁 FAIL/WARN = 固定修法表

裸体 prompt 天然缺东西（没衣服 = 没下装词 / 忘写发型 / 忘写妆容 / 光脚）= 每张都踩同一批 = **修法是固定的，不许现编**。

| 门禁报什么 | 修法 | 写错的后果 |
|---|---|---|
| **FAIL 缺「下装」** | 加一件**画外实物**：`a discarded pair of white cotton briefs on the wooden bench behind her` / `a discarded light blue denim skirt and sheer black tights crumpled on the floor beside the bed` | 写成她穿着 = 底模真给她穿上 = 直接毁图 |
| **FAIL 缺「下装」（裸体/半裸图）** | 同上，但**画外下装不限于内裤** = 任意衣物都算（`a discarded grey pleated skirt crumpled on the floor at the edge of the frame` / `a discarded denim shorts lying on the wet tile floor beside the drain`）= 门禁只认**下装正则命中**（skirt/shorts/pants/dress/…）= 0 只能写 briefs | 同上 |
| **WARN 缺「发型/刘海」** | 发色后补一个短语：`straight with blunt bangs` / `tied in a loose low ponytail` | 锁脸松 = 下一张脸就漂了 |
| **WARN 缺「妆容」** | 补一句短锚：`heavy black waterproof mascara, a soft coral tint on her lips` | 同上 |
| **WARN 缺「鞋履」** | 场景自带赤脚（浴室 / 泳池 / 床上）= 写 `she is barefoot` | 写 `no shoes` = 否定式 = 底模照着画 |
| **WARN 缺「公共场所锚定」** | **直接忽略** | 主人没要求公共场所 = 为过它改场景 = 违背原意 |
| **WARN 缺「穿着方式/内层」** | 单件上装画面（泳衣 / 围裙 / 衬衫）= 服装句里塞一个下装词 `black lace briefs` = 一词过两项 | 反复补长句 = 白烧字符预算 |

**🔴 机械门**：`grep -oE 'nipple|areola' <prompt>` = 命中且**她穿着衣服** = 必删（穿模）；命中且**她裸胸** = 保留（粉嫩锚）。

## 二 · 字符预算：裸体 prompt 天生长 = 删整句的优先级

裸体 prompt 带**身体段（带乳头锚）+ 私处三锚 + 表情组** = 天然在 3200 天花板上下。超了按这个顺序删**整句**（❌ 逐词删 = 改出病句）：

| 顺序 | 删什么 | 为什么可删 |
|---|---|---|
| 1 | 尾参 / 氛围整句（`unposed, grain` / `film grain` / `available light` 的定语）| 纯冗余，不影响画面主体 |
| 2 | 背景人整句细节（`a printer and a stack of folders sit on the middle desk`）| 已有浅景深兜底 |
| 3 | 形容词团（`broad soft rectangle of` → `rectangle of`）| 换更短的等价说法 |
| ⛔ | **光位 / 构图站位 / 裁切线 / 承重面 / 下装锚 / 私处三锚 / 乳头锚** | 删了直接崩 = 崩姿势、崩造型锚、崩穿模 |

**🔴 删完必重跑一次门禁 + 回读** = 只改文件不重跑 = 手里那张还是旧的 = 拿旧稿报新参数 = 假账。

**🔴 超长的省时修法 = 一次 `execute_code` 批量 replace 删整句 = 0 逐字 patch 十轮。**
写法 = 一串 `assert a in s; s = s.replace(a, b)` 打包在一个 execute_code 里 = 一次调用删 5~8 句 = 3~5 次定位删完。**❌ 逐句 patch = 一句一往返 = 烧时间；❌ 整篇重写 = 画面被改没。**
**🔴 别用 `grep -c` 数锚出现次数**（数的是行数）= 用 `grep -o '<锚>' | wc -l`。

## 三 · 一批 N 张的落盘与跑法（三段式）

```
1. 一次 execute_code 写 N 段 prompt 全部落盘 /tmp/<batch>/prompt_<n>.txt
2. 一次 terminal 循环跑三道门禁 → 打印每张字符数 + FAIL/WARN
3. 修完那几张 → 一次 terminal 串完 N 张 wrapper（每张一个 leave_name = 一次真发）
4. cp N 份 prompt 到 /path/to/media/<日期>_<batch>_<n>.prompt.txt
```

**🔴 为什么第 2 步不能省**：边跑边修 = 修到第 3 张才发现超长 = 前面 2 张已经白发给主人 = 主人手机收到 2 张 + 一句「还在调」= 图文两截。

**🔴 提示词道（§3.15）= 只跑第 1~2 步 + 把原文贴进聊天窗口 = 第 3~4 步全部不做**。

## 四 · 一批 N 张 = 五个维度都要不同

| 维度 | 判据 |
|---|---|
| 场景类型 | 公共场所 / 私密场所 各占几 = 混着来 |
| 唯一亮部 | 每张一个 = 同亮部 = 画面同质 |
| 景别 | 至少覆盖 3 种（中景 / 三分之二 / 全身）|
| 姿态 / 主动作动词 | 撩 / 扯 / 蹬 / 抬 / 跪 = 不重复 |
| 勾法（看哪儿）| 小骚穴 / 胸 / 臀 / 腿 / 整体 = 按主人亲排的优先级排（骚穴 > 胸 > 臀 > 腿 > 脚 > 脸）|

**🔴 一批里不是每张都写全身身体段** = 单图单部位 = 只给画幅里拍到的部位写描述 = 全写 = 全抢戏。

## 八 · 🔴 主人说「提示词写不好就写短一点」= 换短版骨架重写 = 0 逐词删（实测有效）

**主人原话**：「**提示词写不好就写短一点**」= 这不是要「把长的削短」= 是要**换一套更短的写法重新写一遍**。

**机制**：CLIP 的注意力预算有限 = 长 prompt 里成串的定语从句（`the darker damp center visible in the lamp light with wet shine along the entrance` / `natural pores and flyaway hair, visible seams and woven fibers` / `restrained highlights, plausible hands and contact shadows`）互相抢注意力 = 画面里该有的东西反而糊。**短版 = 每个语义只留一个最短载体 = 底模读得完 = 画面更干净。**

**实测（同一批 5 张 POV 做爱 · 长版 → 短版）**：

| 版本 | 字符数区间 | 采样 | 主人验收 |
|---|---|---|---|
| 长版（每段 6~7 句 + 大量定语从句）| 1656~1844 | 12.0~12.1s | 「提示词写不好」|
| **短版（每段 5~6 句 + 定语从句全删）** | **1025~1224** | **10.6~12.1s** | 出图正常，**画质没掉，采样还快了两秒** |

**🔴 短版 = 真的重写，不是逐词删**（逐词删 = 改出病句 = 定语从句残缺 = 底模读到半截 = 更糟）。**正解 = 拿同一套骨架，每个语义位只写最短的等价说法**。

### 8.2 短版 = 删掉哪几类东西（不是逐词删 = 删整类）

| 删整类 | 长版长什么样 | 短版替代 |

## 3.8b 🔴 门禁的展示段必须跟判定段用同一套分级 = 不然门禁会骗我（11-04 双人图实测）

**🔴 真洞 = 判定早就按景别分级了，展示段还按「正则没命中就打 FAIL」**：胸像稿明明判定为「跳过下装」（rc=0 = 能出图），打印出来却是 `FAIL 下装` = **看起来必须补画外的内裤** = 我真的去补了 = 底模照着画 = 裁切线滑到桌下，腿跑出来。

- **机制 = 判定段（`_grade` + 豁免函数）和展示段（打印循环）是两段代码** = 改了一段忘了另一段 = 门禁输出成了假账。
- **🔴 正解 = 展示段查「这一项最终有没有进 fails/warns」= 判定和展示 = 同一套逻辑的两个出口**（景别分级 + barefoot / 脚出画豁免全部共用）。画不到的项目显示「跳过」而不是 FAIL。
- **🔴 判据 = 门禁 stdout 出现 FAIL，必须核对 rc 是不是 0**；rc=0 而 stdout 打 FAIL = 展示段骗人 = **0 照着 FAIL 去补词**（补了就等于往 prompt 里写画外的东西 = 景别崩）。**🔴 11-07 已修 = 这种不一致已归零（300 份真产物实测 0 份）= 现在看到 FAIL 行基本就是真 FAIL = 但退出码仍是唯一契约。**

**🔴 景别判定必须认「否定式画外声明」**（`nothing below X is in view` / `only ... are visible`）：门禁只认「画到哪儿」不认「哪里不入画」= 我写了正确声明它当没看见 = 判成全身 = 逼我补画外的下装。

```

the bottom edge of the frame resting on the near edge of the marble tabletop
```

**🔴 强弱阶梯 = 肯定物理边界句 > 否定式声明 > 景别术语（无效）** = 完整实测表 = `yuer-pose-diversity/references/组合描述与畸形诊断.md` §五之二。

**🔴 画外描述检测（写了画外的内裤/丝袜/鞋/腿 = FAIL）只能靠边界句触发**：景别术语底模根本不吃 = 那是我自己写的字 = 拿它当拦人依据 = 会误杀历史真稿（实测一次误杀 12 张）。**门槛 = 边界句判出景别才开画外检测** = 术语词判出来的景别只降级显示、不触发拦截。

## 3.8c 🔴 「单人物」FAIL 的真凶是量词不是人

**单人稿被判多人 = 先查量词，别去开 `--allow-multi`**（开了等于绕门禁，画面里真的会长出第二个人的位置）。

| 命中词 | 为什么被判多人 | 单人稿改写 |
|---|---|---|
| `a pair of ...` | `pair` 在多人词表里 | `a pair of black lace briefs` → `black lace briefs` |
| `both of them` / `the two of ...` | 显式两人指代 | 分开写她的动作（`her palms flat on his chest` / `her back arched`），不写「两人」 |
| **`two girls` / `two students` / `a couple of ...`** | **数字量词 = 多人** | **背景人必须写成「单数 + 他在干什么」逐句排**：`a girl laughing at the next table, a boy queuing at the counter, a staff member wiping a bench` |
| `both hands` / `both knees` | 安全 | 保留，不触发 |

**🔴 背景人 0 带数字 = 公共场景最容易自己把自己拦死的一条**：教室/食堂/图书馆必须写背景人（不写 = 底模给空棚），但一写 `two girls in the background` 就命中单人物 = 要么背景空、要么门禁挂。**正解 = 每个背景人单独一句、只给单数名词和一件手上的事**，三个人三件事 = 背景不空 + 门禁不挂。

**判据 = `check_prompt_subject.py` 打 `主体 = 别人` 或 `check_outfit_lock.py` 打 `FAIL 单人物` 时，先 grep 稿子里的 `pair of` / `both of` / `two `，改完再跑。** 顺带：门禁展示段会把某项印成 `FAIL` 而 rc 仍为 0（判定段已按景别豁免）= **`grep -c FAIL` 不是判据，退出码才是**。

**🔴 另外三类高频 FAIL 的定点改法（0 重写 prompt）**：`stockings`/`pantyhose` **不算下装**（会画成光腿）= 必须另给 `briefs`/`skirt`/`shorts`/`bikini`；**🔴 11-07 已修 = `she is barefoot` / `bare feet` 现在 BOTH 清 WARN 和 FAIL = 写了赤脚还被报鞋履 FAIL = 那不是脚本没生效 = 是真的漏了鞋 = 补鞋或加 `her feet out of frame`**；`<35mm + 距离≤1m` 会撞「人体广角近距」= 焦段提到 `35mm` 以上、或距离拉到 `1.5m` 以上，保留广角就写贴地仰拍豁免句。完整对照表 = `creative/yuer-image/references/门禁高频FAIL与成品牌改刀.md`。

## 3.9 🔴 长度门禁 = 落笔前就少写 + 拦下就改 prompt，0 改门禁

**上限以 `count_prompt_chars.py` / wrapper stdout 当轮打的那行为准**（结构门槛 = 5 大结构段命中 ≥3 + 姿势自然度 = 脚本口径）**= 0 在本文件里写死历史值**
（天花板是配置项，会随配置改；拿旧数当目标 = 要么白写被拦、要么不敢写够把画面写瘦）。**目标 = 当轮上限的 70~80%。**

**🔴 长度 0 阻断 = 参考带长度本身不再拦 = 0 因为超字回头改稿 = 不必贴上限写 = 也不必删。** 真嫌长 = 删整句不挖词 = **只在真嫌长时**用；**❌ 不许逐词删**（挖词改出病句）。

**🔴 减法 = 写作原则 = 写的时候就少写**，不是写完再删整句。真因 = 我写的时候就把「防御句 / 身材堆料 / 重复同义描述 / 负向词」全塞进去了 = 落笔时就该不写。

**落笔前每维过一道「要不要」**（判据 = 画面里看得见吗 / 有没有第二份同义描述）：
- 负向词（no / not / without / never / avoid / lacking）= **一个都不许写** = CLIP 没有否定语义 = 负向词 = 反向提示词
- 身材 = **一条腿锚 + 一条腰臀句 = 全部**（`her legs are longer than her torso reaching up to her chest` + `Her waist is very slim and narrow, her hips are wide, her breasts are large (92cm) and sit high and firm on her chest`）
- 光 = 一处（唯一光源 + 落点 + 一句质感）· 场景 = 前景一件 + 远景两三件 · 表情 = 命中 3 项物理量即止

**标尺 = 参考库 1313 条成品提示词 = 中位 1087 字**（主人认可的样本量级）。

```
写完 prompt
  → 直接跑 wrapper（🔴 长度 0 阻断 = 超了也照样出图 = 0 回读 0 重写 = 0 手工体检）
```

```bash
/usr/bin/python3 ~/.hermes/skills/creative/yuer-image/scripts/count_prompt_chars.py <prompt 文件>
```

**🔴 真嫌长才删 = 优先删第 6 句的可删项**（灯罩反光 / 远景软焦 / 零碎材质 / 景深堆词），**时空机位动作人脸 5 句不动**要的东西
（真要删 = 把 §2.1 里那句氛围/装饰细节整句拿掉）。**超长的真因通常是「多加了一句」不是「写得太细」** —— 先找哪句是多余的，通常一眼能找到。

**🔴 改完重跑一次真出图**：只改文件不重跑 = 手里那张仍是旧的 = 拿旧图报新参数 = 假账。
**🔴 拦下就改 prompt，❌ 不许改门禁阈值**（主人已经判过：提高门禁不会提高质量，只会让它来回重做）。

**两道的门禁不一样**（同一个脚本，去掉 `--report-only` 才是硬门禁）：

| 道 | 拦什么 | 入口 |
|---|---|---|
| **出图道**（看/出图/换场景） | **硬拦 = exit 1 不出图**（结构段命中 <3 / 姿势自然度 FAIL / 超脚本硬顶 = **参考带长度 0 拦**）| `yuer_ka_fast.sh <prompt> <leave>` |
| **抽卡道** | **只报数不拦，照出** | `yuer_ka_fast.sh <prompt> <leave> --report-only` |

**🔴 抽卡道的成品提示词常在 600~800 字符** = 出图道会提示「偏短」但**不是错** = ❌ 不许为了凑 800 给抽到的牌面加料（那会破坏「原样喂」）。

### 3.9b 🔴 主人说「提示词写不好就写短一点」= 换短版骨架重写 = 0 逐词删（实测有效）

**主人原话**：「**提示词写不好就写短一点**」= 这不是「把长的削短」= 是要**换一套更短的写法重新写一遍**。

**机制**：CLIP 注意力预算有限 = 长 prompt 里成串的定语从句（材质堆词 / 同义修饰 / 重复阴影描写）互相抢注意力 = 该有的东西反而糊。**短版 = 每个语义只留一个最短载体 = 底模读得完 = 画面更干净。**

**实测（同一批 5 张 POV · 长版 → 短版）**：长版 1656~1844 字 / 采样 12.0~12.1s → 短版 **1025~1224 字 / 采样 10.6~12.1s** = **画质没掉，采样还快了两秒**。

**🔴 正解 = 拿同一套骨架重写，0 逐词删**（逐词删 = 改出病句 = 定语从句残缺 = 更糟）。三步：

1. 保留骨架顺序（相机 → 她 → 她的穿什么 → 妆容/他的肢体/性器锚 → 私处三锚 → 表情+道具 → 尾参）。
2. **删整类** = 材质堆词句 / 同义定语从句 / 重复阴影描写 / 摄影冗余项（`kept in the natural proportions of the lens` / `anatomically coherent hands and limbs`）。**❌ 0 挖词 0 改病句。**
3. **三条硬约束省不掉** = 私处三锚（`innie pussy` + `smooth and bare` + `vertical seam`）· 画外实物下装（照样会被「下装」门禁 FAIL）· 光位 + 唯一亮部。

**🔴 短版写完验两件事**：① 三道门禁全过（FAIL 0）② **采样时间没变长**（长版更慢 = 说明还是词多）。**主人说「写不好」的正解回话 = 直接重写短版重出 = 0 解释。**

# 诱惑批次场景池 · 五种空间与部位配比

> **主档 = `../SKILL.md`**（判据句在那）。本档 = 现成场景 + 唯一亮部 + 关键道具 + 相机前缀。
> **🔴 一批 5 张的场景必须跨「空间类型」= 0 全在室内**。

| 空间类型 | 现成场景 | 唯一亮部 | 关键道具 |
|---|---|---|---|
| 室内·私密 | 主卧床边落地窗前 | 窗光一道斜切 | 半掩的纱帘 |
| 室外·开放 | 天台栏杆边 | 暮色天光 | 晾着的白衬衫 |
| 公共人流 | 街角便利店冷柜旁 | 冷柜白光 | 玻璃反射 |
| 半私密 | 酒店浴室磨砂玻璃后 | 磨砂透光 | 洗手台雾气 |
| 水边 | 泳池边石阶 | 水面反光 | 漂浮的泳圈 |

**判据 = 这 5 张的【时空 / 服装 / 光源 / 机位 / 风格档】是不是全不一样**。5 张同主题换景别 = 不是「放权」= 是凑数。同一空间出两张 = 第三张开始划走。

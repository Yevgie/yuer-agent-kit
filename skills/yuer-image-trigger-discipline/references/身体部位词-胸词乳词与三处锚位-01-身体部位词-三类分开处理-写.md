# 身体部位词 = 三类分开处理（写 prompt 时的机械门）

> 真值在 `creative/yuer-image/references/铁律/02-身材特征档.md`（**v1.5**）。本档 = **写 prompt 时怎么用 + 机械门**，不重复参数。

## 〇、🔴 参数只住一份 = 其它技能 0 转抄

**真值 = `creative/yuer-image/references/铁律/02-身材特征档.md`（**v1.5**）= 唯一真理来源。**

`yuer-prompt-writer` / `yuer-image` / `yuer-camera-composition-style` 里的身材锚 **一律只指回那份**，**不各自抄一份参数**。

**机制**：参数被抄到多处 = 改了一处忘了另一处 = 两个来源必有一个是旧的 = 出图时不知道听谁的 = **主人要的是“之前记录的更新一下，不要重复了，不要矛盾”**。

**🔴 改身材参数 = 三步**：
```
1. 改 02-身材特征档.md（真值）
2. 扫全库 = grep 'head-lengths|B-cup|petite natural|small bust' 各技能 = 0 残留旧值
3. 改完 = 读回真值 = 0 凭印象说“同步好了”
```

**🔴 禁词表必须分两栏**（否则新旧规则自相矛盾）：
- **形状畸变类 = 禁**（`wasp waist` / `bubble butt` / `curvaceous figure` / `exaggerated curves` / `endless legs` / `hyper-defined` / `huge ass` / `big ass` / `plump rounded buttocks` / `voluptuous`）
- **尺寸类 = 解禁**（`full and firm` / `plump and rounded` / `large breasts` / `heavy bust` / `deep cleavage` / `high lifted`）= 主人钦定要的就是大
- **低垂形态类 = 禁**（`resting low and heavy` / `sagging` / `drooping` / `pendulous`）= 大 ≠ 垂 = 两个独立维度：体积解禁，形态必须紧翘
- **肥臀粗腿类 = 禁**（`thick thighs` / `heavy thighs` / `bulging thighs` / `chunky legs`）= 臀的体积会被摊到大腿 = 腰臀比崩 = 蜜桃感变臃肿
- **旧路线词 = 见到即删**（`hemispherical B-cup` / `petite natural breasts` / `small bust size matching slim physique`）= 与新钦定直接矛盾

**为什么禁词表要分两栏**：旧规则禁 `full and firm` 是因为当时嫌胸大 = 新钦定要大胸 = **同一句禁词表在不同时期含义相反** = 不分类就会在改参数时把新规则一起禁掉。

## 一、三类词 = 三种待遇

| 类别 | 词 | 穿衣服/泳衣 | 裸胸/走光/特写 |
|---|---|---|---|
| **① 体积词** | `bust` / `breast` / `cleavage` / `sitting high and firm` | ✅ **保留** | ✅ 保留 |
| **② 乳头词** | `nipple` / `areola` / 粉嫩颜色锚 | ❌ **必删** | ✅ 保留 |
| **③ 身高比例词** | `head-lengths` / `hip line sitting slightly below` / 防裁句 | ✅ 全身图必带 | ✅ 全身图必带 |

**机制（为什么这样分）**：

- ② = **直接给底模的「画乳头」指令** = 穿着衣服也照样在衣服底下画出来 = **穿模**。底模对关键词是字面执行，它不判断“这件衣服遮不遮”。
- ① = **只是体积描述** = 穿着衣服时画不出乳头 = 留着无害 = 而且它就是大胸参数 = **必须留**（删了 = 胸变平 = 违背钦定）。
- ③ = 底模对「年轻女性」的先验 = 中等身高 = 不给比例尺 = 出来就是矮 = `tall girl` / `very tall` 这类抽象形容词无效 = 只能写可换算的比例。

## 二、机械门（出图前必跑）

```bash
# ② 乳头词 = 唯一需要查的
grep -oE 'nipple|areola' /tmp/prompt_xxx.txt
# 命中 且 她穿着上衣/泳衣/裙 → 删掉再跑

# 命中 且 她裸胸 → 留

# ③ 比例词 = 查有没写
grep -c 'head-lengths' /tmp/prompt_xxx.txt
# = 0 → 全身图漏了比例锚 → 补
grep -oE 'tall girl|very tall' /tmp/prompt_xxx.txt
# 命中 → 换成比例锚

# ① 体积词 = 不查 = 默认保留
```

## 三、颜色锚的正反两面（粉嫩）

想要粉嫩 = **写「粉嫩」那个词本身 + 一条反向排除**：

```
her areola a pale fresh pink, soft and even and clean all the way across,
deepening only slightly into a rosy pink at the very centre,
the nipple itself a light translucent pink,
the colour clean and youthful and free of any dark pigment
```

**🔴 禁** `deeper` / `darker` / `deep brown` / `more intense` = 等于把颜色交给底模自己挑深色 = 出图近黑 = 主人当场打回。
**🔴 阴影词写冷调环境色**（`cool blue shadow` / `deep teal shade`）= 主体色不被阴影污染。

机械自查：`grep -oE 'deeper|darker|deep brown|more intense' prompt.txt` = 命中而你想粉 = 改掉再跑。

## 四、主人报「穿模」/「太瘦」/「太平」= 改词不重画

| 主人说 | 正解动作 | ❌ |
|---|---|---|
| 乳头穿模 | **同构图同机位同光线，只删 ②** 重出 | 重画一幅新画面 |
| 胸太平 | **加回 ①** 重出 | 换场景换姿势 |
| 出得太矮 | **换 ③ 比例锚 + 焦段拉长拉远 + 防裁句** | 只加 `tall` |
| 部位抢戏（要单看某个部位） | **删掉画面里看不到的部位的描述** | 全写上（底模会堆到画面上） |

**判据 = 主人要能直接对比** = 同构图/同机位/同光线 = 每次只动一类词。

## 五、🔴 三版对照 = 「穿模」的第一反应容易过度纠正

主人说「乳头穿模」时，**最直觉的解法是「把胸部和乳头描述一起删掉」= 过度纠正 = 违背钦定**。三版实测（同一场景/构图/机位/光线，只动词）：

| 版 | ① 胸词 | ② 乳头词 | 结果 |
|---|---|---|---|
| v1 | 有 | 有 | ❌ 穿模 = 泳衣底下画出乳头形状 |
| v2 | **删了** | 删了 | ❌ **胸太平** = 大胸参数没了 = 违背「胸更大」钦定 |
| **v3** | **保留** | **删了** | ✅ 胸还是大胸 + 乳头干净 |

**机制**：穿模的真凶**只是 ②**（= 给底模的「画乳头」指令 = 穿衣也画）= ① = 体积描述 = 穿衣画不出乳头 = 留着无害 = 它还是钦定的大胸参数 = **必须留**。

**🔴 规则** = 主人报「穿模」→ **只删 ②，不许顺手删 ①**。若主人接着说「胸太平了」→ 那是过度纠正的后果 → **把 ① 加回来重出** = 0 重画画面。

**🔴 连带 = 机械门只查 ②**（`grep -oE 'nipple|areola'`）= ① 默认保留 = **不查 ①** = 一查就会自己把自己吓到去删。

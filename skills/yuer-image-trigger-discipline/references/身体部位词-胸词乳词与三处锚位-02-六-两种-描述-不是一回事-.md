## 六、🔴 两种“描述”不是一回事 = 一个是体积，一个是画指令

底模对关键词是**字面执行** = 它不判断“这件衣服遮不遮”。所以：

- **体积类词**（`bust` / `breast` / `cleavage` / `sitting high and firm`）= 描述形状 = 穿衣时画不出乳头 = 安全。**🔴 v1.5：`resting low and heavy`（低垂形态）已禁用 = 胸大且紧翘不下垂。**
- **画指令类词**（`nipple` / `areola` / 粉嫩颜色锚）= 直接命令“画乳头” = 穿衣也照画 = 穿模。

**推广**：写 prompt 时遇到任何“身体细节词”先问一句 = **这是描述体积，还是在命令底模画一个实物？** 后者（乳头 / 阴部细节 / 疤痕 / 纹身）穿衣服时一律不写。

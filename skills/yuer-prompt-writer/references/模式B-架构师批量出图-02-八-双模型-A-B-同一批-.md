## 八 · 双模型 A/B = 同一批 brief 跑两遍

**主人说「一个模型测 N 张」再「测试 N 张 <另一个>」= 他要的是对照** = 同一批 brief、同一批场景，两个模型各跑一遍。

**🔴 同一批 brief 换道 = 只换 `--model` + 只换模板 = brief 一个字不改** = 改了就不是对照了。

**能读出来的东西**（实测同批对比）：

| 维度 | 观察 |
|---|---|
| 镜头解法 | Krea2 偏**系统性**（机身/焦段/距离/机位高度都写死，带曝光语言）；Moss 偏**散点式**（会自己加 brief 没指定的巧思，如自己选镜面反射当构图）|
| 场景细节 | 两边都会长细节，但长出来的不一样 |
| 速度 | 见矩阵 §一 速度列 = **别照抄旧数，跑前先测一张** |

**🔴🔴 对照能读出的真结论 = 两个模型的「脑子」不同 = 不是同一套系统的两种参数**：

实测同一批 5 个 brief（理发店镜面 / 防波堤夜 / 旧书店 / 泳池跳台 / 摩托后座）跑两道：

| | Krea2（英文架构师）| Moss（中文架构师）|
|---|---|---|
| 镜头语言 | 写死机身 + 焦段 + 距离 + 机位高度 + 曝光量词（“about a stop darker”）| 不写机身型号 = 写**机位与场景的关系**（“相机几乎贴着镜面玻璃、略低于镜心向上拍”）|
| 段落重心 | 相机段 → 主角段 → 镜子里的倒影段 → 环境段 | 相机段 → 主角段 → 道具段（锅/油/光斑）→ 环境段 |
| 选镜头 | 偏向**导演式**（站在她身后靠镜轴带出正脸）| 偏向**偷拍式**（贴地仰拍、贴水面仰拍）|
| 速度 | ~16-25s/张 | **~10s/张** = 快一倍以上 |

**判据 = 两道产物**结构上就不是一回事**（Krea2 拆镜子倒影成独立段，Moss 拆锅与光斑成独立段）= 底层是两个不同的世界 = **别把一道的产物结构套到另一道上评**。

**🔴 对照出图 = 两批各 5 张 = 10 张 = 主人的手机要一次收 10 张** = 分开发 = 交错发 = 对照感最强（每个场景两张挨着）。

# 模式 B 执行配方 · 架构师模板批量出图

> **唯一职责 = 模式 B 怎么真跑**。模板正文 = `yuer-krea2-prompt`（英文原文）/ `yuer-moss-prompt`（中文改写版）；本档只管**执行链**。
> 模式 A = 我自己在脑子里按 `yuer-prompt-writer` §1~§10 写稿 = 那条道不用本档。

---

## 一 · 模式 B = 什么，什么时候值得走

模式 B = 把底模作者的架构师模板整段当 system prompt 喂给另一个 LLM，它吐出来的稿**直接出图**。

**判据 = 稿子要不要「另一个脑子」来写**：

| 场景 | 走哪 | 为什么 |
|---|---|---|
| 要跑批（5+ 张）| **模式 B** | 我手写第 5 段会抄第 1 段的句式 = 五张一个味 |
| 要双模型对照 | **模式 B** | 两道各用自己的模板 = 同一批 brief 两种镜头解法 |
| 要试新底模的脾气 | **模式 B** | 作者模板 = 底模作者自己知道怎么喂它 |
| 单张赶时间 | 模式 A | 更快 = 少一层子 agent |

**🔴 模式 B 的产物长度 ≠ 模式 A** = 架构师稿 2500~4000 字符，我手写 900~1300 = **两套标尺**（出处见 `creative/yuer-image/references/模型路由与四工作流能力矩阵.md` §5.5）= **0 拿模式 A 的字数标准去砍模式 B 的稿**。

---

## 二 · 执行链 = 四步

```
1. 写 N 个 brief（每个 = 一个独立场景解）
2. delegate_task 一次派 N 个子 agent（并行）= 每个 agent 读模板 + 写一段稿
3. N 段稿落盘 /tmp/<批次>/n1.txt … nN.txt
4. 串行出图（--model krea2 / --model moss）+ 逐张验语言
```

**第 1 步的 brief 设计 = 整条链的质量上限** = 见 §四。

---

## 三 · delegate_task 的 goal / context 怎么写

**一个子 agent = 一个 brief = 一段稿。** N 张 = N 个 task 放进**同一次** `delegate_task` 调用 = 并行跑。

### goal = 四件事，一步不缺

```
你是图像提示词架构师。读一份 system prompt，然后按它的规则写出一段完整的<语言>出图提示词。

步骤：
1. 用 read_file 读取 <模板绝对路径> —— 这是你的 system prompt，必须严格按它的结构、顺序和规则来写。
2. 用户 brief 是：<brief 原文>
3. 按 system prompt 的规则写出最终<语言>提示词。<该道的额外硬约束>

输出要求：只输出最终<语言>提示词正文本身，不要任何标题、不要解释、不要 markdown 围栏、不要前后缀说明。长度 <N 词>。

重要：只允许用 read_file 读一次模板文件，之后不要调用任何其他工具，不要修改任何文件，不要跑命令。你只负责产出这段提示词文本。
```

### context = 模板路径 + 该道的硬约束 + 场景要求

context 里**必须**写的三样：

1. **模板绝对路径**（子 agent 自己 read_file = 0 把 377 行正文塞进我的上下文）
2. **该道的硬约束**（见 §五）
3. **「一批图每张要换可信的不同场景解，不是只换形容词/色盘/衣服」** = 作者模板第 29 条 = 0 让五张长成一个样

**🔴 子 agent 只准调一次工具 = read_file**

**实测踩坑 = 子 agent 会反复调 `execute_code` 去数字数**（tool_trace 里十几次）= 纯浪费。

**正解 = goal 里写死「只用 read_file 读一次模板，之后不要调用任何其他工具」**：

```
重要：只允许用 read_file 读一次模板文件，之后不要调用任何其他工具，不要修改任何文件，不要跑命令。你只负责产出这段提示词文本。
```

**判据 = 子 agent 的 tool_trace 里只有一次 read_file = 写对了。**

**🔴🔴 但「写死一句」不够 = 篇幅越长的稿子越容易破功**：实测 5 张一批时，读 85 行中文模板的那张只调了 1 次工具，读 377 行英文模板的那张调了 7~15 次（全是 execute_code 数字数/查格式）= **模板越长，子 agent 越觉得自己该「先确认一下」**。

**正解 = 把「长度」从子 agent 的活里拿掉 = 不给它数字数的理由**：goal 里**不写**「长度 400-650 词」这种需要它自己数的指标 = 改成「写成一整段完整的提示词散文，不要分段」= 它就 0 去数字数。

**判据 = tool_trace 里 execute_code 出现 0 次**（不是「少」= 是 0）= 写对了。**工具调用多 = 产物不一定差（实测照样出图）= 但每个子 agent 多 5~15 次调用 = 一批 5 张就多几十次 = 慢 = 白烧**。

## 四 · brief 怎么排 = 五个不同场景解

**🔴 brief = 场景 + 人物 + 时刻 + 唯一亮部 + 一个「不对称」的细节**。不对称的那个细节（价目表边角卷起来 / 灯管末梢发黄 / 她手心搁在混凝土接缝的沙上 / 睫毛上挂着一根散发）= 架构师才会往下长出可信细节 = 给「对称的简介」= 出来就是通用写真。

**🔴 五个 brief = 五个不同场所 / 时段 / 机位 / 亮部** = 不是同一场景的五个姿势。**判据 = 把五个 brief 的「场所」写一行 = 五个字全不同** = 才是批；同一个房间换五种姿势 = 那是套图（走 `yuer-set-images`）。

**🔴 每道出图前先核物理一致性**（brief 里就写清）= 子 agent 的任务是写稿不是救稿 = 救不回来。

---

## 五 · 每道要注入的额外硬约束

| 道 | 注入 | 为什么 |
|---|---|---|
| **Krea2** | 「负向词一个都不写 —— 不要加 no text / no watermark / no logo 这类尾巴」| 负向走 `ConditioningZeroOut` = 写了白烧字符（见 `yuer-krea2-prompt` §三适配②）|
| **Moss** | 「绝对不要输出任何坐标、bbox、JSON」| Layout 段已从模板删掉，但模型仍可能想给坐标 |
| **通用** | 「只输出最终提示词正文本身，不要标题/解释/围栏/前后缀」| 见 §六 |

---

## 六 · 子 agent 的输出 = 提示词正文

`delegate_task` 回的是每个 task 的 **summary** 字段 = 子 agent 最后那段文本。

**判据 = summary 直接就是提示词正文**（因为 goal 里说了「只输出正文」）= **直接落盘**。它带了前言/标题/尾巴 = goal 的禁止句没生效 = **手动剥掉再落盘** = 别把 ``` 围栏一起喂进底模。

---

## 七 · 落盘后必验 = 语言占比

出图脚本会把实际用的稿归档成 `<leave_name>.prompt.txt`。

| 道 | 期望 | 判据 |
|---|---|---|
| **Moss** | 中文占比 ≈ 100% | 归档案里中文字数 / 总字符数 |
| **Krea2** | 中文占比 = 0 | 同上 |

**🔴 归档案 ≠ 出图时实际喂的那份** = 归档发生在**翻译之前**（`yuer_ka_fast.sh` 先拷档案、后跑翻译）= 判断「有没有被翻译」要**看 stdout 的「中文已翻译 N 段」那行**，不能只看归档案。

**🔴 走 Moss 道时归档案全中文 = 分流生效的证据** = 中文原生道走白名单跳过翻译（机制见 `creative/yuer-image/references/已知代码坑.md`）。

## 八 · 双模型 A/B = 同一批 brief 跑两遍

**主人说「一个模型测 N 张」再「测试 N 张 <另一个>」= 他要的是对照** = 同一批 brief、同一批场景，两个模型各跑一遍。

**🔴 同一批 brief 换道 = 只换 `--model` + 只换模板 = brief 一个字不改** = 改了就不是对照了。

**能读出来的东西**（实测同批对比）：

| 维度 | 观察 |
|---|---|
| 镜头解法 | Krea2 偏**系统性**（机身/焦段/距离/机位高度都写死，带曝光语言）；Moss 偏**散点式**（会自己加 brief 没指定的巧思，如自己选镜面反射当构图）|
| 场景细节 | 两边都会长细节，但长出来的不一样 |
| 速度 | 见矩阵 §一 速度列 = **别照抄旧数，跑前先测一张** |

**🔴🔴 对照能读出的真结论 = 两个模型的「脑子」不同 = 不是同一套系统的两种参数**：

实测同一批 5 个 brief（理发店镜面 / 防波堤夜 / 旧书店 / 泳池跳台 / 摩托后座）跑两道：

| | Krea2（英文架构师）| Moss（中文架构师）|
|---|---|---|
| 镜头语言 | 写死机身 + 焦段 + 距离 + 机位高度 + 曝光量词（“about a stop darker”）| 不写机身型号 = 写**机位与场景的关系**（“相机几乎贴着镜面玻璃、略低于镜心向上拍”）|
| 段落重心 | 相机段 → 主角段 → 镜子里的倒影段 → 环境段 | 相机段 → 主角段 → 道具段（锅/油/光斑）→ 环境段 |
| 选镜头 | 偏向**导演式**（站在她身后靠镜轴带出正脸）| 偏向**偷拍式**（贴地仰拍、贴水面仰拍）|
| 速度 | ~16-25s/张 | **~10s/张** = 快一倍以上 |

**判据 = 两道产物**结构上就不是一回事**（Krea2 拆镜子倒影成独立段，Moss 拆锅与光斑成独立段）= 底层是两个不同的世界 = **别把一道的产物结构套到另一道上评**。

**🔴 对照出图 = 两批各 5 张 = 10 张 = 主人的手机要一次收 10 张** = 分开发 = 交错发 = 对照感最强（每个场景两张挨着）。

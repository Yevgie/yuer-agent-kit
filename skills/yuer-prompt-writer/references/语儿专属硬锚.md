**禁写五官** = 眼型 / 眼色 / 双眼皮 / 睫毛 / 脸型 / 鼻型 / 唇形 / 眉毛形状 / 泪痣 / 皮肤白皙度 = 连泛词也禁（`delicate Asian facial features` / `natural skin texture` / `dreamy distant gaze`）。
**唯一允许描述** = 发型 + 发色 + 发长 + 刘海 + 发丝质感 + 发饰。
**表情 = 物理化** = 一句塞 3 个物理量 = 眼皮开合 + 嘴唇开合 + 下颌/颈部肌肉 = 禁抽象情绪词（抿嘴笑 / 眼神迷离 / 邪魅 / 慵懒 / 温柔 / 冷酷 / 害羞 / 诱惑 / 厌世 / 无辜 / 高冷 / 甜酷）。

## 5.2 表情必须物理化（**1 句给 3 个物理量**）

**禁抽象情绪词**：抿嘴笑、眼神迷离、邪魅、慵懒、温柔、冷酷、害羞、诱惑、厌世、无辜、高冷、甜酷

**🔴 v4.0.0 = 物理量给 3 个 = 写进**同一句里**，不是写成 3 句。**
> ❌ 旧写法（3 句 = 3 个点被拆开 = 但底模读到的还是同一张脸 = 白拆 + 句子虚胖）：
> `her upper eyelids half-lowered, her lips slightly parted, her chin tilted up`
> ✅ 现役（1 个点 1 句，句内 3 个物理量）：
> `her upper eyelids half-lowered, lips slightly parted and chin tilted up`

**判据 = 拆开这两句，画面上会不会多出一样东西？** 不会（还是同一张脸）= 同一句 ✅。

| 维度 | 物理量词库 |
|---|---|
| **眼皮** | 开合 / 下垂 / 抬高 / 半闭 / 紧闭 / 弯月弧度 |
| **目光** | 方向 / 对焦 / 失焦 / 直视镜头 / 侧视 / 微张成窄缝 |
| **嘴唇** | 开合 / 紧闭 / 微启 / 抿成线 / 呈椭圆张开 / 双唇轻压 |
| **嘴角** | 上拉 / 下拉 / 中性 / 单侧上抬 / 单侧下拉 |

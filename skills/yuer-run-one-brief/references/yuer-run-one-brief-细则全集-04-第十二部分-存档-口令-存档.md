# 第十二部分 · 存档（口令「存档」）

**触发**：主人说「存档」/「agnes 反推存档」。

**0 自动存** = 洗图/反推/收图都**不自动存档** = 只有主人亲口说「存档」才存。

**reply 唯一格式**：
```
🐾 存档成功 · 记录 NNN
```
- ✅ 就这一行（+ 可选 1 句斜体描述）
- ❌ 禁止罗列 6 件套任何字段内容
- ❌ 禁止「✅ 存档成功」变体 = 固定格式不可变
- ❌ 禁止 3 件套清单汇报（「留底 md: ... 留底图: ... 参考库已追加」）
- **记录号 NNN = 必从参考库 grep 现有最大号 +1** = 不手工记
- **存档 reply 不抽骚话库** = 两种模板独立 = 零混用

**agnes 反推元素锁定铁律**：
agnes 只给 6 维度框架不给具体元素 = **会编造图中不存在的元素**（实测把「裸体+护士帽+白袜」反推成「黑比基尼+废弃教室」）。

- ✅ brief 里**直接列出图中全部关键元素** + 写明「严格按这些元素反推，不要添加图中不存在的元素」
- ✅ 第 1 次对不上 = 第 2 次改「关键元素清单 + 严格锁定」= 通常第 2-3 次对上
- ✅ 入库前自检门 = 逐条对照真实元素清单，跑偏 = 重跑
- 🔴 **撞车第 3 次 = 放弃反推，直接用原图描述手工拼记录入库** + 备注撞车（入库价值 = 角色外观 + 骚姿势标注够用 = 不需要反推全文完美）
- ❌ 禁止凭第 1 次跑偏的结果直接入库 = 污染参考库

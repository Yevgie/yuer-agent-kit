# 主题型批次（单主题五瞬间）与批量门禁三坑

> 适用 = 主人说「你自己选一个主题，出 5 张我看看效果」/「再出一个新主题」= **主题型批次**。
> 与「无限勾引批次」是两个形态：**无限勾引 = 广度**（5 个不同时空各 1 张，走时空池抽签）；**主题型 = 深度**（1 个主题的 5 个不同瞬间）。别把主题型写成「同一张图换五个场景词」。

**正解两条**：① `card` 的 `name` 只写 `n1`..`n5`，batch 前缀交给 `emit`；② 主题型批次**逐张自己写整段 prompt**（不经过 card/head），长度按下一节的落点写。
---

## 一、主题怎么选（四条同时成立才落笔）

| # | 判据 | 反例 |
|---|---|---|
| 1 | **一个具体地点 + 一个具体时段** | 「纯欲风」「性感写真」= 抽象氛围 = 出五张同构 |
| 2 | **地点自带 5 个可站/可坐/可倚的承重面** | 只想到一个姿势 = 主题太窄 |
| 3 | **地点自带一个单一光源**（纸灯笼 / 石灯 / 滚筒内胆暖光 / 换币机蓝屏）| 写「柔和光线」= 画面平 |
| 4 | **主题自带一条贯穿道具线**（松掉的腰带 / 湿透的 T 恤），五张由它承接 | 每张换一套衣服 = 散成五张无关图 |

**每张必换【瞬间 / 机位景别 / 唯一亮部 / 风格档 / 服装状态】五样里的至少四样。**
判据 = 把五张的「瞬间」写成一行短语念一遍：有两条读起来是同一件事 = 重排。

**🔴 换景别 = 必须同步换身材锚**（见 §三）= 五张景别不同 = 身体段不同 = **不能一张身体模板套五张**。

**🔴 换景别 = 门禁必跟着放宽**：`check_outfit_lock.py` 的「鞋履」项 = **只在全身景别才查** = 半身/特写 = 跳过 = **0 因为它报了就硬塞一双鞋**（画面里根本没脚 = 塞鞋 = 加噪）。

**收尾报表格式**（主人看的就是这个）：一张表（瞬间 / 机位景别 / 唯一亮部 / 风格 / 耗时）+ 一句下一批主题（只报不跑）+ 1~3 句骚话。不报 leave 名、不报路径、不问「还要吗」。

## 二、逐张手写整段，不套 `card` / `head`


| 毛病 | 机制 | 症状 |
|---|---|---|
| **`head` 丢主体锚** | 主体锚排在最前面 = 后面做字符串裁剪时最容易被当成「最长块」删掉 | `check_prompt_subject.py` 报「稿子年龄 = 未写 / 语儿锚 = False」= rc=1 = 整批不开跑 |
| **`card` 双前缀** | `emit` 落盘名 = `prompt_<batch>_<name>.txt`；若 `name` 已经带了 batch 前缀（`card(BATCH + "_n1", ...)`）= 生成 `prompt_a_a_n1.txt` | `run_batch.sh` 的 glob `prompt_<tag>_n*.txt` 收不到 = 「找不到 prompt 文件 = 0 出图」 |

## 三、长度落点 = 🔴 11-07 起长度 0 阻断 = 不再有硬顶

**🔴 11-04 起 = 2000 只报数；11-07 起 = 唯一硬顶 4000（防失控）= 正常批量稿（1100~1300）离它很远 = 0 因为长度重写。**

**旧文写的「英文硬顶 1300 / 超了 exit 1」= 已作废**（那是 11-04 之前的口径）。**现在判过不过看三道门的 rc，不看字数。**

**🔴 一套标准不一致的老坑（仍成立，但方向变了）**：批量道曾有两套顶（wrapper 1300 / `batch_gate_check.py` 3200）= 过了 batch 门不等于能跑批。**11-07 后两套都不拦长度 = 这坑自动消失 = 但「两套标准」这个机制要记住 = 改任何一道门的阈值前，先确认另外一道不会打架。**

**⚠️ 但「不拦长度」≠「可以堆料」**：一个点写两遍 = CLIP 读成 N 个 = 三只手。同一点 = 只写一次 = 这条跟长度无关。

### 🔴 身材锚 = 按「画幅裁切线」裁，不按字数裁（本节最容易踩）

**机制 = 画幅外的部位锚 = 底模会自己延伸画进来 = 抢戏。** 写半身图里的腿长锚 = 画面里根本没腿 = 模型自己往下延伸画全腿 = 构图毁了。

| 景别 | 必留 | 必删 |
|---|---|---|
| **全身 / 头到膝** | 腿长锚 + 腰臀句 | — |
| **半身（头到胯）** | 腰臀句 + 胸锚 | **腿长锚 / `slender firm thighs` / `long calves`** |
| **特写 / 胸像** | 胸锚 + 妆容锚 | 腿长锚 / 腰臀句 / 臀锚 |

**🔴 五张不同景别 = 五种身材锚 = 不能一张模板套五张**（写批次时把「景别」当第一个变量先把身体锚定死，再写场景）。

**🔴 判定 = 身体锚裁对了没 = 看画幅裁切线，不看字数预算。** 半身稿少写一条腿锚不是偷懒 = 是对的。

### 轻 body 段配方（约 250 字，替掉近 960 字的 COVER 全段）

**🔴 但「轻」≠「删到不全」= 每条必过门还在 = 腿长锚 + 腰臀句 + 胸形态锚 = 缺一条 = 比例差 = 主人当场打回。**

```
slim yet voluptuous hourglass figure, 92-60-92, her legs are longer than her torso, slender firm thighs, her waist very slim, her hips are wide, her breasts are large sitting high and firm, pale skin,
```

960 字的 COVER 全段 + 12 句分镜 = 稳定 1600~2400 字。批量道一律用轻 body，省下的预算给「瞬间 + 光 + 机位」这三个真正决定画面差异的维度。

## 四、裁字保护清单（删错一句 = 整张作废）

**永远不删**：
1. 主体锚 `a 20 years old young Asian woman`（删了主体门禁 rc=1）
2. 身材锚那条腿长句
3. **下装白名单词**
4. **鞋履白名单词**
5. 妆容锚

**删除顺序**：背景陈设 → 装饰性氛围形容词 → 重复的皮肤/材质描述 → 尾部参数堆。

**🔴 裁完必做的两步机械门**（不做 = 一定白跑一轮）：
```bash
python3 scripts/check_prompt_subject.py  /tmp/prompt_<tag>_n1.txt   # → 主体 = 语儿
python3 scripts/check_outfit_lock.py     /tmp/prompt_<tag>_n1.txt   # → 无 FAIL
```

**🔴 按「逗号分隔块」裁的前提 = 块边界要认准**：用 `s.split(", ")` 定位下标删块是安全的；用整段 `replace` 跨多行替换时，锚点里带逗号会把下一段一起吃掉 = 动作句/光句/背景句整段消失 = 语法合法 + 门禁全过 + 图却少了三个维度。
**判据 = 裁完 grep 一句动作短语 + 一句光照短语 + 一句背景短语，三条都还要在文件里。**

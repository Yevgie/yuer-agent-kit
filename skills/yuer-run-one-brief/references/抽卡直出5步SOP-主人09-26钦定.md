### Step 1 · 避号抽签（不让主人撞重复）

```python
import json, os, random

USED_FILE = "/tmp/yuer_used_<YYYY-MM-DD>.json"
if os.path.exists(USED_FILE):
    with open(USED_FILE) as f:
        used = set(json.load(f))
else:
    used = set()

# 从提示词池抽一条（🔴 池格式 = 一行一条 `N|<完整英文提示词>`）
import re
with open("~/.hermes/skills/creative/yuer-image/references/提示词库-nsfw.txt") as f:
    content = f.read()
records = []
for ln in content.split("\n"):
    m = re.match(r"^(\d+)\|(.+)$", ln.strip())
    if m and m.group(2).strip():
        records.append((m.group(1), m.group(2).strip()))

pool = list(range(len(records)))
remaining = [x for x in pool if x not in used]
if not remaining:
    used = set()
    remaining = pool

pick_idx = random.choice(remaining)
used.add(pick_idx)
with open(USED_FILE, "w") as f:
    json.dump(list(used), f)

rec_num, rec_prompt = records[pick_idx]
```

**🔴 池格式 = 一行一条完整英文提示词**（主人钦定）= **0 用旧的 `re.split(r'(?=## 记录 \\d+)')` 切** = 新池里 0 个 `## 记录` = 切出来是空 = 抽卡抽到空 = 静默失败。**池格式规范 = `creative/yuer-image/references/提示词资产池格式规范.md`**

**🔴 路径别自己写 = `from yuer_prompt_pool import PROMPT_POOL, read_pool`**（路径唯一真值 = 改一处漏一处 = 静默读到别的文件）。

**金标准**：
- ✅ 当天一个 `USED_FILE`（按日期区分）= 不污染其他天
- ✅ 抽完全部 = 自动重置 `used = set()` = 再来一轮
- ✅ 0 反问 = 0 选项菜单 = 0 让主人确认
